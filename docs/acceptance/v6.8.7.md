# v6.8.7 安全修复与发布准备

本版承接未公开发布的 6.8.6 全部功能修复，仅额外升级 Electron 安全补丁；
窗口范围仍限单屏，动效仍按用户要求保留默认开启并减弱强度。

## 修复与本地证据

- Electron 精确锁定 42.11.16，包清单及锁文件一致。官方
  [安全通告](https://github.com/electron/electron/security/advisories/GHSA-jr5w-w6x2-84p9)
  说明此版本修复受损中间证书信任问题，没有应用侧绕过方案。
- 从权威锁文件生成的 Electron 运行时依赖闭包通过实时 npm audit，所有级别均为
  零告警，例外为空。这是锁文件预检，不替代 Release 的最终安装包运行时审计。
- `dependency-audit:test` 通过；生产构建、类型及 unpacked 打包通过，打包后的
  二进制实际报告 Electron 42.11.16。最初一次探测早于打包退出，读到旧目录，已排除；
  打包成功退出后重新核对新二进制，不将旧结果冒充修复验证。
- 新运行时在 Windows 原生 175% 缩放、最大界面字号下通过窗口、最大化／还原、
  最小化、紧凑导出和关闭检查；本轮没有启用高对比度，不宣称新增高对比度验收。
- 两项动效默认开启、关闭并重启恢复的原生检查通过。

上述 unpacked 验证发生在将应用版本号改为 6.8.7 之前；证明 Electron 补丁与现有
应用的兼容性，不冒充最终 6.8.7 安装包验证。最终精确提交的完整回归及正式安装包、
下载附件、SBOM、来源证明继续由标准 CI／Release 执行。
