## #247 恢复演练准备

手动 CI 输入 desktop_rehearsal_fail_group 默认为 none，只有 workflow_dispatch＋共享 canary＋首次 attempt＋选中组四项同时满足才产生预期失败。
故障发生在真实制品校验后、场景执行前，不修改制品或产品代码，不把未执行场景标记成功；失败上下文继续保留，聚合必须拒绝通过。
第二次 attempt 不再注入，使操作者可以明确只重跑失败组，验证同 run/SHA/制品下成功组复用。常规 PR/main 不受影响，默认继续旧路径。

后续真实演练（当前尚未执行）：

1. 获准推送候选后，在精确分支发起共享 canary，选择 data 作为 fail-once 组。
2. 等待整轮终止，核对 data 预期失败、editor/native 成功、聚合失败；保留首次报告和制品 ID／摘要。
3. 仅显式重跑 data job（不是整轮），等待依赖聚合重新执行；核对 source SHA、构建 ID／摘要未变、两组旧成功仍属于同轮、data 新 attempt 完整执行。
