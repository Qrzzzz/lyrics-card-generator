# v6.3.4 设置内容整理

状态：本地实现与验收完成，已授权进入发布流程。基于 v6.3.3，分支 `codex/v6.3.4`。

## 边界

统一软件设置与工具内容的布局。全局设置左侧 tab 的结构、样式、动效、键盘交互和导航状态保留；第二步左侧歌词编辑器、左右分栏比例、滚动与选区控制器保留。设置含义、默认值、存储字段和服务请求保持原有语义。

## 界面盘点与处理

| 界面 | 内容类型 | 处理 |
| --- | --- | --- |
| 设置左侧导航及历史导航 | 页面导航 | 保留原实现，不接入设置内容样式 |
| 通用 | 语言选项、交互、历史与恢复 | 语言组按容器宽度排列；历史选项和恢复操作共用字段列线 |
| 外观 | 主题、亚克力、主题色、字体、特效 | 普通设置统一网格；亚克力依附主题，色号依附主题色；保留草稿校验 |
| 卡片与导出默认值 | 页脚开关、署名、格式和质量 | 统一网格；署名输入留在所属开关单元内 |
| AI API 配置 | URL、密钥、模型、连接测试 | 配置字段统一网格；连接测试和反馈独占完整宽度；不改变密钥与请求逻辑 |
| AI 翻译默认值 | 温度、风格、推理 | 统一网格；说明跟随所属选项 |
| AI 提示词资源库 | 预设入口、长文本编辑 | 入口按容器宽度排列；提示词编辑与确认保留独立页面和完整宽度 |
| 关于 | 版本、链接、许可证 | 保留阅读列表，统一点击高度和长标签换行空间 |
| 第一步手动歌曲信息 | 标题、歌手、专辑、封面 | 普通字段统一网格；上传与封面预览保留完整区域 |
| 第二步右侧整理／翻译 | 操作范围、动作、说明、预览 | 保持单列任务顺序，取消范围截断和过小字号，减少动作间重复分隔线 |
| 第二步 AI 翻译 | 风格选项、配置、运行与结果 | 风格按右栏实际宽度排列；保留配置／运行页面切换和取消生命周期 |
| 第 3–5 步 | 参数设置及字体工作区 | 复用既有规范；公共布局入口抽到 UI 层，兼容旧导入路径 |
| 第六步导出 | 格式、质量、进度 | 参数统一网格，进度和阻塞反馈保持整行 |
| 设置确认／历史导入弹窗 | 表单、预览、确认 | 操作按钮可换行；保留焦点约束、确认顺序和导入逻辑 |
| Web Lite | 共享的设置与编辑组件 | 同步生成产物，保留其已有功能边界 |

搜索结果、歌词正文、字体列表、提示词长文本、导出进度不是普通设置格，不强行排列成多列。未增加显示密度开关，也未缩小文字来压缩界面。

## 共用规则

- `components/ui/SettingsLayout.tsx` 提供公共容器与网格；原编辑器路径保留兼容导出。
- 所有普通字段使用同一套 CSS Grid 列宽公式：最小单元 15.5rem、间距 0.75rem、最多三列。实际可用宽度决定列数，不使用页面或步骤专属窗口断点。
- `.settings-content-layout` 仅施加到内容根节点，不能加在包含左侧导航的全局外壳上。
- 标签在控件上方，说明跟随字段；必要文案可以换行。参数控件和主要操作区域以 44px 为最小交互高度。
- 条件字段保持与控制项相邻，使用稳定组件和状态；不因容器宽度变化卸载组件。
- URL、模型、密钥、字体等输入不截断真实值，保留原生输入滚动；不会将密钥输出到验收日志。
- 操作工具保留原有预览、确认与撤销流程；不把动作按钮包装成可持久化设置。

## 验收要求

在本地真实组件与生产应用中核对容器宽度、六语言、条件项、焦点和草稿；检查左侧导航代码与原版一致。截图与日志保存到 `output/`。工程检查覆盖类型、lint、核心回归、稳定性、Web Lite 生成一致性与浏览器回归。

本地浏览器或隔离组件证据不代表 Windows 安装包已发布，也不代表已完成所有 Windows 显示缩放组合的人工验收。后续发布按 PR、精确提交 CI、标签、Release 核验流程执行；本节记录本地验收边界。
