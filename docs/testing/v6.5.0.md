# v6.5.0 本地实施验收

本次基于与 origin/main 一致的 6.4.3 实施，版本为 6.5.0 本地候选，尚未发布。保留原有 output/ 和用户历史数据。

## 实现范围

- 第三步共享背景选择：渐变与独立纯色分支；纯色不创建 SVG 渐变、模糊或网格。
- 复用封面区域分析，按覆盖占比和空间代表性排序，以 OKLab 距离合并近似色，保留最多六个真实候选。无有效分析时显示中性预设。
- 保存 solidColor 与 solidColorSource，区分自动推荐和明确选色；自动黑白文字按最终纯色计算，自定义文字色优先。
- Mona Sans 使用官方 v2.0.27 原始 WOFF2 正体、斜体资源，固定标准宽度，注册 200–900 字重。FontTools 实读确认正体／斜体标志、字重轴范围和无 CJK 字符；中文逐字回退思源黑体。
- 中文署名回退资源为 Adobe Source Han Sans SC Bold 2.004R，实读 OS/2 字重为 700。项目署名 800／600、分享者 700，禁用伪造字形并保留斜体边缘空间。
- 移除旧第三字体的资源、许可、注册、预设、白名单及当前文案；不增加旧预设迁移。历史发布说明作为历史记录保留。
- 六份 README、六份发布说明、应用许可的字体例外条款、第三方声明和 Pages 资源清单同步更新。

- `npm run web-lite:build`、`npm run web-lite:check`、`npm run font-license:test`、六语言发布一致性检查。
- `npm run desktop:pack`：构建本地 Windows x64 未安装目录包。
- `npm run desktop:autosave-test`：真实桌面正常关闭／重启，Mona Sans 和纯色 HEX 恢复、来回切换保持；同时通过强制退出、离线历史恢复、保存失败重试及现有无障碍检查。
