- 验收日期：2026-10-07（Asia/Shanghai）。

- 基线：远端 `main`，版本 6.6.0，提交 `2c225ed5e3021ad7d36fc6fb157bad5e41f213e2`。
- 记录范围：发布前本地开发验收。本记录不是 CI、安装升级或 GitHub Release 验收证据。
- 工作区隔离：改动位于独立工作区，原目录既有的顶栏、设置及文档修改保留。

## 本版范围

- 流光渐变新增 0–100000 的布局种子、换布局与恢复默认操作，支持六种界面语言。
- 布局变化保留默认方案的源颜色、底色、每个色块的能量和颜色家族权重，调整位置与流动方向。几何搜索有次数上限和反射回退，避免有效种子造成摆放失败。
- 原始像素标识与可见像素的构图种子分离；透明区域隐藏 RGB 和原图尺寸不再直接干扰聚类与默认构图。
- 纯色候选先合并相近区域，再过滤小区域；排序使用合并后的有效占比。
- 忽略透明度低于 8/255 的噪声，保留有意使用的半透明内容；聚类收敛后提前结束，并复用同封面的短期分析结果。
- 延续现有 HSL 渐变后处理，本版不包含 OKLCH 后处理调整。

## 兼容说明

旧草稿缺少布局种子时恢复为 0，不继承另一个文档的种子。取色稳定性修复可能使旧草稿的默认渐变重新构图；已保存的手动纯色值保留。更换布局后重叠与局部混色会改变，单色封面的差异可能较小。
