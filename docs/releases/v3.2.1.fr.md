# Notes de version de Lyrics Card Generator v3.2.1

Date de sortie : 2026-06-23

> [!NOTE]
> `v3.2.1` est positionné comme une version de correction de bugs et d'amélioration de l'expérience pour `v3.2.0`.

## Correctifs de stabilité

- Amélioration du contraste des textes et des états avec le thème bleu clair et les arrière-plans personnalisés.
- Agrandissement de l’icône du Header et restauration de « Tout effacer » sans modifier les paramètres.
- Sélection d’image disponible dans tous les modes, avec aperçu immédiat en mode Remplir.
- Correction du comportement transactionnel d’Enregistrer, Annuler et Réinitialiser afin de préserver l’ancien arrière-plan lors d’une annulation.
- Nettoyage des URL d’objet lors des changements répétés et finalisation des tokens du thème personnalisé.
- Ajout des textes d’état et des notes de version dans les six langues.
- Correction de la demande répétée de langue après chaque redémarrage de l’application de bureau ; le premier choix est désormais conservé et les lancements suivants ouvrent directement l’éditeur vide.
- Le contrôle Spark Cursor occupe maintenant toute la largeur de la carte, comme le contrôle Hauteur auto.
- Ajout d’un contrôle Arrière-plan quadrillé fin dans Détails visuels, activé par défaut et appliqué à l’aperçu comme au PNG exporté.

Validation : `npm run typecheck`, `npm run core:test`, `npm run build`, `npm run desktop:build`.
