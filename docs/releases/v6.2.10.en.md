# Lyrics Card Generator v6.2.10

## Fixes and improvements

- [#165](https://github.com/Qrzzzz/lyrics-card-generator/issues/165) Prevent an import awaiting replacement confirmation or draft persistence from overwriting a newer link, lyrics edit or document.
- [#166](https://github.com/Qrzzzz/lyrics-card-generator/issues/166) Reject HTTP redirects consistently for AI translation and connection tests, preventing request bodies from reaching an unauthorized next hop.
- [#167](https://github.com/Qrzzzz/lyrics-card-generator/issues/167) Reserve first-response time for validated fallback addresses so a silent preferred address cannot consume the entire request deadline.
- Use the approved white rounded SVG with 50% opacity and a transparent E cutout for Explicit badges in card previews and exports.

Custom AI providers must use a directly responding HTTPS endpoint or a permitted local loopback HTTP endpoint. If a URL redirects, configure its final API endpoint instead.

- Windows x64: `Lyrics.Card.Generator.Setup.6.2.10.exe`.
