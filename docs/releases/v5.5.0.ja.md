# Lyrics Card Generator v5.5.0 リリースノート

リリース日：2026-07-14

v5.5.0 では縦向きカスタム歌詞カードに任意の自動幅を追加し、画面を不必要に広げず、長さの近い行を読みやすく折り返せるようにしました。

## 主な更新

- 「縦向き → カスタム → 歌詞」に、初期状態ではオフの「自動幅」を追加しました。オンの間は幅スライダーに計算済みピクセル値を表示して操作を無効化し、オフにするとその幅を保ったまま手動調整できます。
- 非表示の等倍組版プローブが最終フォントでブラウザの実表示行を測定します。文字数による推定や縮小された表示プレビューは使いません。
- 原文と翻訳を別々に測定し、CJK の書記素、西洋言語の単語、混在テキストで、次の表示行に1〜2文字や短い単語だけが残る状態を避けます。
- 全候補幅の評価、代表行の抽出、外れ値の重み下げにより、ごく短い合いの手や一部の長い原文・翻訳だけでカードが最大幅になることを防ぎます。
- 内容、フォント、文字サイズ、翻訳の変更は 300ms のデバウンス後に再計算し、安定しきい値で入力中の細かな往復を抑えます。
- 幅の安定後に自動高さを測定します。移行中は書き出しを停止し、固定高さでは従来どおり実オーバーフロー検査が働きます。

## 対象範囲

- 自動幅は縦向き・カスタムサイズ・歌詞モードだけで利用できます。固定比率、横向き、インストゥルメンタルは従来の動作を維持します。
- この項目がない旧状態ではオフになります。縦向き、横向き、固定、カスタム、インストゥルメンタル間の移動ではサイズ履歴を保存・復元します。
- デスクトップ版と Web Lite は測定、評価、自動高さ連携、書き出し安全機構を共有します。
