# Lyrics Card Generator v3.3.0 Release Notes

Release date: 2026-06-25

v3.3.0 adds Spotify track link parsing. You can now paste a Spotify track link, automatically fill in the title, artist, and cover artwork, and keep using the existing lyric card editing, cover palette, and export flow.

## Spotify link parsing

- Spotify track link parsing.
- Support for `open.spotify.com/track/...`, `open.spotify.com/intl-.../track/...`, `open.spotify.com/embed/track/...`, and common Spotify short links.
- Spotify platform logo display for parsed songs.
- Automatic lyric fetching continues to use the existing experimental lyric search.
- Fixed later setup steps showing completed checkmarks immediately after launch; only previously visited steps now show the completed state.

## Notes

- This version does not fetch lyrics from Spotify.
- This version does not require a Spotify account, OAuth, or API key.
- If automatic parsing fails, you can still enter the title, artist, cover, and lyrics manually.

Validation: `npm run typecheck`, `npm run parse:test`, `npm run core:test`, `npm run build`, plus local API checks for Spotify parsing, the lyrics endpoint schema, and the Spotify SVG icon asset.
