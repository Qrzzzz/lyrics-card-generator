# Lyrics Card Generator v4.2.0 リリースノート

リリース日：2026-07-03

v4.2.0 ではデスクトップ版のサンプル歌詞システムを更新し、独立した Web Lite / GitHub Pages デモのデプロイ準備を修正しました。Web Lite は簡易的なオンラインデモであり、デスクトップ版の完全な体験ではありません。

## 主な更新

- サンプル歌詞は「原文言語の歌詞 + 5 つの対象言語の翻訳サンプル」という再利用可能な構造になりました。
- サンプルダイアログは曲名、アーティスト、原文言語を表示し、5 つの翻訳を選択できます。
- 現在の UI 言語に対応する翻訳がある場合はそれを既定で選び、ない場合は最初の利用可能な翻訳を使います。
- サンプル設定はカードの高さ、サイズ、比率、AutoHeight 状態を持たなくなりました。
- サンプル読み込みは曲情報、歌詞、翻訳だけを入力し、カバーとアルバム情報の補完は従来どおりベストエフォートで行います。
- Web Lite / GitHub Pages は明示的な相対アイコンパスを使い、`index.html`、`public/app-icon.png`、`.nojekyll` のみを package します。

## 範囲

- サンプル文面はコンポーネントに埋め込まず、引き続き `lib/examples.ts` に集約しています。
- サンプルのための実行時リクエストは追加せず、歌詞と翻訳はオフラインで利用できます。
- Web Lite の修正は、デスクトップアプリ本体のロジック、Electron ビルド、デスクトップ版のプレビュー / エクスポート動作を変更しません。
- Web Lite は独立した簡易的なオンラインデモのままです。完全な体験にはデスクトップ版を使用してください。

## 検証

- npm run typecheck
- npm run core:test
- npm run build
