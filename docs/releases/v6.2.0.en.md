# Lyrics Card Generator v6.2.0

> Status: released.

## Copy the finished image

- A new Copy Image action beside Complete & Export writes the current result to the system clipboard without saving a file first.
- Clipboard output is always the broadly interoperable PNG format and keeps the current export quality. Copying does not change the selected PNG, WebP, or JPG download format.
- Dedicated progress and success feedback cover the operation, while failures point users toward clipboard-access checks.

## The same guarded output boundary

- Copy and download share the immutable document snapshot, font and image readiness checks, overflow protection, pixel-size limits, and transaction mutex.
- The Windows desktop app sends the decoded image through trusted Electron IPC to the native clipboard, with PNG payload and dimension limits repeated in preload and main.
- Web Lite exposes the same action where browser image-clipboard APIs are available. Unsupported or denied writes leave editor content unchanged and report an error.

## Validation scope

- Type checks, export transactions, six-locale copy completeness, Electron preload and security contracts, step layout, a real Web Lite PNG write, and native desktop clipboard interaction are covered by regression tests.
