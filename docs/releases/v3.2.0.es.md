# Notas de la versión Lyrics Card Generator v3.2.0

> [!WARNING]
> Esta versión `v3.2.0` contiene errores no corregidos. No se recomienda actualizar a esta versión.

Fecha de lanzamiento: 23 de junio de 2026

## Centro de ajustes y personalización

- Nuevo centro con seis pestañas: General, Apariencia, Fondo, Exportar, AI y Acerca de.
- Control de Spark Cursor, tres temas, fuente/acento/color de texto y protección de legibilidad.
- Fondos persistentes de color sólido, estirado, contenido, portada, desenfoque y paleta de imagen; el modo dinámico del álbum sigue siendo el predeterminado.
- Cuatro calidades PNG predeterminadas: baja, estándar, alta y 3x.
- Selector inicial de seis idiomas y editor vacío al iniciar.
- `opposite` se carga desde Ejemplos; la actualización y los enlaces de GitHub pasan a Acerca de.
