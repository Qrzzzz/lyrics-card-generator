# Lyrics Card Generator v6.8.8

**2026-10-27**

最佳化桌面迴歸測試與發佈流程，保留現有歌詞編輯、匯出功能及已儲存設定。

- PR/main 共用一次桌面建置，由編輯、工作區、資料及原生四組獨立驗收；拆分較長的設定情境，保留原有行為斷言。
