# Lyrics Card Generator v5.11.0

> This version is not yet released; these notes describe the local candidate.

## Landscape cards rebuilt

- Landscape is now a free-ratio two-column layout with automatic lyrics-region width and height enabled by default; 16:9, 21:9, and 3:2 presets are gone.
- Automatic width measures complete DOM wrapping and natural height, strongly avoiding overflow, orphans, and excessive wrapping while preferring compact near-equal results.
- The left column uniformly scales the complete-ratio cover, song metadata, platform mark, sharer, and generated watermark as one design unit.
- Requested height is only a minimum. Content grows the canvas instead of being clipped or having its lyric font reduced.

## Editing and compatibility

- Song metadata is always shown. Landscape always shows the cover; portrait can still hide it.
- Landscape accepts up to 12 non-empty logical lines across the original and enabled translation. A 13th line is preserved and returns you to Lyrics with guidance.
- Legacy landscape ratios, size snapshots, and hidden metadata/cover states migrate safely.
- Desktop and Web Lite preview, offscreen export, and immutable export snapshots share the same measured plan.
