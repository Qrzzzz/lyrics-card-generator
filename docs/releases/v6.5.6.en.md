# Lyrics Card Generator v6.5.6 Release notes

Release date：2026-09-22

v6.5.6 refines Light Acrylic with softer frosted surfaces and clearer text, bringing the window background, content panels, and controls into balance.

## Light Acrylic appearance and readability

- Strengthen the milky window base to improve text readability over dark and saturated desktop backgrounds.
- Soften panel borders, shadows, and saturation while retaining translucency and clearer input and button surfaces.
- Fix white hover text on AI settings cards and hard-to-read form error messages on light backgrounds.
- Adapt save notifications, warnings, and keyboard focus to light surfaces, and reduce heavy shadows on search fields and selected controls.
