# Lyrics Card Generator v6.9.2

**2026-11-05**

歌詞なしカードを再設計。余白のないカバー、下部の段階的なぼかし、大きな曲名、独立したクレジットを導入します。

- 1:1 カバーを基準に 1080×1512 に固定し、非正方形画像の縦横比を維持します。
- 下部で二段階の大きなぼかしと滑らかな透過マスクを重ね、短い端だけを反転して継ぎ目と繰り返しを抑えます。
- 既存の単色推薦、候補色、カスタム HEX、白色プリセット、自動文字コントラストを使用します。
- 鮮明な部分から 108px の曲名を配置。漢字五文字で幅の約半分を占め、歌手は 40px、アルバムは 28px。長い曲名は自動調整します。
- 曲情報はカバーと移行部分に重ね、共有者とプロジェクト署名は下部の単色領域に独立配置します。
- デスクトップ版と Web Lite で共通実装を使用し、背景の準備完了後に書き出します。
- 既存の縦・横歌詞レイアウトと多色背景の操作は維持します。
