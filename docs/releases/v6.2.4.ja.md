# Lyrics Card Generator v6.2.4

> 状態：公開済み。

## 設定の信頼性と情報設計

- アプリ設定と AI 設定の保存失敗は、設定画面を閉じた後もローカライズされた通知と明確な再試行状態として表示されます。
- 「カードと書き出し」では、新規カードのフッター既定値とファイル書き出し既定値を分離しました。ソフトウェア透かし、共有者名とその文字列は本当に新しいカードにだけ適用され、現在の文書を上書きしません。内容のクリアは従来どおり現在の見た目を保持します。
- AI ワークスペースでは接続設定、翻訳既定値、プロンプトライブラリを分離しました。AI データは初回アクセス時に読み込み、開いたページのローカル状態はマウントされたまま保持します。

## セキュリティ、履歴、保存領域

- 安全な AI 接続テストは歌詞やユーザー内容を送信せず、厳格なタイムアウトと資源上限、キャンセルを備えます。安全でない、または悪意のある Base URL はプロバイダーへ到達する前に拒否します。
- 自動インポート履歴に「保持しない」を追加し、明示的な手動アーカイブとは分離しました。設定リセットは UI、外観、書き出し既定値だけを戻し、現在の文書、履歴、手動アーカイブ、AI API キーを消去しません。
- 到達不能だった旧式の独立背景設定とデスクトップブリッジを削除しました。アルバム連動のアプリ背景、移行互換性、Web Lite の動作は維持されます。

## アクセシビリティ、フォント、ライセンス

- 設定の見出し階層、グループ名、入力ラベル、エラー関連付けを修正し、モバイルのナビゲーション landmark、履歴移動、最小ウィンドウのレイアウトを改善しました。
- 生の CSS フォント設定にシステム既定値への復元、入力の無害化、検証、アクセシブルなエラーを追加しました。プロンプト統計は保護済み、編集可能、カスタムを区別します。
- デスクトップと Web Lite の「このアプリについて」から、ソフトウェアの Source Available License と Source Han フォントを含む同梱第三者通知をオフラインで開けます。

## ダウンロードと更新

- Windows x64 インストーラー：`Lyrics.Card.Generator.Setup.6.2.4.exe`。
- 本版も Setup のみを提供します。旧版からの更新時に設定の移行は不要です。
