# Lyrics Card Generator v5.12.0

> Status: publicly released through GitHub Releases.

## Local M4A parsing

- Local audio upload now supports M4A alongside MP3 and FLAC, reading the title, artist, album, artwork, and embedded lyrics when available. Files without embedded lyrics still retain the parsed song information for manual editing.
- Common browser and Windows types—`audio/mp4`, `audio/m4a`, and `audio/x-m4a`—are supported while retaining the existing 100 MB file limit, bounded multipart reads, and parse-failure safeguards.
- Windows Desktop import history can record successfully committed M4A files, reimport them, and relocate missing files. History continues to store only the required path and metadata, never the audio content.
