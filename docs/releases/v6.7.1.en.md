# Lyrics Card Generator v6.7.1 Release Notes

Release date: 2026-10-08.

v6.7.1 makes the gradient random action explicit with Generate random background. One click selects a random seed different from the current value and immediately updates the color field layout.

## Generate random background

- In Background → Flowing gradient, select Generate random background above the seed input. The button supports mouse and keyboard actions and shows the new seed in the input.
- Cover colors, manual seed input, Reset layout and draft persistence are preserved. The same cover, seed and aspect ratio still reproduce the layout.
