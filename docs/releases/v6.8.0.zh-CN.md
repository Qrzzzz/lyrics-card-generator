# Lyrics Card Generator v6.8.0 发布说明

发布日期：2026-10-16。

v6.8.0 重组第二步歌词工作台的工具导航：整理、双语、检查三个工作区，统一工具搜索与 Ctrl+K 命令面板，保留现有编辑和业务逻辑。

- 整理工具直接可见，空行、粘贴清理、LRC、合并行、段落标签、保留选区和分隔符均保留。双语区统一翻译开关、AI 翻译、交替拆分、格式化和交换原译。
- 检查整合进侧栏，显示双栏对齐、异常字符、重复行、超长行和导出限制，支持定位全部问题；不自动删除重复歌词。
- 顶部聚焦撤销、重做、获取歌词、AI 翻译和搜索，按选区显示上下文操作；名称、关键词和多语言同义词共用一个工具注册表，危险操作先预览确认。
- 保留约 2/3 编辑区与 1/3 工具区、双栏共享滚动和文本宽度约束；支持侧栏收起与窄窗口抽屉，保留选区、语义滚动锚点、撤销、AI 页面和自动保存机制。
