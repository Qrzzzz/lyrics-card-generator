# Notes de version de Lyrics Card Generator v3.9.0

Date de publication : 2026-07-01

v3.9.0 se concentre sur l’enregistrement des paramètres, la simplification des étapes d’édition, l’affichage des métadonnées de carte et la préparation de publication. Cette mise à jour conserve le périmètre existant de six langues, sans ajout ni suppression de langue, et rend l’enregistrement des paramètres immédiat afin d’éviter des confirmations séparées pour l’arrière-plan, l’apparence et l’IA.

## Enregistrement des paramètres

- Les paramètres sont désormais enregistrés immédiatement : images d’arrière-plan, réglages IA, apparence et préférences générales sont écrits directement dans les préférences locales.
- L’ancienne barre de confirmation Enregistrer / Annuler en bas de fenêtre a été retirée ; des notifications légères indiquent maintenant l’état d’enregistrement.
- Le remplacement d’une image d’arrière-plan nettoie l’ancienne ressource, et l’application de bureau continue de synchroniser les préférences dans le stockage Electron.

## Périmètre multilingue

- Le périmètre de langues de l’interface reste celui des six langues existantes : chinois simplifié, chinois traditionnel, anglais, français, japonais et espagnol.
- Cette version n’ajoute pas de nouvelle langue et ne supprime aucune entrée existante.
- Les README et les notes de version multilingues continuent d’être mis à jour comme un ensemble cohérent de six langues.

## Flux d’édition et métadonnées de carte

- Les informations manuelles du morceau passent d’une étape séparée à une action dépliable dans l’étape de lien, où le titre, l’artiste, l’album et la pochette restent modifiables.
- Les cartes de paroles ajoutent une option « Afficher le nom de l’album », couvrant les mises en page portrait, paysage et instrumentale.
- Le calcul de hauteur automatique et la mise en page paysage réservent de l’espace au nom de l’album afin de limiter les collisions entre les informations du morceau et les paroles.

## Préparation de publication

- Les métadonnées de version, `package.json`, `package-lock.json` et les noms de fichiers de téléchargement dans les README sont synchronisés sur `3.9.0`.
- Les notes de version multilingues comprennent maintenant les 6 fichiers de langue, et `docs/releases/README.md` est mis à jour.
- L’installateur Windows, la version portable et `latest.yml` ont été reconstruits pour l’envoi sur GitHub Release.

## Vérification

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:build
