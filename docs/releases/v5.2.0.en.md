# Lyrics Card Generator v5.2.0 Release Notes

Release date: 2026-07-13

v5.2.0 is a stability, accessibility, desktop-security, and release-engineering update. It preserves the existing card output, data formats, and visual direction.

## Main Updates

- Safe Fetch now validates every resolved address, alternates IPv6/IPv4 candidates, falls back after connection failures, and applies one deadline and redirect budget to the whole request.
- Document-semantic style changes cancel active AI generations atomically, while ordinary visual controls no longer cause unnecessary cancellation. Electron AI cancellation is sender-scoped and safe before the first provider await.
- Desktop preferences use monotonic revisions to reconcile JSON and renderer cache, migrate v5.1.0 data, serialize rapid writes, and flush pending settings before every close path.
- Shared accessible dialogs add initial focus, focus trapping, background inertness, Escape policy, reduced motion, and focus restoration. Search, link parsing, and local-audio status flows now have complete keyboard and live-region behavior.
- Six-language error messages are mapped from stable codes, the document language follows the active locale, focus remains visible with custom accents, and Forced Colors receives explicit system-color behavior.
- External navigation, privileged IPC senders, permissions, and production CSP are now governed by explicit policies.

## Release Assurance

- Lint, critical-module coverage, axe, locale completeness, Electron security, lifecycle, and final-artifact gates are part of CI.
- Setup and portable files are tested as final bytes. Tag-driven releases publish those same bytes with SHA-256 checksums, an SPDX SBOM, and GitHub artifact attestations.
