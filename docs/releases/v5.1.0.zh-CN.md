# Lyrics Card Generator v5.1.0 发布说明

发布日期：2026-07-13

v5.1.0 是稳定性与安全性版本，保留 v5 前两步现有视觉方向，重点修复网络请求、导入竞态和导出一致性。

## 主要更新

- 建立统一 Safe Fetch：每次重定向前都会重新解析和校验目标，并限制私网、保留地址、超时、跳数、内容类型和响应体大小。
- 歌曲、歌词与示例导入采用 document revision 和 last-intent-wins；清空、换歌或较新的操作会中止并废弃旧结果。
- 换歌改为完整替换歌曲文档，不再残留上一首歌的封面、explicit、最终 URL、解析方式或译文。
- 桌面版导出使用不可变快照和同步互斥，歌词、样式、尺寸、文件名与实际 PNG 始终来自同一 revision。
- Web Lite 使用独立离屏导出 host，并与桌面版共享 36 行、字体加载、测量、尺寸稳定和 overflow 安全判断。
- 导出忙碌、被阻止或失败时会显示本地化、可恢复的用户提示。

## 验证

- 新增 SSRF target 零访问、导入竞态矩阵、跨歌曲字段重置、导出快照与并发测试。
- 新增 Web Lite 36/37 行、固定 1:1 overflow 和折叠预览导出测试。
- 完成核心、Web Lite、桌面构建与交互回归。
