# Lyrics Card Generator v5.8.3 Release Notes

Release date: 2026-07-22

v5.8.3 continues refining the step-two Lyrics workspace. The Cleanup and Translation sidebar now follows the app-wide settings control language, while long tool content receives clearer scrolling boundaries and no longer competes with the bottom navigation.

## A more consistent sidebar

- Cleanup／Translation tabs and scope choices now use segmented controls with clearer selection, keyboard focus, and theme-accent feedback.
- Section headings, descriptions, routine actions, and risky actions use the same sizing, spacing, corners, and feedback language as the Settings surface.
- Preview and confirmation content gains more space and a larger text size, making long tool lists easier to scan and use.

## More reliable scrolling boundaries

- The sticky scope block is removed so it cannot cover later tools while the sidebar scrolls.
- Cleanup and Translation content continues to use one bounded sidebar scroller, keeping every tool inside its column and above the bottom step navigation.
- The expanded desktop sidebar, 52 px collapsed tool rail, and narrow-screen modal drawer retain their existing layout boundaries.

## Preserved behavior and compatibility

- Blank-line cleanup, LRC cleanup, paragraph-tag handling, alternating-lyric splitting, translation formatting, column swapping, and AI translation behave as before.
- Resizing, shared scrolling, selection anchors, undo and redo, keyboard tab navigation, ARIA, and focus feedback are preserved.
- The six-step Stepper, the hidden lyric-card preview in step two, and the 36-line export boundary remain unchanged.
