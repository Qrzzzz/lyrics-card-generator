# Lyrics Card Generator v3.2.1 Release Notes

Release date: 2026-06-23

> [!NOTE]
> `v3.2.1` is positioned as a bug-fix and experience enhancement release for `v3.2.0`.

## Stability fixes

- Fixed text and status-message contrast in the light-blue theme and on custom backgrounds.
- Enlarged the Header app icon and restored Clear all while preserving app settings.
- Kept background image selection available in every mode and switched new images to Cover mode for immediate preview.
- Fixed transactional Save, Cancel, and Reset behavior so cancelling cannot remove the previous background.
- Fixed object URL cleanup during repeated background changes and completed custom-theme tokens.
- Added the related status copy and release notes in all six languages.
- Fixed the desktop app repeatedly asking for a language after restart; the first choice is now persisted and later launches open the blank editor directly.
- Expanded the Spark Cursor switch across the settings card to match the Auto Height control.
- Added a Fine Grid Background switch under Visual Details, enabled by default and applied to both the preview and exported PNG.

Validation: `npm run typecheck`, `npm run core:test`, `npm run build`, `npm run desktop:build`.
