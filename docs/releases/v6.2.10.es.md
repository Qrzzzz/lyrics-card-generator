# Lyrics Card Generator v6.2.10

## Correcciones y mejoras

- [#165](https://github.com/Qrzzzz/lyrics-card-generator/issues/165) Evita que una importación pendiente de confirmación o de guardar el borrador sobrescriba un enlace, una letra o un documento editados durante la espera.
- [#166](https://github.com/Qrzzzz/lyrics-card-generator/issues/166) Rechaza las redirecciones HTTP en la traducción con IA y las pruebas de conexión para impedir que el cuerpo de la solicitud llegue a un destino no autorizado.
- [#167](https://github.com/Qrzzzz/lyrics-card-generator/issues/167) Reserva tiempo de primera respuesta para las direcciones alternativas validadas, evitando que una dirección sin respuesta agote el plazo global.
- El distintivo Explicit usa el SVG blanco redondeado aprobado, con un 50 % de opacidad y una E recortada transparente, tanto en la vista previa como en la exportación.

Los proveedores de IA personalizados deben usar un endpoint HTTPS que responda directamente o un endpoint HTTP de bucle local permitido. Si una URL redirige, configura la dirección final de la API.

- Windows x64: `Lyrics.Card.Generator.Setup.6.2.10.exe`.
