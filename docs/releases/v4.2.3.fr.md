# Notes de version de Lyrics Card Generator v4.2.3

Date de publication : 2026-07-03

v4.2.3 reconstruit le système d’apparence de l’interface de l’application. Les réglages auparavant répartis entre Apparence, Arrière-plan, couleur d’accent et couleur de texte sont regroupés dans un seul modèle de mode d’apparence. Cette version ne change pas le style des cartes exportées, n’ajoute pas de flux d’arrière-plan image et n’étend pas les couleurs de thème choisies par l’utilisateur.

## Principales nouveautés

- La page indépendante Arrière-plan est retirée de la fenêtre de réglages ; les onglets sont maintenant Général / Apparence / Exportation / AI / À propos.
- La page Apparence n’expose plus que le mode d’apparence et la police de l’interface.
- Le mode d’apparence est limité à cinq choix : Dynamique de l’album, Mode sombre, Mode clair, Acrylique sombre et Acrylique clair.
- Dynamique de l’album reste le mode par défaut et continue d’utiliser la palette de la pochette pour l’ambiance et la couleur d’accent.
- Le mode sombre utilise désormais un fond proche du noir, et le mode clair un fond blanc stable, sans les anciens préréglages bleu-blanc ou noir-rose.
- Acrylique sombre et Acrylique clair continuent d’utiliser le chemin Windows Acrylic d’Electron.

## Compatibilité et migration

- Les anciens réglages `light-blue` migrent vers `light`.
- Les anciens réglages `dark-pink` migrent vers `dark`.
- Les anciens réglages `custom` migrent vers `album-dynamic`.
- Les anciens champs d’arrière-plan restent dans la structure interne, mais l’arrière-plan de l’application est désormais piloté directement par `uiTheme`.
- La couleur d’accent manuelle, la couleur de texte manuelle et les modes d’image d’arrière-plan ne sont plus exposés dans les réglages.

## Périmètre

- Le rendu d’aperçu et l’export PNG des cartes de paroles sont inchangés.
- Aucune fonctionnalité d’image d’arrière-plan n’est ajoutée.
- Aucune fonctionnalité de couleur de thème personnalisée n’est ajoutée.
- `BackgroundSettingsSection` reste temporairement comme fichier de compatibilité interne, mais n’est plus monté dans la fenêtre de réglages.

## Vérification

- npm run typecheck
- npm run core:test
- npm run build
