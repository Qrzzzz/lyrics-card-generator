# Lyrics Card Generator v6.0.0

> Status: publicly released through GitHub Releases.

## Structured lyric document engine

- `LyricDocumentV2` is now the lyric source of truth. Natural paragraphs are Blocks; source/translation groups are Units with stable IDs; every effective operation advances the document revision.
- Plain-text paste and editing remain unchanged. A deterministic parser handles blocks, alignment, and identity reconciliation while preserving order, blank lines, and translations. Legacy archives migrate on load.
- Import, editing, undo/redo, manual archives, preview, automatic layout, and export consume the same document. The former `lyrics` and `translationText` values are derived compatibility projections only.

## AI translation and export consistency

- AI translation requests and commits Unit-ID-addressed JSON and accepts only complete, correctly ordered results whose revision still matches.
- Late responses, incorrect IDs, missing Units, and extra fields cannot overwrite the current document. Streaming output updates translations only after it becomes complete valid JSON.
- Export snapshots freeze the lyric document, document revision, style, and resolved layout to prevent preview/export drift during editing.

## Compatibility

- Desktop and Web Lite retain the existing lyric editing experience and card visual language.
- v1 manual archives remain readable. New v2 archives persist stable Block/Unit IDs behind strict boundary validation.
