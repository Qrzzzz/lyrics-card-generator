# Lyrics Card Generator v3.6.0 发布说明

发布日期：2026-06-29

v3.6.0 聚焦 Windows 桌面端的 Acrylic 视觉体验：新增深色亚克力与浅色亚克力应用主题，接入真正的 Windows Acrylic 半透明窗口材质，并将桌面窗口升级为自绘标题栏。

## 新增

- 新增“深色亚克力”和“浅色亚克力”界面主题。
- Windows 桌面端在支持的系统上使用原生 Acrylic 窗口材质，窗口后方内容会以系统模糊效果透出。
- 新增自绘桌面标题栏，保留左侧应用图标、软件名和版本号，以及右侧最小化、最大化/还原、关闭按钮。
- 新增桌面窗口控制 IPC，让自绘标题栏可以调用最小化、最大化/还原和关闭窗口。

## 改进

- 标题栏与窗口本体使用同一层透明 Acrylic 背景，弱化独立标题栏边界，让顶部区域与主界面融合得更自然。
- 桌面端内容滚动区域改为窗口内部滚动，右侧滚动条不再贴在系统窗口外侧。
- 为应用内滚动区域加入更简洁的细滚动条样式，并启用 Chromium overlay scrollbar 特性。
- Acrylic 主题下优化文字、按钮、输入框、设置弹窗、状态提示和 toast 的可读性。
- Acrylic 主题只影响应用界面，不影响歌词卡片本体或 PNG 导出效果。

## 修复

- 修复桌面端启动后默认最大化的问题，应用现在按正常窗口尺寸打开。
- 修复自绘标题栏关闭按钮无法正常关闭窗口的问题。
- 修复最大化按钮点击后无法回退到窗口化的问题；现在会记录窗口化尺寸，并在再次点击时可靠还原。
- 非 Windows 或不支持 Acrylic 的系统会降级为可读的透明界面，不会因为窗口材质不可用而崩溃。

## 验证

- 验证两个 Acrylic 主题出现在“设置 → 外观 → 界面主题”中。
- 验证切回普通主题时会关闭 Acrylic 窗口材质。
- 验证桌面开发版可正常启动并返回页面。
- 执行 `npm run typecheck`、`npm run core:test`、`npm run build` 和 `npm run desktop:build`。
