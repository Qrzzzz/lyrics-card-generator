This is the first official desktop release of Lyrics Card Generator. Compared to the initial v0.1.0 desktop version, this release focuses on refining the Windows desktop distribution process, in-app update checking, card layout stability, and export experience, making it suitable for use as a formal distributable version.

## Major Updates

### Windows Desktop Version Finalized

* Application version upgraded to `1.0.0`.
* Added an Electron desktop entry point; Windows users can directly run the EXE.
* The desktop version starts a built-in Next standalone server locally and loads the local application in a desktop window.
* Users do not need to install Node.js or manually run a development server.
* Supports Windows x64 installer and portable editions.
* The window opens maximized by default.
* External links are opened in the system browser.
* When closing the application, the local service process is automatically cleaned up, reducing background residue.

### New Check for Updates

* A "Check for Updates" button has been added to the top toolbar.
* The application requests the latest version information from GitHub Releases.
* Supports comparing version number formats like `v1.0.0` / `1.0.0`.
* If a new version is found, it provides an entry point to the download page.
* If `.exe` or `.msi` installers exist in the Release, they will be prioritized as download resources.
* This feature only checks for updates and opens the download page; it does not silently download or automatically replace the current program.

### Auto Height Fix

* Under custom portrait dimensions, auto height now comprehensively estimates based on actual lyric content, translation content, font size, line spacing, title area, border, and footer content.
* After enabling the platform logo, sharer, or generation watermark, the card will increase height downward instead of compressing the lyric area.
* Auto height is enabled by default.
* The maximum custom height for portrait mode has been increased to `3200px`, better suited for scenarios with long lyrics, translations, and footer enabled simultaneously.

### Landscape Border Layout Fix

* Fixed the misalignment of platform info, sharer, and generation watermark when "Border + Shadow" is enabled on landscape cards.
* The landscape layout now uses a unified frame-aware coordinate system.
* When the border is enabled, the cover, song info, lyrics, and footer elements all enter the inner safe area of the border.
* Fixed the issue where the footer and border were misaligned under landscape ratios such as 16:9, 21:9, and 3:2.

### Export Experience Optimized

* The export flow has been simplified to "Finish & Export", reducing redundant export settings entry points.
* High-resolution 2x PNG output continues to be used by default.
* The celebration animation after a successful export has been replaced with a more restrained top confetti effect.
* Fixed an issue where the "Clear All Content" action could mistakenly trigger the export celebration animation.

### Icons and Release Engineering Improvements

* Replaced and unified application icon assets.
* Added Windows installer icon, portable icon, web favicon, and in-app title area icon.
* Added desktop build scripts and release preparation scripts.
* Added desktop run instructions, migration checklist, known issues document, and release notes.
* Updated `.gitignore` to prevent committing build artifacts, release files, caches, and logs into the source repository.

## Retained Capabilities

* Link parsing for Apple Music, NetEase Cloud Music, and QQ Music.
* Manual editing of song information, lyrics, and translations.
* Local cover upload, remote cover proxy, and cover color extraction.
* Portrait / landscape card generation.
* Visual settings including font, font size, line spacing, color, border, shadow, watermark, sharer, and platform logo.
* Chinese / English interface switching.
* Offline opening, manual editing, local cover, and PNG export.

## Features Still Requiring Internet Connection

* Music platform link parsing.
* Remote cover loading.
* LRCLIB automatic lyric fetching.
* GitHub check for updates.

## Known Limitations

* The current version is still not code-signed; Windows may display a SmartScreen prompt.
* The update check does not automatically download installers; users need to manually open the download page.
* The current distribution target is Windows x64.
* Third-party platform parsing and lyric fetching are subject to the availability of upstream services.
