# Lyrics Card Generator v6.2.12

## Installer update

- A minimal setup window with the app icon, version and Install button; language selection stays at the top right.
- Expand the side options within the same window to choose the location, installation scope and desktop shortcut.
- The installer follows the system light or dark theme. This layout becomes the default for subsequent versions.
- Retains NSIS installation, upgrades and uninstallation, with six interface languages.

- Windows x64: `Lyrics.Card.Generator.Setup.6.2.12.exe`.
