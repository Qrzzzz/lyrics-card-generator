# Lyrics Card Generator v3.6.1 发布说明

发布日期：2026-06-29

v3.6.1 是 v3.6.0 Acrylic 桌面更新后的修复版本，重点修缮自绘标题栏的窗口状态同步、视觉融合、hover 状态、层级和多语言文案，同时修正当前下载入口。

## 改进

- 标题栏加入向下自然消失的渐变玻璃模糊层，让顶部区域与 Acrylic 窗口材质融合得更自然。
- 标题栏层级调整到设置、示例、首次语言选择和 toast 下方，避免压住弹窗内容。
- 标题栏窗口控制按钮补齐多语言 `aria-label` 和 `title` 文案，并随最大化/还原状态切换。
- 最大化按钮现在会在窗口最大化后切换为还原图标。

## 修复

- 修复点击最大化/还原后前端图标状态没有立即更新的问题。
- 修复系统 Snap、双击标题栏或原生窗口事件触发最大化后，标题栏按钮状态不同步的问题。
- 修复浅色亚克力主题下关闭按钮 hover 可能不稳定变红的问题。
- 修复 README 当前版本下载文件名和发布说明入口仍可能指向旧版的问题。
- 歌词卡片 PNG 导出逻辑未改动，Acrylic 和标题栏不会进入导出图片。

## 验证

- 验证自绘标题栏在桌面环境外不会渲染。
- 验证标题栏按钮文案可随当前界面语言变化。
- 验证 `data-export-card="true"` 的卡片区域不包含桌面标题栏。
- 执行 `npm run typecheck`、`npm run core:test`、`npm run build` 和 `npm run desktop:build`。
