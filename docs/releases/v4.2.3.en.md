# Lyrics Card Generator v4.2.3 Release Notes

Release date: 2026-07-03

v4.2.3 rebuilds the app-interface appearance system. Settings that were previously spread across Appearance, Background, accent color, and text color are now consolidated into one clear appearance-mode model. This release does not change exported lyric-card styling, add background-image workflows, or expand user-selected theme colors.

## Main Updates

- The separate Background settings page is removed from the settings dialog; the tabs are now General / Appearance / Export / AI / About.
- The Appearance page now exposes only Appearance mode and UI font family.
- Appearance mode is limited to five choices: Album dynamic, Dark mode, Light mode, Dark Acrylic, and Light Acrylic.
- Album dynamic remains the default mode and continues to use the cover palette for the app mood and accent color.
- Dark mode now uses a stable near-black background, and Light mode uses a stable white background instead of the old blue-white or black-pink presets.
- Dark Acrylic and Light Acrylic continue to use Electron's Windows Acrylic window-material path.

## Compatibility and Migration

- Existing `light-blue` settings migrate to `light`.
- Existing `dark-pink` settings migrate to `dark`.
- Existing `custom` settings migrate to `album-dynamic`.
- Legacy background fields remain in the internal settings shape, but the app background is now driven directly by `uiTheme`.
- Manual UI accent color, manual text color, and background-image modes are no longer exposed in the settings UI.

## Scope

- Lyric-card preview and exported PNG styling are unchanged.
- No background-image features are added.
- No custom theme-color features are added.
- `BackgroundSettingsSection` remains temporarily as an internal compatibility file, but it is no longer mounted in the settings dialog.
