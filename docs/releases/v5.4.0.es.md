# Notas de la versión 5.4.0 de Lyrics Card Generator

Fecha de publicación: 2026-07-13

La versión 5.4.0 completa la estructura compartida de los seis pasos del editor y reconstruye el primero como el mismo espacio de trabajo compacto del resto del flujo.

## Novedades principales

- El paso 1 utiliza el mismo Stepper compacto que los pasos 2 a 6 y reúne el paso activo, la ruta completa, Ejemplos, Borrar todo y Ajustes en un único indicador.
- Se elimina el gran encabezado duplicado del paso 1; la barra de título de Windows conserva el nombre, el icono y la versión de la aplicación.
- La primera página pasa a ser un espacio de dos columnas cuyo indicador de progreso abarca la búsqueda de NetEase y la barra lateral de importación.
- La información de la canción, los enlaces, el audio local y la edición manual se reúnen en un solo panel, manteniendo todas las vías de importación y su semántica de accesibilidad.
- En el ancho mínimo de escritorio de 1000px, la barra lateral mantiene 320px y aumenta a 360px y 400px en ventanas más amplias.

## Alcance

- La búsqueda de NetEase, el análisis de enlaces y audio local, los datos manuales, el documento de letras y la traducción con IA no cambian.
- Los pasos 2 a 6, la vista previa, la exportación PNG, los ajustes, los proyectos y el comportamiento compartido de Web Lite no cambian.

## Verificación

- `npm run lint` / `npm run typecheck` / `npm run core:test` / `npm run build`
- `npm run web-lite:build` / `npm run web-lite:check` / `npm run web-lite:smoke`
- `npm run desktop:build` / `npm run desktop:interaction-test` / `npm run desktop:final-artifact-smoke`
- Regresiones de escritorio en 1000×700, 1023×700, 1024×700, 1280×900, 1440×900 y 1920×1080
