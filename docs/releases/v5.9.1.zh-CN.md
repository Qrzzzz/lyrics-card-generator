# Lyrics Card Generator v5.9.1 发布说明

发布日期：2026-08-06

v5.9.1 为 Windows 桌面版新增显式手动存档。它不是自动保存，也不是完整文档版本历史。

## 手动存档与载入

- 桌面版顶部操作区在“历史记录”和“清空内容”之间新增图标式“手动存档”按钮。首次保存会创建记录；继续编辑后再次保存会更新同一 ID，并保留原创建时间。
- 同一文档没有变化时不会写盘；快速双击只会产生一次写入。空白文档、AI 操作或文档替换事务进行中不可保存，写入失败不会把当前修订误标为已保存。
- 历史页可单独筛选手动存档，并用“载入存档”在本地恢复内容，不发起网络请求，也不提供文件重新定位。删除当前绑定记录或清空历史会解除绑定。
- 载入手动存档后继续保存会更新原记录；普通导入、其他历史重放、内置示例、清空编辑器和上传本地封面会开始新的存档会话。记录已在磁盘外部删除时，本次保存只解除旧绑定，不会静默新建。

## 安全存储与迁移

- 历史 schema 升级到 v2；旧 v1 记录按原顺序无损迁移，重复载入不会继续改变数据。
- 手动存档只保留歌曲来源、标题、歌手、专辑、歌词、译文、译文开关及安全的远程 URL 等语义内容。样式、设置、导出图片、本地路径、API 密钥、图片二进制、Base64、blob URL 和 data URL 均不保存。
- ID 与时间戳由 Electron 主进程生成；创建和更新使用独立的安全 IPC，并经过字段限制、单记录 512 KiB 上限、串行原子写入及退出前排空保护。

## 范围与验证

- 新增界面文案覆盖简体中文、繁體中文、English、Français、日本語和 Español。
- Web Lite 的界面与行为保持不变，不提供浏览器端手动存档替代实现，也不新增 `Ctrl+S` 快捷键。
- 存储、迁移、安全 IPC、界面契约、打包及真实 Electron 交互回归覆盖创建、原位更新、无变化跳过、绑定生命周期、失败重试与退出排空语义。
