# Lyrics Card Generator v6.0.0

> Estado: publicado públicamente mediante GitHub Releases.

## Motor de documento de letras estructurado

- `LyricDocumentV2` pasa a ser la única fuente de verdad. Los párrafos naturales son Blocks y los grupos de original/traducción son Units con ID estable; cada operación efectiva incrementa la revisión del documento.
- El pegado y la edición de texto simple no cambian. Un parser determinista gestiona bloques, alineación e identidades y conserva orden, líneas vacías y traducciones. Los archivos antiguos se migran al cargarlos.
- Importación, edición, deshacer/rehacer, archivos manuales, vista previa, diseño automático y exportación consumen el mismo documento. `lyrics` y `translationText` quedan solo como proyecciones de compatibilidad derivadas.

## Traducción con IA y coherencia de exportación

- La traducción con IA solicita y confirma JSON dirigido por Unit ID y solo acepta resultados completos, ordenados y vinculados a la misma revisión.
- Las respuestas tardías, los ID incorrectos, las Units ausentes y los campos extra no pueden sobrescribir el documento actual. El streaming actualiza la traducción únicamente cuando forma JSON completo y válido.
- La instantánea de exportación congela el documento, su revisión, el estilo y el diseño resuelto para evitar diferencias con la vista previa durante la edición.

## Compatibilidad

- Escritorio y Web Lite conservan la experiencia de edición y el lenguaje visual existentes.
- Los archivos manuales v1 siguen siendo legibles; los nuevos archivos v2 guardan ID estables de Block/Unit tras una validación estricta.
