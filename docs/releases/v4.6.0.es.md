# Notas de la versión de Lyrics Card Generator v4.6.0

> [!WARNING]
> La versión `v4.6.0` contiene un error grave aún no corregido. No se recomienda actualizar a esta versión.

Fecha de publicación: 2026-07-11

Esta versión reconstruye el sistema de prompts de traducción para gestionar por separado las reglas estrictas de salida, los estilos predeterminados y los estilos personalizados, manteniendo el requisito de que la IA devuelva únicamente la letra traducida.

## Principales novedades

- Ajustes de IA ahora contiene dos páginas: Configuración de API y Biblioteca de prompts, con Atrás, Adelante y una ruta navegable al estilo de un explorador de archivos.
- Recomendada es el único preajuste protegido y siempre permanece disponible. Los otros cinco permiten editar título y prompt, eliminar, restablecer y restaurar.
- Se pueden crear hasta dos preajustes personalizados, cada uno con título y prompt de estilo, para un máximo de ocho preajustes en la biblioteca.
- La entrada de preajustes personalizados del panel principal permanece plegada de forma predeterminada y muestra como máximo dos elementos al expandirse.
- Las reglas de formato estrictas siguen siendo un módulo compartido. Se requieren dos confirmaciones para editarlas y siempre pueden restaurarse a los valores de v4.6.0.
- Los ajustes de IA anteriores se migran automáticamente. Un estilo personalizado sustituye solo el módulo de estilo y no elimina las reglas comunes de salida.

## Verificación

- npm run typecheck
- npm run core:test
- npm run build
- Comprobación de versiones, nombres de archivo, enlaces de idioma y entradas de publicación en los seis idiomas
