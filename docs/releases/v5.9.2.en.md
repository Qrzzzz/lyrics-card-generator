# Lyrics Card Generator v5.9.2 Release Notes

Release date: 2026-08-06

v5.9.2 fixes an issue in the Windows desktop app where loading a manual archive from History did not restore its saved album cover.

## History loading and cover restoration

- Loading a manual archive now restores its sanitized remote cover URL and sends it through the existing image proxy and palette extraction flow.
- The song link is not reparsed, and archived titles, artists, albums, lyrics, and translations are not overwritten. Existing archive binding and in-place update semantics remain unchanged.
- Older archives without a cover URL still load without a cover. Local covers continue to use the existing file-history and relocation flow.

## Security boundaries and validation

- Remote covers are loaded only through the in-app image proxy, never directly from the external cover address. Image bytes, Base64, blob URLs, local paths, and sensitive query parameters are not stored in manual archives.
- Regression coverage confirms that the cover renders and feeds palette extraction without rerunning song-link, search-result, or local-audio parsing.
- Web Lite keeps its existing interface and behavior.
