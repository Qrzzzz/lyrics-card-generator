# Lyrics Card Generator v3.9.0 Release Notes

Release date: 2026-07-01

v3.9.0 focuses on settings persistence, editor-step simplification, card metadata display, and release preparation. This update keeps the existing six-language scope with no added or removed locales, and changes settings persistence to save immediately so users do not need to confirm background, appearance, and AI changes separately.

## Settings Persistence

- Settings now save immediately, so background images, AI settings, appearance, and general preferences are written directly to local preferences.
- The old bottom Save / Cancel confirmation bar has been removed; lightweight notifications now report saved state.
- Replacing a background image cleans up the previous resource, and the desktop app still syncs preferences to Electron preference storage.

## Multilingual Scope

- The UI language scope remains the existing six languages: Simplified Chinese, Traditional Chinese, English, French, Japanese, and Spanish.
- This release does not add a new language and does not remove an existing language entry.
- Multilingual READMEs and release notes continue to be updated as a matched six-language set.

## Editor Flow and Card Metadata

- Manual song information has moved from its own step into an expandable action on the song-link step, where title, artist, album, and cover can still be edited manually.
- Lyric cards now include a “Show Album Name” toggle, covering portrait, landscape, and instrumental card layouts.
- Auto height and landscape layout calculations reserve room for album names to reduce collisions between song information and lyrics.

## Release Prep

- Version metadata, `package.json`, `package-lock.json`, and README download filenames are synchronized to `3.9.0`.
- The multilingual release notes now include all 6 language files, and `docs/releases/README.md` is updated.
- The Windows installer, portable build, and `latest.yml` have been rebuilt for GitHub Release upload.
