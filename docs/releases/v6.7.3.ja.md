# Lyrics Card Generator v6.7.3 リリースノート

公開日：2026-10-14。

v6.7.3 は自動折り返しと手動改行の間隔を区別し、可変行間を維持しながら長い歌詞と対訳の読みやすさを改善します。

- 同じ入力行の自動折り返しには狭い行間を使います。手動改行は選択した行間を維持し、隣り合う歌詞を区別しやすくします。
- 行間は引き続き 1.5–2.1、刻み 0.05、既定値 1.8 です。歌詞と対訳の折り返しもスライダーに連動し、新しい設定は追加しません。
- 縦型、横型、プレビュー、書き出し、自動サイズ測定に同じ規則を適用します。結合した単位内の複数行、空行、区切り線、対訳の対応を保持します。
