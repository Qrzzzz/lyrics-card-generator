# Notas de la versión de Lyrics Card Generator v4.6.4

Fecha de publicación: 2026-07-11

Esta versión continúa las mejoras de v4.6.2 para el restablecimiento de Ajustes, la Biblioteca de prompts y las vistas previas, y corrige un grave problema de interacción global.

## Principales novedades

- Se corrige el bloqueo de todas las páginas y campos de texto después de restablecer un preajuste; el restablecimiento ya no abre un diálogo nativo bloqueante.
- Las reglas de formato estrictas pasan a ser un módulo de seguridad integrado e inmutable; se eliminan todas las entradas de desbloqueo y las sustituciones antiguas dejan de participar en la generación.
- Se añade navegación global Atrás, Adelante y de ruta para todas las categorías y subpáginas de Ajustes, unificada en la cabecera superior izquierda.
- La vista previa de la tarjeta real queda fijada arriba durante el desplazamiento y se elimina la tarjeta tipográfica independiente para mostrar los cambios directamente en la tarjeta real.
- Las cuatro tarjetas de ejemplo se acortan ligeramente y se elimina la etiqueta «Álbum».
- Cada preajuste conserva Restablecer para recuperar su título y prompt iniciales.
- La página principal conserva Restablecer todo para recuperar conjuntamente los valores predeterminados, los elementos eliminados y los personalizados.
- Los preajustes personalizados guardan su contenido inicial al crearse; los datos existentes usan de forma segura su contenido actual como base tras la migración.
- Se simplifica la descripción de la biblioteca y el botón verde maximizado muestra ahora «Modo ventana».
- El borde de la vista previa en directo se adapta a la altura de la tarjeta y elimina el gran espacio vacío inferior.
