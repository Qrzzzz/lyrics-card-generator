# Lyrics Card Generator v5.9.5 發布說明

發布日期：2026-08-08

v5.9.5 是穩定性回退版本。它撤回 v5.9.4 的效能最佳化實作，將受影響的桌面啟動、資源載入、編輯器渲染、匯出量測與系統字型路徑恢復到經過驗收的 v5.9.3 架構，並讓操作結果提示更清楚、更精簡。

## 穩定性回退

- 桌面本機服務、renderer 來源確認與靜態資源載入恢復為 v5.9.3 已驗證的啟動路徑，同時保留原有安全檢查。
- 範例、歷史、設定、AI 翻譯與匯出介面恢復為穩定的既有載入及錯誤處理方式，不再依賴 v5.9.4 新增的延遲介面層。
- ClickSpark、自動寬度、編輯器渲染邊界與匯出就緒量測恢復為驗收過的實作。
- 系統字型重新使用原有查詢路徑，不再依賴 v5.9.4 的程序內快取、目錄服務與登錄檔更新邏輯。

## 結果回饋

- 全域結果提示按綠色成功、黃色警告、紅色錯誤區分，桌面版的歷史、手動存檔、設定、AI 翻譯、清理與匯出操作使用同一套狀態語意。
- 六語言 Desktop 與 Web Lite 結果文案同步精簡，省去句末標點以及不適合在一般介面直接顯示的內部錯誤細節、路徑與備份檔名。
- 一般動畫使用更明確的縮放與位移回饋；減少動態設定下仍只進行透明度切換。

## 相容性

- 本版本不變更歌詞文件、匯入歷史或手動存檔的資料格式，也不需要遷移使用者資料。
- v5.9.3 的請求邊界、單一執行個體保護、本機音訊解析、多平台歌曲匯入、AI 翻譯以及 PNG、WebP、JPG 匯出繼續保留。
- v5.9.4 的公開發布記錄與檔案仍保留在歷史頁面；v5.9.5 是新的建議穩定版本。

## 發布狀態

v5.9.5 已透過 GitHub Releases 公開發布。標籤原始碼、安裝版、可攜版、SPDX SBOM 與 SHA256SUMS 均可從該發布頁面取得。
