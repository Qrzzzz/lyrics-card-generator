# Lyrics Card Generator v3.0.0

Fecha de publicación: 2026-06-20

v3.0.0 añade un flujo de traducción de letras y un centro de ajustes unificado. En la interfaz en español, el resultado se genera en español. El idioma de destino sigue el idioma actual de la interfaz.

## Descargas

- `Lyrics Card Generator Setup 3.0.0.exe`
- `Lyrics Card Generator-3.0.0-portable.exe`
- `Lyrics Card Generator Setup 3.0.0.exe.blockmap`

## Cambios principales

- Nueva entrada de traducción en el editor de letras.
- Traducción al español después de elegir un estilo.
- Seis estilos de traducción disponibles.
- Nuevo cuadro de ajustes unificado.
- Vista previa inmediata al cambiar de idioma.
- Un único botón principal en el paso final.
- Menos espacio vacío en la pantalla final.

## Verificación

`npm run typecheck`, `npm run core:test`, `npm run build` y `npm run desktop:build` se completaron correctamente.

## Notas

- Windows puede mostrar un aviso de SmartScreen porque el build no está firmado.
- Al actualizar desde v2.x, los ajustes relacionados deben configurarse de nuevo.
