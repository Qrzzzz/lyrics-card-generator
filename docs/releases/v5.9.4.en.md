# Lyrics Card Generator v5.9.4 Release Notes

Release date: 2026-08-08

v5.9.4 is a behavior-preserving performance release. It reduces repeated startup work, unnecessary editor rendering, and expensive scans while adding recovery boundaries around the newly deferred paths.

## Startup and resource loading

- Streamlines packaged local-server orchestration, renderer-origin validation, and static-asset caching while retaining the existing security checks.
- Places clearer limits around asynchronous data and inactive-surface work so content that is not in use does not participate in the current interaction.
- Examples, History, Settings, AI translation, and Export remain demand-loaded and do not add work to the initial screen.

## Editing and export performance

- ClickSpark no longer runs an animation-frame loop while idle; its trigger and visible behavior remain unchanged.
- Auto-width measurement reuses one host, and lyrics input performs less viewport work and fewer component commits.
- Export-readiness measurements coalesce duplicate requests instead of repeating geometry reads for the same state change.
- Render boundaries isolate closed and inactive surfaces so long lyrics input and AI streaming do not repeatedly render unrelated regions.

## Deferred surfaces and system fonts

- Each deferred surface has a local error boundary. If its first chunk request fails, the main editor stays usable and the user can close, go back, or retry.
- Retry creates a new `React.lazy` generation and invokes the loader again instead of reusing React's cached rejected promise.
- The system-font list uses an in-process cache with concurrent-request deduplication. Hot requests start no new PowerShell scan, and four concurrent cold requests share one scanner process.
- Font-directory changes still invalidate immediately. Registry-only registrations, removals, and display-name changes now invalidate the cache within a maximum of five minutes.

## Release status

v5.9.4 is publicly available through GitHub Releases. The tagged source, installer, portable build, SPDX SBOM, and SHA256SUMS are available from that release page.
