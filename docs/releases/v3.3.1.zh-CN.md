# Lyrics Card Generator v3.3.1 发布说明

发布日期：2026-06-27

v3.3.1 是 v3.3.0 后的 bugfix 版本，主要修复卡片背景中“细网格背景”开关的显示问题。

## 修复内容

- 修复开启“细网格背景”后，卡片背景中出现两层网格叠加的问题。
- 修复关闭“细网格背景”后，卡片背景仍残留一层网格的问题。
- 现在“细网格背景”开关会准确控制卡片内部网格显示；关闭后预览和导出图片中都不会再显示卡片内部细网格。
- 应用主界面的背景纹理不受影响。

## 验证

- 验证竖版卡片中开启 / 关闭“细网格背景”的预览效果。
- 验证横版卡片中开启 / 关闭“细网格背景”的预览效果。
- 验证导出的 PNG 与预览一致。
- 执行 `npm run typecheck`、`npm run build`。
