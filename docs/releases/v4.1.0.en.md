# Lyrics Card Generator v4.1.0 Release Notes

Release date: 2026-07-02

v4.1.0 refactors the visual hierarchy of the style panel. It does not change lyric-card rendering, the export DOM, the left/right layout, or the settings state shape. Instead, it separates visual scheme choices from ordinary parameter controls: font schemes keep their card-based treatment, while font size, line height, alignment, toggles, crop, colors, and detail controls now read as continuous setting rows.

## Main Updates

- Section now defaults to a plain section and supports `plain`, `card`, and `subtle` container levels.
- Added SettingRow for font size, line height, size, color, crop, and other ordinary scalar settings.
- ToggleRow no longer looks like an independent card while preserving full-row click behavior, switch semantics, keyboard focus, and accessibility state.
- Layout mode and similar horizontal selectors keep their original segmented treatment for readability.
- The font scheme and export areas no longer add an extra outer card border.
- Font preset cards are now fully clickable; users no longer need to target the small apply button.
- NetEase search placeholders are localized with language-specific popular song examples.
- The stepper header uses automatic height and no longer shows the small secondary hint line.
- Language-change save notifications now use the newly selected language, and custom-size auto height defaults on.

## Scope

- The right-side Preview, export DOM, lyric-card rendering logic, and settings state structure are unchanged.
- Exported PNG output is not intentionally changed by this panel refactor.
- OptionCard remains reserved for visual scheme or preset selection, not ordinary scalar controls.
