# Lyrics Card Generator v6.8.0 Release Notes

Release date: 2026-10-16.

v6.8.0 reorganizes Step 2 into Cleanup, Bilingual and Review workspaces with unified tool search and a Ctrl+K command palette, preserving the existing editor and business logic.

- Cleanup tools are directly visible: blank lines, paste cleanup, LRC, line merging, paragraph tags, keep selection and separators. Bilingual groups translation, AI, alternating split, formatting and column swap.
- Review moves into the sidebar with alignment, unusual characters, duplicates, long lines and export limits. Every reported issue can be located; repeated lyrics are never automatically removed.
- The command bar concentrates undo, redo, fetch, AI and search, with selection-based contextual actions. Names, keywords and multilingual synonyms share one registry. Destructive actions retain preview and confirmation.
- Retains the approximate two-thirds editor and one-third tools split, shared bilingual scrolling and readable text widths. Adds sidebar collapse and narrow-window drawers while reusing selection anchors, undo, AI pages and autosave.
