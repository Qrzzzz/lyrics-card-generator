# Lyrics Card Generator v3.7.1 發布說明

發布日期：2026-06-30

v3.7.1 是一次介面控制元件標準化版本，不引入 v3.8.0 規劃中的動效升級。這次更新聚焦於統一開關、選項卡片、分段控制與設定面板基礎控制元件，同時改善可及性與鍵盤 / 焦點行為，為後續 v3.8.0 的動效升級打基礎。

## 改進

- 統一樣式面板、歌詞輸入、歌曲資訊與設定中的開關控制元件，讓切換狀態、停用狀態與視覺回饋更一致。
- 將語言選擇等單選項整理為統一的選項卡片，並將版面模式、網格密度、邊框 / 滿幅等緊湊選擇整理為一致的分段控制。
- 統一設定面板中常用輸入框、文字區域、下拉選擇與操作按鈕的外觀與互動回饋，讓不同區塊的控制元件風格更連貫。

## 可及性與一致性

- 改善常見控制元件的鍵盤可用性、焦點可見性、標籤呈現與停用態回饋，減少不同面板之間的互動差異。
- 收斂部分開關顏色與主題分支樣式，改為更多依賴既有主題 token，以便在深色、淺色、Acrylic 與自訂主題下保持更穩定的表現。
- 本次僅整理控制層與互動基礎，不包含新的 v3.8.0 動效系統，也不改變匯出結果、設定結構或既有功能流程。

## 驗證

- npm run typecheck
- npm run core:test
- npm run build
