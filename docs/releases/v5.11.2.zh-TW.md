# Lyrics Card Generator v5.11.2

> 狀態：已透過 GitHub Releases 公開發布。

## 多行標題修正

- 原本「標題允許兩行」選項已在六種介面語言中統一更名為「標題允許多行」，實際行為不再限制為兩行。開啟後，直式歌詞卡與純音樂卡都能完整顯示三行以上標題；關閉時仍維持單行省略。
- 直式歌詞卡的自動高度現在會將標題行數納入估算，避免長標題占用正文空間或在匯出時被裁切。
- 固定 1:1 的純音樂卡會為多行歌曲資訊動態預留高度，並在空間不足時縮小封面，防止標題、歌手或專輯資訊越界。橫式原有的實測多行版面經審計無須修改；桌面版與 Web Lite 共用相同行為。
