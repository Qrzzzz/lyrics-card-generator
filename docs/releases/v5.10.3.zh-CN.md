# Lyrics Card Generator v5.10.3

> 状态：已通过 GitHub Releases 公开发布。

这是一次面向可访问性、供应链与跨端质量门禁的维护版本。产品界面与导出设计保持不变，同时将此前只能依靠人工检查的关键边界纳入可重复验证。

## 更新重点

- 修复 Web Lite 中重复、嵌套的主地标，并让 axe 自动化门禁覆盖相关可访问性规则。
- 更新生产与构建依赖，加入带理由和到期时间的依赖告警例外、Release SBOM 与 CI／Release 阻断策略。
- 在仓库、Web Lite、GitHub Pages、桌面服务器、安装版和便携版中完整附带 Source Han Sans／Serif 的 OFL 许可文本。
- 新增持续渲染回归、定时长卡构图基准、Electron 运行时静态分析与风险边界覆盖率，以及 Firefox／WebKit 冒烟矩阵。

## 验证

本版本通过类型检查、代码检查、依赖与字体许可策略、Chromium 可访问性、Firefox／WebKit 冒烟、生产渲染边界、Web Lite 完整回归、Electron 覆盖率、桌面交互、最终 Windows 制品 smoke、SBOM、校验和与 attestation 门禁。
