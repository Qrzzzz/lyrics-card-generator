# Lyrics Card Generator v3.2.0 Release Notes

> [!WARNING]
> This version `v3.2.0` contains unfixed bugs. It is not recommended to upgrade to this version.

Release date: 2026-06-23

## Settings Center & Personalization Update

- Rebuilt Settings as a six-tab center for General, Appearance, Background, Export, AI, and About.
- Added Spark Cursor control, three UI themes, UI font/accent/text controls, and readable-color safeguards.
- Added persistent solid, stretch, contain, cover, blur, and image-palette backgrounds while retaining album-dynamic mode as the default.
- Added Low, Standard, High, and Ultra default PNG quality settings.
- Added a one-time six-language chooser and changed startup to a blank editor.
- Moved `opposite` to the new Example picker and moved update/GitHub links to About.
- Added a shared app icon to the header and kept AI credentials in the existing secure store.

Validation: `npm run typecheck`, `npm run core:test`, `npm run build`, `npm run desktop:build`.
