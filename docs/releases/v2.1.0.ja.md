# Lyrics Card Generator v2.1.0 リリースノート

言語：[简体中文](./v2.1.0.zh-CN.md) · [繁體中文](./v2.1.0.zh-TW.md) · [English](./v2.1.0.en.md) · [Français](./v2.1.0.fr.md) · 日本語 · [Español](./v2.1.0.es.md)

## ダウンロードとインストール

GitHub Releases から該当するファイルをダウンロードしてください：

- インストーラー：`Lyrics Card Generator Setup 2.1.0.exe`
- ポータブル版：`Lyrics Card Generator-2.1.0-portable.exe`

通常利用にはインストーラー版を推奨します。一時的な試用、テスト、またはリムーバブルドライブからの実行にはポータブル版を選択してください。

> このビルドはコード署名されていません。Windows で SmartScreen 警告が表示される場合がありますが、未署名の個人アプリではよくある挙動です。

## 更新内容

v2.1.0 では、デスクトップ体験、横向きレイアウト、カスタムキャンバスサイズ、多言語 UI、ローカルメディア処理を重点的に改善しました。

### 追加

- Windows デスクトップアプリのパッケージングフローを追加しました。
- インストーラー版とポータブル版の 2 種類の配布形式を追加しました。
- ローカル MP3 / FLAC 解析を追加し、タイトル、アーティスト、アルバム、カバー、埋め込み歌詞の読み取りを試行します。
- Windows システムフォントの検出とカスタムフォント選択を追加しました。
- 簡体字中国語、繁体字中国語、英語、フランス語、日本語、スペイン語の UI 切り替えを追加しました。
- GitHub Releases 経由で更新を確認する入口を追加しました。

### 改善

- 安全領域、カバー列、コンテンツ列、フッター領域を基準に横向きレイアウトを再構築しました。
- 縦向きカスタムキャンバスで、実際の DOM 測定に基づく自動高さをサポートしました。
- 原文歌詞と翻訳のレイアウトを安定化し、現在の UI 言語に基づく原文 / 翻訳行の分割に対応しました。
- リモートカバーの書き出しを画像プロキシ経由に変更し、PNG 書き出し時のクロスオリジン失敗を減らしました。
- プラットフォームロゴをローカル SVG に移行し、PNG 書き出しがリモートアイコンに依存しないようにしました。

### 修正

- 一部のカスタムサイズで発生するコンテンツのはみ出しや不自然な余白を修正しました。
- 横向きカードでカバー、歌詞、フッター情報が互いに圧迫される問題を修正しました。
- 一部のリモートカバーがエクスポート PNG に正しく書き込まれない問題を修正しました。

## アップグレード時の注意

- 旧バージョンからのアップグレードでは、通常アンインストールは不要です。
- インストーラーが旧バージョンを上書きできない場合は、旧バージョンを終了してから再実行してください。
- ポータブル版が起動しない場合は、古いプロセスがバックグラウンドで残っていないか確認してください。

## 既知の制限

- 音楽プラットフォームのリンク解析、リモートカバーの読み込み、自動歌詞取得、更新確認にはインターネット接続が必要です。
- 自動歌詞取得はまだ実験的な機能です。結果が不完全または不正確な場合があります。利用権限を必ず確認してください。
- 現在のビルドはコード署名されていません。Windows SmartScreen 警告は、プログラムが必ず危険であることを意味しません。
