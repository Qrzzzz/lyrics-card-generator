# Lyrics Card Generator v6.8.0 發布說明

發布日期：2026-10-16。

v6.8.0 重整第二步歌詞工作台的工具導覽：整理、雙語、檢查三個工作區，統一工具搜尋與 Ctrl+K 命令面板，保留既有編輯與業務邏輯。

- 整理工具直接可見，保留空行、貼上清理、LRC、合併行、段落標籤、保留選取及分隔符。雙語區統一翻譯開關、AI 翻譯、交替拆分、格式化與交換原譯。
- 檢查整合至側欄，顯示雙欄對齊、異常字元、重複行、超長行及匯出限制，可定位所有問題，不會自動刪除重複歌詞。
- 頂部保留復原、重做、取得歌詞、AI 翻譯與搜尋，依選取範圍顯示操作；名稱、關鍵字與多語同義詞共用工具註冊表，危險操作先預覽確認。
- 保留約 2/3 編輯區、1/3 工具區、雙欄共用捲動及文字寬度約束；支援側欄收合與窄視窗抽屜，沿用選取、捲動錨點、復原、AI 頁面及自動儲存機制。
