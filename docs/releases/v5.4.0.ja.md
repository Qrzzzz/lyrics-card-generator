# Lyrics Card Generator v5.4.0 リリースノート

リリース日：2026-07-13

v5.4.0 では、6つの編集手順すべての上部構造を統一し、手順1を後続手順と同じコンパクトなワークベンチへ再構築しました。

## 主な更新

- 手順1でも手順2〜6と同じコンパクトな Stepper を使用し、現在の手順、全体ルート、「サンプル」「すべて消去」「設定」を1つの進行レールにまとめました。
- 手順1の重複した大きなアプリ見出しを削除し、Windows タイトルバーにはアプリ名、アイコン、バージョンを引き続き表示します。
- 最初のページを2列の共通ワークベンチへ変更し、進行レールが NetEase 検索とインポート用サイドバーを横断します。
- 曲情報、曲リンク、ローカル音源、手動編集を1つのサイドパネルへ統合し、既存の取り込み方法とアクセシビリティ上の意味は維持します。
- 最小デスクトップ幅1000pxでは320pxのサイドバーを使い、広いウィンドウでは360px、400pxへ拡張します。

## 変更範囲

- NetEase 検索、リンク解析、ローカル音源解析、曲情報の手入力、歌詞文書、AI 翻訳の動作は変更していません。
- 手順2〜6、リアルタイムプレビュー、PNG書き出し、設定データ、プロジェクト形式、Web Lite の共有動作は変更していません。

## 検証

- `npm run lint` / `npm run typecheck` / `npm run core:test` / `npm run build`
- `npm run web-lite:build` / `npm run web-lite:check` / `npm run web-lite:smoke`
- `npm run desktop:build` / `npm run desktop:interaction-test` / `npm run desktop:final-artifact-smoke`
- 1000×700、1023×700、1024×700、1280×900、1440×900、1920×1080 のデスクトップ回帰
