これは「スリム化」と「整理」に重点を置いたメンテナンスアップデートです。

本バージョンでは、大量のレガシーコードと未使用コードを削除し、肥大化していたエディタロジックを分割し、Windows デスクトップ版のビルドおよびパッケージングフローを整理しました。一般ユーザーにとってはコア機能に大きな変更はありません。今後の開発にとっては、プロジェクト構造がより明確になり、メンテナンスコストが低減します。

## 主な変更点

* 未使用コードと冗長なロジックを削除し、プロジェクトの負担を軽減。
* エディタ構造をリファクタリングし、UI とロジックの一部を独立したコンポーネントに分割。
* 既存のカードレイアウトアルゴリズムを維持し、コードクリーンアップが歌詞カードのレンダリングに影響しないように配慮。
* デスクトップ版のエクスポートパネルと PNG エクスポートコントロールを修正。
* デスクトップ版のフォントバンドル問題を修正し、内蔵フォントが正常に読み込まれるように改善。
* Windows デスクトップ版のビルドフローを整理。
* バージョン番号、ダウンロードファイル名、および関連バージョン情報を `1.1.0` に更新。

## ダウンロード

* インストーラー版：`Lyrics Card Generator Setup 1.1.0.exe`
* ポータブル版：`Lyrics Card Generator-1.1.0-portable.exe`

## 注意事項

本バージョンは引き続きコード署名されていません。Windows が SmartScreen 警告を表示することがありますが、これは未署名の個人アプリケーションでは一般的な現象です。
