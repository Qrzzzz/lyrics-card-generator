# Lyrics Card Generator v5.5.0 發布說明

發布日期：2026-07-14

v5.5.0 為直式自訂歌詞卡新增可選的自動寬度，讓長度相近的歌詞在不過度拉寬畫布的前提下獲得更舒適的換行。

## 主要更新

- 在「直式 → 自訂 → 歌詞」中新增預設關閉的「自動寬度」。開啟後寬度滑桿顯示即時像素值並暫時停用；關閉後保留最後計算寬度，方便手動微調。
- 使用隱藏的原尺寸排版探針與最終字型測量瀏覽器真實視覺行，不依字數估算，也不使用縮放後的可見預覽。
- 正文與譯文分別檢查中日韓字素、西文單字與混合文字，避免下一個視覺行只留下 1–2 個字或短詞。
- 全域候選寬度評分搭配主體行抽樣與離群降權，避免極短副歌或單條超長正文／譯文把卡片拉到最大寬度；譯文參與孤行限制，但不主導整體寬度。
- 內容、字型、字級與譯文變更會在 300ms 防抖後重新求解，並以穩定門檻避免輸入時反覆跳動。
- 自動寬度先穩定，自動高度再依新寬度測量；中間狀態禁止匯出，固定高度不足時仍由真實溢出檢查阻止匯出。

## 版本範圍

- 自動寬度僅支援直式、自訂尺寸與歌詞模式；固定比例、橫式與純音樂模式維持原有行為。
- 舊狀態缺少自動寬度欄位時預設關閉；在直式、橫式、固定比例、自訂尺寸與純音樂之間往返時會儲存並還原對應尺寸歷史。
- 桌面版與 Web Lite 共用相同的測量、評分、自動高度協調與匯出安全路徑。
