# Lyrics Card Generator v4.3.0 リリースノート

リリース日：2026-07-05

このバージョンでは、サンプル曲フロー、レイアウトコントロール、Explicit バッジのレンダリング、および最終書き出しステップを更新しました。

## 主な更新

- サンプル曲ダイアログをレスポンシブグリッドに再構築し、ウィンドウ幅に応じて 2 列または 3 列で表示するようにしました。
- 曲ごとの翻訳言語ボタンを削除し、サンプルは現在の UI 言語に一致する翻訳を読み込むようになりました。
- 英語 UI で英語の原詞を選択した場合、翻訳フィールドは空欄になります。
- オプションの曲フィールド `explicit: boolean` を追加し、ビジュアル詳細スイッチでバッジを直接制御できるようにしました。
- プレビューおよび書き出し PNG 出力の両方で、タイトルの横にインライン E バッジを表示します。
- 初期サイズモードをカスタムに固定し、自動高さを有効化しました。
- コンテンツタイプとテキストカラーをセグメントスライダーコントロールに変更しました。
- 対応するモードが選択されている場合のみ、プリセットとカスタムテキストカラーオプションを表示します。
- ビジュアル詳細トグルを 2 列レイアウトに再配置しました。
- 「完了して書き出し」を最終ステップナビゲーションの右側に移動し、「戻る」ボタンと高さを揃えました。
- フレームとシャドウのレンダリングパスおよびそのビジュアルコントロールを削除しました。

## 検証

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:build
