# Lyrics Card Generator v5.0.0 リリースノート

リリース日：2026-07-12

v5.0.0 では最初の 2 ステップを、曲の取り込みに集中したフローと長い歌詞向けワークスペースへ再構築し、編集ビューポート、歌詞ドキュメント、書き出しカードを完全に分離しました。

## 主な更新

- ステップ 1 は NetEase Cloud Music 検索を中心に再構成し、検索欄と候補一覧を拡大しました。リンク解析、ローカル音声、手動メタデータはコンパクトな補助列に残ります。
- ステップ 2 は「曲の概要 + 歌詞ドキュメント + 編集ツール」の 3 列ワークスペースになりました。原文と翻訳は同じ高さの 2 列で、1 本のメインスクロールを共有します。
- 歌詞ビューポートに標準、拡張、アプリ内集中の 3 状態を追加し、ドラッグ吸着、ダブルクリック復元、Esc での復帰、キーボード操作に対応しました。
- ステップ 1 と 2 ではカードプレビューとモバイル用プレビュー切替を表示しません。従来のカード設計とプレビューはステップ 3 から復帰します。
- 常時マウントされる画面外ホストから書き出すため、編集領域の高さやスクロール位置が PNG の論理サイズへ影響しません。
- 書き出し上限を空でない論理行 36 行に設定しました。翻訳有効時は原文と翻訳を別々に数え、空行と表示上の折り返しは数えません。インストゥルメンタルモードは対象外です。
- 縦向き自動高さの上限を 6400px に拡張しました。固定比率または横向きカードで実際に溢れる場合は、無言で切り取らず書き出しを停止します。
- 6 言語の文言、フォーカス、アクセシビリティの意味付けを整備し、Web Lite の既存機能範囲を維持しました。

## 検証

- npm run core:test
- npm run build
- npm run web-lite:build / web-lite:check / web-lite:smoke
- npm run desktop:build / desktop:interaction-test
- 1000×700、1023×700、1024×700、1280×900、1440×900 のデスクトップ回帰
