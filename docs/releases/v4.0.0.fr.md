# Notes de version de Lyrics Card Generator v4.0.0

Date de publication : 2026-07-01

v4.0.0 transforme la première étape de choix de morceau en recherche NetEase Cloud Music. Les utilisateurs peuvent saisir un titre, un artiste ou un album, choisir un résultat en direct, puis importer automatiquement les métadonnées, la pochette et les paroles disponibles. Les liens, l’audio local, l’édition manuelle, la traduction IA, les thèmes et l’export PNG restent disponibles.

## Principales nouveautés

- Ajout de la recherche NetEase Cloud Music comme première entrée « Choisir un morceau ».
- Affichage de candidats en direct avec titre, artiste, album et durée pendant la saisie.
- Sélection avec les flèches, import avec Entrée et import au clic souris.
- Import du titre, de l’artiste, de l’album, de la pochette et des paroles NetEase disponibles.
- Un échec de récupération des paroles ne bloque pas l’import des métadonnées.

## Compatibilité

- Les entrées de liens Spotify, Apple Music, NetEase Cloud Music et QQ Music restent disponibles.
- L’analyse des métadonnées et paroles intégrées MP3 / FLAC locales reste disponible.
- L’édition manuelle, les paroles, la traduction IA, l’extraction de couleurs, les styles et l’export PNG sont inchangés.

## Conseils d’utilisation

- Si les résultats sont imprécis, recherchez avec le titre et l’artiste.
- La recherche NetEase et la récupération des paroles nécessitent Internet.
- Les paroles récupérées automatiquement peuvent être incomplètes ; vérifiez-les avant l’export.

- npm run typecheck
- npm run music-search:normalize-test
- npm run parse:test
