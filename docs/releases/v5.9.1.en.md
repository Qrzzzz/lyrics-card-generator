# Lyrics Card Generator v5.9.1 Release Notes

Candidate notes prepared: 2026-08-04

v5.9.1 adds explicit manual archives to the Windows desktop app. These notes describe a local release candidate and do not claim that the version has been published. This is not autosave or full document version history.

## Manual save and load

- The desktop header has a new icon-only Manual Save action between History and Clear Content. The first save creates a record; saving after further edits updates the same ID while preserving its original creation time.
- An unchanged document causes no disk write, and a rapid double-click produces only one write. Blank documents, AI work, and active document-replacement transactions cannot be saved. A failed write never marks the current revision as saved.
- History can filter manual saves separately and load them locally with “Load save,” without a network request or file-relocation action. Deleting the bound record or clearing history removes the binding.
- Saving after loading a manual archive updates that record. A normal import, another history replay, a built-in example, clearing the editor, or uploading a local cover starts a new save session. If the record was removed outside the current view, that save only drops the stale binding and never silently creates a replacement.

## Secure storage and migration

- History schema v2 migrates legacy v1 records losslessly in their original order. Loading the migrated data again is idempotent.
- Manual archives retain only semantic song content: source, title, artist, album, lyrics, translation, the translation toggle, and safe remote URLs. They never store styles, settings, exported images, local paths, API keys, image binaries, Base64, blob URLs, or data URLs.
- Electron’s main process owns IDs and timestamps. Separate create and update IPC paths enforce field limits, a 512 KiB record cap, serialized atomic writes, and a shutdown drain.

## Scope and verification

- New interface copy is complete in Simplified Chinese, Traditional Chinese, English, French, Japanese, and Spanish.
- Web Lite keeps its existing interface and behavior, with no browser-side manual-save substitute and no new `Ctrl+S` shortcut.
- Store, migration, secure IPC, UI contract, packaging, and real Electron interaction regressions cover creation, in-place update, unchanged skips, binding lifecycle, write retry, and shutdown-drain semantics.
