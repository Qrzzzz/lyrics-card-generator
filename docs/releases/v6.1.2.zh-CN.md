# Lyrics Card Generator v6.1.2

> 状态：已通过 GitHub Releases 正式发布。

## 原生双字体方案

- 自定义方案将原先分开的中日韩与西文字体入口合并为一个“编辑方案”入口。
- Windows 桌面版打开归属于主窗口的原生 WinForms 方案窗口；两个“选择”按钮分别调用系统 `FontDialog`，不创建 Electron 或 HTML 自绘字体选择窗口。
- 方案窗口同时展示两种当前字体与预览。“取消”整体放弃草稿；“应用字体方案”一次提交两种字体，随后将焦点恢复到主界面入口。

## 字体完整性与兼容性

- Windows 系统 `FontDialog` 直接展示系统字体，不再经过应用内的字体名称分类；非 Windows 桌面版与浏览器回退中，字体类别只影响推荐项和预览文字，所有已枚举字体都可用于两种角色。
- 原生桥接继续使用严格字段校验、主窗口句柄模态归属和受限结果解析；非 Windows 桌面回退保留隔离的最小权限 IPC。
- 自定义方案仍沿用现有预览、导出和持久化数据结构，不改变歌词卡渲染规则。
