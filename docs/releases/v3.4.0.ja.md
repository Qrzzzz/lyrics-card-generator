# Lyrics Card Generator v3.4.0 リリースノート

リリース日：2026-06-28

v3.4.0 では、「レイアウト」ステップをコンテンツ種別中心に整理し、背景グリッドを「視覚細部」で設定できるオプションにしました。

## 変更

- 「レイアウト」ステップでは、先にコンテンツ種別を選び、その後で利用できるレイアウト、サイズ、文字組みオプションを表示します。
- インストゥルメンタル / 歌詞なしカードは、カバーと曲情報を安定して表示するため縦向き 1:1 出力に固定されます。
- 「レイアウト」ステップから未使用のインストゥルメンタル説明入力を削除しました。
- 背景グリッドはデフォルトでオフになり、「視覚細部」で「疎 / 中 / 密」の密度を選べます。

## 修正

- インストゥルメンタル / 歌詞なしモードで横向きカードを選択できていた問題を修正しました。
- インストゥルメンタル / 歌詞なしモードで互換性のない非正方形サイズを使えていた問題を修正しました。
- 前バージョンの背景グリッドが過密に見える問題を修正しました。

## 検証

- インストゥルメンタル / 歌詞なしモードがすぐに縦向き 1:1 に切り替わることを確認しました。
- インストゥルメンタル / 歌詞なしモードで横向きボタンがグレー表示になり、クリックできないことを確認しました。
- 背景グリッドがデフォルトでオフであり、オンにすると三段階の密度を切り替えられることを確認しました。
- `npm run typecheck`、`npm run core:test`、`npm run build` を実行しました。
