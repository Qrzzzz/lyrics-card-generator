# Notes de version de Lyrics Card Generator v3.3.0

Date de sortie : 2026-06-25

La v3.3.0 ajoute l’analyse des liens de morceaux Spotify. Vous pouvez désormais coller un lien de morceau Spotify, remplir automatiquement le titre, l’artiste et la pochette, puis continuer à utiliser l’édition de cartes de paroles, la palette de pochette et le flux d’export existants.

## Analyse des liens Spotify

- Analyse des liens de morceaux Spotify.
- Prise en charge de `open.spotify.com/track/...`, `open.spotify.com/intl-.../track/...`, `open.spotify.com/embed/track/...` et des liens courts Spotify courants.
- Affichage du logo Spotify pour les morceaux analysés.
- La récupération automatique des paroles continue d’utiliser la recherche expérimentale existante.
- Correction des coches de fin qui apparaissaient immédiatement sur les étapes suivantes au lancement ; seules les étapes déjà parcourues affichent désormais l’état terminé.

## Notes

- Cette version ne récupère pas les paroles depuis Spotify.
- Cette version ne nécessite pas de compte Spotify, d’OAuth ni de clé API.
- Si l’analyse automatique échoue, vous pouvez toujours saisir manuellement le titre, l’artiste, la pochette et les paroles.

Validation : `npm run typecheck`, `npm run parse:test`, `npm run core:test`, `npm run build`, ainsi que des vérifications locales d’API pour l’analyse Spotify, le schéma de l’endpoint de paroles et l’asset SVG Spotify.
