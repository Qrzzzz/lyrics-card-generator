# Lyrics Card Generator v5.11.2

> Estado: publicado públicamente mediante GitHub Releases.

## Correcciones de títulos multilínea

- La antigua opción «Permitir título de dos líneas» pasa a llamarse «Permitir título multilínea» en los seis idiomas y deja de estar limitada a dos líneas. Al activarla, las tarjetas verticales con letras o instrumentales pueden mostrar títulos de más de dos líneas; al desactivarla, se mantiene el truncado en una sola línea.
- La altura automática de las tarjetas verticales ahora tiene en cuenta las líneas del título, evitando que un título largo reduzca el espacio de las letras o se recorte al exportar.
- Las tarjetas instrumentales fijas de 1:1 reservan dinámicamente altura para la información multilínea y reducen la portada cuando falta espacio, manteniendo dentro de los límites el título, el artista y el álbum. Se auditó el diseño horizontal multilínea medido existente y no requirió cambios; Escritorio y Web Lite comparten el mismo comportamiento.
