# Lyrics Card Generator v6.1.4

> 状态：已正式发布。

## 可搜索的共享字体浏览器

- Windows 原生字体方案窗口现在让中日韩与西文字体共用一个系统字体浏览器，切换角色即可为对应位置选择字体。
- 搜索框会即时筛选已安装字体，每一项直接显示字体名称与字形预览，并提供结果数量和空结果状态。
- 支持交换两种字体、恢复打开窗口时的方案以及键盘搜索和选择；只有确认提交后的选择才会应用到当前方案。

## 原生桥接可靠性

- 完整 WinForms 辅助脚本改由标准输入传给 PowerShell，避免复杂界面脚本超过 Windows 命令行长度限制。
- 保留主窗口模态归属、受限输出解析、输入字段校验与异常回退，不改变非 Windows 桌面版、浏览器选择器或歌词卡渲染规则。
