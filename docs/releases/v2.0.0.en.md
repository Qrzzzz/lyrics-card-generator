# Lyrics Card Generator v2.0.0 Release Notes

Release date: 2026-06-18

v2.0.0 is a focused desktop and card-generation improvement release. It covers landscape layout, custom-size height calculation, local audio parsing, Windows system fonts, PNG export, update checks, and Windows build assets.

## Highlights

- Reworked the landscape card layout with a safe area for cover art, lyrics, song metadata, and footer information.
- Custom portrait sizes now recalculate height from real DOM measurement.
- Added multilingual lyric splitting and Chinese translation cleanup tools.
- Added local MP3 / FLAC parsing for title, artist, album, cover art, and embedded lyrics where available.
- Added Windows system font selection and safer external-link opening in the desktop app.
- Update checks now request GitHub Releases through a local Next API route.

## Release Assets

- `Lyrics Card Generator Setup 2.0.0.exe`
- `Lyrics Card Generator-2.0.0-portable.exe`
- `Lyrics Card Generator Setup 2.0.0.exe.blockmap`
