# Lyrics Card Generator v5.8.0 Release Notes

Release date: 2026-07-18

v5.8.0 completes a full rebuild of the step-two Lyrics workspace. The editor remains the visual and operational focus, with a narrow command bar above and four stable tabs on the right. The main steps 1–6 Stepper, later settings steps, and existing export boundaries are unchanged.

## Narrow command bar and stable sidebar

- The approximately 44 px command bar shows the active tab, active original/translation column, and cursor line. It also provides operation-level undo/redo, blank-line cleanup, Find, AI translation, the 36-line budget, and the sidebar toggle.
- The right sidebar now has four stable tabs: Cleanup, Translation, Review, and Source. Switching tabs does not reset editor scroll, selection, or the logical-line anchor.
- Source continuously holds the song summary, source status, and lyric retrieval. AI translation and lyric retrieval no longer replace the entire sidebar unpredictably.

## Explicit scope and undoable text processing

- Deterministic transforms affect the selection when one exists; otherwise they affect the active column. The interface clearly reports both the scope and the concrete result.
- Aligned two-column blank cleanup must be selected explicitly and removes a row only when the original and translation are both blank at the same index, preventing alignment drift.
- Paste cleanup, LRC timeline/metadata cleanup, Find and Replace, selected-line merging, and previewable section-label cleanup are included. Risky actions require a preview or confirmation, every change can be undone immediately, and no-op results are stated clearly.

## Translation, review, and continuous editing

- Translation gathers the existing AI workflow, alternating-lyrics split, Chinese translation formatting, original/translation swap, and two-column alignment checks with issue location.
- Review shows the 36-line budget, column line-count difference, long lines, consecutive duplicate lines, and invisible characters with clickable locations. Repeated choruses are reported but never deleted automatically.
- Original and translation continue to share one main scroll, with cursor line, selection restoration, and the resizable/collapsible desktop sidebar preserved. Narrow screens use an overlay drawer instead of squeezing the reading area.
- All new visible copy covers the existing six interface languages and follows the existing keyboard, ARIA, reduced-motion, theme, and accent systems.
