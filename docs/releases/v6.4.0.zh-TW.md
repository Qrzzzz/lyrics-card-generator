# Lyrics Card Generator v6.4.0

Windows x64: `Lyrics.Card.Generator.Setup.6.4.0.exe`.

## 新增得意黑字型預設

- 桌面版和 Web Lite 新增得意黑（Smiley Sans）預設，可直接用於歌詞卡預覽與匯出。
- 沿用上一版本內建字型，無需額外安裝；桌面版字型選擇隨卡片設定儲存與還原。
