# Lyrics Card Generator v6.7.0 发布说明

发布日期：2026-10-07。

v6.7.0 新增流光渐变布局种子，同一套封面配色可以尝试、保存和复现不同的色块排布，并改善纯色候选推荐与透明封面取色。

## 流光渐变布局

- 在背景设置中输入“布局种子”，或点击“换一种布局”调整色块位置与流动方向；“恢复默认布局”回到种子 0。
- 更换布局保留封面配色与各颜色的分配权重。相同封面、种子和画布比例可复现构图；提高同一比例的导出分辨率不会重排。
- 布局种子随桌面草稿保存与恢复，切换纯色后再切回渐变也保留选择。

## 封面取色改进

- 修复相近颜色被拆分后影响纯色推荐排序的问题，按合并后的有效占比推荐主要颜色。
- 先合并相近颜色再过滤小区域，减少封面候选色遗漏。
- 抑制近乎透明的杂色像素；完全透明区域的隐藏颜色和原图分辨率不再改变默认布局种子。
- 复用短期内同一封面的分析结果，并在颜色聚类收敛后提前结束计算。

## 使用说明

- 色块移动后的重叠会改变局部混色；单色封面不同布局的视觉差异可能较小。旧草稿缺少布局种子时使用默认布局。
- 取色稳定性调整后，旧版草稿的默认渐变可能重新构图；手动选择的纯色保持原值。
