# Lyrics Card Generator v6.8.7

**2026-10-25**

Includes all fixes prepared for 6.8.6 and pins Electron from 42.11.3 to 42.11.16 to address compromised intermediate certificate trust, GHSA-jr5w-w6x2-84p9. The original 6.8.6 tag and failed run remain intact; security gates remain enforced.

Softens preview and click decorations and pins the browser test environment with earlier failure diagnostics.

Preserves current default switches, saved preferences and reduced-motion support. Preview tilt, movement, highlights and click sparks are subtler. Window acceptance covers the work area, DPI and compact controls on one display; multiple displays are outside this version’s scope.

Browser CI uses a digest-pinned image matching the lockfile, checks actual versions and startup, and preserves context before tests start. Natural-expiry recovery and performance observations are recorded separately from local tests.

Updates Zod and undici to address new production dependency advisories while preserving request validation, error responses and security gates.
