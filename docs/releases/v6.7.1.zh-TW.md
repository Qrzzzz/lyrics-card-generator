# Lyrics Card Generator v6.7.1 發布說明

發布日期：2026-10-08。

v6.7.1 將漸層隨機入口明確為「隨機產生新背景」，一鍵使用與目前值不同的隨機種子，立即更新色塊佈局。

## 隨機產生新背景

- 在「背景 → 流光漸層」中，點擊種子輸入框上方的「隨機產生新背景」。按鈕支援滑鼠與鍵盤操作，並同步顯示新種子。
- 保留封面配色、種子輸入、恢復預設佈局與草稿儲存功能。同一封面、種子與畫布比例仍可重現佈局。
