# Notes de version de Lyrics Card Generator v5.4.0

Date de publication : 2026-07-13

La v5.4.0 achève l’unification de l’interface des six étapes et reconstruit la première comme le même espace de travail compact que la suite du parcours.

## Nouveautés principales

- L’étape 1 utilise désormais le même Stepper compact que les étapes 2 à 6, avec l’étape active, le parcours complet, Exemples, Tout effacer et Paramètres dans un seul rail.
- Le grand en-tête dupliqué disparaît de l’étape 1 ; la barre de titre Windows conserve le nom, l’icône et la version de l’application.
- La première page devient un espace à deux colonnes dont le rail couvre la recherche NetEase et la barre latérale d’importation.
- Les informations du morceau, les liens, l’audio local et la saisie manuelle sont regroupés dans un seul panneau, sans retirer de méthode d’importation ni de sémantique d’accessibilité.
- À la largeur minimale de 1000px, la barre latérale reste à 320px, puis passe à 360px et 400px sur les fenêtres plus larges.

## Périmètre

- La recherche NetEase, l’analyse des liens et de l’audio local, la saisie manuelle, le document de paroles et la traduction IA ne changent pas.
- Les étapes 2 à 6, l’aperçu, l’export PNG, les réglages, les projets et le comportement Web Lite partagé ne changent pas.

## Vérification

- `npm run lint` / `npm run typecheck` / `npm run core:test` / `npm run build`
- `npm run web-lite:build` / `npm run web-lite:check` / `npm run web-lite:smoke`
- `npm run desktop:build` / `npm run desktop:interaction-test` / `npm run desktop:final-artifact-smoke`
- Régressions de fenêtres 1000×700, 1023×700, 1024×700, 1280×900, 1440×900 et 1920×1080
