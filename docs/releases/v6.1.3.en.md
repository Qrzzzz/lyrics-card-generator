# Lyrics Card Generator v6.1.3

> Status: officially released.

## Single-window two-font selection

- The native Windows WinForms scheme window now contains CJK and Latin font lists directly instead of opening a separate system `FontDialog` for each role.
- Both lists enumerate installed system families without inferring language coverage from font names, and vertical aliases are excluded.
- Both current selections and live previews remain visible. Cancel discards the whole draft, while “Apply Font Scheme” still commits both families atomically with one confirmation.

## High-DPI clarity and compatibility

- The native helper enables Per-Monitor V2 DPI awareness before creating WinForms UI, preventing Windows from bitmap-stretching a 96-DPI window.
- The 96-DPI baseline layout is scaled natively for the actual DPI of the main window's display, improving control and text clarity at scale factors such as 125%, 150%, and 175%.
- The native bridge retains bounded field validation, main-window handle ownership, and restricted result parsing. The non-Windows desktop fallback, browser picker, and lyric-card rendering rules remain unchanged.
