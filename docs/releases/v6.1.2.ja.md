# Lyrics Card Generator v6.1.2

> 状態：GitHub Releases で正式公開済みです。

## ネイティブの 2 フォント構成

- CJK 用と欧文用に分かれていたカスタムフォント入口を、1 つの「構成を編集」に統合しました。
- Windows ではメインウィンドウを所有元とするネイティブ WinForms 構成ウィンドウを開き、2 つの選択ボタンからそれぞれシステム `FontDialog` を呼び出します。Electron や HTML で描画したフォント選択画面は作成しません。
- 構成ウィンドウには現在の両フォントとプレビューを表示します。キャンセルは下書き全体を破棄し、「フォント構成を適用」は両方を一度に確定してメイン入口へフォーカスを戻します。

## フォント一覧の完全性と互換性

- Windows の `FontDialog` はアプリ内の名前分類を介さず、システムフォントを直接表示します。非 Windows デスクトップ版とブラウザのフォールバックでは、カテゴリはおすすめ項目とプレビュー文字だけに影響し、列挙された全フォントを両方の役割で選択できます。
- ネイティブ橋渡しは厳格な値検証、メインウィンドウハンドルによるモーダル所有、制限付きの結果解析を維持します。非 Windows デスクトップ版のフォールバックは独立した最小権限 IPC を保ちます。
- カスタム構成は既存のプレビュー、書き出し、永続化データ構造を引き続き使用し、歌詞カードの描画規則は変更しません。
