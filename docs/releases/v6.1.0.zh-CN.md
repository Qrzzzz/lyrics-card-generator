# Lyrics Card Generator v6.1.0

> 状态：已通过 GitHub Releases 正式发布。

## Electron 原生字体选择窗口

- Windows 桌面版将自定义字体选择器从应用内部弹层迁移为带系统标题栏的 Electron 原生子窗口。
- 字体搜索、推荐字体、完整系统字体列表与逐项字样预览全部保留，并新增随悬停或键盘焦点变化的放大预览。
- 选择字体后仍先更新自定义方案草稿和右侧真实歌词卡预览，只有“保存为当前方案”才会提交更改。

## 安全与兼容性

- 字体窗口拥有独立、最小化的 IPC 身份，不能调用主窗口的文件、历史记录或 AI 权限。
- Web Lite 与普通浏览器继续使用兼容的应用内回退界面。
