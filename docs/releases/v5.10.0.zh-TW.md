# Lyrics Card Generator v5.10.0

> 狀態：本機候選版本，尚未發布。

此版本重構取色卡片背景：不再依賴固定曲線或簡單角落色塊，而是從封面的空間色彩關係產生穩定、連續且會隨卡片比例重新構圖的柔性色場。

## 更新重點

- 感知調色盤保留色彩的位置、面積、明暗與顯著度，並由封面內容產生穩定種子。
- 空間錨點會依直式、橫式與超長畫布重新配置，再融合為連續色場。
- 新約束抑制平行色帶、封閉輪廓、重複 S 曲線、髒色與突兀亮斑。
- 歌詞安全區採用局部明度與對比度控制，不再替整張圖統一加黑。
- 編輯預覽、匯出與 Web Lite 共用確定性渲染路徑，同一封面可穩定重現。

## 驗證

已涵蓋調色盤、空間色場、構圖矩陣、文字對比度、Web Lite 視覺回歸與桌面成品驗證。
