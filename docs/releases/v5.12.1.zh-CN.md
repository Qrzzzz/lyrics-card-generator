# Lyrics Card Generator v5.12.1

> 状态：已通过 GitHub Releases 公开发布。

## 仅保留选中文本

- 第二步顶部工具栏首位新增“仅保留选中”，以轻量强调色显示；没有选中文本时按钮保持禁用。
- 在原文或译文栏中选择一段文本后执行此操作，会精确保留所选字符并删除当前栏的其余内容，不会改动另一栏。
- 操作沿用现有的选区恢复和撤销／重做历史，处理后仍会选中保留下来的文本，便于继续编辑或立即撤销。
