# Lyrics Card Generator v6.1.8

> Status: released.

## Drafts must be resolved explicitly

- Step one's Manual Adjustment action now sits at the lower right of the song-information panel. Its entry, summary, and editor continue to share one panel.
- While manual song information is unsaved, neither the top step rail nor Next can leave the current page. The app asks the user to save or cancel and moves focus to Cancel.
- Custom font schemes use the same guard. The current draft must be applied or cancelled before another step opens, so previewed fonts cannot be mistaken for a saved scheme.

## Refined font and translation controls

- Custom schemes no longer borrow the user's theme accent. Current-scheme, role, and font selections use the same fixed cyan language as both presets.
- Font rows use clear checked boxes. The disabled Apply button keeps a readable label when the draft is unchanged instead of looking blank.
- The fixed type specimen drops the background-algorithm explanation and four color strips. The step-two AI Translate button drops its trailing pulse dot.

## Validation scope

- Type checks, six-locale copy completeness, step-layout, type-specimen, and settings-interaction regressions cover both guards, focus restoration, selection styling, and the removed decorations.
