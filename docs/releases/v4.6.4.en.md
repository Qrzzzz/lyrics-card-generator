# Lyrics Card Generator v4.6.4 Release Notes

Release date: 2026-07-11

This release continues the v4.6.2 work on Settings reset, the Prompt Library, and editor previews while fixing a severe global interaction issue.

## Highlights

- Fixed the issue where resetting a prompt preset made every page and text field non-interactive; reset actions no longer invoke a blocking native confirmation dialog.
- Made Strict Format Rules an immutable built-in safety module, removed every unlock-editing entry point, and stopped legacy overrides from affecting generation.
- Added global Back, Forward, and path navigation for every Settings category and subpage, unified in the upper-left header.
- Pinned the real card preview to the top while the editor scrolls and removed the separate font-preview card so font changes appear directly on the real card.
- Slightly shortened the four example-song cards and removed their “Album” labels.
- Kept Reset on every prompt preset so its initial title and prompt can be restored.
- Kept Reset all on the Prompt Library home page to restore defaults, removed presets, and custom presets together.
- Custom presets now record their initial content when first saved; existing data safely uses its current content as the reset baseline after migration.
- Simplified the Prompt Library description and changed the maximized green-button tooltip to “Windowed.”
- Made the Live Preview border follow the card content height instead of leaving a large blank area below it.
