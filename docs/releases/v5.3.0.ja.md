# Lyrics Card Generator v5.3.0 リリースノート

リリース日：2026-07-13

v5.3.0 では手順2〜6の上部ナビゲーションを統一し、編集フローの視覚的な階層をよりコンパクトで一貫したものにしました。

## 主な更新

- 手順2〜6で歌詞ワークスペースを基準としたコンパクトな Stepper を共有し、現在の手順、6手順すべてのナビゲーション、共通操作を1つのパネルにまとめました。
- 「サンプル」「すべて消去」「設定」を Stepper 見出し行の右側へ移動し、手順2の独立した操作バーと手順3〜6の大きなアプリ見出しを廃止しました。
- 手順3〜6の設定パネル、リアルタイムプレビュー、エクスポートフローは従来どおりです。利用可能な領域だけを広げ、カードデザインの動作は変更していません。
- Windows のカスタムタイトルバーでアプリ名の左側に小さなアプリアイコンを表示し、ウィンドウ操作、ドラッグ領域、バージョン情報は維持しました。
- コンパクトな操作領域でもアイコン、ラベル、フォーカス復帰、多言語の意味情報を維持し、最小幅1000pxでは間隔を調整します。

## リリース範囲

- 手順1は従来のアプリ見出しと曲選択レイアウトを維持し、今回の6手順統一における明確な対象外としています。
- 歌詞ドキュメント、プレビュー描画、PNG エクスポート、設定データ、プロジェクト形式は変更していません。
