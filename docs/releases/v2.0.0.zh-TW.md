# Lyrics Card Generator v2.0.0 發布說明

發布日期：2026-06-18

v2.0.0 集中強化卡片編輯、預覽、匯出和桌面端能力。主要內容包括橫版版面重構、自訂尺寸高度計算、本機音訊解析、Windows 系統字體、PNG 匯出、更新檢查和 Windows 構建說明。

## 主要更新

- 橫版卡片改用安全區域約束封面、歌詞、歌曲資訊和底部資訊，減少擠壓、越界和遮擋。
- 直版自訂尺寸改為基於真實 DOM 測量重新計算高度。
- 新增多語言歌詞拆分與中文翻譯整理能力。
- 新增本機 MP3 / FLAC 解析，可嘗試讀取標題、歌手、專輯、封面和內嵌歌詞。
- 桌面版新增 Windows 系統字體選擇和外部連結開啟能力。
- 更新檢查改為透過本機 Next API 路由請求 GitHub Releases。

## 發布產物

- `Lyrics Card Generator Setup 2.0.0.exe`
- `Lyrics Card Generator-2.0.0-portable.exe`
- `Lyrics Card Generator Setup 2.0.0.exe.blockmap`

## 驗證結果

已通過 `npm run core:test`、`npm run typecheck`、`npm run build` 和 `npm run desktop:build`。

## 注意事項

目前 Windows 構建未進行程式碼簽章，Windows 可能顯示 SmartScreen 提示。
