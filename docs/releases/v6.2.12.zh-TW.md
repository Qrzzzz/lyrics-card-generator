# Lyrics Card Generator v6.2.12

## 安裝程式更新

- 採用極簡安裝視窗：圖示、版本號和安裝按鈕；右上角切換語言。
- 安裝位置、安裝範圍和桌面捷徑收進同一視窗右側的展開選項。
- 安裝程式跟隨系統使用深色或淺色外觀，後續版本沿用此預設配置。
- 保留 NSIS 安裝、覆蓋和解除安裝機制，支援六種語言。

- Windows x64: `Lyrics.Card.Generator.Setup.6.2.12.exe`.
