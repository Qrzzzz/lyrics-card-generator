# Notes de version de Lyrics Card Generator v4.6.2

Date de publication : 2026-07-11

Cette version corrige le grave problème d’édition de la v4.6.0 et complète la réinitialisation de la Bibliothèque de prompts ainsi que la mise en page de l’aperçu.

## Principales nouveautés

- Correction de la saisie de remplacement dans les champs du bureau, notamment les préréglages IA et les règles de format déverrouillées.
- Ajout d’un bouton Réinitialiser dans chaque préréglage pour rétablir son titre et son prompt initiaux.
- Ajout de Tout réinitialiser sur la page principale de la bibliothèque afin de restaurer les préréglages, les règles strictes, les éléments supprimés et les éléments personnalisés.
- Les préréglages personnalisés enregistrent leur contenu initial à la première sauvegarde ; les données existantes utilisent leur contenu actuel comme base sûre.
- Simplification de la description de la bibliothèque et remplacement de l’infobulle du bouton vert maximisé par « Mode fenêtré ».
- Le cadre de l’aperçu en direct suit désormais la hauteur de la carte sans grand espace vide inférieur.

## Vérification

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:build
