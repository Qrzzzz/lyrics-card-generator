# Lyrics Card Generator v4.3.4 Release Notes

Release date: 2026-07-06

This release turns Examples from a modal dialog into an upper surface above the main editor. When examples open, the editor recedes downward, the in-app header docks at the bottom as the return anchor, and example cards now respond to the main window width.

## Main Updates

- Replaced the ExamplesDialog modal with an ExamplesFloor upper surface, without an overlay, modal shell, or portal.
- Clicking the header Examples button brings the examples surface down from above, moves the editor downward, and docks the header at the bottom.
- The docked header reuses the normal header structure and replaces the original Examples button position with a compact X return button.
- Example cards now switch between one, two, and three columns based on the main window width, avoiding horizontal overflow on small windows.
- The examples surface reserves bottom space for the docked header so the last row of cards remains visible while scrolling.
- Escape returns to the editor, and loading any example automatically returns to the editor.
- Surface motion now uses a calmer spring curve, with large movement disabled when reduced motion is enabled.

## Verification
