# Lyrics Card Generator v6.2.0

> ステータス：公開済み。

## 完成画像をコピー

- 「完了して書き出し」の隣に「画像をコピー」を追加し、先にファイルを保存しなくても現在の完成画像をシステムのクリップボードへ書き込めるようにしました。
- クリップボードには互換性の高い PNG を常に使用し、現在の書き出し品質を引き継ぎます。コピーしても PNG、WebP、JPG の保存形式は変わりません。
- 専用の進行表示と完了通知を追加し、失敗時にはクリップボード権限の確認を案内します。

## 書き出しと同じ保護境界

- コピーと保存は、固定された文書スナップショット、フォントと画像の準備確認、はみ出し防止、ピクセル上限、排他トランザクションを共有します。
- Windows デスクトップ版は、信頼済み Electron IPC を通してデコード済み画像をネイティブクリップボードへ渡し、プリロードとメインの両方で PNG データと寸法を制限します。
- Web Lite でもブラウザーが画像クリップボード API に対応している場合は同じ操作を利用できます。未対応または拒否された場合も編集内容は変わらず、エラーを表示します。

## 検証範囲

- 型検査、書き出しトランザクション、6 言語の完全性、Electron のプリロードとセキュリティ契約、ステップ配置、Web Lite の実 PNG コピー、デスクトップのネイティブクリップボード操作を回帰対象にしました。
