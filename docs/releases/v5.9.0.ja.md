# Lyrics Card Generator v5.9.0 リリースノート

リリース日：2026-07-31

v5.9.0 では Windows デスクトップ版に「読み込み・解析履歴」を追加しました。正常に解析した曲や保存したカバーを再読み込みする機能であり、歌詞の自動保存や文書のバージョン履歴ではありません。

## デスクトップの読み込み・解析履歴

- 上部操作の「歌詞の例」と「内容を消去」の間に「履歴」を追加しました。全画面の履歴ページでは、検索、取得元フィルター、ページ単位の追加読み込み、1 件削除、全件消去を利用できます。
- リンク解析、検索結果からの曲選択、ローカル MP3／FLAC 解析、ローカルカバーのアップロード後の保存が実際に成功した場合だけ記録します。失敗、キャンセル、内蔵例、通常の編集、消去、書き出しは記録しません。
- カードには曲、取得元、読み込み日時、ファイル名またはドメインを表示します。再読み込みでも既存の文書置換確認を使い、リモート処理の失敗やローカルファイルの欠落では現在の文書を変更しません。
- 移動したローカルファイルは再指定できます。サイズまたは更新日時が変わっている場合は簡潔に通知し、現在のファイルを解析します。

## 安全な保存と保持上限

- Electron のメインプロセスが schema バージョン付き UTF-8 JSON への書き込みを直列化し、一時ファイルから原子的に置換します。破損ファイルはタイムスタンプ付きバックアップとして残してから、新しい空の履歴を作成します。
- 記録するのは再実行に必要な最小限の取得元と表示用テキストだけです。画像バイナリ、Base64、blob URL、書き出し画像、パレット、スタイルは保存せず、リモートカバーは URL のみ保存します。
- renderer は再読み込み時に履歴 ID だけを送信します。ローカルパスはメインプロセスが保持・検証・読み込みを行い、Electron 42 の `webUtils.getPathForFile` で安全に登録します。
- 同じプラットフォームの曲、正規化済みリンク、ローカルパスは既存カードを更新して先頭へ移動します。設定 → 一般で 5 件、10 件（既定）、無制限を選択でき、上限を下げるときは確認後に最近使った順で古い項目を削除します。

## 対象範囲と検証

- 新しい画面テキストは簡体字中国語、繁体字中国語、英語、フランス語、日本語、スペイン語に対応しています。
- Web Lite の画面と動作は変更せず、ブラウザー側の履歴代替機能も追加していません。
- 純粋な履歴 store、安全な IPC、設定移行、パッケージ内容、実 Electron 操作の回帰テストで、永続化、重複排除、上限、再読み込み、変更／欠落／再指定されたファイル、書き込み失敗の動作を確認します。
