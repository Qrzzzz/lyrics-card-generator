# Lyrics Card Generator v6.2.2

> Estado: publicada.

## La distribución de Windows usa solo Setup

- Desde v6.2.2, la única descarga para Windows es el instalador x64 `Lyrics.Card.Generator.Setup.6.2.2.exe`; los paquetes autónomos ya no se compilan ni publican.
- v6.2.1 y versiones anteriores siguen abriendo la última GitHub Release desde la comprobación de actualizaciones; quienes usen un paquete autónomo antiguo pueden descargar Setup allí.
- La Release contiene exactamente tres archivos: Setup, el SBOM SPDX y `SHA256SUMS`. El workflow genera procedencia para cada uno.

## Correcciones de IA, límites de solicitudes y persistencia

- Las URL de servicios de IA fuera de loopback requieren HTTPS; HTTP en loopback sigue disponible para modelos locales. Las mutaciones vinculan la comprobación de origen a un host externo de confianza. (#143, #145)
- Los cuerpos de solicitud, respuestas ascendentes, flujos JSON/SSE de IA, metadatos remotos y cancelaciones tienen límites explícitos de tamaño, tiempo y aborto. (#146)
- Los ajustes de IA se guardan atómicamente contra truncamientos, y los guardados simultáneos de idioma y preferencias conservan la configuración más reciente. (#147, #148)
- Las imágenes del portapapeles de Electron se validan por área decodificada y presupuesto de bytes antes de asignar la imagen nativa. (#149)

## Controles de publicación y cadena de suministro

- Una versión debe descender de `main` revisado y su commit exacto debe superar toda la CI requerida; la autorización se repite antes de modificar y publicar. (#144)
- Se elimina la excepción obsoleta de Sharp para Next 15.5.24, y Electron empaquetado se incluye en una auditoría dedicada y en el SBOM SPDX. (#150, #151)
- La consulta de Releases recorre todas las páginas y falla de forma segura ante conflictos, incluso cuando el repositorio supera 100 Releases. (#152)

## Validación

- Las pruebas empaquetadas de Windows instalan sus observadores antes de las actualizaciones controladas y esperan a que la relocalización del historial esté realmente lista, sin debilitar sus aserciones.
- El tipado, lint, las suites de estabilidad y núcleo, Web Lite, las políticas de dependencias y SBOM, las regresiones empaquetadas y el smoke de instalación/inicio/cierre/desinstalación de Setup bloquean la publicación.
