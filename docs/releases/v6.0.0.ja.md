# Lyrics Card Generator v6.0.0

> ステータス：GitHub Releases で公開済みです。

## 構造化歌詞ドキュメントエンジン

- 歌詞の唯一の正本を `LyricDocumentV2` に移行しました。自然な段落は Block、原文／翻訳の組は安定 ID を持つ Unit となり、有効な操作ごとに document revision が進みます。
- プレーンテキストの貼り付けと編集方法は変わりません。決定的パーサーが段落、対応関係、ID の調整を行い、順序、空行、翻訳を保持します。旧アーカイブは読み込み時に移行されます。
- インポート、編集、元に戻す／やり直し、手動アーカイブ、プレビュー、自動レイアウト、書き出しが同じ文書を使用します。旧 `lyrics` と `translationText` は互換用の派生値のみです。

## AI 翻訳と書き出しの整合性

- AI 翻訳は Unit ID ごとの JSON を要求し、完全で順序が正しく、revision が一致する結果のみを適用します。
- 遅延応答、誤った ID、欠落 Unit、余分なフィールドは現在の文書を上書きできません。ストリームは完全で有効な JSON になった時点でのみ翻訳を更新します。
- 書き出しスナップショットは歌詞文書、document revision、スタイル、解決済みレイアウトを固定し、編集中のプレビュー差異を防ぎます。

## 互換性

- デスクトップ版と Web Lite は従来の歌詞編集体験とカードの視覚表現を維持します。
- v1 手動アーカイブは引き続き読み込めます。新しい v2 アーカイブは厳格な境界検証の下で Block／Unit ID を保存します。
