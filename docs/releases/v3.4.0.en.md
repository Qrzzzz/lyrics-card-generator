# Lyrics Card Generator v3.4.0 Release Notes

Release date: 2026-06-28

v3.4.0 reworks the Layout step around content type, and upgrades the background grid into a configurable Visual Details option.

## Changed

- The Layout step now asks for content type before showing available layout, size, and typography options.
- Instrumental / no-lyrics cards are now locked to portrait 1:1 output so the cover and song information stay stable.
- Removed the unused instrumental description input from the Layout step.
- Background grid is now disabled by default and available in Visual Details with Sparse / Medium / Dense density options.

## Fixed

- Fixed an issue where instrumental / no-lyrics mode could still select landscape cards.
- Fixed an issue where instrumental / no-lyrics mode could use incompatible non-square canvas sizes.
- Fixed the overly dense background grid from the previous version.

## Validation

- Verified that instrumental / no-lyrics mode immediately switches to portrait 1:1.
- Verified that the landscape button is dimmed and disabled in instrumental / no-lyrics mode.
- Verified that the background grid is disabled by default and supports all three density levels after it is enabled.
- Ran `npm run typecheck`, `npm run core:test`, and `npm run build`.
