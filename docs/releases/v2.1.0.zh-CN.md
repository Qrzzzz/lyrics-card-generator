# Lyrics Card Generator v2.1.0 发布说明

语言：简体中文 · [繁體中文](./v2.1.0.zh-TW.md) · [English](./v2.1.0.en.md) · [Français](./v2.1.0.fr.md) · [日本語](./v2.1.0.ja.md) · [Español](./v2.1.0.es.md)

## 下载与安装

请在 GitHub Releases 下载对应资产：

- 安装版：`Lyrics Card Generator Setup 2.1.0.exe`
- 便携版：`Lyrics Card Generator-2.1.0-portable.exe`

普通用户建议使用安装版；只想临时试用、测试或放在移动硬盘中使用时，可以选择便携版。

> 当前版本未进行代码签名。Windows 可能显示 SmartScreen 提示，这是未签名个人应用常见现象。

## 本次更新

v2.1.0 重点强化桌面端体验、横版排版、自定义尺寸、多语言界面和本地素材处理能力。

### 新增

- 新增 Windows 桌面应用打包流程。
- 新增安装版和便携版两种分发形式。
- 新增本地 MP3 / FLAC 解析，尝试读取标题、艺人、专辑、封面和内嵌歌词。
- 新增 Windows 系统字体读取和自定义字体选择。
- 新增简体中文、繁體中文、英文、法语、日语、西班牙语界面切换。
- 新增从 GitHub Releases 检查更新的入口。

### 改进

- 重构横版布局，基于安全区域、封面列、内容列和底部信息区进行排版。
- 竖版自定义尺寸支持基于真实 DOM 测量的自动高度。
- 歌词原文与译文排版更稳定，支持按当前界面语言拆分原文 / 译文。
- 远程封面导出改用图片代理，降低 PNG 导出时的跨域失败概率。
- 平台 Logo 改为本地 SVG 资源，导出时不依赖远程图标。

### 修复

- 修复部分自定义尺寸下内容溢出或留白异常的问题。
- 修复横版卡片中封面、歌词和底部信息相互挤压的问题。
- 修复部分远程封面在导出时无法被正确写入 PNG 的问题。

## 升级注意事项

- 从旧版本升级通常不需要卸载。
- 如果安装版无法覆盖安装，可以先退出旧版本，再重新运行安装包。
- 如果便携版无法启动，建议确认旧进程是否仍在后台运行。

## 已知限制

- 音乐平台链接解析、远程封面加载、自动歌词获取、检查更新需要联网。
- 自动歌词获取仍为实验性功能，结果可能不完整或不准确，请自行确认使用权限。
- 当前版本未代码签名，Windows SmartScreen 提示不代表程序一定有风险。
