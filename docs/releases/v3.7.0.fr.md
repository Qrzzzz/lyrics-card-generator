# Notes de version de Lyrics Card Generator v3.7.0

Date de publication : 2026-06-29

v3.7.0 est une version de maintenance et de stabilisation. Elle n’ajoute ni nouveau mode de mise en page, ni thème, ni plateforme musicale, ni comportement d’export. Cette mise à jour se concentre sur la sécurité des chemins d’image de fond, le repli des erreurs de traduction IA, la cohérence de l’entrée de mise à jour, le nettoyage de code obsolète et la stabilité des contrôles de publication.

## Correctifs

- Validation renforcée des `imageId` d’image de fond du bureau : seuls les noms générés par l’application en `png`, `jpg`, `jpeg`, `webp` et `gif` sont acceptés, avec rejet des traversées de chemin et des valeurs forgées.
- La lecture des images de fond utilise désormais une table MIME explicite et n’accepte ni SVG ni extensions inconnues.
- Le repli des erreurs de traduction IA a été amélioré face aux réponses fournisseur non standard, aux erreurs en texte brut, au JSON malformé et aux corps vides afin d’éviter les crashs.
- Le bouton « Ouvrir la page de version » ouvre désormais toujours la page GitHub Release correspondante au lieu d’un lien direct vers l’installateur.

## Maintenance

- Suppression de l’ancien code `CustomFontPanel` inutilisé, sans changer le comportement actuel de `FontSchemePanel`.
- Suppression des textes i18n obsolètes de l’ancien champ instrumental, tout en conservant la compatibilité `instrumentalText` et le rendu visuel des cartes.
- Remplacement du test de publication spécifique à `v3.6.1` par un test générique de cohérence de release et un test de régression de la barre de titre.
- Ajout d’un workflow CI minimal pour l’installation, la vérification TypeScript, les tests cœur et le build Web.

## Vérification

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:dev
- npm run desktop:build
