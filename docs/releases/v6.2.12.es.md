# Lyrics Card Generator v6.2.12

## Nuevo instalador

- Ventana mínima con icono, versión y botón Instalar; idioma en la esquina superior derecha.
- Las opciones laterales reúnen carpeta, alcance y acceso directo en la misma ventana.
- El tema claro u oscuro sigue al sistema. Este diseño será el predeterminado en próximas versiones.
- Conserva NSIS para instalar, actualizar y desinstalar, con seis idiomas.

- Windows x64: `Lyrics.Card.Generator.Setup.6.2.12.exe`.
