# Lyrics Card Generator v5.2.0 发布说明

发布日期：2026-07-13

v5.2.0 是一次稳定性、可访问性、桌面安全与发布工程更新，保持现有歌词卡输出、数据格式和视觉方向不变。

## 主要更新

- Safe Fetch 会验证解析得到的全部地址，交错尝试 IPv6/IPv4，并在连接失败后安全 fallback；整个请求共享同一 timeout 与 redirect budget。
- 文档语义样式变更会原子取消当前 AI generation，普通视觉控件不再产生无意义取消；Electron AI 取消按窗口 sender 隔离，并覆盖 provider 首次等待前的窗口。
- 桌面设置使用单调 revision 协调 JSON 与 renderer cache，迁移 5.1.0 数据，串行处理快速写入，并在所有关闭路径上 flush pending settings。
- 共享 accessible dialog 补齐初始焦点、焦点循环、背景 inert、Escape 策略、减弱动效和焦点恢复；搜索、链接解析与本地音频状态支持完整键盘和 live region。
- 六语错误提示由稳定错误码映射，文档语言跟随当前 locale；自定义 accent 下焦点仍清晰，并加入 Forced Colors 系统色规则。
- 外部导航、特权 IPC sender、权限请求与生产 CSP 均使用明确安全策略。

## 发布保障

- CI 新增 lint、关键模块 coverage、axe、六语完整性、Electron 安全、生命周期与最终制品门禁。
- Setup 与 portable 按最终字节测试；tag 驱动发布会为同一批字节生成 SHA-256、SPDX SBOM 与 GitHub artifact attestation。
