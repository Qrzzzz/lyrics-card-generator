# Lyrics Card Generator v6.10.3

修正淺色封面被壓暗的問題，統一原文與譯文欄頭，並精簡儲存庫根目錄。

## 改進

- 淺色封面保留原圖的明度與顏色比例，小面積點綴不再擠占主體背景；自動文字顏色依實際漸層選用黑字或白字，保留手動配色。
- 原文與譯文統一為完整編輯面板，以短線與小標記提示目前欄位；保留點擊欄頭聚焦與共用捲動吸頂，避免文字透到欄頭後方。
- 翻譯 README、Playwright 與專項 TypeScript 設定集中歸檔，根目錄檔案從 26 個減為 15 個，並同步修正連結、測試入口與快取位置。

## 驗證範圍

本機通過相關行為回歸、型別檢查、lint、正式建置與文件連結檢查；Chromium 驗證淺深色編輯器及橫直版 PNG 匯出。桌面介面使用桌面橋測試夾具；完整回歸與原生安裝、更新及附件驗證由 CI 和 Release 工作流程執行。應用仍未程式碼簽章；舊翻譯 README 檔案直連需更新。
