# Notas de la versión 3.2.1 de Lyrics Card Generator

Fecha de lanzamiento: 2026-06-23

La versión 3.2.1 sigue siendo una versión de corrección de errores de la 3.2.0, sin cambiar de nuevo el número de versión.

## Correcciones de estabilidad

- Se corrigió el contraste del texto y de los estados en el tema azul claro y en fondos personalizados.
- Se amplió el icono del Header y se restauró «Borrar todo» conservando los ajustes.
- La selección de imagen está disponible en todos los modos y muestra una vista previa inmediata en modo Rellenar.
- Se corrigió el comportamiento transaccional de Guardar, Cancelar y Restablecer para conservar el fondo anterior al cancelar.
- Se liberan las URL de objeto al cambiar fondos repetidamente y se completaron los tokens del tema personalizado.
- Se añadieron los textos de estado y las notas de versión en los seis idiomas.
- Se corrigió la solicitud repetida de idioma tras cada reinicio de la aplicación de escritorio; la primera elección se conserva y los siguientes inicios abren directamente el editor vacío.
- El control Spark Cursor ahora ocupa todo el ancho de la tarjeta, igual que Altura automática.
- Se añadió Fondo de cuadrícula fina en Detalles visuales, activado de forma predeterminada y aplicado tanto a la vista previa como al PNG exportado.

Validación: `npm run typecheck`, `npm run core:test`, `npm run build`, `npm run desktop:build`.
