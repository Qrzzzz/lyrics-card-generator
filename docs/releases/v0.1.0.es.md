# Notas de la versión de Lyrics Card Generator v0.1.0

Fecha de publicación: 2026-06-16

## Resumen de la versión

Esta es la primera versión de escritorio para Windows de Lyrics Card Generator. Convierte la aplicación WebUI basada en Next.js en una aplicación Windows EXE lista para usar. Los usuarios no necesitan instalar Node.js, iniciar manualmente un servidor de desarrollo ni desplegar el proyecto en la nube.

La aplicación de escritorio usa Electron con un servicio local Next standalone. Al iniciarse, abre un servicio integrado en `127.0.0.1` y carga esa dirección local dentro de la ventana de escritorio. Apple Music, NetEase Cloud Music, QQ Music, las portadas remotas y LRCLIB funcionan solo como fuentes de datos, no como dependencias de despliegue.

## Descarga e instalación

- Instalador: `Lyrics.Card.Generator.Setup.0.1.0.exe`
- Versión portable: `Lyrics.Card.Generator-0.1.0-portable.exe`

Para uso normal se recomienda el instalador. La versión portable es adecuada para probar la aplicación temporalmente o evitar escribir en el directorio de aplicaciones del sistema.

## Funciones principales

- Análisis de enlaces de Apple Music, NetEase Cloud Music y QQ Music.
- Edición manual del título, artista, álbum y URL de portada.
- Entrada y edición manual de letras.
- Edición de traducciones línea por línea, con opción de mostrar u ocultar la traducción.
- Modo instrumental para canciones sin letra.
- Portadas remotas, subida de portadas locales, proxy de portada y extracción de colores.
- Ajustes de diseño vertical / horizontal, tamaño, altura automática, fuente, tamaño de texto, interlineado, color, bordes redondeados, marco, sombra, logo de plataforma, marca de agua y texto de compartido por.
- Cambio entre interfaz en chino e inglés, con persistencia local del idioma.
- Exportación PNG mediante el flujo DOM-to-PNG existente, con salida 2x de alta calidad.

## Experiencia de escritorio

- La aplicación se inicia con doble clic en el EXE.
- La ventana se abre maximizada por defecto.
- El icono de la aplicación se aplica al instalador, la versión portable, la barra de tareas, la barra de título, el favicon web y el encabezado interno.
- Al cerrar la ventana también se detiene el servicio local integrado, evitando procesos residuales.
- Los enlaces externos se abren en el navegador del sistema.

## Uso sin conexión y con conexión

Disponible sin conexión: abrir la aplicación, introducir datos de canción manualmente, editar letras y traducciones, usar una portada local, ajustar el estilo de la tarjeta y exportar PNG.

Requiere conexión: análisis de enlaces de Apple Music / NetEase Cloud Music / QQ Music, carga de portadas remotas y obtención automática de letras mediante LRCLIB.

## Limitaciones iniciales

- Esta versión no incluye actualización automática.
- La compilación de Windows no está firmada, por lo que Windows puede mostrar un aviso de SmartScreen.
- El instalador y la versión portable son para Windows x64.
- El análisis remoto y la obtención de letras dependen de la disponibilidad de fuentes de datos de terceros.

## Verificación

Antes de publicar, `npm run typecheck`, `npm run build` y `npm run desktop:build` se completaron correctamente. Se generaron los artefactos instalador y portable. También se verificaron con ejemplos el arranque del servicio Next integrado, el análisis de enlaces, el proxy de portadas locales, la obtención de letras con LRCLIB y la exportación PNG.
