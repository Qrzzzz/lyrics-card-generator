# Lyrics Card Generator v6.0.1

> Status: publicly released through GitHub Releases.

## Native Electron system dialogs

- The Windows desktop app now presents six prompts as native Electron system dialogs: song replacement, translation overwrite, history clearing, history trimming, history-check failure, and save failure during window close.
- Confirmations use the operating system’s warning icon, while failures use its error icon, with no extra icon assets to package.
- Dialog titles, details, and buttons fully support Simplified Chinese, Traditional Chinese, English, French, Japanese, and Spanish.

## Safety and compatibility

- Destructive replace, overwrite, and delete actions focus Cancel by default; closing the dialog or pressing Escape also cancels the operation.
- Dialog inputs are validated in the renderer facade, preload bridge, and main process, and only bounded primitive fields cross contextBridge.
- Web Lite and regular browsers retain a compatible fallback without changing existing web functionality.
