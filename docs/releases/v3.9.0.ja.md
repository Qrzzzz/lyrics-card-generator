# Lyrics Card Generator v3.9.0 リリースノート

リリース日：2026-07-01

v3.9.0 は設定保存、編集ステップの簡素化、カード情報表示、リリース準備に焦点を当てた更新です。既存の 6 言語範囲は維持し、新しい言語の追加や削除は行わず、背景、外観、AI 設定を個別に確定しなくても済むように設定保存を即時反映にしました。

## 設定保存

- 設定画面は即時保存になり、背景画像、AI 設定、外観、一般設定の変更がローカル設定へ直接保存されます。
- 旧来の下部にあった保存 / キャンセルの確認バーは削除され、軽量な通知で保存状態を示します。
- 背景画像を置き換えた場合は古いリソースをクリーンアップし、デスクトップ版では引き続き Electron の設定ストレージへ同期します。

## 多言語範囲

- UI 言語の範囲は既存の 6 言語、簡体字中国語、繁体字中国語、英語、フランス語、日本語、スペイン語のままです。
- このリリースでは新しい言語を追加せず、既存の言語入口も削除しません。
- 多言語 README とリリースノートは、引き続き 6 言語の一貫したセットとして更新します。

## 編集フローとカード情報

- 手動の曲情報入力は独立ステップから曲リンクステップ内の展開アクションへ移動し、タイトル、アーティスト、アルバム、カバーは引き続き手動編集できます。
- 歌詞カードに「アルバム名を表示」スイッチを追加し、縦版、横版、インストゥルメンタルの各レイアウトに対応しました。
- 自動高さと横版レイアウトの計算ではアルバム名の領域を確保し、曲情報と歌詞の重なりを減らします。

## リリース準備

- バージョンメタデータ、`package.json`、`package-lock.json`、README のダウンロードファイル名を `3.9.0` に同期しました。
- 多言語リリースノートは 6 言語分のファイルを揃え、`docs/releases/README.md` も更新しました。
- Windows インストーラー、ポータブル版、`latest.yml` は GitHub Release へのアップロード用に再ビルド済みです。

## 検証

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:build
