# Lyrics Card Generator v6.8.1

**2026-10-22**

v6.8.1 focuses on content protection, recoverable output failures, usable windows and compact layouts, and clear editing state. Core scope: #229, #230, #231, #232, #233, #235, #237 and #238; also includes the six-language settings copy cleanup in #240.

- Instrumental mode hides translation without deleting it. Clearing song details, cover art and both lyric columns requires confirmation; cancel preserves content and save failures still block clearing.
- Export and copy failures stay visible with a retry action. Retries retain transaction safeguards and never modify the document.
- Initial, minimum and restored window bounds fit the display work area in DIP, with updates after display changes. Traffic-light controls gain recognizable glyphs and borders in forced colors.
- Compact layouts put settings and actions before the preview. Steps show current and visited navigation rather than positional completion. Persistent bilingual headings identify the active column during shared scrolling.
- Settings use plain font and reasoning terminology, with environment-specific key-storage information while retaining privacy, security and billing notices.

Real Windows light/dark high contrast, 1366×768 at 125%, 1920×1080 at 150%, native split-screen and live DPI changes passed locally. #232 remains incomplete pending cross-display movement on a dual-monitor system; emulation and geometry unit tests do not replace that gate. See the [local candidate acceptance record](../acceptance/v6.8.1.md). #239 numeric entry is deferred.
