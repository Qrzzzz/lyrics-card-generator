# Lyrics Card Generator v4.6.4 发布说明

发布日期：2026-07-11

这一版本继续完善 v4.6.2 的设置重置、提示词资源库与编辑器预览体验，并修复影响全局交互的严重问题。

## 主要更新

- 修复提示词预设重置后所有页面与文本框失去交互的问题；重置不再调用会阻塞桌面壳的原生确认框。
- 严格格式规则固定为不可修改的内置安全模块；移除所有解锁编辑入口，历史覆盖内容不再参与生成。
- 设置页新增适用于全部分类与子页的全局前进、后退和路径栏，并统一放入左上角页头。
- 右侧真实卡片预览在编辑页滚动时固定在顶部；文字设计页移除独立字体预览卡片，字体变化直接显示在真实卡片上。
- 四张示例歌曲卡片略微缩短，并移除卡片顶部的“专辑”标签。
- 每个提示词预设保留“重置”按钮，可恢复各自的初始标题和提示词。
- 提示词资源库主页保留“一键重置全部”，同时恢复默认、已删除和自定义预设。
- 自定义预设首次保存时记录初始内容；旧数据迁移后安全地以当前内容作为重置基线。
- 精简提示词资源库说明，并将最大化状态的绿灯提示改为“窗口化”。
- 实时预览边框随卡片内容自适应高度，不再在下方保留大块空白。

## 验证

- npm run core:test
- npm run build
