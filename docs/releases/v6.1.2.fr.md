# Lyrics Card Generator v6.1.2

> Statut : publié officiellement via GitHub Releases.

## Jeu natif à deux polices

- Les entrées séparées pour les polices CJK et latine sont remplacées par une seule entrée « Modifier le jeu ».
- Sous Windows, elle ouvre une fenêtre WinForms native rattachée à la fenêtre principale. Ses deux boutons de sélection appellent chacun le `FontDialog` du système ; aucun sélecteur Electron ou HTML redessiné n’est créé.
- La fenêtre affiche les deux polices et leurs aperçus. Annuler abandonne tout le brouillon ; « Appliquer le jeu » valide les deux polices en une fois puis restitue le focus à l’entrée principale.

## Exhaustivité des polices et compatibilité

- Sous Windows, `FontDialog` présente directement les polices système, sans classement par nom dans l’application. Dans les solutions de repli pour bureau non Windows et navigateur, les catégories ne déterminent que les recommandations et l’aperçu, et toutes les polices détectées restent disponibles pour les deux rôles.
- Le pont natif conserve des champs strictement bornés, le rattachement modal au handle principal et une analyse limitée du résultat. Le repli de bureau non Windows garde un IPC minimal et isolé.
- Les jeux personnalisés conservent les structures existantes de prévisualisation, d’exportation et de persistance, sans modifier le rendu des cartes.
