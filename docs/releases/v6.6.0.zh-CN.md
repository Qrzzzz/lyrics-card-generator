# Lyrics Card Generator v6.6.0 发布说明

发布日期：2026-10-04

v6.6.0 支持在桌面版中选择红绿灯或 Windows 风格顶栏，默认继续使用红绿灯。窗口按钮的布局可以按个人习惯调整。

## 顶栏样式

- 在“设置 → 外观 → 顶栏样式”中选择“红绿灯（默认）”或“Windows 风格”。新安装和未设置过该选项的用户继续使用红绿灯。
- Windows 风格将最小化、最大化和关闭按钮放在顶栏右侧；最大化后，按钮图标和提示会切换为“窗口化”。
- 切换立即生效并自动保存，重启后保留选择。恢复应用默认设置时，顶栏会回到红绿灯样式。
