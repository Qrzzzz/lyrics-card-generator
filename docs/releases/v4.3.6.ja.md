# Lyrics Card Generator v4.3.6 リリースノート

リリース日：2026-07-07

このバージョンでは、v4.3 系列のサンプル曲画面とメイン編集画面のつながりをさらに調整しました。アプリ内ヘッダーはメイン編集内容の一部として扱われるようになり、サンプル曲画面では同じヘッダーを下部の戻り位置として引き続き再利用します。サンプル読み込み、翻訳の連動、書き出し品質の表記も整理しました。

## 主な更新

- メイン編集画面のヘッダーは内容フローに入り、ステップ領域やプレビュー領域の上に重なる浮動レイヤーではなくなりました。
- サンプル曲画面では同じヘッダーを下部の戻り位置として再利用しつつ、切り替えアニメーション中にヘッダーの残像が見える問題を修正しました。
- サンプル曲画面の外側の枠感を取り除き、各サンプルカード下部の翻訳言語ブロックを廃止しました。
- 翻訳言語はサンプルタイトル右側に一度だけ表示され、現在のインターフェイス言語に合わせて読み込まれる翻訳言語を示します。
- 翻訳を読み込むスイッチを追加し、既定でオンにしました。オンの場合はサンプル読み込み時に翻訳を書き込み、メイン編集画面の翻訳スイッチもオンにします。オフの場合は曲情報と歌詞だけを読み込みます。
- 簡体字中国語と繁体字中国語をまたぐ場合は、既定で翻訳を読み込まないようにし、2 つの中国語 UI モード間で不要な自動翻訳が入らないようにしました。
- サンプル画面下部の X 戻るボタンに、オレンジから赤系のホバー反応を追加しました。
- 書き出し品質の表記を 標準 / 高画質 / 超高画質 に変更しました。実際の倍率は引き続き 1x / 1.4x / 2x です。
