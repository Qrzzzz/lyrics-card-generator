# Notas de la versión 5.5.2 de Lyrics Card Generator

Fecha de publicación: 2026-07-14

La versión 5.5.2 aclara los dos primeros pasos del flujo de escritorio, asigna un lugar más claro a cada método de importación y reduce los marcos anidados del espacio de letras largas.

## Cambios destacados

- El paso 1 mantiene la búsqueda de NetEase en la parte superior de la columna izquierda. La importación por enlace y por audio local se sitúa debajo y aparece en paralelo cuando hay espacio.
- La columna derecha presenta la portada, el título, el artista y el álbum, y conserva el editor manual desplegable.
- El paso 1 deja de mostrar un botón Atrás inutilizable; la navegación de los pasos posteriores no cambia.
- El paso 2 elimina el marco general y los marcos propios de las columnas de resumen, documento y herramientas.
- En diseños anchos solo queda un separador vertical de un píxel; en diseños estrechos apilados se convierte en un separador horizontal.

## Alcance

- La búsqueda, el análisis de enlaces y audio local, la edición manual, las letras y la exportación mantienen su comportamiento.
- Los campos, mensajes de estado, estadísticas y paneles dinámicos conservan los límites locales necesarios.
- La navegación compartida por escritorio y Web Lite oculta de forma coherente la acción Atrás inválida del primer paso.

## Validación

- `npm run typecheck` / `npm run lint` / `npm run core:test` / `npm run build`
- `npm run web-lite:build` / `npm run web-lite:check` / `npm run web-lite:smoke`
- `npm run desktop:build` / `npm run desktop:interaction-test`
