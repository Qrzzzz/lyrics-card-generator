# Lyrics Card Generator v6.2.3

> Status: released.

## Local-readability shadow fix

- Song metadata, lyrics, and footer accessories now use the same local-readability shadow depth.
- The three regional gradients are merged into one alpha mask before the tone adjustment is applied. Overlaps can no longer darken twice or create conspicuous header and footer bands.
- Extra shadows were removed from the platform logo, shared-by label, and generated watermark so these elements rely on the same readability layer and remain consistent between preview and export.

## Validation

- Background-composition regression covers 120 deterministic combinations and now asserts both one shared opacity ceiling for overlaps and equal depth across all three regions.
- Type checking, lint, production build, Web Lite build and consistency checks passed, followed by a real Chromium 2× PNG export and Firefox/WebKit rendering checks.

## Download and upgrade

- Windows x64 installer: `Lyrics.Card.Generator.Setup.6.2.3.exe`.
- This release remains Setup-only; upgrading from an older version requires no settings migration.
