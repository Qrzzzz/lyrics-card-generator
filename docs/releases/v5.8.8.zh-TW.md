# Lyrics Card Generator v5.8.8 發布說明

發布日期：2026-07-30

v5.8.8 是凍結 v5.8.7 前端呈現的內部整理版本。它不新增或移除任何可見功能，只收斂已經穩定的實作邊界，讓後續維護更清楚。

## 凍結 v5.8.7 前端

- 頁面結構、元素 class、自動化 `data-testid`、視覺樣式、固定 2:1 分欄與窄螢幕抽屜維持不變。
- 雙欄共享捲動、編輯器尺寸同步、選取範圍與游標復原、焦點接力及非作用中頁面 `inert` 隔離維持不變。
- Esc 層級、減少動態效果、AI 請求啟動／取消／返回／卸載生命週期及譯文寫入邏輯維持不變。

## 內部結構整理

- 移除已經沒有執行入口的舊樣式面板、舊輸入分支與相容路徑，不改變桌面版或 Web Lite 的可達功能。
- 將 `LyricsSidebar` 的導覽／焦點控制與「整理／翻譯」呈現拆開；三頁軌道仍是第二步側欄專用實作，沒有擴充為通用頁面系統。
- 將 `LyricsWorkspace` 的文件變換、復原／重做歷史與選取範圍控制收斂到專用 controller，版面與 DOM 呈現仍由工作區元件負責。

## 版本與驗證

- `package.json`、鎖定檔、六語 README、六語發布說明、發布索引與 Web Lite 統一為 5.8.8。
- 型別檢查、零警告 lint、正式版建置、核心回歸、Web Lite 檢查／冒煙測試及桌面 Electron 互動矩陣涵蓋這次行為不變的整理。
