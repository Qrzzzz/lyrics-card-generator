# Lyrics Card Generator v5.10.0

> Estado: publicado en GitHub Releases.

Esta versión reconstruye los fondos derivados de la portada. En lugar de curvas fijas o simples colores de esquina, crea un campo suave, estable y continuo a partir de las relaciones espaciales de la portada y lo recompone para cada proporción de tarjeta.

## Novedades

- La paleta perceptual conserva posición, área, luminosidad y relevancia, con una semilla estable derivada de la portada.
- Las anclas espaciales se reorganizan para lienzos verticales, horizontales y ultralargos antes de fusionarse en un campo continuo.
- Las nuevas restricciones reducen bandas paralelas, contornos cerrados, curvas S repetidas, mezclas apagadas y brillos abruptos.
- Las zonas seguras de letras usan control local de luminosidad y contraste en lugar de un velo oscuro uniforme.
- La vista previa, la exportación y Web Lite comparten una ruta de renderizado determinista para resultados reproducibles.

## Validación

La cobertura incluye paleta, campo espacial, matriz de composición, contraste del texto, regresión visual de Web Lite y artefactos de escritorio.
