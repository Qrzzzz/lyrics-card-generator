# Lyrics Card Generator v5.10.3

> Status: publicly released through GitHub Releases.

This maintenance release focuses on accessibility, supply-chain controls, and cross-platform quality gates. The product interface and export design remain unchanged while critical boundaries that previously depended on manual review become repeatably verifiable.

## Highlights

- Fixes duplicate and nested main landmarks in Web Lite and makes the axe automation gate enforce the relevant accessibility rules.
- Updates production and build dependencies, adding reasoned, expiring advisory exceptions, a release SBOM, and blocking CI/release policy.
- Ships the complete Source Han Sans and Serif OFL text in the repository, Web Lite, GitHub Pages, desktop server, installer, and portable build.
- Adds continuous render regressions, a scheduled long-card composition benchmark, Electron runtime static analysis and risk-boundary coverage, plus Firefox and WebKit smoke tests.

## Validation

This release passed type checking, lint, dependency and font-license policy, Chromium accessibility, Firefox/WebKit smoke, production render-boundary, full Web Lite regression, Electron coverage, desktop interaction, final Windows artifact smoke, SBOM, checksum, and attestation gates.
