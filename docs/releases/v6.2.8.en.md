# Lyrics Card Generator v6.2.8

## Automatic saving and history recovery

- The manual archive button is removed. A single centered title-bar line shows saving status; the current draft saves after 5 seconds without edits.
- Drafts preserve source lyrics, translations, sections and alignment, song details, card styles, export settings, the current step and unsubmitted song-detail forms. Local covers can be restored with the draft.
- Normal closing or switching documents flushes pending changes immediately, and the next launch restores the last draft. A failed save blocks normal closing; click the title-bar error to retry. Older history and manual archives remain readable.
- Duplicate CI, build and release checks are removed while data recovery, security, browser compatibility, rendering/export and new-installer verification remain covered.

## Scope and limitations

- Automatic drafts are desktop-only. Selecting no history retention pauses future saves without deleting existing drafts. Deleting the current history entry stops writes for that session; import another song or clear the document to start again.
- Forced termination, power loss or disk damage can recover only successfully written versions. Continuous editing without a 5-second pause can leave more than 5 seconds of work unsaved; this version has no per-keystroke emergency backup.
- Remote covers are not guaranteed offline. Remote-history JSON keeps its existing scope and does not include full card styles or local covers.

- Windows x64: `Lyrics.Card.Generator.Setup.6.2.8.exe`.
