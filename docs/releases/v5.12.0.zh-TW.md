# Lyrics Card Generator v5.12.0

> 狀態：已透過 GitHub Releases 公開發布。

## 本機 M4A 解析

- 本機音訊上傳現在除了 MP3、FLAC 之外也支援 M4A，可從檔案讀取標題、藝人、專輯、封面與內嵌歌詞；沒有內嵌歌詞時，仍會保留已讀取的歌曲資訊供手動編輯。
- 支援瀏覽器與 Windows 常見的 `audio/mp4`、`audio/m4a` 及 `audio/x-m4a` 類型，並沿用既有的 100 MB 檔案上限、有界 multipart 讀取與解析失敗保護。
- Windows 桌面版的匯入歷史可記錄成功提交的 M4A 檔案，並支援重新匯入與檔案重新定位；歷史仍只儲存必要的路徑與中繼資料，不會儲存音訊內容。
