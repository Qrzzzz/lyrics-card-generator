# Lyrics Card Generator v6.5.8 リリースノート

公開日：2026-09-30

v6.5.8 はデスクトップの下書き復元とカバー読み込みの安全性を改善します。

## 修正

- 履歴の主ファイルがない場合、有効なバックアップから下書き全体、編集中の記録、カバーを復元します。初回保存から復元用コピーを作成し、削除した記録は復活させません。
- リモートカバーは制限付きプロキシを経由し、同一オリジンを正確に確認します。ローカル画像のアップロードを維持し、ファイル用プロトコルと偽装ホストを拒否します。アップロードと埋め込み画像は 20 MB 以下に制限します。
- ビルド・テスト用依存関係の brace-expansion と fast-uri のセキュリティ問題を修正します。
