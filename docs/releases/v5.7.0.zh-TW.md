# Lyrics Card Generator v5.7.0 發行說明

發佈日期：2026-07-16

v5.7.0 重構桌面版主頁的六步驟工作流程，讓第 3–5 步的設定區與即時預覽可依任務調整寬度，並為設定項加入依容器寬度計算的緊湊排版。桌面版與 Web Lite 繼續提供 PNG、WebP 與 JPG 匯出。

## 可調整設定/預覽工作區

- 第 3–5 步新增垂直分隔器，左側設定區可從 1/2 連續擴展到最高 2/3。
- 在較窄的桌面視窗中，上限會自動收緊，確保預覽區至少保留 360 px；小於 1024 px 時仍使用上下排列。
- 分隔器支援拖曳、方向鍵微調、Home/End 跳轉與雙擊恢復 1:1，並向輔助技術提供目前比例。
- 第 5→6 步繼續共用同一個預覽實體，工作區依實際設定寬度平移。

## 容器驅動的緊湊排版

- 版面、字體設計與視覺細節改為依左側設定容器的實際寬度計算欄數。
- 一般版面列在寬欄下可從一欄變為兩欄；視覺開關可從兩欄四列收緊為三欄三列。
- 條件面板與相依輸入保持橫跨整列，並維持 DOM 與鍵盤導覽順序。
- Toggle 控制項改用最小高度，較長的多語言標籤可自然換行。

## 主頁、預覽與匯出

- 六個桌面編輯步驟統一使用緊湊 Stepper 與頂部操作區。
- 即時預覽會在分欄、視窗大小或範例匯入改變時重新測量，並在支援的指標裝置上提供輕量立體壓力回饋。
- 桌面版與 Web Lite 均可選擇 PNG、WebP 或 JPG；預設格式可在設定中儲存。
