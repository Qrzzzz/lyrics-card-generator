# Lyrics Card Generator v3.6.0 發布說明

發布日期：2026-06-29

v3.6.0 聚焦 Windows 桌面端的 Acrylic 視覺體驗：新增深色壓克力與淺色壓克力應用主題，接入真正的 Windows Acrylic 半透明視窗材質，並將桌面視窗升級為自繪標題列。

## 新增

- 新增「深色壓克力」和「淺色壓克力」介面主題。
- Windows 桌面端在支援的系統上使用原生 Acrylic 視窗材質，視窗後方內容會以系統模糊效果透出。
- 新增自繪桌面標題列，保留左側應用程式圖示、軟體名稱和版本號，以及右側最小化、最大化/還原、關閉按鈕。
- 新增桌面視窗控制 IPC，讓自繪標題列可以呼叫最小化、最大化/還原和關閉視窗。

## 改進

- 標題列與視窗本體使用同一層透明 Acrylic 背景，弱化獨立標題列邊界，讓頂部區域與主介面融合得更自然。
- 桌面端內容滾動區域改為視窗內部滾動，右側滾動條不再貼在系統視窗外側。
- 為應用程式內滾動區域加入更簡潔的細滾動條樣式，並啟用 Chromium overlay scrollbar 特性。
- Acrylic 主題下優化文字、按鈕、輸入框、設定彈窗、狀態提示和 toast 的可讀性。
- Acrylic 主題只影響應用程式介面，不影響歌詞卡片本體或 PNG 匯出效果。

## 修復

- 修復桌面端啟動後預設最大化的問題，應用程式現在會以正常視窗尺寸開啟。
- 修復自繪標題列關閉按鈕無法正常關閉視窗的問題。
- 修復最大化按鈕點擊後無法回退到視窗化的問題；現在會記錄視窗化尺寸，並在再次點擊時可靠還原。
- 非 Windows 或不支援 Acrylic 的系統會降級為可讀的透明介面，不會因為視窗材質不可用而崩潰。

## 驗證

- 驗證兩個 Acrylic 主題出現在「設定 → 外觀 → 介面主題」中。
- 驗證切回普通主題時會關閉 Acrylic 視窗材質。
- 驗證桌面開發版可正常啟動並返回頁面。
- 執行 `npm run typecheck`、`npm run core:test`、`npm run build` 和 `npm run desktop:build`。
