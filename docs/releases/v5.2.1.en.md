# Lyrics Card Generator v5.2.1 Release Notes

## Song link parsing restored

v5.2.1 restores real song-link parsing for Spotify, Apple Music, NetEase Cloud Music, and QQ Music while preserving the network hardening introduced in v5.1.0 and v5.2.0.

- Numeric QQ Music `songDetail` links now use `songid` and correctly populate the title, artist, album, and cover.
- NetEase JSON requests negotiate the correct response type and once again return complete song, artist, and album metadata.
- Apple Music uses the original track ID even when the page redirects home, then returns a valid track URL.
- Spotify track links remain compatible, and all four platforms are covered by live-link regression assertions.

## Security and compatibility

- Per-hop URL/DNS validation, redirect revalidation, response size and type limits, and multi-address IPv6/IPv4 fallback remain enabled.
- Lyric-card output, project data formats, and the existing visual direction are unchanged.
- Windows x64 Setup and portable artifacts have been rebuilt for v5.2.1.
