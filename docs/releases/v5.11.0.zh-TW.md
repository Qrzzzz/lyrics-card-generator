# Lyrics Card Generator v5.11.0

> 狀態：已透過 GitHub Releases 公開發佈。

## 橫式卡片全面重寫

- 橫式改為自由比例雙欄版面，預設同時啟用自動歌詞區域寬度與自動高度，不再提供 16:9、21:9、3:2 預設。
- 自動寬度完整測量真實 DOM 換行與自然高度，避開溢出、孤行及不合理的多重換行，近分時優先較緊湊的寬度。
- 左欄統一承載完整比例封面、歌曲資訊、平台標誌、分享者與產生浮水印，並作為單一設計單元等比例縮放。
- 指定高度只作為最小值；內容需要更多空間時畫布會延伸，不會裁切或自動縮小歌詞字級。

## 編輯與相容性

- 歌曲資訊始終顯示；橫式封面始終顯示，直式仍可關閉封面。
- 橫式最多支援 12 個非空邏輯行（原文加已啟用譯文）；第 13 行會保留內容並返回歌詞編輯提供提示。
- 舊橫式比例、尺寸快照與隱藏歌曲資訊／封面的狀態會安全遷移。
- 桌面版與 Web Lite 的預覽、離屏匯出及不可變匯出快照共用同一份測量計畫。
