# Lyrics Card Generator v4.3.0 Release Notes

Release date: 2026-07-05

This release updates the example-song flow, layout controls, Explicit badge rendering, and the final export step.

## Highlights

- Rebuilt the example-song dialog as a responsive grid that chooses two or three columns based on window width.
- Removed per-song translation language buttons; examples now load the translation that matches the current UI language.
- English original lyrics in the English UI now leave the translation field empty.
- Added optional song field `explicit: boolean`; the song info switch now controls the badge directly.
- Renders the inline E badge beside the title in both preview and exported PNG output.
- Keeps the initial size mode on Custom with AutoHeight enabled.
- Changed Content Type and Text Color to segmented slider controls.
- Shows preset and custom text-color options only when their matching mode is selected.
- Reflows visual detail toggles into two columns.
- Moves Complete & Export to the right side of the final step navigation, matching Back button height.
