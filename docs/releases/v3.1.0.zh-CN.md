# Lyrics Card Generator v3.1.0 发布说明

发布日期：2026-06-21

## 概览

v3.1.0 完成字体方案面板重构，让用户能够分别控制中日韩文字体与西文字体，并继续提升 Windows 系统字体在预览和 PNG 导出中的可靠性。

## 修复与改进

- 新增“当前方案 / 预设方案 / 自定义方案 / 字体预览卡片”四个明确区域。
- 预设精简为思源黑体和思源宋体两套方案；每套方案的中日韩与西文字体保持一致。
- 自定义方案可分别选择中日韩文字体与西文字体，数字和半角标点优先跟随西文字体。
- 字体选择改为专用弹窗，提供推荐字体、搜索、完整可滚动列表和候选字体预览。
- 新增真实歌词语境预览；背景由真实卡片算法生成，固定以深海蓝、钴蓝、靛蓝、夜幕蓝作为取色输入。
- 完整字体预览移动到右侧真实卡片下方，并改为更窄、行间距更大且高度刚好包住歌词的纵向版式。
- “字体方案”从布局面板拆分为独立流程步骤；步骤导航按标签长度自适应宽度，短标签不再挤压长标签或显示省略形式。
- 背景生成只用于字体面板预览，不会修改歌词卡片背景参数或最终 PNG。
- 六种界面语言同步加入字体方案文案、按钮、背景算法说明与卡片外脚注。
- 当前方案会按字体组合识别为思源黑体、思源宋体或自定义方案。
- 预览 DOM 与 PNG 导出使用同一套已清理的中日韩 / 西文 `font-family` 栈。
- Windows 字体枚举会拆分组合名称、去重并排序，不再生成含逗号的错误 family 名称。
- 中文字体显示名现在会映射到字体文件中的真实 CSS family，并保留字重和斜体信息。
- 删除了容易产生无效输入的手动 `font-family` 输入框。
- 选择可能无法被当前浏览器识别的字体时会显示非阻断警告。
