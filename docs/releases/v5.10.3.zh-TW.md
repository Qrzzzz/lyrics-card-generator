# Lyrics Card Generator v5.10.3

> 狀態：已透過 GitHub Releases 公開發佈。

這是一次著重無障礙、供應鏈與跨端品質門禁的維護版本。產品介面與匯出設計維持不變，同時將過去仰賴人工檢查的關鍵邊界納入可重複驗證。

## 更新重點

- 修正 Web Lite 中重複、巢狀的主地標，並讓 axe 自動化門禁涵蓋相關無障礙規則。
- 更新生產與建置相依套件，加入具理由與到期日的安全通告例外、Release SBOM，以及 CI／Release 阻斷策略。
- 在儲存庫、Web Lite、GitHub Pages、桌面伺服器、安裝版和可攜版中完整附帶 Source Han Sans／Serif 的 OFL 授權文字。
- 新增持續渲染回歸、排程長卡構圖基準、Electron 執行階段靜態分析與風險邊界覆蓋率，以及 Firefox／WebKit 冒煙矩陣。

## 驗證

本版本通過型別檢查、程式碼檢查、相依與字型授權策略、Chromium 無障礙、Firefox／WebKit 冒煙、生產渲染邊界、Web Lite 完整回歸、Electron 覆蓋率、桌面互動、最終 Windows 成品 smoke、SBOM、校驗和與 attestation 門禁。
