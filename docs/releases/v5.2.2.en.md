# Lyrics Card Generator v5.2.2 Release Notes

## Release and workflow fixes

v5.2.2 fixes the v5.2.1 release tag mismatch and polishes Stepper status, Settings navigation, and the live preview after importing an example.

- The v5.2.1 workflow no longer uses the v5.2.0 tag pattern. A regression gate now requires every release workflow to accept only its own version and matching RC tags.
- The v5.2.2 release flow aligns the app version, six localized notes, Windows artifact names, SBOM, and published-asset verification.

## Interface and preview

- Stepper checkmarks now appear only on steps completed before the active step; the active and future steps retain their correct numbers.
- The Settings back/forward controls no longer have an outer group border, their spacing is slightly wider, and the breadcrumb path is more compact.
- After opening examples from step three, confirming a different song, and returning to the editor, the live preview remeasures after the surface transition and no longer remains abnormally small.
- Lyric-card output, project data formats, and the existing visual direction remain unchanged.
