# Lyrics Card Generator v5.10.2

> 状态：已通过 GitHub Releases 公开发布。

这是一次轻量的提示配色更新。成功、警告与错误轻提示现在统一使用对应语义色的暗色底，并以更鲜亮的同色边框和文字呈现，减少亮色提示的视觉突兀，同时保持状态清晰可辨。

## 更新重点

- 成功提示改为暗绿色底，搭配鲜绿色边框与文字。
- 警告提示改为暗黄色底，搭配鲜黄色边框与文字，不再使用亮黄色背景。
- 错误提示改为暗红色底，搭配鲜红色边框与文字。
- 提示布局、动效、触发方式及产品行为保持不变。

## 验证

三种提示均完成实际界面检查，并通过样式契约、类型检查、代码检查、生产构建和 Web Lite 回归门禁。文字与背景对比度约为：成功 5.23:1、警告 9.52:1、错误 5.84:1。
