# Lyrics Card Generator v4.0.0 リリースノート

リリース日：2026-07-01

v4.0.0 では、最初の曲選択ステップを NetEase Cloud Music の曲名検索にアップグレードしました。曲名、アーティスト、アルバムを入力して候補から選ぶと、楽曲情報、カバー、取得可能な歌詞を自動で取り込めます。既存のリンク解析、ローカル音声解析、手動編集、AI 翻訳、テーマ、PNG 書き出しは引き続き利用できます。

## 主な更新

- NetEase Cloud Music 検索を「曲を選択」の最初の入口として追加。
- 入力中に曲名、アーティスト、アルバム、再生時間を含む候補を表示。
- 矢印キー選択、Enter 取り込み、マウスクリック取り込みに対応。
- 曲名、アーティスト、アルバム、カバー、取得可能な NetEase 歌詞を取り込み。
- 歌詞取得に失敗しても楽曲情報の取り込みは継続し、既存の歌詞取得ボタンや手動編集を使えます。

## 互換性

- Spotify、Apple Music、NetEase Cloud Music、QQ Music のリンク解析入口は残しています。
- ローカル MP3 / FLAC のメタデータと埋め込み歌詞解析は残しています。
- 手動編集、歌詞編集、AI 翻訳、カバー色抽出、スタイル設定、PNG 書き出しは変更していません。

## 利用メモ

- 結果が曖昧な場合は、曲名とアーティスト名を一緒に入力してください。
- NetEase 検索と歌詞取得にはインターネット接続が必要です。
- 自動取得した歌詞は不完全な場合があるため、書き出し前に確認してください。
