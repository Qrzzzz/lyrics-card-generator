# Lyrics Card Generator v6.9.0

**2026-10-28**

Refines buttons and switches with SaltUI-inspired styling while retaining the original text fields and sliders.

- Capsule action buttons keep distinct primary, neutral, destructive, ghost and icon treatments, with readable text for album and custom accents.
- Ring-to-bar switches add clear state feedback and respect both system and app reduced-motion preferences.
- Text fields and sliders retain their original appearance and input behavior. Settings groups use consistent corners and spacing.
- The About page and all six README editions credit SaltUI and Moriafly. SaltUI’s Apache-2.0 license and attribution are bundled for offline access.
