# Notas de la versión de Lyrics Card Generator v4.3.8

Fecha de publicación: 2026-07-08

Esta versión reconstruye la pantalla de canciones de ejemplo como tarjetas locales de vista previa, más compactas y con color. Las portadas reales de álbumes solo se usan temporalmente para extraer paletas durante el desarrollo y no se distribuyen con la aplicación.

## Cambios principales

- La interfaz de canciones de ejemplo ahora usa tarjetas locales más compactas con máscara de paleta.
- Las imágenes de vista previa de los ejemplos se generan reutilizando el flujo principal de renderizado de tarjetas de letras.
- Las portadas reales de álbumes solo sirven como entrada temporal para extraer colores y no se distribuyen con el software.
- Se añadió `docs/examples.md` para documentar el flujo de mantenimiento de canciones de ejemplo.

- npm run core:test
