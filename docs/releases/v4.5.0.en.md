# Lyrics Card Generator v4.5.0 Release Notes

Release date: 2026-07-11

This release refines information layout on Instrumental cards and the desktop window controls, while completing Settings tab transitions, motion preferences, and export defaults. The new settings connect directly to the current editing flow without changing the existing window-button motion.

## Main Updates

- Instrumental / No Lyrics cards now use more generous spacing between the song title, artist, and album information. The album appears like it does in lyric mode when an album name is available and takes no extra space when it is absent.
- The red, yellow, and green window controls drop the previous release’s 3D styling, return to a flat appearance, and use tighter spacing while preserving their current motion.
- Settings tabs now animate their content transitions for a more connected change between categories.
- General now includes a Reduce motion switch that is off by default. Enabling it reduces interface movement, transitions, and celebration effects; the system reduced-motion preference continues to take effect regardless of the in-app switch.
- Export adds default watermark and sharer settings before Export Quality. Sharer is off by default; when enabled, a default sharer text field becomes available, and both the switch and text update the current card immediately.

- Clear All now slides and fades the existing preview card out to the left while a new blank card enters and fades in from the right. If the card is already blank, a lightweight notice appears and no clear operation is repeated.
- Lightweight notices now use a clearer icon, visual hierarchy, shadow, countdown line, and refined entrance and exit motion. Repeating the same notice retriggers it cleanly.
- The Export step removes the redundant large outer frames and the “Exports only the card, never the editor UI.” information block while preserving quality selection, the export action, and progress feedback.
