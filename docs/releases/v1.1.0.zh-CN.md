这是一次以"瘦身"和"整理"为主的维护更新。

本版本清理了大量历史遗留和未使用代码，拆分了原本过于臃肿的编辑器逻辑，并整理了 Windows 桌面版的构建与打包流程。对普通用户来说，核心功能基本保持不变；对后续开发来说，项目结构更清楚，维护成本更低。

## 主要变化

* 清理未使用代码和冗余逻辑，减少项目负担。
* 重构编辑器结构，将部分界面和逻辑拆分为独立组件。
* 保留原有卡片布局算法，避免清理代码影响歌词卡片渲染效果。
* 修复桌面版导出面板和 PNG 导出控制项。
* 修复桌面版字体打包问题，确保内置字体能够正常加载。
* 整理 Windows 桌面版构建流程。
* 更新版本号、下载文件名和相关版本信息至 `1.1.0`。

## 下载

* 安装版：`Lyrics Card Generator Setup 1.1.0.exe`
* 便携版：`Lyrics Card Generator-1.1.0-portable.exe`

## 注意

本版本仍未进行代码签名。Windows 可能会显示 SmartScreen 提示，这是个人未签名应用的常见现象。
