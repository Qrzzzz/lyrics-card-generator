# Lyrics Card Generator v5.0.2 リリースノート

リリース日：2026-07-12

v5.0.2 は v5.0.0 を基にしたリリース強化版です。既存の編集、プレビュー、書き出し操作は変更していません。

## 主な更新

- アプリ、ロックファイル、6 言語の README、リリースノートをバージョン 5.0.2 に統一しました。
- Next.js、Undici などを互換範囲内で更新し、実行時依存関係の重大度「高」の警告を解消しました。
- Web Lite、Windows インストーラー、ポータブル版、差分更新検証ファイルを再検証して再ビルドしました。

## 検証

- `npm run typecheck`
- `npm run core:test`
- `npm run build`
- `npm run web-lite:build` / `web-lite:check` / `web-lite:smoke`
- `npm run desktop:build` / `desktop:interaction-test`
