# Lyrics Card Generator v3.3.0 發布說明

發布日期：2026-06-25

v3.3.0 新增 Spotify 單曲連結解析支援。現在可以貼上 Spotify 歌曲連結，自動讀取歌曲標題、歌手與封面，並繼續使用現有歌詞卡片編輯、封面取色與匯出流程。

## Spotify 連結解析

- 支援 Spotify 單曲連結解析。
- 支援 `open.spotify.com/track/...`、`open.spotify.com/intl-.../track/...`、`open.spotify.com/embed/track/...` 以及常見 Spotify 短連結。
- Spotify 歌曲可顯示平台 Logo。
- 自動歌詞取得繼續沿用現有實驗性歌詞搜尋邏輯。
- 修復應用程式剛開啟時後續步驟提前顯示完成勾選的問題；現在只有已走過的步驟會顯示完成狀態。

## 使用說明

- 本版本不從 Spotify 取得歌詞。
- 本版本不需要 Spotify 帳號、OAuth 或 API 金鑰。
- 如果自動解析失敗，仍可手動填寫歌曲標題、歌手、封面與歌詞。

驗證：`npm run typecheck`、`npm run parse:test`、`npm run core:test`、`npm run build`，並透過本機 API 驗證 Spotify 解析、歌詞介面 schema 與 Spotify SVG 圖示資源。
