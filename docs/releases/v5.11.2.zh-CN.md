# Lyrics Card Generator v5.11.2

> 状态：已通过 GitHub Releases 公开发布。

## 多行标题修复

- 原“标题允许两行”选项已在六种界面语言中统一更名为“标题允许多行”，实际行为不再限制为两行。开启后，竖版歌词卡和纯音乐卡均可完整显示三行以上标题；关闭时仍保持单行省略。
- 竖版歌词卡的自动高度现在会将标题行数纳入估算，避免长标题占用正文空间或在导出时被裁切。
- 固定 1:1 的纯音乐卡会为多行歌曲信息动态预留高度，并在空间不足时缩小封面，防止标题、歌手或专辑信息越界。横版原有的实测多行布局经审计无需修改；桌面版与 Web Lite 共用相同行为。
