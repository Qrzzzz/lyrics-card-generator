# Lyrics Card Generator v6.7.0 リリースノート

公開日：2026-10-07。

v6.7.0 は流れるグラデーションにレイアウトシードを追加し、同じジャケットの配色で異なる配置を試し、保存して再現できます。単色の候補と透明なジャケットの色抽出も改善します。

## グラデーションの配置

- 背景設定で「レイアウトシード」を入力するか「別の配置を試す」で色の領域と流れの方向を変えます。「標準の配置に戻す」はシード 0 に戻します。
- 配色と各色のエネルギー配分を保ちます。同じジャケット、シード、縦横比で配置を再現でき、同じ縦横比の書き出し解像度を上げても配置は変わりません。
- シードはデスクトップの下書きと一緒に保存・復元され、単色とグラデーションを切り替えても維持されます。

## ジャケットの色抽出

- 似た色が分割されると単色の推奨順位が偏る問題を修正し、統合後の有効面積で主要な色を選びます。
- 似た色を統合してから小さな領域を除外し、代表的な候補の欠落を減らします。
- ほぼ透明な色のノイズを抑えます。完全に透明な領域の隠れた RGB 値と元画像の解像度は、標準の配置シードを変えなくなります。
- 同じジャケットの直近の解析を再利用し、色のクラスタリングが収束したら計算を終了します。

## 使用上の注意

- 領域の移動により重なりと局所的な混色が変わります。単色のジャケットでは配置の違いが小さい場合があります。シードのない古い下書きは標準配置を使います。
- 色抽出の安定性の変更により、古い下書きの標準グラデーションは再配置される場合があります。手動で選んだ単色の値は維持されます。
