# Lyrics Card Generator v6.2.4

> 狀態：已發布。

## 設定可靠性與資訊架構

- 應用程式偏好與 AI 設定儲存失敗後，會在設定頁之外持續顯示本地化提示並提供明確的重試狀態；關閉設定時也不會靜默遺失失敗資訊。
- 「卡片與匯出」分別管理新建卡片的頁尾預設值和檔案匯出預設值。軟體浮水印、分享者及其文字只會在真正新建卡片時套用，不會覆寫目前文件；清空內容仍保留目前視覺設定。
- AI 工作區會分層顯示連線設定、翻譯預設值與提示詞庫，並在首次進入 AI 分類時才載入資料，同時保留已開啟頁面的本機狀態。

## 安全、歷史與儲存

- 新增安全的 AI 連線測試：不傳送歌詞或使用者內容，採用嚴格逾時與資源上限，支援取消，並在觸達服務商前拒絕不安全或惡意 Base URL。
- 自動匯入歷史新增「不保留」，不影響使用者明確儲存的手動封存。應用程式偏好重設只恢復介面、外觀與匯出預設值，不會清除目前文件、歷史、手動封存或 AI API Key。
- 已清理無法到達的舊獨立背景設定與桌面橋接；目前有效的專輯動態應用背景、舊設定移轉相容性與 Web Lite 行為維持不變。

## 無障礙、字型與授權

- 修正設定標題層級、群組名稱、輸入標籤與錯誤關聯，並改善行動版導覽 landmark、歷史導覽和最小視窗版面。
- 原始 CSS 字型設定新增系統預設恢復、輸入淨化、驗證與無障礙錯誤提示；提示詞庫統計現在會區分受保護、可編輯與自訂預設。
- 關於頁新增離線可用的軟體 Source Available License 與隨包思源字型等第三方授權入口，桌面版與 Web Lite 均可存取。

## 下載與升級

- Windows x64 安裝版：`Lyrics.Card.Generator.Setup.6.2.4.exe`。
- 本版本繼續採用 Setup-only 發布方式；從舊版本升級不需要移轉設定。
