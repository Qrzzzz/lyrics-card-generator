# Notes de version de Lyrics Card Generator v3.2.0

Date de sortie : 23 juin 2026

## Centre de paramètres et personnalisation

- Nouveau centre à six onglets : Général, Apparence, Arrière-plan, Exportation, AI et À propos.
- Contrôle Spark Cursor, trois thèmes, police/couleur d’accent/couleur de texte et protection de lisibilité.
- Arrière-plans persistants : couleur unie, étiré, contenu, couverture, flou et palette d’image ; le mode album dynamique reste la valeur par défaut.
- Quatre qualités PNG par défaut : faible, standard, haute et ultra.
- Choix initial parmi six langues et démarrage dans un éditeur vide.
- `opposite` est disponible dans Exemples ; les liens de mise à jour et GitHub se trouvent dans À propos.
