# Lyrics Card Generator v6.4.3

Windows x64：`Lyrics.Card.Generator.Setup.6.4.3.exe`。

## 重要提示与草稿可靠性

- 新增右上角可交互通知，用于草稿恢复、自动保存失败、设置保存失败和历史恢复等需要用户处理的情况；支持关闭、查看历史和重试保存。
- 启动时仅在实际恢复了有内容的草稿后显示“已恢复上次的草稿”，并明确区分自动保存的编辑内容和尚未导出的图片。
- 修复得意黑字体方案无法通过草稿校验、导致关闭前保存失败并阻止应用退出的问题。
- 统一字体方案卡片的标题、说明和同行高度，仅在字体名称样本中使用对应预览字体。
