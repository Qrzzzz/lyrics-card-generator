# Lyrics Card Generator v5.9.7 发布说明

发布日期：2026-08-19

v5.9.7 新增对不规则专辑封面的完整支持。封面不再被强制裁成正方形，而是按图片的原始长宽比参与卡片布局，同时保持既有 1:1 封面的像素级表现不变。

## 原始比例封面

- 横版封面保持原正方形封面的标准高度，并按原始比例向左右扩展。
- 竖版封面保持原正方形封面的标准宽度，并按原始比例向上下扩展。
- 1:1 封面的尺寸、圆角、位置和周边排版保持不变；极端长宽比只在触及画布安全边界时整体等比缩小。
- 所有封面均使用完整图像，不裁切、不拉伸，也不通过方形舞台补边。

## 透明封面与全链路一致性

- 透明 PNG／WebP 不再铺设方形底板，透明区域直接显示卡片背景，并使用适合透明轮廓的阴影。
- 封面的天然宽高、透明度与取色在同一次图片解码中确定，避免预览和导出采用不同尺寸。
- 编辑预览、未缩放导出、纯音乐卡、Web Lite、歌曲信息、导入摘要、搜索结果和历史记录缩略图共用同一套比例规则。
- 导出快照会冻结封面尺寸信息，并在图片解码完成前保持等待，避免异步切换封面时捕获旧比例或未完成图像。

## 兼容性与验证

- 不改变歌词文档、导入历史或手动存档格式，不需要迁移用户数据。
- 已覆盖 1:1、1200×802 横版、879×1200 竖版、极端比例与透明 PNG；1:1 用例保留原尺寸，长方形用例保持完整原图。
- v5.9.6 的导入、解析、AI 翻译、设置、历史记录以及 PNG、WebP、JPG 导出能力继续保留。

## 发布状态

v5.9.7 已通过 GitHub Releases 公开发布。标签源码、安装版、便携版、SPDX SBOM 与 SHA256SUMS 均可从该发布页面获取。
