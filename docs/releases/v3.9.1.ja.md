# Lyrics Card Generator v3.9.1 リリースノート

リリース日：2026-07-01

v3.9.1 は、デスクトップウィンドウの角丸を修正し、カスタムタイトルバーのレイアウトを更新します。非 Acrylic テーマでは Windows ネイティブの角丸クリップを使い、デスクトップ背景、タイトルバーのグラデーション、ノイズレイヤーはアプリ外枠の内側で描画されます。書き出される歌詞カード PNG には影響しません。

## デスクトップウィンドウの角丸

- 非 Acrylic テーマでは透明な CSS 外枠だけに頼らず、Windows ネイティブのウィンドウ境界で外側をクリップします。
- Acrylic テーマは Windows ネイティブの Acrylic 素材を使い続けながら、ウィンドウ背景を透明に保ちます。
- アプリ背景レイヤーは外枠内の絶対配置になり、画像背景、動的アルバム背景、単色背景が角丸コンテナでクリップされます。

## タイトルバー

- カスタムタイトルバーは、左側の赤・黄・緑のウィンドウ操作ボタンで閉じる、最小化、最大化/復元を行うようになりました。
- アプリ名とバージョンは操作ボタンの横に残り、右側の小さなアプリアイコンは削除しました。
- タイトルバーでのウィンドウドラッグは維持し、操作ボタンはドラッグ不可領域として安定してクリックできます。

## 書き出しと Web 版

- ブラウザで動作する Web 版では引き続きデスクトップタイトルバーを表示せず、デスクトップ専用の上部余白も確保しません。
- PNG 書き出し経路には、デスクトップタイトルバー、ウィンドウ枠、外枠背景、Electron デスクトップ API が含まれません。

## 検証

- npm run typecheck
- npm run core:test
