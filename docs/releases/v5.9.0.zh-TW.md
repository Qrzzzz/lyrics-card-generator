# Lyrics Card Generator v5.9.0 發布說明

發布日期：2026-07-31

v5.9.0 為 Windows 桌面版新增「匯入／解析歷史」，用來重新匯入已成功解析或儲存的歌曲與封面。它不是歌詞自動儲存，也不是文件版本歷史。

## 桌面版匯入／解析歷史

- 頂端操作區新增「歷史記錄」，位於「歌詞範例」與「清除內容」之間；全螢幕歷史頁支援搜尋、來源篩選、分批載入、刪除單筆記錄及清除全部歷史。
- 只記錄真正提交成功的連結解析、歌曲搜尋選取、本機 MP3／FLAC 解析，以及上傳本機封面後儲存的操作。失敗、取消、內建範例、一般編輯、清除和匯出皆不記錄。
- 歷史卡片顯示歌曲、來源、匯入時間，以及檔名或網域。重新匯入仍沿用文件取代確認；遠端失敗或本機檔案遺失時，目前文件不會改變。
- 本機檔案移動後可「重新定位」；若檔案大小或修改時間已變更，應用程式會提示並依目前檔案重新解析。

## 安全儲存與保留上限

- 歷史由 Electron 主程序以含 schema 版本的 UTF-8 JSON 串行、原子寫入。損壞的檔案會保留時間戳記備份，再建立空白歷史。
- 記錄只保留重播所需的最小來源與顯示文字，不儲存圖片二進位、Base64、blob URL、匯出圖片、色盤或樣式；遠端封面只保留 URL。
- 呈現程序重新匯入時只提交記錄 ID；本機路徑由主程序保存、驗證與讀取，並透過 Electron 42 的 `webUtils.getPathForFile` 安全登記。
- 相同平台歌曲、正規化連結或本機路徑會更新原記錄並移到最前。設定 → 一般可選擇最多保留 5 筆、10 筆（預設）或無限制；調低上限時會先確認，再依最近使用順序裁剪。

## 範圍與驗證

- 新增介面文案涵蓋简体中文、繁體中文、English、Français、日本語與 Español。
- Web Lite 維持原有介面與行為，不提供瀏覽器版歷史替代實作。
- 純歷史儲存、安全 IPC、設定遷移、封裝清單及真實 Electron 互動回歸涵蓋持久化、去重、裁剪、重播、檔案變更／遺失／重新定位與寫入失敗語意。
