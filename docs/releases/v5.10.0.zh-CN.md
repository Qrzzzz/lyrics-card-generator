# Lyrics Card Generator v5.10.0

> 状态：已通过 GitHub Releases 公开发布。

本版本重构取色卡片背景：不再依赖固定曲线或简单角落色块，而是从封面的空间色彩关系生成稳定、连续且随卡片比例重新构图的柔性色场。

## 更新重点

- 感知调色板保留颜色的位置、面积、明暗、显著度，并由封面内容生成稳定种子。
- 空间锚点会按竖版、横版和超长画布重新布局，融合为连续色场。
- 新约束抑制平行色带、封闭轮廓、重复 S 曲线、脏色和突兀亮斑。
- 歌词安全区使用局部明度与对比度控制，不再给整张图统一盖黑。
- 编辑预览、导出和 Web Lite 共用确定性渲染路径，同一封面结果稳定可复现。

## 验证

已覆盖调色板、空间色场、构图矩阵、文字对比度、Web Lite 视觉回归及桌面制品验证。
