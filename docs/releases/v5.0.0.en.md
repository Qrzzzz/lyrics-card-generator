# Lyrics Card Generator v5.0.0 Release Notes

Release date: 2026-07-12

v5.0.0 rebuilds the first two steps as a focused song-import flow and a long-lyrics workspace, while fully separating the editor viewport, lyrics document, and exported card.

## Main Updates

- Step one now prioritizes NetEase Cloud Music search with a larger query field and result list. Link parsing, local audio, and manual song metadata remain in a compact secondary column.
- Step two becomes a three-column Song Summary, Lyrics Document, and Editing Tools workspace. Original lyrics and translations use equal-height columns with one shared primary scrollbar.
- The lyrics viewport supports Standard, Expanded, and in-app Immersive states, including drag snapping, double-click reset, Escape restore, and keyboard controls.
- Steps one and two no longer render a visible card preview or mobile preview toggle. The existing card-design and preview workflow returns from step three onward.
- Export now uses a permanently mounted off-screen host, so editor height and scroll position cannot change the PNG’s logical dimensions.
- Export is limited to 36 authored non-empty logical lines. Original and translation lines count separately when translation is enabled; blank lines and visual wrapping do not count, and Instrumental mode is exempt.
- Portrait auto height now supports up to 6400px. Real overflow in fixed-ratio or landscape cards blocks export instead of silently clipping content.
- Added complete six-language copy, focus and accessibility semantics, while preserving the existing Web Lite feature boundary.
