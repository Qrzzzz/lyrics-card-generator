# Lyrics Card Generator v4.2.6 リリースノート

リリース日：2026-07-03

このバージョンでは、アプリのアクセントカラーを再構成し、分散していた色取得を統一されたグローバル Accent 仕組みに整理しました。

## 主な更新

- アルバムカバー連動、プリセット、カスタム HEX に対応した統一アクセントカラー設定を追加しました。
- プリセット色は赤、オレンジ、黄、緑、青、紫に対応します。
- AI 翻訳ボタン、最終書き出しボタン、Spark Cursor、Stepper、選択中コントロール、フォーカス状態のアクセント色を統一しました。
- 外観設定を再構成し、インターフェイスモードと Acrylic 効果を別々の設定にしました。
- アルバム動的カラーモードでは Acrylic 効果をまだ利用できません。
- 最終書き出しステップに画像書き出し品質の選択を追加しました。
- 書き出し品質は低、標準、高画質の 3 段階になりました。
- Ultra 書き出し品質を削除し、旧 Ultra 設定は自動的に高画質へ移行します。
- Taylor Swift「Opalite」の多言語サンプル曲を追加しました。
- 今後のインターフェイステーマ拡張に向けて、古い設定フィールドと背景関連文言を整理しました。

## 互換性と移行

- 旧 `uiAccentColor` は新しいアクセント設定へ移行され、主フィールドとしては使われません。
- 旧 `dark-acrylic` / `light-acrylic` はインターフェイスモードと Acrylic スイッチへ移行されます。
- 旧 `ultra` 書き出し品質は `high` へ移行されます。

## 検証

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:build
