# Lyrics Card Generator v6.2.6

> 狀態：尚未發布。

## 更輕的內容層次

- 移除歌曲資訊、歌詞與頁尾後方覆蓋較大範圍的局部可讀性遮罩，背景不再出現成片的明暗陰影。
- 淺色文字只保留 2px 位移、8px 模糊的低透明度投影；深色文字使用更輕的 1px 位移、4px 模糊亮邊，讓字形輕輕浮在背景上。
- 專輯封面的透明邊緣與一般矩形封面統一改用更小、更低透明度的投影，同時保留透明 PNG 的自然輪廓。

## 字型方案與版面

- 自訂方案移除外層巢狀底板，改用與思源黑體、思源宋體預設相同的單層卡片、邊框與選取語意。
- 「編輯方案」、目前使用狀態、自訂字型摘要與鍵盤焦點行為維持不變。
- 版面步驟中「內容需要更多空間時……」的冗餘說明繼續保持移除；自動高度與防裁切行為不變。

## 下載與升級

- Windows x64 安裝版：`Lyrics.Card.Generator.Setup.6.2.6.exe`。
- 本版本繼續採用僅 Setup 的發佈方式；從舊版本升級不需要移轉設定。
