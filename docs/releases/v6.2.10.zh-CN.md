# Lyrics Card Generator v6.2.10

## 修复与改进

- [#165](https://github.com/Qrzzzz/lyrics-card-generator/issues/165) 修复导入等待替换确认或自动草稿补存时，旧操作可能覆盖新链接、歌词或文档的问题。
- [#166](https://github.com/Qrzzzz/lyrics-card-generator/issues/166) AI 翻译与连接测试统一拒绝 HTTP 重定向，阻止请求正文被转发到未授权的下一跳。
- [#167](https://github.com/Qrzzzz/lyrics-card-generator/issues/167) 为经过验证的备用网络地址预留首响应等待时间，避免首个静默地址耗尽整次请求的超时预算。
- Explicit 标识改为白色、50% 不透明度的圆角 SVG，以透明镂空 E 统一卡片预览与导出。

自定义 AI 提供商需要填写可直接响应的 HTTPS 地址，或合法的本机 loopback HTTP 地址；需要重定向的地址请改为最终接口地址。

- Windows x64: `Lyrics.Card.Generator.Setup.6.2.10.exe`.
