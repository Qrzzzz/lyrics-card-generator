# Lyrics Card Generator v5.12.1

> 狀態：已透過 GitHub Releases 公開發布。

## 僅保留所選文字

- 第二步頂端工具列首位新增「僅保留所選內容」，並以輕量強調色顯示；未選取文字時按鈕會維持停用。
- 在原文或譯文欄選取一段文字後執行此操作，會精確保留所選字元並刪除目前欄的其餘內容，不會改動另一欄。
- 操作沿用現有的選取範圍還原與復原／重做記錄；處理後仍會選取保留下來的文字，方便繼續編輯或立即復原。
