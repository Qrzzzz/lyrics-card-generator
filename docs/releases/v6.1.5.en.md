# Lyrics Card Generator v6.1.5

> Status: officially released.

## In-app two-font workbench

- Custom font selection no longer opens a separate WinForms window. It expands inside the existing Font Scheme area and follows the app’s themes, controls, and layout language.
- Compact role cards for CJK and Latin fonts share search, recommendations, and the complete system-font list. Every option shows its family name and a glyph preview.
- Hovering or navigating with the keyboard updates the real lyric card immediately. Swap, restore, and cancel affect only the draft; Apply writes both font roles together.

## Restored sample preview and a leaner desktop path

- The earlier dedicated sample-lyrics card is restored below the real preview, using a fixed background for easier type comparison. It appears only while editing custom fonts and is never included in exports.
- The obsolete native child window, WinForms helper, and related IPC and packaging entries are removed, while the guarded system-font directory service remains available.
- Light and dark themes, custom accent colors, focus restoration, and empty or failed-loading states are covered. Desktop and Web Lite continue to share the same font-scheme and preview rules.
