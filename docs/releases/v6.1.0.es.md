# Lyrics Card Generator v6.1.0

> Estado: publicado oficialmente mediante GitHub Releases.

## Ventana nativa de Electron para elegir fuentes

- La aplicación de Windows mueve la selección de fuentes personalizadas fuera de la superposición interna a una ventana secundaria de Electron con barra de título del sistema.
- Se mantienen la búsqueda, las recomendaciones, la lista completa de fuentes del sistema y las muestras, con una vista previa ampliada que sigue al puntero y al foco del teclado.
- La elección continúa actualizando solo el borrador y la vista previa real de la tarjeta; Guardar como combinación actual sigue siendo el punto de confirmación.

## Seguridad y compatibilidad

- La ventana de fuentes tiene una identidad IPC mínima e independiente, sin acceso a los privilegios de archivos, historial o IA de la ventana principal.
- Web Lite y los navegadores normales conservan una interfaz alternativa integrada compatible.
