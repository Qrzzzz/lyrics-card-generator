# Lyrics Card Generator v0.1.0 發布說明

發布日期：2026-06-16

## 版本定位

這是 Lyrics Card Generator 的第一個 Windows 桌面版發布。它將原有的 Next.js WebUI 歌詞卡片生成器封裝為可直接執行的 Windows EXE 應用，使用者不需要安裝 Node.js，也不需要手動啟動開發伺服器或部署到雲端。

桌面版採用 Electron + Next standalone 本機服務方案。應用啟動後會自動啟動內建 Next 服務，並在桌面視窗中載入本機地址。頁面與 API routes 均在本機執行；Apple Music、網易雲音樂、QQ 音樂、遠端封面與 LRCLIB 只是資料來源，不是部署依賴。

## 下載與安裝

- 安裝版：`Lyrics.Card.Generator.Setup.0.1.0.exe`
- 便攜版：`Lyrics.Card.Generator-0.1.0-portable.exe`

一般使用者建議使用安裝版；如果只是臨時試用，或不想寫入系統安裝目錄，可以使用便攜版。

## 核心功能

- 支援 Apple Music、網易雲音樂、QQ 音樂連結解析。
- 支援手動編輯歌曲名稱、歌手、專輯與封面連結。
- 支援手動輸入與編輯歌詞。
- 支援逐行編輯譯文，並可顯示或隱藏譯文。
- 支援無歌詞或純音樂內容展示。
- 支援遠端封面、本機封面上傳、封面中繼與封面取色。
- 支援直式 / 橫式版面、尺寸、自動高度、字型、字號、行距、文字顏色、圓角、邊框、陰影、平台 Logo、浮水印與分享者文字等樣式控制。
- 支援中文與 English 介面切換，並保留語言設定。
- 支援透過原有 DOM-to-PNG 流程匯出 PNG，預設高畫質 2x 輸出。

## 桌面端體驗

- 雙擊 EXE 即可啟動。
- 視窗預設最大化開啟。
- 應用圖示已覆蓋安裝包、便攜版、工作列、視窗標題列、Web favicon 與應用內標題區。
- 關閉視窗時會自動關閉內建本機服務，避免殘留背景程序。
- 外部連結會交由系統瀏覽器開啟。

## 離線與連線說明

離線可用：開啟應用、手動輸入歌曲資訊、編輯歌詞與譯文、使用本機封面、調整卡片樣式、匯出 PNG。

需要連線：Apple Music / 網易雲音樂 / QQ 音樂連結解析、遠端封面載入、LRCLIB 自動歌詞獲取。

## 初版限制

- 暫不支援自動更新。
- 目前 Windows 構建未進行程式碼簽章，Windows 可能顯示 SmartScreen 提示。
- 安裝版與便攜版均為 Windows x64 構建。
- 遠端解析與歌詞獲取依賴第三方資料來源的可用性。
