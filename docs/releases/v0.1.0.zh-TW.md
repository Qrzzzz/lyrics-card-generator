# Windows 桌面版初版發布

## 更新日誌

### 發布概覽

這是 Lyrics Card Generator 的第一個 Windows 桌面版發布。這個版本將原有的 Next.js WebUI 歌詞卡片產生器完整封裝為可直接執行的 Windows EXE 應用程式。使用者不需要安裝 Node.js，不需要手動啟動開發伺服器，也不需要將專案部署到 Vercel、Netlify 或任何雲端服務。

桌面版採用 Electron + Next standalone 本地服務方案：應用程式啟動後會自動在本機 `127.0.0.1` 上啟動內建 Next 服務，並在桌面視窗中載入本地位址。所有頁面和 API routes 都在本機執行；Apple Music、網易雲音樂、QQ 音樂、遠端封面和 LRCLIB 只作為資料來源，不是應用程式部署依賴。

### 下載選擇

- 安裝版：`Lyrics.Card.Generator.Setup.0.1.0.exe`
- 可攜版：`Lyrics.Card.Generator-0.1.0-portable.exe`

建議一般使用者優先使用安裝版。如果你只是想暫時試用，或不想寫入安裝目錄，可以使用可攜版。

### 核心功能

- 歌曲連結解析：支援 Apple Music、網易雲音樂、QQ 音樂連結。
- 手動輸入歌曲資訊：可手動編輯歌曲名、歌手名、專輯名和封面連結。
- 歌詞編輯：支援手動輸入和編輯歌詞。
- 翻譯編輯：支援逐行翻譯文字，並可顯示或隱藏翻譯。
- 純音樂模式：支援無歌詞或純音樂內容展示。
- 封面能力：支援遠端封面、本機封面上傳、封面代理和封面取色。
- 視覺樣式：支援直式/橫式、尺寸設定、自動高度、字型、字級、行距、文字顏色、圓角、邊框、陰影、平台 Logo、浮水印和分享者文字等樣式控制。
- 語言切換：支援中文和 English UI，並保留語言設定。
- PNG 匯出：保留原有 DOM-to-PNG 匯出方式，預設高解析 2x 輸出，不改用 Electron 螢幕截圖。

### 桌面版體驗

- 按兩下 EXE 即可啟動。
- 預設以最大化視窗開啟。
- 應用程式圖示已統一替換為新的透明圓角圖示，涵蓋安裝包、可攜版、工作列、視窗標題列、Web favicon 和軟體內標題區。
- 關閉視窗時會自動關閉內建本機服務，避免殘留背景程序。
- 外部連結會交由系統瀏覽器開啟，不會在應用程式內部亂跳。

### 離線和連線說明

離線可用：

- 開啟應用程式。
- 手動輸入歌曲資訊。
- 手動編輯歌詞和翻譯。
- 使用本機封面。
- 調整卡片樣式。
- 匯出 PNG。

需要連線：

- Apple Music / 網易雲音樂 / QQ 音樂連結解析。
- 遠端封面載入。
- LRCLIB 自動歌詞取得。

### 初版限制

- 這個版本沒有自動更新功能。
- 這個版本沒有程式碼簽章，Windows 可能顯示 SmartScreen 提示。
- 安裝版和可攜版均為 Windows x64 建構。
- 遠端解析和歌詞取得依賴第三方資料來源的可用性。
