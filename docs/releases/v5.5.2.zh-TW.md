# Lyrics Card Generator v5.5.2 發布說明

發布日期：2026-07-14

v5.5.2 調整前兩步的桌面工作流程，讓歌曲匯入層級更清楚，並減少長歌詞編輯工作區中過多的巢狀邊框。

## 主要更新

- 第一步將網易雲音樂搜尋保留在左側上方；歌曲連結解析與本機音訊解析移至搜尋下方，空間足夠時橫向並排。
- 右側獨立顯示專輯封面、歌曲名、歌手名與專輯名，仍可展開手動編輯歌曲資訊。
- 第一步不再顯示無法使用的「上一步」按鈕；後續步驟的導覽行為維持不變。
- 第二步移除整個歌詞工作區，以及摘要、歌詞文件、編輯工具三欄各自的外框。
- 寬螢幕只在相鄰欄位之間保留 1 像素直向分隔線；窄螢幕堆疊時自動改為橫向分隔線。

## 版本範圍

- 搜尋、連結解析、本機音訊解析、手動歌曲資訊、歌詞編輯與匯出邏輯保持原有行為。
- 輸入框、狀態提示、歌詞統計與動態工具面板仍保留必要的局部邊界。
- 桌面版與 Web Lite 共用的步驟導覽會一致隱藏第一步的無效返回按鈕。

- `npm run web-lite:build` / `npm run web-lite:check` / `npm run web-lite:smoke`
