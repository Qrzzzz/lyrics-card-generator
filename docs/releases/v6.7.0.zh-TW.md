# Lyrics Card Generator v6.7.0 發布說明

發布日期：2026-10-07。

v6.7.0 新增流光漸層佈局種子，同一套封面配色可嘗試、儲存及重現不同的色塊排列，並改善純色候選推薦與透明封面取色。

## 流光漸層佈局

- 在背景設定輸入「佈局種子」，或按「換一種佈局」調整色塊位置與流動方向；「恢復預設佈局」回到種子 0。
- 更換佈局保留封面配色與各顏色的分配權重。相同封面、種子及畫布比例可重現構圖；提高相同比例的匯出解析度不會重新排列。
- 佈局種子隨桌面草稿儲存與還原，切換純色後再切回漸層也保留選擇。

## 封面取色改進

- 修復相近顏色被拆分後影響純色推薦排序的問題，按合併後的有效占比推薦主要顏色。
- 先合併相近顏色再篩選小區域，減少封面候選色遺漏。
- 抑制近乎透明的雜色像素；完全透明區域的隱藏顏色與原圖解析度不再改變預設佈局種子。
- 重用短期內相同封面的分析結果，並在顏色聚類收斂後提早結束計算。

## 使用說明

- 色塊移動後的重疊會改變局部混色；單色封面不同佈局的視覺差異可能較小。舊草稿沒有佈局種子時使用預設佈局。
- 取色穩定性調整後，舊版草稿的預設漸層可能重新構圖；手動選擇的純色保留原值。
