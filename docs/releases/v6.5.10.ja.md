# Lyrics Card Generator v6.5.10 リリースノート

公開日：2026-10-02

v6.5.10 は多数の下書きの保存処理を改善し、下書きのスタイルと AI 設定の検証を統一して、履歴が保存上限を超えた場合のデータを保護します。

## 修正と改善

- 同一の下書きやプレビューだけの変更では重複コピーを省略し、履歴の削除判定を線形走査に変更しました。
- 履歴 JSON ファイルが 64 MiB を超える場合は読み込みや保存を停止し、既存のファイルとバックアップを保持して復元案内を表示します。保存時に上限を超えた場合は、履歴から不要な下書きを削除して再試行できます。
- 下書きのスタイルと AI 設定に共通の検証を使用します。古い下書きの不足フィールドは従来の既定値で補い、型が不正な AI リクエストはプロバイダー呼び出し前に拒否します。

## 更新時の注意

下書きは件数制限によって自動削除されません。既存の履歴ファイルが 64 MiB を超えて履歴を開けない場合は、ユーザーデータ内の app-data/import-history.json と .bak のコピーをバックアップし、開発者に復元をご相談ください。
