# Lyrics Card Generator v5.1.0 發佈說明

發佈日期：2026-07-13

v5.1.0 是穩定性與安全性版本，保留 v5 前兩步既有的視覺方向，集中修正網路請求、匯入競態與匯出一致性。

## 主要更新

- 建立統一 Safe Fetch：每次重新導向前都會再次解析與驗證目標，並限制私有網路、保留位址、逾時、跳數、內容類型及回應大小。
- 歌曲、歌詞與範例匯入採用 document revision 與 last-intent-wins；清空、換歌或較新的操作會中止並捨棄舊結果。
- 換歌改為完整替換歌曲文件，不再殘留上一首歌的封面、explicit、最終 URL、解析方式或譯文。
- 桌面版匯出使用不可變快照與同步互斥，歌詞、樣式、尺寸、檔名及實際 PNG 始終來自同一 revision。
- Web Lite 使用獨立離屏匯出 host，並與桌面版共用 36 行、字型載入、測量、尺寸穩定及 overflow 安全判斷。
- 匯出忙碌、遭阻擋或失敗時會顯示在地化、可恢復的使用者提示。

## 驗證

- 新增 SSRF target 零存取、匯入競態矩陣、跨歌曲欄位重設、匯出快照與並發測試。
- 新增 Web Lite 36/37 行、固定 1:1 overflow 與摺疊預覽匯出測試。
- 完成核心、Web Lite、桌面建置與互動回歸。
