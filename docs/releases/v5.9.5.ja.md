# Lyrics Card Generator v5.9.5 リリースノート

リリース日：2026-08-08

v5.9.5 は安定性を優先したロールバック版です。v5.9.4 のパフォーマンス実装を取り下げ、デスクトップ起動、リソース読み込み、エディター描画、エクスポート計測、システムフォントの各経路を検証済みの v5.9.3 アーキテクチャへ戻し、操作結果の表示も明確で簡潔にしました。

## 安定性のためのロールバック

- デスクトップのローカルサービス起動、renderer のオリジン確認、静的リソース読み込みを、既存のセキュリティ確認を維持したまま v5.9.3 の検証済み経路へ戻しました。
- 例、履歴、設定、AI 翻訳、エクスポート画面は、v5.9.4 で追加した遅延画面レイヤーに依存せず、実績のある読み込みとエラー処理へ戻りました。
- ClickSpark、自動幅、エディターの描画境界、エクスポート準備完了の計測を、検証済みの実装へ戻しました。
- システムフォントは、v5.9.4 のプロセス内キャッシュ、ディレクトリサービス、レジストリ更新ロジックではなく、従来の照会経路を再び使用します。

## 結果表示

- アプリ全体の結果表示を、成功は緑、警告は黄、エラーは赤に分けました。デスクトップ版の履歴、手動保存、設定、AI 翻訳、消去、エクスポートが同じ状態表現を使用します。
- Desktop と Web Lite の六言語メッセージを短くし、文末記号を省き、一般画面に内部エラーの詳細、パス、バックアップファイル名を表示しないようにしました。
- 通常のアニメーションは拡大縮小と上下移動を明確にし、視差効果を減らす設定では透明度だけで切り替わります。

## 互換性

- 歌詞ドキュメント、インポート履歴、手動保存の形式は変更されず、ユーザーデータの移行は不要です。
- v5.9.3 のリクエスト境界、単一インスタンス保護、ローカル音声解析、複数サービスからの曲取り込み、AI 翻訳、PNG・WebP・JPG 書き出しは維持されます。
- 公開済みの v5.9.4 とそのファイルはリリース履歴に残り、v5.9.5 が新しい推奨安定版になります。

## 公開状況

v5.9.5 は GitHub Releases で公開されています。タグ付きソース、インストーラー、ポータブル版、SPDX SBOM、SHA256SUMS はリリースページから取得できます。
