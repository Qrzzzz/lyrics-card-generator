# Lyrics Card Generator v6.4.3

Windows x64：`Lyrics.Card.Generator.Setup.6.4.3.exe`。

## 重要な通知と下書きの信頼性

- 下書きの復元、自動保存や設定保存の失敗、履歴の復旧を知らせる操作可能な通知を右上に追加しました。通知を閉じる、履歴を開く、保存を再試行する操作を利用できます。
- 起動時に内容のある下書きを実際に復元した場合だけ「前回の下書きを復元しました」と表示し、保存済みの編集内容と未書き出しの画像を明確に区別します。
- Smiley Sans を使った下書きが終了時の検証に失敗し、保存失敗後にアプリを閉じられなくなる問題を修正しました。
- フォント方案カードの見出し、説明、同じ行の高さを統一し、各プリセットのフォントはフォント名のサンプルだけに適用します。
