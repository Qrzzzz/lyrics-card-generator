# Lyrics Card Generator v5.10.1

> 状态：已通过 GitHub Releases 公开发布。

本版本修复 v5.10.0 空间色场可能放大小面积高饱和色、反转封面主导色系的问题。背景现在先按封面可见面积分配颜色家族预算，再在预算内优化空间构图与色差。

## 更新重点

- 锚点数量与总能量按来源颜色家族的可见面积分配，主导色系在各预设比例中保持主导。
- 小面积高光色具有明确扩张上限，不再吞并整张背景。
- 四个边缘锚点也使用来源颜色家族偏好；色差优化只在已分配家族内进行。
- 相同宽高比共用语义种子，改变输出分辨率不会重新排列颜色角色。
- 编辑预览、导出与 Web Lite 共用同一修复后的确定性渲染路径。

## 验证

加入 88% 冷蓝、12% 暖色高光的回归夹具并覆盖五种预设比例；暖色输出面积稳定在 5.0%–8.2%。同时通过完整核心测试、120 项构图矩阵、生产构建、Web Lite 浏览器测试和 Windows 安装包／便携版冒烟测试。
