# Lyrics Card Generator v6.8.0 リリースノート

公開日：2026-10-16。

v6.8.0 は第2ステップを「整理」「対訳」「確認」に再編し、ツール検索と Ctrl+K コマンドパレットを統合します。既存の編集機能と業務ロジックを維持します。

- 空行、貼り付け、LRC、行結合、段落タグ、選択範囲の保持、区切りを直接表示します。対訳には翻訳切り替え、AI、交互分割、書式、原文と訳文の交換をまとめます。
- 行の対応、異常な文字、重複、長い行、書き出し制限をサイドバーで確認できます。すべての問題を該当箇所へ移動でき、繰り返しの歌詞を自動削除しません。
- 上部は元に戻す、やり直す、歌詞取得、AI、検索を中心とし、選択範囲に応じた操作を表示します。名前・キーワード・多言語の類義語を共通の登録表で検索し、破壊的操作はプレビューで確認します。
- 編集約2/3・ツール約1/3、対訳の共有スクロール、読みやすい幅を維持します。折りたたみと狭い画面のドロワーに対応し、選択・スクロール位置・取り消し・AI ページ・自動保存を再利用します。
