# Lyrics Card Generator v6.1.4

> ステータス：正式リリース済み。

## 検索できる共有フォントブラウザー

- Windows のネイティブフォント構成ウィンドウで、CJK 用と欧文用の役割が 1 つのシステムフォントブラウザーを共有するようになりました。役割を切り替えて、それぞれの位置に使うファミリーを選択できます。
- 検索するとインストール済みフォントが即座に絞り込まれます。各行にはファミリー名と字形プレビューが表示され、件数表示と検索結果がない場合の専用状態も備えています。
- 2 つのフォントの交換、ウィンドウを開いた時の構成への復元、キーボードによる検索と選択に対応しました。確定した選択だけが現在の構成へ反映されます。

## ネイティブブリッジの信頼性

- 完全な WinForms 補助スクリプトを標準入力経由で PowerShell に渡すようにし、複雑な UI スクリプトが Windows のコマンドライン長制限を超えないようにしました。
- メインウィンドウへのモーダル所有関係、制限付き結果解析、入力検証、失敗時のフォールバックは維持されます。Windows 以外のデスクトップ版フォールバック、ブラウザーの選択画面、歌詞カードの描画規則は変更していません。
