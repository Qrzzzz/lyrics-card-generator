# Lyrics Card Generator v5.0.4 發佈說明

發佈日期：2026-07-12

v5.0.4 精簡歌詞編輯操作，並統一設定頁的視覺層級。

## 主要更新

- 繼承 v5.0.2 的固定搜尋結果區域、結果數量、網易雲來源標籤和重新設計的歌曲清單。
- 第二步固定使用最大可用高度，移除標準、延展、沉浸切換與底部拖曳列。
- 重排設定頁首和麵包屑，改善導覽空間與目前路徑辨識度。
- 將 AI 工作區重做為與其他設定頁面一致的緊湊入口清單。
- 新增 Olivia Rodrigo 的《honeybee》和 BIGBANG 的《Lies》範例，並讓範例庫以兩列捲動版面顯示。

## 驗證

- `npm run typecheck`
- `npm run core:test`
- `npm run build`
