# Lyrics Card Generator v6.2.6

> 状态：尚未发布。

## 更轻的内容层次

- 移除歌曲信息、歌词和页脚后方覆盖较大范围的局部可读性遮罩，背景不再出现成片的明暗阴影。
- 浅色文字仅保留 2px 位移、8px 模糊的低透明度投影；深色文字使用更轻的 1px 位移、4px 模糊亮边，让字形像轻轻浮在背景上。
- 专辑封面的透明边缘和普通矩形封面统一改用更小、更低透明度的投影，同时保持透明 PNG 的自然轮廓。

## 字体方案与布局

- 自定义方案移除外层嵌套底板，改用与思源黑体、思源宋体预设相同的单层卡片、边框和选中语义。
- “编辑方案”、当前使用状态、自定义字体摘要和键盘焦点行为保持不变。
- 布局步骤中“内容需要更多空间时……”的冗余说明继续保持移除；自动高度和防裁切行为不变。

## 下载与升级

- Windows x64 安装版：`Lyrics.Card.Generator.Setup.6.2.6.exe`。
- 本版本继续采用 Setup-only 发布方式；从旧版本升级无需迁移配置。
