# Lyrics Card Generator v6.1.2

> Estado: publicado oficialmente mediante GitHub Releases.

## Combinación nativa de dos fuentes

- Las entradas separadas para las fuentes CJK y latina se sustituyen por una única entrada «Editar combinación».
- En Windows abre una ventana WinForms nativa vinculada a la ventana principal. Sus dos botones de selección invocan por separado el `FontDialog` del sistema; no se crea un selector dibujado con Electron o HTML.
- La ventana muestra ambas familias actuales y sus vistas previas. Cancelar descarta todo el borrador; «Aplicar combinación» confirma las dos fuentes una sola vez y devuelve el foco a la entrada principal.

## Integridad de fuentes y compatibilidad

- En Windows, `FontDialog` presenta directamente las fuentes del sistema, sin clasificación por nombre dentro de la aplicación. En las alternativas para escritorio no Windows y navegador, las categorías solo afectan a las recomendaciones y la vista previa, y todas las fuentes enumeradas siguen disponibles para ambos usos.
- El puente nativo conserva validación estricta de campos, propiedad modal mediante el identificador de la ventana principal y análisis restringido del resultado. La alternativa de escritorio no Windows mantiene IPC aislado y mínimo.
- Las combinaciones personalizadas mantienen las estructuras existentes de vista previa, exportación y persistencia, sin cambiar las reglas de renderizado de las tarjetas.
