# Lyrics Card Generator v5.8.6 Release Notes

Release date: 2026-07-24

v5.8.6 changes only the AI translation hierarchy inside the Translation tool in step two. AI translation no longer expands inline on the home page; it opens as an independent second-level sliding page with a reversible Back transition. Existing AI behavior, lyric editing, and workspace layout are unchanged.

## An independent AI translation page

- Opening AI translation slides Translation home out to the left while the AI page enters from the right. Back moves both pages together in the opposite direction.
- Cleanup／Translation tabs, operation feedback, the sidebar frame, lyric editor, top command bar, and fixed 2:1 split remain stationary.
- Translation home and the AI page own separate vertical scrollers, avoiding extra space from the taller page and preventing horizontal overflow.

## Keyboard and narrow-screen hierarchy

- Focus moves to the AI page Back button after entry completes, then returns to the AI translation trigger after the reverse transition.
- The exiting page is removed from interaction and assistive-technology navigation immediately, so offscreen controls cannot enter the Tab order.
- In the narrow-screen drawer, the first Escape returns to Translation home and the second closes the drawer. Returning during a translation stops the request first.
- Reduced motion removes horizontal travel while preserving page hierarchy and focus behavior.

## AI behavior is unchanged

- Translation styles, custom styles, Reasoning, loading state, reasoning stream, translation stream, errors, and result application are unchanged.
- Starting a translation keeps the AI page visible so users can follow the stream or stop the request explicitly.
- Cleanup, column tools, the lyric editor, and all other settings pages are unchanged in this release.
