# Lyrics Card Generator v6.2.8

## 自動儲存與歷史還原

- 移除手動存檔按鈕，在標題列正中央以一行文字顯示自動儲存狀態；停止修改 5 秒後儲存目前草稿。
- 草稿保留歌詞原文、譯文、分段與對應關係，以及歌曲資訊、卡片樣式、匯出設定、目前步驟及尚未提交的歌曲資訊表單；本機封面可隨草稿還原。
- 正常關閉或切換文件前立即補存，下次啟動還原上次草稿。儲存失敗會阻止正常關閉，點選標題列失敗提示可重試；舊歷史與手動存檔仍可讀取。
- 精簡重複的 CI、建置與發佈檢查，保留資料還原、安全、跨瀏覽器、渲染匯出及新安裝程式驗證。

## 範圍與限制

- 僅桌面版提供自動草稿。歷史選擇「不保留」會暫停後續自動儲存，但不刪除既有草稿；刪除目前歷史後，該工作階段停止寫入，匯入新歌曲或清空後重新開始。
- 強制結束程序、斷電或磁碟損壞時只能還原成功寫入的版本。持續編輯而未停滿 5 秒時，未儲存內容可能超過 5 秒；本版本不提供逐鍵緊急備份。
- 網路封面不保證離線可用；遠端歷史 JSON 的範圍不變，不包含完整卡片樣式或本機封面。

- Windows x64: `Lyrics.Card.Generator.Setup.6.2.8.exe`.
