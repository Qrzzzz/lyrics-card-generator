# Lyrics Card Generator v5.5.1 发布说明

发布日期：2026-07-14

v5.5.1 将自动宽度设为新建竖版自定义歌词卡的默认行为，并进一步加固内容测量、候选选择、行高规范化和跨端回归测试。

## 主要更新

- 新建竖版自定义歌词卡默认开启“自动宽度”。启用时宽度滑块显示实时结果并暂时禁用；关闭后保留最后计算宽度，仍可继续手动微调。
- 行高统一限制为 1.5–2.1、步长 0.05，新建卡片默认 1.8；旧的越界、非步长和无效值会安全归一化。
- 隐藏的原尺寸排版探针会用最终字体完整测量 720–1440 的 37 个候选宽度，求解结果只由当前内容与排版决定，不受开启前手动宽度影响。
- 候选集合必须宽度完整且无重复后才参与计算；评分以全局中位数为中心，并使用稳定的同分决胜规则，测量不完整时不会写入可疑宽度。
- 正文与翻译继续分别检测中日韩字素、西文单词和混合文本的严重孤行，六个内置样例在 Web Lite 与桌面端从最窄或最宽起点都会收敛到同一宽度。
- 内置样例目标宽度固定为 Opalite 1380、相反的我 840、勇者 1100、光辉岁月 800、蜜蜂 880、谎言 920，并允许渲染环境产生 ±20 像素差异。

## 版本范围

- 自动宽度仍只支持竖版、自定义尺寸和歌词模式；固定比例、横版与纯音乐模式保持原有行为。
- 旧状态缺少 `autoWidth` 字段时继续按关闭处理，不会擅自覆盖用户保存的手动宽度。
- 桌面版与 Web Lite 共用同一套测量、评分、自动高度协调和导出安全路径。
