# Lyrics Card Generator v5.0.2 Release Notes

Release date: 2026-07-12

v5.0.2 is a release-hardening update based on v5.0.0. It does not change the existing editing, preview, or export interactions.

## Main Updates

- Aligned the application, lockfile, six localized READMEs, and release notes on version 5.0.2.
- Refreshed Next.js, Undici, and related dependencies within compatible ranges, clearing high-severity runtime dependency alerts.
- Reverified and rebuilt Web Lite, the Windows installer, portable build, and incremental-update validation file.

## Verification

- `npm run typecheck`
- `npm run core:test`
- `npm run build`
- `npm run web-lite:build` / `web-lite:check` / `web-lite:smoke`
- `npm run desktop:build` / `desktop:interaction-test`
