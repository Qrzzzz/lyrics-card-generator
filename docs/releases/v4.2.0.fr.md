# Notes de version de Lyrics Card Generator v4.2.0

Date de publication : 2026-07-03

La v4.2.0 améliore le système d’exemples de paroles de l’application desktop et corrige la préparation du déploiement pour la démo séparée Web Lite / GitHub Pages. Web Lite reste une démonstration en ligne simplifiée, pas l’expérience desktop complète.

## Principales nouveautés

- Les exemples de paroles utilisent maintenant une structure réutilisable : paroles en langue originale + cinq exemples de traductions cibles.
- La fenêtre d’exemples affiche désormais le titre, l’artiste et la langue originale, avec cinq traductions sélectionnables.
- Quand la langue actuelle de l’interface dispose d’un exemple correspondant, cette traduction est sélectionnée par défaut ; sinon la première traduction disponible est utilisée.
- La configuration des exemples ne porte plus la hauteur, la taille, le ratio ni l’état AutoHeight de la carte.
- Charger un exemple renseigne seulement la chanson, les paroles et la traduction, tout en conservant l’enrichissement optionnel de la pochette et de l’album.
- Web Lite / GitHub Pages utilise maintenant des chemins d’icône relatifs explicites et ne package que `index.html`, `public/app-icon.png` et `.nojekyll`.

## Portée

- Le texte des exemples n’est pas intégré aux composants ; il reste centralisé dans `lib/examples.ts`.
- Les exemples n’ajoutent pas de requête à l’exécution, les paroles et traductions restent donc disponibles hors ligne.
- Le correctif Web Lite ne change pas la logique desktop, le build Electron ni le comportement de prévisualisation / export desktop.
- Web Lite reste une démonstration en ligne séparée, simplifiée et approximative ; utilisez l’application desktop pour l’expérience complète.

## Vérification

- npm run typecheck
- npm run core:test
- npm run build
