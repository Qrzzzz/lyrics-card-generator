# Lyrics Card Generator v5.6.2 リリースノート

リリース日：2026年7月16日

v5.6.2 では、編集後半の空間的な連続性とプレビューの操作感を改善し、Desktop と Web Lite の両方に実際の WebP、JPG 書き出しを追加しました。

## より触感のあるライブプレビュー

- ステップ 3〜6 では、歌詞カードがポインターに合わせて軽く傾き、ホバー時に浮き上がり、押下時に控えめな反発を返します。
- カード外でボタンを離した場合、操作をキャンセルした場合、またはプレビューから離れた場合は確実に初期姿勢へ戻り、傾きや浮き上がりが残りません。
- タッチ操作ではポインター傾斜を有効にしません。システムまたはアプリで視差効果を減らす設定を選ぶと、安定した静止表示に切り替わります。
- これらの効果は表示中のプレビュー層だけに適用されます。独立した書き出しホストには 3D 変形、ハイライト、押下時の影が入りません。

## ステップ 5 から 6 へ続く作業領域

- 「ビジュアル」から「書き出し」へ進むと、以前の設定、プレビュー、新しい書き出し設定が同じ 3 パネルのトラックに並び、全体が左へ移動します。
- プレビューは右から左へ連続して移り、以前の設定は左へ抜け、書き出し設定は右から入ります。ステップ 5 に戻ると同じ経路を逆方向にたどります。
- 画面外の設定は操作不能になり、支援技術からも隠されるため、キーボードフォーカスが見えないコントロールへ移りません。
- 狭いウィンドウではプレビューを先に置く縦並びへ切り替わり、スクロール、sticky プレビュー、横方向にはみ出さない動作を維持します。

## PNG、WebP、JPG 書き出し

- ステップ 6 で PNG、WebP、JPG を選択でき、実際のエンコード、拡張子、MIME タイプが一致するファイルを生成します。
- PNG は可逆のままです。WebP と JPG は高品質の非可逆エンコードを使用し、従来の品質設定は引き続き出力のピクセル比を決めます。
- 「設定 → 書き出し」で既定の画像形式を保存できます。保存後はステップ 6 と次回起動時にその選択を使用します。Web Lite も形式と品質の設定を保存します。
- 書き出しごとに形式、ファイル名、キャンバス寸法、ピクセル比、カード内容を固定します。同時クリック、タイムアウト、キャンセルによって古いダウンロードが確定することはありません。
- SVG は v5.6.2 の対象外であり、このリリースには SVG 書き出しを含みません。

## クロスサーフェスとリリース検証

- Desktop と Web Lite は形式選択、スナップショット書き出し、レスポンシブな作業領域を共有し、生成済み `index.html` はソースと同期しています。
- 6 つの UI 言語、キーボードと支援技術の意味付け、タッチ/視差効果の低減、正方向と逆方向の切り替え、狭いウィンドウ、PNG/WebP/JPG のファイルシグネチャを回帰テストで確認します。
- Windows インストーラーとポータブル版は、パッケージ版の操作テストと最終成果物の smoke test を引き続き通過します。公開 Release では正確なバージョン付きファイル名、SHA256SUMS、SPDX SBOM、GitHub attestation を検証します。
