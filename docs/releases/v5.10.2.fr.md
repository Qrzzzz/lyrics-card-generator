# Lyrics Card Generator v5.10.2

> Statut : publiée sur GitHub Releases.

Cette mise à jour légère ajuste les couleurs des notifications. Les états de succès, d’avertissement et d’erreur utilisent désormais un fond sombre de leur famille sémantique, avec une bordure et un texte assortis plus lumineux. Ils restent ainsi faciles à distinguer sans surface claire trop vive.

## Points forts

- Les notifications de succès utilisent un fond vert sombre avec une bordure et un texte vert vif.
- Les avertissements utilisent un fond jaune-brun sombre avec une bordure et un texte jaune vif, au lieu d’un fond jaune clair.
- Les erreurs utilisent un fond rouge sombre avec une bordure et un texte rouge vif.
- La disposition, les animations, les déclencheurs et le comportement restent inchangés.

## Validation

Les trois états ont été contrôlés visuellement et ont passé les contrats de style, la vérification des types, le lint, la compilation de production et les tests Web Lite. Les rapports de contraste approximatifs sont de 5,23:1 pour le succès, 9,52:1 pour l’avertissement et 5,84:1 pour l’erreur.
