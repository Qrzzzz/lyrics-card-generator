# Lyrics Card Generator v6.1.1

> 状態：GitHub Releases で正式公開済みです。

## Windows 標準のネイティブフォントダイアログ

- Windows デスクトップ版は、Electron や HTML で描画したフォントウィンドウを作成せず、OS の `FontDialog` を直接呼び出すようになりました。
- システムダイアログは Electron メインウィンドウのハンドルを owner として真の Windows モーダル関係を保ちます。同時に開けるのは 1 つだけで、確定・キャンセル後にフォーカスを戻します。
- 選択したフォントファミリーは、まずカスタム構成の下書きと実際の歌詞カードプレビューを更新し、「現在の構成として保存」で確定します。

## 信頼性と互換性

- ネイティブブリッジは STA を明示し、ウィンドウハンドル、フォント名、補助プロセスの出力、戻り値を制限します。起動に失敗した場合は未選択として安全に終了します。
- デスクトップ回帰テストは古い `release` ビルドではなく、指定した隔離候補 EXE を対象にできます。ブリッジ、IPC セキュリティ、パッケージ内容には個別の契約テストがあります。
- Windows 以外のデスクトップ環境と通常のブラウザーは従来のアプリ内フォールバックを維持し、Web Lite のフォント選択動作は変わりません。
