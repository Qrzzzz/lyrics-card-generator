# Lyrics Card Generator v5.9.2 发布说明

发布日期：2026-08-06

v5.9.2 修复 Windows 桌面版从历史记录载入手动存档后，已保存的专辑封面不会恢复的问题。

## 历史载入与封面恢复

- 载入手动存档时会恢复存档中经过安全清洗的远程封面 URL，并交给现有图片代理和封面取色流程处理。
- 不会重新解析歌曲链接，也不会覆盖存档中的标题、歌手、专辑、歌词或译文；原有的存档绑定与后续原位更新语义保持不变。
- 没有封面 URL 的旧存档继续以无封面状态载入；本地封面仍按原有文件历史与重新定位流程处理。

## 安全边界与验证

- 远程封面仍只通过应用内图片代理加载，不直接请求外部封面地址；图片二进制、Base64、blob URL、本地路径与敏感查询参数不会写入手动存档。
- 回归覆盖确认封面能够显示和取色，同时不会触发歌曲链接、搜索结果或本地音频的重复解析。
- Web Lite 的界面与行为保持不变。
