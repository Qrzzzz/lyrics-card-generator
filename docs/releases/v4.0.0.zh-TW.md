# Lyrics Card Generator v4.0.0 發佈說明

發佈日期：2026-07-01

v4.0.0 將第一步選歌入口升級為網易雲音樂歌名搜尋。使用者可以直接輸入歌名、歌手或專輯關鍵字，從即時候選中選擇歌曲，然後自動填入歌曲資訊、封面和可用歌詞。原有連結解析、本機音訊解析、手動編輯、AI 翻譯、主題和匯出流程保持可用。

## 主要更新

- 新增網易雲音樂歌名搜尋入口，作為「選擇歌曲」的第一入口。
- 輸入關鍵字時即時顯示候選歌曲，並展示歌名、歌手、專輯和時長。
- 支援方向鍵選擇、Enter 匯入和滑鼠點擊匯入。
- 選中歌曲後自動填入標題、歌手、專輯、封面，並盡量取得網易雲歌詞。
- 歌詞取得失敗時不會阻塞歌曲資訊匯入，使用者仍可使用現有自動取得歌詞或手動編輯。

## 相容與保留

- Spotify、Apple Music、網易雲音樂、QQ 音樂連結解析入口繼續保留。
- 本機 MP3 / FLAC 中繼資料和內嵌歌詞解析繼續保留。
- 手動填寫歌曲資訊、歌詞編輯、AI 翻譯、封面取色、樣式設定和 PNG 匯出流程保持不變。

## 使用建議

- 搜尋結果不準確時，建議同時輸入歌名和歌手名。
- 網易雲搜尋和歌詞取得需要連網。
- 自動歌詞結果可能不完整，請在匯出前自行檢查。
