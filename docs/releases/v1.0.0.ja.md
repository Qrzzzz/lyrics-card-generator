これは Lyrics Card Generator の初の公式デスクトップリリースです。v0.1.0 の初回デスクトップ版と比較して、このリリースでは Windows 向けデスクトップ配布プロセスの改善、アプリ内アップデートチェック、カードレイアウトの安定性、エクスポート体験の向上に重点を置いており、正式な配布可能バージョンとしてご利用いただけます。

## 主な更新内容

### Windows デスクトップ版の正式化

* アプリバージョンが `1.0.0` にアップグレードされました。
* Electron デスクトップエントリポイントを追加し、Windows ユーザーは EXE を直接実行できます。
* デスクトップ版はビルトインの Next standalone サービスをローカルで起動し、デスクトップウィンドウ内にローカルアプリを読み込みます。
* Node.js のインストールや開発サーバーの手動起動は不要です。
* Windows x64 インストーラー版とポータブル版に対応しています。
* デフォルトでウィンドウを最大化して開きます。
* 外部リンクはシステムブラウザで開きます。
* アプリ終了時にローカルサービスを終了します。

### 新機能: アップデートの確認

* 上部ツールバーに「アップデートを確認」ボタンを追加しました。
* アプリは GitHub Releases から最新バージョン情報を取得します。
* `v1.0.0` / `1.0.0` のようなバージョン番号形式の比較に対応しています。
* 新しいバージョンが見つかった場合、ダウンロードページへの入口を提供します。
* リリースに `.exe` または `.msi` インストーラーが含まれている場合は、それらを優先的に案内します。
* この機能はアップデートの確認とダウンロードページを開くのみで、現在のプログラムの自動置き換えは行いません。

### 自動高さ修正

* 縦向きカスタムサイズで、自動高さが実際の歌詞内容、翻訳内容、フォントサイズ、行間、タイトル領域、ボーダー、フッター内容に基づいて総合的に推定されるようになりました。
* プラットフォームロゴ、シェア者、生成ウォーターマークを有効にすると、歌詞領域を圧縮せずにカードの高さが下方向に拡張されます。
* 自動高さはデフォルトで有効です。
* 縦向きカスタム高さの上限が `3200px` に引き上げられ、長い歌詞や翻訳、フッターを同時に表示するシーンに適しています。

### 横向きボーダーレイアウト修正

* 横向きカードで「ボーダー + 影」を有効にした際の、プラットフォーム情報、シェア者、生成ウォーターマークの配置ずれを修正しました。
* 横向きレイアウトは統一された frame-aware 座標系を使用するようになりました。
* ボーダーを有効にすると、カバー、曲情報、歌詞、フッター要素がすべてボーダー内側のセーフエリアに入ります。
* 16:9、21:9、3:2 などの横向き比率におけるフッターとボーダーの位置ずれを修正しました。

### エクスポート体験の最適化

* エクスポートフローを「完了してエクスポート」に簡素化し、重複するエクスポート設定入口を削減しました。
* デフォルトで高解像度 2x PNG 出力を継続使用します。
* エクスポート成功時の祝賀アニメーションを、より控えめなトップ紙吹雪エフェクトに変更しました。
* 「すべてのコンテンツをクリア」した際にエクスポート祝賀アニメーションが誤って発動する問題を修正しました。

### アイコンとリリースエンジニアリングの改善

* アプリアイコンアセットを置き換え、統一しました。
* Windows インストーラーアイコン、ポータブルアイコン、Web favicon、アプリ内タイトル領域アイコンを追加しました。
* デスクトップ版ビルドスクリプトおよびリリース準備スクリプトを追加しました。
* デスクトップ版実行手順、移行チェックリスト、既知の問題ドキュメント、リリースノートを追加しました。
* `.gitignore` を更新し、ビルド成果物、リリースファイル、キャッシュ、ログがソースリポジトリにコミットされるのを防止します。

## 保持されている機能

* Apple Music、NetEase Cloud Music、QQ Music のリンク解析。
* 曲情報、歌詞、翻訳の手動編集。
* ローカルカバーアップロード、リモートカバー中継、カバーカラー抽出。
* 縦向き / 横向きカード生成。
* フォント、フォントサイズ、行間、色、ボーダー、影、ウォーターマーク、シェア者、プラットフォームロゴなどのビジュアル設定。
* 中国語 / 英語インターフェース切替。
* オフライン起動、手動編集、ローカルカバー、PNG エクスポート。

## 引き続きインターネット接続が必要な機能

* 音楽プラットフォームリンク解析。
* リモートカバーの読み込み。
* LRCLIB 自動歌詞取得。
* GitHub アップデート確認。

## 既知の制限事項

* 現在のバージョンは未署名のため、Windows で SmartScreen 警告が表示される場合があります。
* アップデート確認ではインストーラーを自動ダウンロードしません。ユーザーが手動でダウンロードページを開く必要があります。
* 現在の配布ターゲットは Windows x64 です。
* サードパーティプラットフォームの解析と歌詞取得は、上流サービスの可用性に依存します。

## 検証

* `npm run typecheck` 合格。
* `npm run build` 合格。
* `npm run desktop:pack` 合格。
* `npm run desktop:build` 合格。
* Apple Music、NetEase Cloud Music、QQ Music 解析サンプル合格。
* ローカルカバー中継検証合格。
* LRCLIB 歌詞取得検証合格。
* ポータブル EXE および unpacked EXE の起動検証合格。
* アプリ終了後に残留プロセスがないことを確認。
* デフォルト `1040x1080` カードが `2080x2160` PNG としてエクスポート可能。
