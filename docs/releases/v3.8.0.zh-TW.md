# Lyrics Card Generator v3.8.0 發布說明

發布日期：2026-06-30

v3.8.0 聚焦於介面動效與互動打磨，在 v3.7.1 統一控制元件層的基礎上加入集中化動效系統。動效套用於編輯器外殼、設定對話框、預覽外殼、共享控制元件、AI 翻譯面板與應用背景；匯出的歌詞卡片 PNG 輸出沒有刻意變更，本版本也不引入動畫化卡片匯出。

## 動效系統與編輯體驗

- 新增輕量動效令牌與可重用動效元件，統一面板、對話框、步驟切換與控制回饋的持續時間、緩動與彈性參數。
- 步驟設定器改用方向感知切換：前進時內容從右側進入、向左退出；後退時方向相反。
- 設定對話框、設定分類標籤與預覽外殼採用統一進入 / 退出動效，行動版預覽展開收合更平滑。

## 控制元件、AI 面板與背景

- 共享按鈕、開關、選項卡片與分段控制加入克制的按壓、選取與指示器動效，並保留鍵盤操作、焦點樣式、ARIA 與測試鉤子。
- AI 翻譯面板改用共享選項卡片、開關與按鈕，並為狀態、思考流與譯文流加入統一過渡；請求、串流輸出與取消邏輯保持不變。
- 應用外殼背景在主題、圖片與調色盤模式切換時更順滑，但不改動匯出卡片內部的 `PaletteBackground`。

## 可及性與匯出安全

- 尊重 `prefers-reduced-motion`：橫向移動、懸浮位移、裝飾 keyframe、點擊火花與匯出慶祝等動效會降級為透明度變化或直接停用。
- `LyricCard.tsx`、`LandscapeLyricCard.tsx` 與 `PaletteBackground.tsx` 未引入 Framer Motion。
- `data-export-card="true"` 的靜態匯出路徑保持穩定，匯出的 PNG 外觀沒有刻意改動。

## 驗證

- npm run typecheck
- npm run core:test
- npm run build
