# Lyrics Card Generator v3.7.0 發布說明

發布日期：2026-06-29

v3.7.0 是一次維護與穩定性版本，不引入新的版面、主題、音樂平台或匯出行為。這次更新聚焦於桌面背景圖片路徑安全、AI 翻譯錯誤兜底、更新入口一致性、舊程式碼清理與發布校驗穩定性。

## 修復

- 強化桌面背景圖片 `imageId` 驗證，只接受應用程式生成的 `png`、`jpg`、`jpeg`、`webp`、`gif` 檔名，並拒絕路徑穿越或偽造值。
- 讀取背景圖片時改用明確 MIME 對應，不再接受 SVG 或未知副檔名。
- 改善 AI 翻譯對非標準服務商回應、純文字錯誤、損壞 JSON 與空回應的兜底處理，避免異常回應導致應用程式崩潰。
- 「開啟發布頁面」按鈕現在始終開啟 GitHub Release 頁面，不再跳往安裝包直連。

## 維護

- 移除未使用的舊版 `CustomFontPanel` 程式碼，同時保留目前 `FontSchemePanel` 行為不變。
- 清理已移除純音樂輸入框的殘留 i18n 文案，同時保留 `instrumentalText` 資料相容與卡片視覺結果。
- 將 `v3.6.1` 專用發布測試拆分為通用發布一致性測試與標題列回歸測試。
- 新增最小 CI 工作流，用於執行安裝、型別檢查、核心測試與 Web 建置。

## 驗證

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:dev
- npm run desktop:build
