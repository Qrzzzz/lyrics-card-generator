# Lyrics Card Generator v5.0.4 发布说明

发布日期：2026-07-12

v5.0.4 精简歌词编辑操作，并统一设置页的视觉层级。

## 主要更新

- 继承 v5.0.2 的固定搜索结果区域、结果数量、网易云来源标签和重设计歌曲列表。
- 第二步固定使用最大可用高度，移除标准、扩展、沉浸切换与底部拖动条。
- 重排设置页头和面包屑，改善导航空间与当前路径辨识度。
- 将 AI 工作区重做为与其他设置页面一致的紧凑入口列表。
- 新增 Olivia Rodrigo 的《honeybee》和 BIGBANG 的《Lies》示例，并让示例库以两行滚动布局展示。

## 验证

- `npm run typecheck`
- `npm run core:test`
- `npm run build`
