# Lyrics Card Generator v6.2.5

> 状態：公開済み。

## 軽量なプロジェクト署名

- 書き出しカードの `generated by lyric card generator` を、説明的な接頭辞のない短い `Qrzzzz/lyrics-card-generator` に変更しました。
- 署名両側の区切り線を廃止し、ウェイト 400、縦向き基準 26px、横向きスケール基準 30px、文字間隔 0.02em の標準字幅サンセリフ 1 行表示にしました。
- `Qrzzzz` と `/lyrics-card-generator` は連続したまま表示し、72% と 52% の控えめな不透明度差で階層を保ちつつ、縮小後のにじみを避けます。

## フッターと設定

- 縦向きでは署名とプラットフォーム／共有者情報の間隔を 14px に縮小しました。横向きは既存の accessories 描画経路と比例する 16px 間隔を維持し、レイアウト手順の冗長な自動拡張説明を削除しました。
- エディターの「生成ウォーターマークを表示」を「プロジェクト署名を表示」に変更し、アプリ設定の新規カード既定値も同じ表現に統一しました。
- `showGeneratedWatermark` など既存の文書・設定フィールドは変更しないため、設定や過去の文書の移行は不要です。

## ダウンロードとアップグレード

- Windows x64 インストーラー：`Lyrics.Card.Generator.Setup.6.2.5.exe`。
- 本リリースも Setup のみを配布します。旧バージョンからのアップグレードに設定移行は不要です。
