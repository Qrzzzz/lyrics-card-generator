# Lyrics Card Generator v4.6.0 Release Notes

Release date: 2026-07-11

This release rebuilds the AI lyric-translation prompt system so strict output rules, default styles, and user-defined styles can be managed independently while keeping the requirement that AI returns only the translated lyrics.

## Main Updates

- AI Settings now contains separate API Configuration and Prompt Library pages, with file-explorer-style Back, Forward, and clickable path navigation.
- Recommended is the one protected preset and always remains available. The other five defaults support title and style-prompt editing, deletion, reset, and restoration.
- Users can create up to two custom presets, each with a title and style prompt, for a maximum library size of eight presets.
- The custom-preset entry on the main translation panel stays collapsed by default and shows at most two user presets when expanded.
- Strict Format Rules remain a shared module for every preset. Editing requires two confirmations, and the module can always be reset to the v4.6.0 defaults.
- Existing AI settings migrate automatically. A custom style replaces only the style module and never removes the shared output-format requirement.
