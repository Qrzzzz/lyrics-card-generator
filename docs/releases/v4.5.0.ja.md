# Lyrics Card Generator v4.5.0 リリースノート

リリース日：2026-07-11

このリリースでは、インストゥルメンタルカードの情報配置とデスクトップのウィンドウ操作ボタンを整え、設定タブの切り替え、モーション設定、書き出しの既定値を拡充しました。新しい設定は現在の編集フローへ直接反映され、既存のウィンドウ操作ボタンのアニメーションは変更しません。

## 主な更新

- インストゥルメンタル／歌詞なしカードでは、曲名、アーティスト、アルバム情報の間隔を広げ、ゆとりのある配置にしました。アルバム名がある場合は歌詞ありモードと同様に表示し、ない場合は余分な空間を取りません。
- 赤・黄・緑のウィンドウ操作ボタンから前バージョンの 3D 表現をなくし、平面的なスタイルへ戻してボタン同士の間隔を狭めました。現在のアニメーションはそのまま維持しています。
- 設定の各タブに内容切り替えアニメーションを追加し、カテゴリ間をより滑らかに移動できるようにしました。
- 「一般」に、初期状態ではオフの「動きを減らす」スイッチを追加しました。有効にすると画面移動、切り替え、お祝いエフェクトが抑えられます。アプリ内スイッチの状態にかかわらず、システム側のモーション低減設定も引き続き反映されます。
- 「書き出し品質」の前に、ウォーターマークと共有者の既定値を追加しました。共有者は初期状態ではオフで、有効にすると既定の共有者テキストを入力でき、スイッチとテキストの変更が現在のカードへ即時反映されます。

- 「すべて消去」を実行すると、現在のプレビューカードが左へスライドしながら消え、新しい空のカードが右からスライドして徐々に表示されます。すでに空の場合は軽い通知だけを表示し、消去処理を繰り返しません。
- 軽い通知のアイコン、視覚的な階層、影、残り時間ライン、表示・終了アニメーションを改善しました。同じ通知を続けて発生させた場合も改めて表示されます。
- 書き出し手順から不要な大きい外枠と「カードのみを書き出し、編集画面は含みません。」の案内ブロックを削除し、品質選択、書き出し操作、進行状況は維持しました。
