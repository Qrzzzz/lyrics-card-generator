# Lyrics Card Generator v6.10.0

**2026-11-05**

重做無歌詞分享圖：封面貼邊與漸進柔化，大標題從清晰區起筆，歌曲資訊與底部署名分區排布。

- 固定輸出為 1080×1512，以常見 1:1 封面為設計基準，保留非方形封面的自然比例。
- 封面下部以兩檔大半徑模糊與柔和透明度遮罩漸進柔化，僅鏡像底邊的一小段，避免硬邊與重複畫面。
- 底部沿用現有純色推薦算法，保留候選色、自訂 HEX、白色預設與自動文字對比度。
- 標題預設 108px，五個漢字約佔半幅寬，從清晰封面起筆；歌手 60px、專輯 44px、分享人 36px、專案署名 32px，長標題自動適配。
- 無歌詞卡可在文字排版的對齊設定中選擇靠左或置中，歌曲資訊與署名同步對齊。
- 歌曲資訊跨封面與過渡區排布，分享人及專案署名獨立位於底部純色區，保留顯示開關。
- 桌面版與 Web Lite 共用實作；匯出等待背景完成，避免半成品與舊封面混入。
- 歌詞直式、橫式與原有多色背景維持既有使用方式。
