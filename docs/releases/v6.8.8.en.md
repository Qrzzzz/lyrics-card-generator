# Lyrics Card Generator v6.8.8

**2026-10-27**

Improves desktop regression testing and release delivery while preserving lyric editing, exports and saved settings.

- PR/main share one desktop build across independent editor, workspace, data and native test groups. Long settings scenarios are split without removing behavior assertions.
- Checks the locked Electron runtime for advisories before building, while retaining the final installer’s live security audit.
- Releases may reuse the runtime from the exact final main commit after verifying provenance signatures, toolchain identity and resource hashes. Missing or expired artifacts trigger a full build; identity mismatches stop delivery.
- Improves candidate archiving, interruption recovery and status polling to reduce repeated waits and reruns.

All five required CI checks, final Setup installation and update tests, SBOM, checksums, provenance and public attachment verification remain enforced. Existing motion defaults and window support scope are unchanged. No fixed release duration is promised.
