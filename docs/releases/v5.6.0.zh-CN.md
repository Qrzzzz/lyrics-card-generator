# Lyrics Card Generator v5.6.0 发布说明

发布日期：2026-07-15

v5.6.0 重制“歌词示例”的外层框架，修复窗口边缘渐变，并将第一步“手动调整”升级为带草稿保存与取消的双向滑动编辑流程。示例卡片本身及其他编辑、导入和导出能力保持不变。

## 歌词示例框架

- “歌词示例”现在复用“设置”界面的顶部标题栏结构，并将关闭按钮放在右上角。
- 页面底部原有的“歌词卡片生成器”大型标题框架和关闭入口已移除，示例内容拥有独立的滚动区域。
- 内部示例卡片的内容、渲染和选择导入行为保持不变。

## 窗口边缘渐变

- 修复标题栏单层窗口边缘渐变的重复遮罩，避免模糊和遮罩在边缘过早衰减。
- 模糊层与主题遮罩现在共享一层完整的渐隐范围，并继续适配深色、浅色和亚克力界面。
- “歌词示例”底部复用同一效果的反向版本，让滚动内容与窗口边缘自然衔接。

## 手动调整

- 打开“手动调整”时，现有歌曲信息预览向左滑动并渐隐，编辑页面从右侧滑入并渐显。
- 编辑内容先保存在独立草稿中；“保存”应用草稿，“取消”放弃草稿，不会在编辑过程中直接覆盖当前歌曲信息。
- 保存或取消后，编辑页面以相反动画退出，歌曲信息预览从左侧恢复。

## 开发周期备注

- GitHub Actions 当前提示部分固定 SHA 的 action 仍以 Node.js 20 为目标，并被 runner 强制使用 Node.js 24。
- 该提示留作 5.6.0 开发周期内的独立评估；本次界面更新未修改 workflow 或固定 SHA，也不表示该提示已经解决。
