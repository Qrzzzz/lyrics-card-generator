# Lyrics Card Generator v5.7.0 发布说明

发布日期：2026-07-16

v5.7.0 重构桌面端主页六步工作流，让第 3–5 步的设置区与实时预览可以按任务调整宽度，并为设置项加入按容器宽度计算的紧凑排版。桌面端与 Web Lite 继续提供 PNG、WebP 与 JPG 导出。

## 可调节设置/预览工作台

- 第 3–5 步新增垂直分隔器，左侧设置区可从 1/2 连续扩展到最高 2/3。
- 在较窄的桌面窗口中，上限会自动收紧，保证预览区至少保留 360 px；小于 1024 px 时仍使用上下排列。
- 分隔器支持拖动、方向键微调、Home/End 跳转与双击恢复 1:1，并向辅助技术暴露当前比例。
- 第 5→6 步继续复用同一预览实例，工作台按实际设置宽度平移，不会因切换导出步骤重置预览。

## 容器驱动的紧凑排版

- 布局、文字设计与视觉细节不再仅依赖整个窗口的媒体断点，而是按左侧设置容器的实际宽度计算列数。
- 常规布局行在宽栏下可从一列变为两列；视觉开关可从两列四行收紧为三列三行。
- 条件面板与依赖输入保持整行，所有重排继续保持 DOM 与键盘导航顺序。
- Toggle 控件改用最小高度，长语言标签可以自然换行，不再被固定高度裁切。

## 主页、预览与导出

- 六个桌面端编辑步骤统一使用紧凑 Stepper 和顶部操作区，歌曲、歌词、设置、预览与导出保持同一层级。
- 实时预览会在分栏、窗口尺寸或导入示例变化时重新测量，并在支持的指针设备上提供轻量立体压感反馈。
- 桌面端与 Web Lite 均可按次选择 PNG、WebP 或 JPG；默认格式可在设置中保存，文件扩展名与实际编码格式保持一致。
