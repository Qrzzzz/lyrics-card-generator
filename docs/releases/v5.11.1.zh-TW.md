# Lyrics Card Generator v5.11.1

> 狀態：已透過 GitHub Releases 公開發佈。

## 匯出正確性修正

- 直式卡片中的連續分享者文字現在可在任意字元處換行，並納入完整內容區、頁尾與附屬元素的匯出溢位檢查，不再出現介面允許匯出、成品卻靜默裁切文字的情況。
- PNG、WebP 與 JPG 現在會統一核對要求的像素與實際畫布像素。高品質超長卡片超過瀏覽器單邊 16384 像素限制時會明確阻止匯出，提示降低品質或縮短內容，不再暗中縮小圖片後回報成功。
- 桌面版與 Web Lite 共用相同的內容幾何和像素尺寸門檻；一般尺寸的橫式、直式卡片及既有自動高度演算法維持不變。
