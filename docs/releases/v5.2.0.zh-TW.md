# Lyrics Card Generator v5.2.0 發布說明

發布日期：2026-07-13

v5.2.0 是穩定性、可存取性、桌面安全與發布工程更新，維持既有歌詞卡輸出、資料格式和視覺方向。

## 主要更新

- Safe Fetch 會驗證解析出的全部位址，交錯嘗試 IPv6/IPv4，並在連線失敗後安全切換；整個請求共用同一逾時與重新導向預算。
- 文件語意樣式變更會原子取消目前 AI generation，普通視覺控制不再造成無意義取消；Electron AI 取消依視窗 sender 隔離，並涵蓋 provider 首次等待前的時機。
- 桌面設定使用單調 revision 協調 JSON 與 renderer cache、遷移 5.1.0 資料、序列化快速寫入，並在所有關閉路徑 flush pending settings。
- 共用 accessible dialog 補齊初始焦點、焦點循環、背景 inert、Escape 策略、減弱動效與焦點還原；搜尋、連結解析及本機音訊狀態支援完整鍵盤與 live region。
- 六語錯誤提示由穩定錯誤碼映射，文件語言跟隨 locale；自訂 accent 下焦點仍清晰，並加入 Forced Colors 系統色規則。
- 外部導覽、特權 IPC sender、權限請求與正式版 CSP 均採用明確安全策略。

## 發布保障

- CI 新增 lint、關鍵模組 coverage、axe、六語完整性、Electron 安全、生命週期與最終成品門檻。
- Setup 與 portable 以最終位元組測試；tag 驅動發布會為相同檔案產生 SHA-256、SPDX SBOM 與 GitHub artifact attestation。
