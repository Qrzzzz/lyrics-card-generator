# Lyrics Card Generator v5.10.3

> ステータス：GitHub Releases で一般公開済みです。

アクセシビリティ、サプライチェーン、クロスプラットフォーム品質ゲートを強化するメンテナンスリリースです。製品 UI と書き出しデザインは維持しながら、従来は手動確認に依存していた重要な境界を再現可能な検証へ移行しました。

## 主な更新

- Web Lite の重複・入れ子になった `main` ランドマークを修正し、関連するアクセシビリティ規則を axe 自動化ゲートで検出します。
- 本番・ビルド依存関係を更新し、理由と期限を持つアドバイザリ例外、リリース SBOM、CI／Release のブロックポリシーを追加しました。
- Source Han Sans／Serif の完全な OFL 本文を、リポジトリ、Web Lite、GitHub Pages、デスクトップサーバー、インストーラー、ポータブル版に同梱しました。
- 継続的なレンダリング回帰、定期実行の長大カード構図ベンチマーク、Electron ランタイムの静的解析とリスク境界カバレッジ、Firefox／WebKit スモークテストを追加しました。

## 検証

型検査、lint、依存関係とフォントライセンスのポリシー、Chromium アクセシビリティ、Firefox／WebKit スモーク、本番レンダリング境界、Web Lite の完全回帰、Electron カバレッジ、デスクトップ操作、最終 Windows 成果物の smoke、SBOM、チェックサム、attestation の各ゲートに合格しています。
