# Lyrics Card Generator v4.0.0 发布说明

发布日期：2026-07-01

v4.0.0 将第一步选歌入口升级为网易云音乐歌名搜索。用户可以直接输入歌名、歌手或专辑关键词，从实时候选中选择歌曲，然后自动填入歌曲信息、封面和可用歌词。原有链接解析、本地音频解析、手动编辑、AI 翻译、主题和导出流程保持可用。

## 主要更新

- 新增网易云音乐歌名搜索入口，作为“选择歌曲”的第一入口。
- 输入关键词时实时显示候选歌曲，并展示歌名、歌手、专辑和时长。
- 支持方向键选择、Enter 导入和鼠标点击导入。
- 选中歌曲后自动填入标题、歌手、专辑、封面，并尽量获取网易云歌词。
- 歌词获取失败时不会阻塞歌曲信息导入，用户仍可使用现有自动获取歌词或手动编辑。

## 兼容与保留

- Spotify、Apple Music、网易云音乐、QQ 音乐链接解析入口继续保留。
- 本地 MP3 / FLAC 元数据和内嵌歌词解析继续保留。
- 手动填写歌曲信息、歌词编辑、AI 翻译、封面取色、样式设置和 PNG 导出流程保持不变。

## 使用建议

- 搜索结果不准确时，建议同时输入歌名和歌手名。
- 网易云搜索和歌词获取需要联网。
- 自动歌词结果可能不完整，请在导出前自行检查。
