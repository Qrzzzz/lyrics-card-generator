# Notas de la versión Lyrics Card Generator v3.9.1

Fecha de publicación: 2026-07-01

La versión v3.9.1 corrige las esquinas redondeadas en la ventana de escritorio y actualiza el diseño de la barra de título personalizada. Los temas no Acrylic ahora usan el recorte de esquinas redondeadas nativo de Windows, mientras que el fondo de escritorio, el degradado de la barra de título y la capa de ruido siguen dibujándose dentro del contenedor de la app. La salida PNG de las tarjetas de letras exportadas no se ve afectada.

## Esquinas de la ventana de escritorio

- Los temas no Acrylic ya no dependen de esquinas transparentes solo por CSS; el borde nativo de la ventana de Windows realiza el recorte exterior.
- Los temas Acrylic siguen usando el material Acrylic nativo de Windows mientras mantienen transparente el fondo de la ventana.
- La capa de fondo de la app ahora usa posicionamiento absoluto dentro del contenedor, por lo que los fondos de imagen, álbum dinámico y color sólido quedan recortados por el contenedor redondeado.

## Barra de título

- La barra de título personalizada ahora usa controles rojo, amarillo y verde a la izquierda para cerrar, minimizar y maximizar/restaurar.
- El nombre de la app y la versión permanecen junto a los controles, y se eliminó el icono pequeño de la derecha.
- La barra de título sigue permitiendo arrastrar la ventana, mientras que los botones de control permanecen como zona no arrastrable para clics estables.

## Exportación y versión Web

- En el navegador, la versión Web sigue ocultando la barra de título de escritorio y no reserva espacio superior exclusivo del escritorio.
- La ruta de exportación PNG sigue libre de la barra de título de escritorio, el marco de la ventana, el fondo del contenedor y la API de escritorio de Electron.

## Verificación

- npm run typecheck
- npm run core:test
- npm run build
