# Lyrics Card Generator v5.9.2 リリースノート

リリース日：2026-08-06

v5.9.2 では、Windows デスクトップ版で履歴から手動保存を読み込んだ際に、保存済みのアルバムカバーが復元されない問題を修正しました。

## 履歴の読み込みとカバーの復元

- 手動保存の読み込み時に、安全化済みのリモートカバー URL を復元し、既存の画像プロキシとパレット抽出へ渡します。
- 曲リンクは再解析せず、保存済みのタイトル、アーティスト、アルバム、歌詞、翻訳も上書きしません。保存の紐付けと同じ項目への更新動作は変わりません。
- カバー URL を持たない古い保存は、引き続きカバーなしで読み込まれます。ローカルカバーは従来のファイル履歴と再指定フローを使用します。

## セキュリティ境界と検証

- リモートカバーはアプリ内の画像プロキシだけを経由し、外部アドレスへ直接アクセスしません。画像バイト、Base64、blob URL、ローカルパス、機密性のあるクエリパラメータは保存されません。
- 回帰テストでは、曲リンク、検索結果、ローカル音声を再解析せずにカバー表示とパレット抽出が行われることを確認しています。
- Web Lite の画面と動作は変更しません。
