# Lyrics Card Generator v5.1.0 Release Notes

Release date: 2026-07-13

v5.1.0 is a stability and security release. It preserves the existing visual direction of the first two v5 steps while hardening network requests, import races, and export consistency.

## Main Updates

- Introduces a unified Safe Fetch layer that resolves and validates every redirect before requesting it, with private/reserved address, timeout, redirect, content-type, and body-size limits.
- Song, lyric, and example imports now use document revisions and last-intent-wins; clear, song replacement, and newer intents abort and invalidate older work.
- Song replacement is canonical instead of a partial merge, preventing cover, explicit, final URL, parser method, or translation fields from leaking across songs.
- Desktop export uses an immutable snapshot and synchronous mutex so lyrics, style, size, filename, and captured PNG come from one revision.
- Web Lite uses an independent off-screen export host and shares the desktop 36-line, font-loading, measuring, size-stability, and overflow checks.
- Busy, blocked, and failed exports now provide localized, recoverable user feedback.

## Verification

- Added zero-access SSRF target, import race matrix, cross-song reset, export snapshot, and concurrency tests.
- Added Web Lite 36/37-line, fixed 1:1 overflow, and collapsed-preview export coverage.
- Completed core, Web Lite, desktop build, and desktop interaction regressions.
