# Lyrics Card Generator v6.1.7

> Status: released.

## One transition track for the right preview

- Opening a custom font scheme now fades the real lyric card out to the left while the fixed type specimen enters from the right and takes over the same preview slot instead of appearing below the real card.
- Cancel or Apply runs the exact reverse transition: the specimen exits right and the real lyric card returns from the left, matching the first step's page-transition rhythm.

## Clear preview behavior

- Exactly one right-side preview stays active. Pointer and keyboard font browsing updates only the editing specimen; Apply returns the real card with the committed fonts, while Cancel restores the original scheme.
- Reduced Motion keeps the mutually exclusive pages and focus restoration while removing horizontal travel. Clear animation and final export behavior remain unchanged.
- Motion and desktop interaction regressions now pin both directions, right-pane exclusivity, draft cancellation, and real-card restoration after atomic Apply.
