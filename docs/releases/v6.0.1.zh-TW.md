# Lyrics Card Generator v6.0.1

> 狀態：已透過 GitHub Releases 公開發佈。

## Electron 原生系統對話框

- Windows 桌面版將取代歌曲、覆寫譯文、清除歷史、裁剪歷史、歷史核對失敗及關閉時儲存失敗這 6 處提示統一為 Electron 原生系統對話框。
- 確認操作使用系統警告圖示，失敗提示使用系統錯誤圖示，不需要額外封裝圖示資源。
- 對話框標題、內容與按鈕完整支援简体中文、繁體中文、English、Français、日本語與 Español。

## 安全與相容性

- 取代、覆寫與刪除等危險操作預設聚焦「取消」；關閉對話框或按 Esc 也不會繼續執行。
- 渲染層、preload 與主程序皆會驗證對話框參數，跨 contextBridge 僅傳遞受限的基本欄位。
- Web Lite 與一般瀏覽器環境保留相容回退，不改變既有網頁端功能。
