這是 Lyrics Card Generator 的第一個桌面正式版。相比 v0.1.0 桌面初版，本版本重點完善了 Windows 桌面發行流程、應用程式內檢查更新、卡片版面配置穩定性與匯出體驗，適合作為正式可散佈版本使用。

## 主要更新

### Windows 桌面版正式化

* 應用程式版本升級至 `1.0.0`。
* 新增 Electron 桌面進入點，Windows 使用者可以直接執行 EXE。
* 桌面版會在本機啟動內建 Next standalone 服務，並在桌面視窗中載入本機應用程式。
* 使用者無需安裝 Node.js，也無需手動執行開發伺服器。
* 支援 Windows x64 安裝版與 portable 可攜版。
* 預設以最大化開啟視窗。
* 外部連結會交由系統瀏覽器開啟。
* 關閉應用程式時會自動清除本機服務處理程序，減少背景殘留。

### 新增檢查更新

* 頂部工具區新增「檢查更新」按鈕。
* 應用程式會從 GitHub Releases 請求最新版本資訊。
* 支援比較 `v1.0.0` / `1.0.0` 這類版本號格式。
* 若發現新版本，會提供下載頁面進入點。
* 若 Release 中存在 `.exe` 或 `.msi` 安裝套件，會優先指向安裝套件資源。
* 本功能只負責檢查更新與開啟下載頁面，不會靜默下載或自動取代當前程式。

### 自動高度修復

* 直式自訂尺寸下，自動高度現在會依實際歌詞內容、翻譯內容、字型大小、行距、標題區、邊框與 footer 內容綜合估算。
* 開啟平台 Logo、分享人、產生浮水印後，卡片會向下增加高度，而非壓縮歌詞區域。
* 自動高度預設為開啟。
* 直式自訂高度上限提高至 `3200px`，更適合長歌詞、翻譯與 footer 同時開啟的情境。

### 橫式邊框版面配置修復

* 修復橫式卡片開啟「邊框 + 陰影」時，平台資訊、分享人、產生浮水印錯位的問題。
* 橫式版面配置現在使用統一的 frame-aware 座標體系。
* 開啟邊框後，封面、歌曲資訊、歌詞與 footer 元素會一同進入邊框內部安全區域。
* 修復 16:9、21:9、3:2 等橫式比例下 footer 與邊框未對齊的問題。

### 匯出體驗最佳化

* 匯出流程簡化為「完成並匯出」，減少重複的匯出設定進入點。
* 預設繼續使用高解析度 2x PNG 輸出。
* 匯出成功後的慶祝動畫改為更克制的頂部彩帶效果。
* 修復「一鍵清空所有內容」時可能誤觸發匯出慶祝動畫的問題。

### 圖示與發佈工程完善

* 替換並統一應用程式圖示資源。
* 新增 Windows 安裝套件圖示、可攜版圖示、Web favicon 與應用程式內標題區圖示。
* 新增桌面版建置指令稿與發佈準備指令稿。
* 新增桌面版執行說明、遷移檢查清單、已知問題文件與發佈記錄。
* 更新 `.gitignore`，避免將建置產出、release 檔案、快取與記錄提交至原始碼儲存庫。

## 保留能力

* Apple Music、網易雲音樂、QQ 音樂連結解析。
* 手動編輯歌曲資訊、歌詞與翻譯。
* 本機封面上傳、遠端封面代理與封面取色。
* 直式 / 橫式卡片生成。
* 字型、字型大小、行距、顏色、邊框、陰影、浮水印、分享人與平台 Logo 等視覺設定。
* 中文 / English 介面切換。
* 離線開啟、手動編輯、本機封面與 PNG 匯出。

## 仍需連線的功能

* 音樂平台連結解析。
* 遠端封面載入。
* LRCLIB 自動歌詞取得。
* GitHub 檢查更新。

## 已知限制

* 當前版本仍未進行程式碼簽章，Windows 可能顯示 SmartScreen 提示。
* 檢查更新不會自動下載安裝套件，需要使用者手動開啟下載頁面。
* 當前發行目標為 Windows x64。
* 第三方平台解析與歌詞取得會受上游服務可用性影響。

## 驗證

* `npm run typecheck` 通過。
* `npm run build` 通過。
* `npm run desktop:pack` 通過。
* `npm run desktop:build` 通過。
* Apple Music、網易雲音樂、QQ 音樂解析範例通過。
* 本機封面代理驗證通過。
* LRCLIB 歌詞取得驗證通過。
