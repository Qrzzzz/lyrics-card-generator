# Lyrics Card Generator v6.1.2

> 狀態：已透過 GitHub Releases 正式發布。

## 原生雙字體方案

- 自訂方案將原先分開的中日韓與西文字體入口合併為一個「編輯方案」入口。
- Windows 桌面版會開啟隸屬於主視窗的原生 WinForms 方案視窗；兩個「選擇」按鈕分別呼叫系統 `FontDialog`，不建立 Electron 或 HTML 自繪字體選擇視窗。
- 方案視窗同時顯示兩種目前字體與預覽。「取消」會整體放棄草稿；「套用字體方案」一次提交兩種字體，之後把焦點還原至主介面入口。

## 字體完整性與相容性

- Windows 系統 `FontDialog` 直接顯示系統字體，不再經過應用程式內的字體名稱分類；非 Windows 桌面版與瀏覽器回退中，字體類別只影響推薦項目和預覽文字，所有已列舉字體都可用於兩種角色。
- 原生橋接繼續使用嚴格欄位驗證、主視窗控制代碼模態歸屬與受限結果解析；非 Windows 桌面回退保留隔離的最小權限 IPC。
- 自訂方案仍沿用現有預覽、匯出與持久化資料結構，不改變歌詞卡渲染規則。
