# Lyrics Card Generator v3.3.0 发布说明

发布日期：2026-06-25

v3.3.0 添加 Spotify 单曲链接解析支持。现在可以粘贴 Spotify 歌曲链接，自动读取歌曲标题、歌手与封面，并继续使用现有歌词卡片编辑、封面取色和导出流程。

## Spotify 链接解析

- 支持 Spotify 单曲链接解析。
- 支持 `open.spotify.com/track/...`、`open.spotify.com/intl-.../track/...`、`open.spotify.com/embed/track/...` 以及常见 Spotify 短链接。
- Spotify 歌曲可显示平台 Logo。
- 自动歌词获取继续沿用现有实验性歌词搜索逻辑。
- 修复应用刚打开时后续步骤提前显示完成勾选的问题；现在只有已走过的步骤会显示完成状态。

## 使用说明

- 本版本不从 Spotify 获取歌词。
- 本版本不需要 Spotify 账号、OAuth 或 API 密钥。
- 如果自动解析失败，仍可手动填写歌曲标题、歌手、封面与歌词。

验证：`npm run typecheck`、`npm run parse:test`、`npm run core:test`、`npm run build`，并通过本地 API 验证 Spotify 解析、歌词接口 schema 与 Spotify SVG 图标资源。
