这是 Lyrics Card Generator 的第一个桌面正式版。相比 v0.1.0 桌面初版，本版本重点完善了 Windows 桌面发行流程、应用内更新检查、卡片布局稳定性和导出体验，适合作为正式可分发版本使用。

## 主要更新

### Windows 桌面版正式化

* 应用版本升级到 `1.0.0`。
* 新增 Electron 桌面入口，Windows 用户可以直接运行 EXE。
* 桌面版会在本机启动内置 Next standalone 服务，并在桌面窗口中加载本地应用。
* 用户无需安装 Node.js，也无需手动运行开发服务器。
* 支持 Windows x64 安装版和 portable 便携版。
* 默认最大化打开窗口。
* 外部链接会交给系统浏览器打开。
* 关闭应用时会自动清理本地服务进程，减少后台残留。

### 新增检查更新

* 顶部工具区新增“检查更新”按钮。
* 应用会从 GitHub Releases 请求最新版本信息。
* 支持比较 `v1.0.0` / `1.0.0` 这类版本号格式。
* 如果发现新版本，会提供下载页入口。
* 如果 Release 中存在 `.exe` 或 `.msi` 安装包，会优先指向安装包资源。
* 本功能只负责检查更新和打开下载页，不会静默下载或自动替换当前程序。

### 自动高度修复

* 竖版自定义尺寸下，自动高度现在会按实际歌词内容、翻译内容、字号、行距、标题区、边框和 footer 内容综合估算。
* 打开平台 Logo、分享人、生成水印后，卡片会向下增加高度，而不是压缩歌词区域。
* 自动高度默认开启。
* 竖版自定义高度上限提高到 `3200px`，更适合长歌词、翻译和 footer 同时开启的场景。

### 横版边框布局修复

* 修复横版卡片开启“边框 + 阴影”时，平台信息、分享人、生成水印错位的问题。
* 横版布局现在使用统一的 frame-aware 坐标体系。
* 开启边框后，封面、歌曲信息、歌词和 footer 元素会一起进入边框内部安全区域。
* 修复 16:9、21:9、3:2 等横版比例下 footer 与边框不对齐的问题。

### 导出体验优化

* 导出流程简化为“完成并导出”，减少重复的导出设置入口。
* 默认继续使用高清 2x PNG 输出。
* 导出成功后的庆祝动画改为更克制的顶部彩带效果。
* 修复“一键清空所有内容”时可能误触发导出庆祝动画的问题。

### 图标与发布工程完善

* 替换并统一应用图标资源。
* 新增 Windows 安装包图标、portable 图标、Web favicon 和应用内标题区图标。
* 新增桌面版构建脚本和发布准备脚本。
* 新增桌面版运行说明、迁移检查清单、已知问题文档和发布记录。
* 更新 `.gitignore`，避免把构建产物、release 文件、缓存和日志提交进源码仓库。

## 保留能力

* Apple Music、网易云音乐、QQ 音乐链接解析。
* 手动编辑歌曲信息、歌词和翻译。
* 本地封面上传、远程封面代理和封面取色。
* 竖版 / 横版卡片生成。
* 字体、字号、行距、颜色、边框、阴影、水印、分享人和平台 Logo 等视觉设置。
* 中文 / English 界面切换。
* 离线打开、手动编辑、本地封面和 PNG 导出。

## 仍需联网的功能

* 音乐平台链接解析。
* 远程封面加载。
* LRCLIB 自动歌词获取。
* GitHub 检查更新。

## 已知限制

* 当前版本仍未进行代码签名，Windows 可能显示 SmartScreen 提示。
* 检查更新不会自动下载安装包，需要用户手动打开下载页。
* 当前发行目标为 Windows x64。
* 第三方平台解析和歌词获取受上游服务可用性影响。

## 验证

* `npm run typecheck` 通过。
* `npm run build` 通过。
* `npm run desktop:pack` 通过。
* `npm run desktop:build` 通过。
* Apple Music、网易云音乐、QQ 音乐解析样例通过。
* 本地封面代理验证通过。
* LRCLIB 歌词获取验证通过。
* portable EXE 和 unpacked EXE 启动验证通过。
* 关闭应用后无残留应用进程。
* 默认 `1040x1080` 卡片可导出为 `2080x2160` PNG。
