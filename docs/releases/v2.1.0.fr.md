# Notes de version de Lyrics Card Generator v2.1.0

Langues : [简体中文](./v2.1.0.zh-CN.md) · [繁體中文](./v2.1.0.zh-TW.md) · [English](./v2.1.0.en.md) · Français · [日本語](./v2.1.0.ja.md) · [Español](./v2.1.0.es.md)

## Téléchargement et installation

Téléchargez les fichiers correspondants depuis GitHub Releases :

- Installateur : `Lyrics Card Generator Setup 2.1.0.exe`
- Version portable : `Lyrics Card Generator-2.1.0-portable.exe`

L'installateur est recommandé pour un usage régulier. Choisissez la version portable pour un essai temporaire, des tests ou une utilisation depuis un support amovible.

> Cette version n'est pas signée. Windows peut afficher un avertissement SmartScreen, ce qui est courant pour les applications personnelles non signées.

## Nouveautés

v2.1.0 renforce surtout l'expérience bureau, la mise en page paysage, les dimensions personnalisées, l'interface multilingue et le traitement des médias locaux.

### Ajouts

- Ajout du flux de packaging pour l'application de bureau Windows.
- Ajout de deux formats de distribution : installateur et version portable.
- Ajout de l'analyse locale MP3 / FLAC pour lire le titre, l'artiste, l'album, la pochette et les paroles intégrées.
- Ajout de la détection des polices système Windows et du choix de police personnalisée.
- Ajout du changement d'interface en chinois simplifié, chinois traditionnel, anglais, français, japonais et espagnol.
- Ajout d'un point d'entrée pour vérifier les mises à jour via GitHub Releases.

### Améliorations

- Refonte de la mise en page paysage autour des zones sûres, de la colonne de pochette, de la colonne de contenu et du pied de page.
- Prise en charge d'une hauteur automatique mesurée pour les toiles portrait personnalisées.
- Meilleure stabilité de la mise en page paroles originales / traduction, avec séparation des lignes selon la langue actuelle de l'interface.
- Export des pochettes distantes via le proxy d'image afin de réduire les échecs PNG liés au cross-origin.
- Passage des logos de plateforme à des SVG locaux afin que l'export PNG ne dépende pas d'icônes distantes.

### Corrections

- Correction de débordements de contenu ou d'espaces vides inattendus avec certaines dimensions personnalisées.
- Correction des chevauchements entre pochette, paroles et informations de bas de carte en mode paysage.
- Correction de cas où certaines pochettes distantes n'étaient pas correctement intégrées au PNG exporté.

## Notes de mise à niveau

- La mise à niveau depuis une ancienne version ne nécessite généralement pas de désinstallation.
- Si l'installateur ne peut pas remplacer l'ancienne version, quittez l'ancienne application puis relancez l'installateur.
- Si la version portable ne démarre pas, vérifiez qu'un ancien processus n'est pas encore actif en arrière-plan.

## Limites connues

- L'analyse des liens musicaux, le chargement des pochettes distantes, la récupération automatique des paroles et la vérification des mises à jour nécessitent une connexion internet.
- La récupération automatique des paroles reste expérimentale. Les résultats peuvent être incomplets ou inexacts. Assurez-vous d'avoir le droit de les utiliser.
- La version actuelle n'est pas signée. Un avertissement Windows SmartScreen ne signifie pas forcément que le programme est dangereux.
