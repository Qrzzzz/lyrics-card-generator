# Lyrics Card Generator v6.6.0 リリースノート

公開日：2026-10-04

v6.6.0 では、デスクトップ版のタイトルバーを信号機スタイルと Windows スタイルから選べます。既定は引き続き信号機スタイルで、ウィンドウボタンの配置を好みに合わせて変更できます。

## タイトルバーのスタイル

- 「設定 → 外観 → タイトルバーのスタイル」で「信号機（既定）」または「Windows スタイル」を選択できます。新規インストール時や未設定の場合は、信号機スタイルを使用します。
- Windows スタイルでは、最小化・最大化・閉じるボタンを右側に配置します。最大化すると、最大化ボタンのアイコンとツールチップが「ウィンドウ表示」に切り替わります。
- 変更はすぐに反映され、自動保存されます。再起動後も選択を保持し、アプリの既定設定を復元すると信号機スタイルに戻ります。
