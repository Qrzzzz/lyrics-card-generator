# Lyrics Card Generator v5.10.1

> 狀態：已透過 GitHub Releases 公開發布。

此版本修正 v5.10.0 空間色場可能放大小面積高飽和色、反轉封面主導色系的問題。背景現在會先依封面可見面積分配色彩家族預算，再於預算內最佳化空間構圖與色差。

## 更新重點

- 錨點數量與總能量依來源色彩家族的可見面積分配，主導色系在各預設比例中維持主導。
- 小面積高光色具有明確的擴張上限，不再吞沒整張背景。
- 四個邊緣錨點也採用來源色彩家族偏好；色差最佳化只在已分配家族內進行。
- 相同長寬比共用語意種子，改變輸出解析度不會重新排列色彩角色。
- 編輯預覽、匯出與 Web Lite 共用同一條修正後的確定性渲染路徑。

## 驗證

新增 88% 冷藍、12% 暖色高光的回歸夾具並涵蓋五種預設比例；暖色輸出面積穩定在 5.0%–8.2%。同時通過完整核心測試、120 項構圖矩陣、正式建置、Web Lite 瀏覽器測試及 Windows 安裝包／可攜版冒煙測試。
