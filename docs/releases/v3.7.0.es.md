# Notas de la versión Lyrics Card Generator v3.7.0

Fecha de lanzamiento: 2026-06-29

v3.7.0 es una versión de mantenimiento y estabilización. No añade un nuevo modo de diseño, tema, plataforma musical ni comportamiento de exportación. Esta actualización se centra en la seguridad de rutas para imágenes de fondo de escritorio, el fallback de errores de traducción IA, la coherencia de la entrada de actualización, la limpieza de código obsoleto y la estabilidad de las comprobaciones de lanzamiento.

## Correcciones

- Refuerza la validación de `imageId` para imágenes de fondo de escritorio: solo acepta nombres generados por la app en `png`, `jpg`, `jpeg`, `webp` y `gif`, y rechaza traversal o valores falsificados.
- La lectura de imágenes de fondo ahora usa un mapa MIME explícito y no acepta SVG ni extensiones desconocidas.
- Mejora el fallback de errores de traducción IA ante respuestas no estándar del proveedor, errores en texto plano, JSON malformado y cuerpos vacíos para evitar cierres inesperados.
- El botón «Abrir página de lanzamiento» ahora abre siempre la página correspondiente de GitHub Release en lugar de un enlace directo al instalador.

## Mantenimiento

- Elimina el código heredado `CustomFontPanel` sin uso y mantiene intacto el comportamiento actual de `FontSchemePanel`.
- Elimina las copias i18n obsoletas del antiguo campo instrumental mientras conserva la compatibilidad de `instrumentalText` y el resultado visual de las tarjetas.
- Sustituye la prueba específica de `v3.6.1` por una prueba genérica de coherencia de release y una prueba de regresión de la barra de título.
- Añade un flujo CI mínimo para instalación, typecheck, pruebas core y build Web.

## Verificación

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:dev
- npm run desktop:build
