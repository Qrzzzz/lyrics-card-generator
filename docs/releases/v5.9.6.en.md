# Lyrics Card Generator v5.9.6 Release Notes

Candidate date: 2026-08-09

v5.9.6 restores the performance implementation. It reintroduces the accepted final v5.9.4 performance architecture on the v5.9.5 baseline while fully preserving v5.9.5's three-level toast feedback, concise copy, and desktop close-lifecycle fix.

## Performance implementation restored

- Restores packaged local-server orchestration, renderer-origin validation, and static-asset caching to reduce repeated probing and unnecessary launch work.
- Restores idle ClickSpark, single-host auto-width measurement, lyrics-input, and render-boundary optimizations to reduce wasted animation frames, layout reads, and unrelated commits.
- Restores coalesced export-readiness measurements, demand-loaded Examples, History, Settings, AI, and Export surfaces, plus local chunk-failure isolation and true retries.
- Restores in-process system-font scan caching and concurrent-request deduplication. Directory changes still invalidate immediately, while registry-only staleness remains bounded to five minutes.

## v5.9.5 feedback retained

- Global toasts keep fixed green, yellow, and red semantic backgrounds without restoring the left icon or countdown progress bar.
- Enter and exit animations remain exact reverses through translation, scale, and opacity; reduced-motion mode still changes opacity only.
- Six-language toast copy remains concise and punctuation-free, without exposing internal paths, backup names, or exception details in general UI messages.

## Compatibility

- This version does not change lyric-document, import-history, or manual-save data formats and requires no user-data migration.
- v5.9.5 import, parsing, AI translation, settings, history, and PNG, WebP, and JPG export behavior remains available.

## Candidate status

v5.9.6 is undergoing full local validation. The public tag, installer, portable build, SPDX SBOM, and SHA256SUMS will enter the release workflow after all gates and manual acceptance are complete.
