# Lyrics Card Generator v5.0.0 發布說明

發布日期：2026-07-12

v5.0.0 將前兩個步驟重構為專注式歌曲匯入與長歌詞工作台，並徹底分離編輯視窗、歌詞文件和最終匯出卡片。

## 主要更新

- 第一步以網易雲音樂搜尋為主要入口，放大搜尋框與候選結果；連結解析、本機音訊和手動歌曲資訊保留於緊湊輔助欄。
- 第二步升級為「歌曲摘要 + 歌詞文件 + 編輯工具」三欄工作台。原文與譯文採用等高雙欄，並共用唯一主要捲動容器。
- 歌詞視窗提供標準、延展與應用程式內沉浸三種狀態，支援拖曳吸附、按兩下復位、Esc 返回與鍵盤操作。
- 第一、二步不再顯示卡片預覽或行動版預覽開關；第三步起恢復原有卡片設計與預覽流程。
- 匯出卡片改為持續掛載的畫面外宿主，編輯視窗高度和捲動位置不再影響 PNG 邏輯尺寸。
- 新增 36 個非空邏輯行的匯出上限：啟用翻譯時原文與譯文分別計數，空行和自動換行不計，純音樂模式豁免。
- 直式自動高度上限提高至 6400px；固定比例或橫式版面若存在真實溢出會阻止匯出，不再靜默裁切。
- 補齊六種語言文案、焦點與無障礙語意，並維持 Web Lite 原有功能邊界。

- npm run desktop:build / desktop:interaction-test
