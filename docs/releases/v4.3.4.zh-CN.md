# Lyrics Card Generator v4.3.4 发布说明

发布日期：2026-07-06

本版本将“歌词示例”从弹窗改为主界面上方的空间层。打开示例时，编辑器整体退到下方，应用内标题栏滑到底部作为返回锚点，示例卡片改为基于主窗口宽度的响应式网格。

## 主要更新

- 将原来的 ExamplesDialog 弹窗改为 ExamplesFloor 上方空间层，不再使用遮罩、Modal 或 Portal。
- 点击标题栏的“示例”后，示例层从上方进入，主编辑界面向下退场，标题栏滑到底部。
- 底部标题栏复用正常标题栏结构，并在原“示例”按钮位置替换为精简的 X 返回按钮。
- 示例卡片根据主窗口宽度自动切换为一栏、两栏或三栏，小窗口下避免横向滚动。
- 示例层底部保留标题栏高度，滚动到底部时不会遮挡最后一行卡片。
- 支持按 Escape 返回主界面，载入任一示例后会自动回到编辑器。
- 动画改为更克制的 spring 曲线，并在 reduced motion 设置下关闭大幅滑动。

## 验证

- npm run typecheck
- npm run core:test
- npm run build
- 浏览器检查 1280px、900px、520px 三个宽度下的示例层布局、X 返回、Escape 返回、载入示例后返回和底部留白。
