# Lyrics Card Generator v5.0.4 リリースノート

リリース日：2026年7月12日

v5.0.4 は歌詞編集の操作を簡素化し、設定画面の視覚階層を統一します。

## 主な更新

- v5.0.2 の固定検索結果領域、件数表示、NetEase のソースラベル、再設計した曲一覧を引き継ぎました。
- ステップ 2 は常に利用可能な最大高さを使い、標準・拡張・集中の切り替えと下部のサイズ変更バーを削除しました。
- 設定画面のヘッダーとパンくずを再配置し、現在位置を見やすくしました。
- AI ワークスペースを、ほかの設定ページと揃えたコンパクトな移動先リストへ変更しました。
- Olivia Rodrigo の「honeybee」と BIGBANG の「Lies」を追加し、サンプル一覧をスクロール可能な 2 行レイアウトにしました。

## 検証

- `npm run typecheck`
- `npm run core:test`
- `npm run build`
