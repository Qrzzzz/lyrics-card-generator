# Lyrics Card Generator v5.8.8 リリースノート

リリース日：2026-07-30

v5.8.8 は、v5.8.7 のフロントエンドを固定した内部整理版です。見える機能の追加や削除は行わず、すでに安定している実装の境界だけを明確にしました。

## v5.8.7 フロントエンドの固定

- ページ構造、要素の class、自動化用 `data-testid`、見た目、固定 2:1 分割、狭幅画面のドロワーは変わりません。
- 2 列の共有スクロール、エディター高さの同期、選択範囲とカーソルの復元、フォーカス移動、非アクティブページの `inert` 隔離は変わりません。
- Esc 階層、モーション軽減、AI リクエストの開始／キャンセル／戻る／アンマウントのライフサイクル、訳文の適用ロジックは変わりません。

## 内部構造の整理

- 実行入口のない旧スタイルパネル、入力分岐、互換経路を削除し、デスクトップ版と Web Lite で到達可能な機能は維持しました。
- `LyricsSidebar` のナビゲーション／フォーカス制御を「整理／翻訳」の表示から分離しました。3 ページのトラックはステップ 2 のサイドバー専用のままで、汎用ページシステムにはしていません。
- `LyricsWorkspace` の文書変換、取り消し／やり直し履歴、選択範囲制御を専用 controller に移し、レイアウトと DOM 描画は引き続きワークスペースコンポーネントが担当します。

## バージョンと検証

- `package.json`、ロックファイル、6 言語の README、6 言語のリリースノート、リリース一覧、Web Lite を 5.8.8 に統一しました。
- 型チェック、警告ゼロの lint、本番ビルド、コア回帰、Web Lite のチェック／スモークテスト、デスクトップ Electron の操作マトリクスで、動作を変えない整理を確認します。
