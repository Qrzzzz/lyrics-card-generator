# Lyrics Card Generator v6.2.8

## 自動保存と履歴の復元

- 手動保存ボタンを削除し、タイトルバー中央の一行で自動保存の状態を表示します。変更が 5 秒間なければ現在の下書きを保存します。
- 歌詞原文、訳文、区切りと対応関係、曲情報、カードのスタイル、書き出し設定、現在の手順、未確定の曲情報フォームを下書きに保存します。ローカルのジャケットも復元できます。
- 通常の終了や文書の切り替え前に未保存の変更を書き込み、次回起動時に前回の下書きを復元します。保存に失敗した場合は通常の終了を止め、タイトルバーのエラーをクリックして再試行できます。従来の履歴と手動保存も引き続き読み込めます。
- 重複する CI、ビルド、リリース検証を削減し、データ復元、安全性、ブラウザー互換性、描画・書き出し、新しいインストーラーの検証は維持します。

## 対象と制限

- 自動下書きはデスクトップ版のみです。履歴を保存しない設定では今後の自動保存を停止し、既存の下書きは削除しません。現在の履歴を削除すると、そのセッションの書き込みを停止します。別の曲を取り込むか内容をクリアすると再開します。
- 強制終了、停電、ディスク破損時は書き込みに成功した版のみ復元できます。5 秒間の停止なしで編集を続けると、それ以上の作業が未保存になる場合があります。本版にはキー入力ごとの緊急バックアップはありません。
- リモートのジャケットはオフラインでの利用を保証しません。リモート履歴 JSON の対象は従来どおりで、カードの完全なスタイルやローカルのジャケットは含みません。

- Windows x64: `Lyrics.Card.Generator.Setup.6.2.8.exe`.
