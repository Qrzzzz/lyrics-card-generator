# Lyrics Card Generator v6.5.5 Release Notes

Release date: 2026-09-22

v6.5.5 simplifies the desktop Settings → About → Support the author page, bringing network selection, the QR code, and receiving details into a clearer layout.

## Author support page

- Use compact TRON and X Layer network options with a clear selected state.
- Reduce the QR code size and rearrange the asset, network, address, and copy button, removing repeated labels and the separate address box.
- Refine the heading icon, explanatory text, and spacing for dark and light themes and narrower windows.
