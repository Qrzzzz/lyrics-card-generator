# Lyrics Card Generator v4.2.6 發布說明

發布日期：2026-07-03

本版本重構了軟體主題色系統，將介面主題色從零散取色改為統一的全域 Accent 機制。

## 主要更新

- 新增統一主題色設定，支援跟隨專輯封面、預設顏色和自訂色號。
- 預設主題色支援紅、橙、黃、綠、藍、紫。
- 統一 AI 翻譯按鈕、完成匯出按鈕、Spark Cursor、Stepper、控制項選取態與焦點態的主題色來源。
- 重構外觀設定，將介面模式與壓克力效果拆分為更清楚的設定項。
- 專輯封面動態取色模式下暫不支援壓克力效果。
- 在最終匯出步驟中新增圖片匯出品質選擇。
- 匯出品質選項調整為低、標準、高清三檔。
- 移除超清匯出品質選項，並對舊設定中的超清選項自動降級為高清。
- 範例歌曲新增 Taylor Swift《Opalite》的多語言翻譯樣例。
- 清理部分舊設定欄位與背景相關文案，為後續介面主題擴展做準備。

## 相容與遷移

- 舊的 `uiAccentColor` 會遷移到新的主題色設定，不再作為主欄位使用。
- 舊的 `dark-acrylic` / `light-acrylic` 會遷移為介面模式加壓克力開關。
- 舊的 `ultra` 匯出品質會自動遷移為 `high`。

## 驗證

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:build
