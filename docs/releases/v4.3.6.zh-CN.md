# Lyrics Card Generator v4.3.6 发布说明

发布日期：2026-07-07

本版本继续打磨 v4.3 系列的示例歌曲界面和主界面衔接。重点是让主界面标题栏真正成为编辑内容的一部分，同时保留示例歌曲界面底部复用标题栏的返回方式，并整理示例导入、翻译联动和导出质量文案。

## 主要更新

- 主界面的应用标题栏现在进入主编辑内容流，不再作为浮层压在步骤区和预览区上方。
- 示例歌曲界面仍复用同一个标题栏作为底部返回锚点，并修复切换动画中标题栏下滑时出现第二层虚影的问题。
- 示例歌曲界面去掉最外层边框感，示例卡片下方不再重复显示“译文语言”块。
- 译文语言统一显示在“示例歌曲”标题右侧，跟随当前界面语言提示将要导入的译文语言。
- 新增“导入翻译”开关，默认开启；开启时载入示例会写入译文并同步打开主界面的“启用翻译”，关闭时只导入歌曲和歌词。
- 简体中文和繁体中文交错时不再默认导入翻译，避免简繁界面之间出现不必要的自动翻译。
- 示例界面底部 X 返回按钮增加橙红色悬停反馈。
- 最后一步导出质量文案调整为“标准 / 高清 / 超清”，实际导出倍率仍保持 1x / 1.4x / 2x 不变。
