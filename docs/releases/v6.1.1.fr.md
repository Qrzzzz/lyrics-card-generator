# Lyrics Card Generator v6.1.1

> Statut : publié officiellement via GitHub Releases.

## Boîte de dialogue système native de Windows

- L'application Windows appelle désormais directement le `FontDialog` du système au lieu de créer une fenêtre de sélection rendue par Electron ou HTML.
- La boîte de dialogue utilise le handle de la fenêtre principale Electron comme propriétaire et conserve une vraie modalité Windows ; une seule instance peut s'ouvrir et le focus revient après validation ou annulation.
- La famille choisie met toujours d'abord à jour le brouillon et l'aperçu réel de la carte ; l'enregistrement du jeu reste l'étape de validation.

## Fiabilité et compatibilité

- Le pont natif utilise explicitement le mode STA et borne le handle, le nom de police, la sortie du processus auxiliaire et la valeur retournée ; un échec de lancement se termine sans sélection.
- La régression du bureau peut cibler un EXE candidat isolé précis plutôt qu'une ancienne compilation `release`, avec des contrats séparés pour le pont, la sécurité IPC et le manifeste empaqueté.
- Les environnements de bureau non Windows et les navigateurs ordinaires conservent le repli intégré existant ; la sélection de polices de Web Lite reste inchangée.
