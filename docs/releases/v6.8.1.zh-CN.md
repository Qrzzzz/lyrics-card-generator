# Lyrics Card Generator v6.8.1

**2026-10-22**

v6.8.1 聚焦内容保护、输出失败恢复、窗口与紧凑布局，以及编辑状态的清晰表达。核心范围为 #229、#230、#231、#232、#233、#235、#237、#238，另包含 #240 六语言设置文案整理。

- 切换纯音乐模式隐藏译文而不删除；清空歌曲、封面、原文与译文前明确确认，取消保留原文档，保存失败继续阻止清空。
- 导出或复制失败后保留错误和重试入口；重试复用输出事务保护，内容不因失败而改变。
- 窗口按显示器逻辑工作区确定初始、最小和恢复边界；跨显示器及显示参数变化后重新约束。强制颜色下红绿灯按钮增加可识别图形与边界。
- 紧凑窗口先显示设置和任务操作，再显示预览；步骤导航区分当前、访问过与未访问，不再把位置显示成完成检查。原文与译文提供可见、随共享滚动保持的栏头与活动栏提示。
- 设置文案改用字体名称和推理过程等用户术语，密钥存储说明按桌面／浏览器环境显示，保留安全、隐私与计费告知。

已通过 Windows 实际深浅高对比度、1366×768／125%、1920×1080／150%、原生分屏和运行中 DPI 切换检查。#232 的跨显示器移动仍待双屏实机验收，保持未完成；浏览器模拟和几何单元测试不能替代。详见[本地候选验收记录](../acceptance/v6.8.1.md)。#239 精确数值输入留待后续。
