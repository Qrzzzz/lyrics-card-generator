# Lyrics Card Generator v5.0.0 发布说明

发布日期：2026-07-12

v5.0.0 重构前两步为专注式歌曲导入与长歌词工作台，并将编辑视口、歌词文档和最终导出卡片彻底解耦。

## 主要更新

- 第一步以网易云音乐搜索为主入口，放大搜索与候选结果；链接解析、本地音频和手动歌曲信息保留在紧凑辅助栏中。
- 第二步升级为“歌曲摘要 + 歌词文档 + 编辑工具”三栏工作台。原文与译文使用等高双栏，并共享唯一主滚动容器。
- 歌词视口提供标准、扩展和应用内沉浸三种状态，支持拖动吸附、双击复位、Esc 返回与键盘操作。
- 第一、二步不再显示卡片预览或移动端预览开关；第三步起恢复原有卡片设计与预览流程。
- 导出卡片改为始终挂载的离屏宿主，编辑视口高度和滚动位置不再影响 PNG 的逻辑尺寸。
- 新增 36 个非空逻辑行的导出上限：启用翻译时原文和译文分别计数，空行和自动换行不计，纯音乐模式豁免。
- 纵向自动高度上限提高到 6400px；固定比例或横版存在真实溢出时会阻止导出，不再静默裁切。
- 补齐六语言文案、焦点与无障碍语义，并保持 Web Lite 的原有功能边界。
