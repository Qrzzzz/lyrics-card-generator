# Lyrics Card Generator v5.6.2 Release Notes

Release date: July 16, 2026

Version 5.6.2 improves the spatial continuity and feel of the later editing steps, and adds real WebP and JPG export to both Desktop and Web Lite.

## A more tactile live preview

- In steps 3–6, the lyric card tilts gently with the pointer, lifts on hover, and gives restrained press feedback.
- Releasing outside the card, cancelling the pointer, or leaving the preview reliably resets the card instead of leaving it tilted or raised.
- Touch input does not enable pointer tilt. When the system or app requests reduced motion, the preview uses a stable static presentation.
- These effects exist only in the visible preview layer. The independent export host never includes the 3D transform, highlight, or pressure shadow.

## A continuous step 5-to-6 workbench

- Moving from Visual to Export places the old settings, preview, and new export settings on one three-panel track and pans the entire track left.
- The preview moves continuously from right to left while the old settings leave on the left and export settings enter from the right. Returning to step 5 reverses the same path.
- Off-screen settings are inert and hidden from assistive technology, preventing keyboard focus from entering invisible controls.
- Narrow windows switch to a vertical preview-first layout while preserving scrolling, sticky preview behavior, and freedom from horizontal overflow.

## PNG, WebP, and JPG export

- Step 6 can now select PNG, WebP, or JPG and produces matching real encodings, filename extensions, and MIME types.
- PNG remains lossless; WebP and JPG use high-quality lossy encoding. The existing quality levels continue to control the export pixel ratio.
- Settings → Export stores the default image format. Once saved, step 6 and the next launch use that choice. Web Lite also persists its own format and quality preference.
- Every export freezes the format, filename, canvas size, pixel ratio, and card content. Concurrent clicks, timeouts, and cancellation cannot commit a stale download.
- SVG is outside the scope of v5.6.2; this release does not add SVG export.

## Cross-surface and release verification

- Desktop and Web Lite share format selection, snapshot export, and responsive workbench behavior, and the generated `index.html` stays in sync with its source.
- Regression coverage includes all six UI languages, keyboard and assistive semantics, touch/reduced-motion fallbacks, forward and reverse navigation, narrow windows, and PNG/WebP/JPG file signatures.
- The Windows installer and portable build continue through packaged interaction and final-artifact smoke tests. The public Release verifies exact versioned asset names, SHA256SUMS, an SPDX SBOM, and GitHub attestations.
