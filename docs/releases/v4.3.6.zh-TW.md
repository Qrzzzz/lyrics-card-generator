# Lyrics Card Generator v4.3.6 發布說明

發布日期：2026-07-07

本版本繼續打磨 v4.3 系列的範例歌曲介面與主介面的銜接。重點是讓主介面標題列真正成為編輯內容的一部分，同時保留範例歌曲介面底部複用標題列的返回方式，並整理範例匯入、譯文聯動與匯出品質文案。

## 主要更新

- 主介面的應用標題列現在進入主編輯內容流，不再作為浮層壓在步驟區和預覽區上方。
- 範例歌曲介面仍複用同一個標題列作為底部返回錨點，並修復切換動畫中標題列下滑時出現第二層殘影的問題。
- 範例歌曲介面去掉最外層邊框感，範例卡片下方不再重複顯示「譯文語言」區塊。
- 譯文語言統一顯示在「範例歌曲」標題右側，跟隨目前介面語言提示將要匯入的譯文語言。
- 新增「匯入譯文」開關，預設開啟；開啟時載入範例會寫入譯文並同步打開主介面的「啟用翻譯」，關閉時只匯入歌曲與歌詞。
- 簡體中文和繁體中文交錯時不再預設匯入譯文，避免簡繁介面之間出現不必要的自動翻譯。
- 範例介面底部 X 返回按鈕增加橙紅色懸停回饋。
- 最後一步匯出品質文案調整為「標準 / 高清 / 超清」，實際匯出倍率仍保持 1x / 1.4x / 2x 不變。
