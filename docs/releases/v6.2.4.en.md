# Lyrics Card Generator v6.2.4

> Status: released.

## Settings reliability and information architecture

- App-preference and AI-setting save failures now remain visible outside the settings surface with localized feedback and an explicit retry state. Closing settings no longer hides a failed save.
- “Cards & Export” separates new-card footer defaults from file-export defaults. The software watermark, shared-by label, and its text apply only when a genuinely new card is created; they no longer overwrite the current document, while clearing content still preserves its visual settings.
- The AI workspace now separates connection details, translation defaults, and the prompt library. AI data loads on first access to the category while already opened pages keep their mounted local state.

## Security, history, and storage

- A safe AI connection test sends no lyrics or user content, uses strict time and resource limits, supports cancellation, and rejects unsafe or hostile Base URLs before any provider request occurs.
- Automatic import history can now be set to “Do not keep” without disabling explicit manual archives. Preference reset restores only UI, appearance, and export defaults; it does not erase the current document, history, manual archives, or the AI API key.
- Unreachable legacy standalone-background settings and desktop bridges were removed. The active album-driven app background, migration compatibility, and Web Lite behavior remain intact.

## Accessibility, fonts, and licenses

- Settings heading levels, group names, input labels, and error relationships were corrected, with improved mobile navigation landmarks, history navigation, and minimum-window layout.
- Raw CSS font settings now support restoring system defaults, input sanitization, validation, and accessible errors. Prompt-library statistics distinguish protected, editable, and custom presets.
- About now provides offline links to the app’s Source Available License and bundled third-party notices, including Source Han fonts, in both desktop and Web Lite.

## Download and upgrade

- Windows x64 installer: `Lyrics.Card.Generator.Setup.6.2.4.exe`.
- This release remains Setup-only; upgrading from an older version requires no settings migration.
