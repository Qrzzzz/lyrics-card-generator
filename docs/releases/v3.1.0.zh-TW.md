# Lyrics Card Generator v3.1.0 發布說明

發布日期：2026-06-21

## 概覽

v3.1.0 完成字型方案面板重構，讓使用者可分別控制中日韓字型與西文字型，並持續提升 Windows 系統字型在預覽和 PNG 匯出中的可靠性。

## 修復與改進

- 新增「目前方案 / 預設方案 / 自訂方案 / 字型預覽卡片」四個明確區域。
- 預設精簡為思源黑體與思源宋體兩套方案；每套方案的中日韓與西文字型保持一致。
- 自訂方案可分別選擇中日韓字型與西文字型，數字和半形標點優先跟隨西文字型。
- 字型選擇改為專用視窗，提供推薦字型、搜尋、完整可捲動清單與候選字型預覽。
- 新增真實歌詞情境預覽；背景由真實卡片演算法生成，固定以深海藍、鈷藍、靛藍、夜幕藍作為取色輸入。
- 完整字型預覽移到右側真實卡片下方，並改為更窄、行距更大且高度剛好包住歌詞的直向版式。
- 「字型方案」從版面配置面板拆分為獨立流程步驟；步驟導覽會依標籤長度調整寬度，短標籤不再擠壓長標籤或顯示省略形式。
- 背景生成只用於字型面板預覽，不會修改歌詞卡片背景參數或最終 PNG。
- 六種介面語言同步加入字型方案文案、按鈕、背景演算法說明與卡片外註記。
- 目前方案會依字型組合識別為思源黑體、思源宋體或自訂方案。
- 預覽 DOM 與 PNG 匯出使用同一套已清理的中日韓 / 西文 `font-family` 堆疊。
- Windows 字型列舉會拆分組合名稱、去重並排序，不再產生含逗號的錯誤 family 名稱。
- 中文字型顯示名稱現在會對應到字型檔案中的真實 CSS family，並保留字重和斜體資訊。
- 移除了容易產生無效輸入的手動 `font-family` 輸入框。
- 選擇可能無法被目前瀏覽器識別的字型時會顯示非阻斷警告。
