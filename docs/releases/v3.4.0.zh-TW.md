# Lyrics Card Generator v3.4.0 發布說明

發布日期：2026-06-28

v3.4.0 重構了「佈局」步驟的內容類型邏輯，並把背景網格升級為可設定的視覺細節選項。

## 變更

- 「佈局」步驟現在會先選擇內容類型，再顯示可用的佈局、尺寸與文字排版選項。
- 「純音樂 / 無歌詞」卡片現在鎖定為直向 1:1 匯出，確保封面與歌曲資訊穩定顯示。
- 移除了「佈局」步驟中無效的「純音樂說明」輸入框。
- 背景網格現在預設關閉，並在「視覺細節」中提供「稀疏 / 中等 / 密」三檔密度。

## 修復

- 修復「純音樂 / 無歌詞」模式仍可選擇橫向卡片的問題。
- 修復「純音樂 / 無歌詞」模式仍可使用不相容的非方形尺寸問題。
- 修復上一版本背景網格視覺過密的問題。

## 驗證

- 驗證「純音樂 / 無歌詞」會立即切換為直向 1:1。
- 驗證橫向按鈕在「純音樂 / 無歌詞」模式下變灰且不可點擊。
- 驗證背景網格預設關閉，開啟後可切換三檔密度。
- 執行 `npm run typecheck`、`npm run core:test`、`npm run build`。
