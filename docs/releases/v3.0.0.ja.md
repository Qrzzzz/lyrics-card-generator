# Lyrics Card Generator v3.0.0 リリースノート

公開日：2026-06-20

v3.0.0 では歌詞翻訳機能と統合設定センターを追加しました。日本語 UI では、日本語の歌詞翻訳を生成します。翻訳先の言語は現在の UI 言語に従います。

## ダウンロード

- `Lyrics Card Generator Setup 3.0.0.exe`
- `Lyrics Card Generator-3.0.0-portable.exe`
- `Lyrics Card Generator Setup 3.0.0.exe.blockmap`

## 主な更新

- 歌詞エディターに翻訳入口を追加しました。
- 統合設定ダイアログを追加しました。
- 言語切り替えを即時プレビューできます。
- 最終ステップには「完了して書き出し」主ボタンのみを残しました。
- 最後の画面の余白を減らしました。

## 検証

`npm run typecheck`、`npm run core:test`、`npm run build`、`npm run desktop:build` が成功しました。

## 注意事項

- Windows ビルドは署名されていないため、SmartScreen の警告が表示される場合があります。
- v2.x からアップグレードした場合、関連設定を再設定する必要があります。
