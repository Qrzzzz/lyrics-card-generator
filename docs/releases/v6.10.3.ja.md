# Lyrics Card Generator v6.10.3

明るいジャケットが暗くなる問題を修正し、原文と訳文の見出しを統一して、リポジトリのルートを整理しました。

## 改善

- 明るいジャケットの明度と色の比率を保ち、小さな差し色が背景全体を占めないようにしました。自動文字色は実際のグラデーションから黒または白を選び、手動の色指定も維持します。
- 原文と訳文の編集面と見出しを統一しました。短い下線と印で対象列を示し、見出しのクリックで入力欄にフォーカスします。共有スクロール中も見出しの背後に本文が透けません。
- 翻訳 README、Playwright 設定、専用 TypeScript 設定を整理し、ルートのファイル数を 26 から 15 に削減しました。リンク、画像、テストコマンド、増分キャッシュの保存先も更新しました。

## 検証範囲

関連する動作回帰、型検査、lint、本番ビルド、Web Lite と文書リンクをローカルで確認しました。Chromium で明暗テーマ、フォーカス、共有スクロール、選択範囲の復元、および明るいジャケットの縦横 PNG 出力を検証しました。デスクトップ画面はブリッジのテスト用代替実装を使用します。完全な回帰、実際のインストール、更新、配布ファイルと来歴の検証は CI と Release が担当します。アプリは引き続き未署名で、旧翻訳 README への外部リンクは更新が必要です。
