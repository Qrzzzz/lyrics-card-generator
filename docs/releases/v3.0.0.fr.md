# Notes de version de Lyrics Card Generator v3.0.0

Date de publication : 2026-06-20

## Aperçu

v3.0.0 ajoute la traduction de paroles par IA et un centre de paramètres unifié. Pour les utilisateurs francophones, la traduction générée est en français ; elle n'est pas limitée au chinois.

## Téléchargements

- Installateur : `Lyrics Card Generator Setup 3.0.0.exe`
- Version portable : `Lyrics Card Generator-3.0.0-portable.exe`
- Blockmap : `Lyrics Card Generator Setup 3.0.0.exe.blockmap`

## Nouveautés

### Traduction IA des paroles

- Ajout d'une entrée de traduction IA dans l'éditeur de paroles.
- Après le choix d'un style, l'application peut générer une traduction française des paroles.
- Six styles sont disponibles : recommandé, chantable, fidèle, oral, imagé et sobre.
- La langue cible suit la langue actuelle de l'interface.
- La sortie en flux, l'affichage du processus, l'annulation et les messages d'erreur sont pris en charge.

### Centre de paramètres

- Ajout d'une boîte de dialogue de paramètres unifiée.
- Le changement de langue propose un aperçu immédiat.
- Les paramètres de traduction IA et le test de connexion sont disponibles dans les paramètres.
- Les textes associés sont disponibles dans les six langues de l'interface.

### Flux d'exportation

- La dernière étape ne conserve qu'un seul bouton principal Terminer et exporter.
- L'animation de fin a été déplacée vers le panneau d'exportation.
- La hauteur du bouton revient à une taille d'action standard.
- La zone de navigation finale évite les grands espaces vides.

## Validation

```bash
npm run typecheck
npm run core:test
npm run build
npm run desktop:build
```

## Notes

- Le build Windows n'est pas signé ; Windows peut afficher un avertissement SmartScreen.
- v3.0.0 n'inclut pas d'accès intégré à un service d'IA.
- La qualité et la vitesse de traduction dépendent du service choisi par l'utilisateur.
- Après une mise à niveau depuis v2.x, les paramètres liés à l'IA doivent être reconfigurés.
