# Lyrics Card Generator v6.1.6

> Status: released.

## Directional motion across both panes

- Opening a custom scheme fades the left overview out toward the left while the editor subview enters from the right. Cancel and Apply reverse that movement, carrying the first step's page-transition rhythm into Text Design.
- The fixed type specimen independently fades and slides in from the right without remounting the real lyric card. Reduced Motion removes the horizontal travel.

## One entry point for custom fonts

- Text Design no longer repeats the current-scheme summary and two outer font-role cards. Presets now carry their active state directly, while custom editing has one clear entry point.
- Opening the custom scheme replaces the left-side overview in place instead of appending another workbench below it.

## Clearer editing state

- CJK and Latin roles appear only once inside the editor subview, with one contextual usage description. The role controls stack automatically in narrower panels.
- Swap and restore are labeled secondary actions, Cancel is the sole exit action, and the footer explicitly distinguishes an unchanged scheme from an unapplied draft.

## Preview and apply semantics preserved

- Pointer and keyboard font previews still update the real lyric card and the fixed type specimen. Cancel discards the pair, while Apply commits both roles atomically.
- Desktop interaction coverage now pins the single entry point, role switching, draft status, focus restoration, and preset recovery.
