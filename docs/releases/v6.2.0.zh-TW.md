# Lyrics Card Generator v6.2.0

> 狀態：已發布。

## 複製成品圖片

- 「完成並匯出」旁新增「複製圖片」，不必先儲存檔案即可將目前成品寫入系統剪貼簿。
- 剪貼簿統一使用相容性更穩定的 PNG，並沿用目前匯出清晰度；複製不會變更 PNG、WebP 或 JPG 的下載格式選擇。
- 操作期間會顯示專用進度與完成提示；失敗時會提供剪貼簿權限檢查指引。

## 與匯出共用安全邊界

- 複製與下載共用不可變文件快照、字型與圖片就緒檢查、內容溢出防線、像素尺寸上限與互斥交易。
- Windows 桌面版透過受信任的 Electron IPC 將已解碼圖片寫入原生剪貼簿，並在預載層與主程序重複限制 PNG 資料和尺寸。
- Web Lite 在瀏覽器支援圖片剪貼簿 API 時提供相同入口；不支援或權限遭拒時不會改動編輯內容，並會顯示錯誤提示。

## 驗證範圍

- 型別檢查、匯出交易、六語言完整性、Electron 預載與安全契約、步驟版面、Web Lite 真實 PNG 複製及桌面原生剪貼簿互動均納入回歸。
