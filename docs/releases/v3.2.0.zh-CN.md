# Lyrics Card Generator v3.2.0 发布说明

> [!WARNING]
> 此版本 `v3.2.0` 存在尚未修复的 Bug，不建议更新到此版本。

发布日期：2026-06-23

## 设置中心与个性化更新

- 设置升级为通用、外观、背景、导出、AI、关于六个分类。
- 新增 Spark Cursor 开关、三套界面主题、界面字体/主色/文字颜色和可读性保护。
- 新增可持久化的纯色、拉伸、适应、填充、模糊和图片取色背景；默认仍为专辑封面动态取色。
- 新增低、标准、高清、超清四档默认 PNG 导出质量。
- 首次启动可选择六种语言，默认进入空白编辑器。
- `opposite` 改为从“示例”入口手动载入；更新检查和 GitHub 链接移入“关于”。
- Header 新增统一应用图标；AI 密钥继续使用原有安全存储。

验证：`npm run typecheck`、`npm run core:test`、`npm run build`、`npm run desktop:build`。
