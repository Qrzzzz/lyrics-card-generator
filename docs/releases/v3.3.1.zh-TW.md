# Lyrics Card Generator v3.3.1 發布說明

發布日期：2026-06-27

v3.3.1 是 v3.3.0 之後的 bugfix 版本，主要修復卡片背景中「細網格背景」開關的顯示問題。

## 修復內容

- 修復開啟「細網格背景」後，卡片背景中出現兩層網格疊加的問題。
- 修復關閉「細網格背景」後，卡片背景仍殘留一層網格的問題。
- 現在「細網格背景」開關會準確控制卡片內部網格顯示；關閉後預覽和匯出圖片中都不會再顯示卡片內部細網格。
- 應用程式主介面的背景紋理不受影響。

## 驗證

- 驗證直式卡片中開啟 / 關閉「細網格背景」的預覽效果。
- 驗證橫式卡片中開啟 / 關閉「細網格背景」的預覽效果。
- 驗證匯出的 PNG 與預覽一致。
- 執行 `npm run typecheck`、`npm run build`。
