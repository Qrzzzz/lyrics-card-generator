# Lyrics Card Generator v6.8.8

**2026-10-27**

Mejora las pruebas de regresión de escritorio y la publicación, conservando la edición de letras, las exportaciones y los ajustes guardados.

- PR/main comparten una sola compilación entre cuatro grupos independientes: editor, espacio de trabajo, datos y funciones nativas. Se dividen los escenarios largos de ajustes sin eliminar las comprobaciones de comportamiento.
- Comprueba los avisos de seguridad del runtime de Electron fijado antes de compilar y mantiene la auditoría actualizada del instalador final.
- La publicación puede reutilizar el runtime del mismo commit final de main tras verificar las firmas de procedencia, las herramientas y los hashes de los recursos. Si el artefacto falta o ha caducado, se realiza una compilación completa; una identidad incorrecta detiene la publicación.
- Mejora el archivado de candidatos, la recuperación tras interrupciones y la consulta del estado para reducir esperas y repeticiones.

Se mantienen las cinco comprobaciones obligatorias de CI, las pruebas de instalación y actualización del Setup final, el SBOM, las sumas de comprobación, la procedencia y la verificación de los archivos adjuntos públicos. No cambian los efectos de movimiento predeterminados ni el alcance de compatibilidad de las ventanas. No se promete una duración fija de publicación.
