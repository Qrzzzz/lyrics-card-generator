# Lyrics Card Generator v5.4.0 Release Notes

Release date: 2026-07-13

v5.4.0 completes the shared chrome across all six editor steps and rebuilds step one as the same compact workbench used by the rest of the flow.

## Highlights

- Step one now uses the same compact Stepper as steps two through six, combining the active step, the full route, Examples, Clear all, and Settings in one process rail.
- The duplicate large app header is removed from step one; the Windows title bar continues to show the app name, icon, and version.
- The first page becomes a shared two-column workbench whose process rail spans NetEase search and the song-import sidebar.
- Song details, song links, local audio, and manual editing are consolidated into one sidebar panel while preserving every import path and accessibility contract.
- The minimum 1000px desktop width keeps a 320px sidebar, which grows to 360px and 400px at wider breakpoints.

## Scope

- NetEase search, link parsing, local-audio parsing, manual song details, the lyrics document, and AI translation behavior are unchanged.
- Steps two through six, live preview, PNG export, settings data, project files, and shared Web Lite behavior are unchanged.

## Verification

- `npm run lint` / `npm run typecheck` / `npm run core:test` / `npm run build`
- `npm run web-lite:build` / `npm run web-lite:check` / `npm run web-lite:smoke`
- `npm run desktop:build` / `npm run desktop:interaction-test` / `npm run desktop:final-artifact-smoke`
- Desktop regressions at 1000×700, 1023×700, 1024×700, 1280×900, 1440×900, and 1920×1080
