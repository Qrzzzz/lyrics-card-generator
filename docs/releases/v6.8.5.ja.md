リリース処理自身による push の後だけ、既知の古い PR head が更新されるまで有限時間待機します。正確なコミットによる承認を維持し、中断からの再開で記録済みの push を繰り返しません。

Web Lite のインストールとテストに個別の制限時間を設け、コマンドログ、失敗時の画像と trace を保存します。デスクトップ共有 canary はダウンロード前に成果物の識別情報と有効期限を確認します。利用できない場合は停止し、再ビルドと全利用グループの再実行を要求します。
