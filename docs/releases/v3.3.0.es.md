# Notas de la versión 3.3.0 de Lyrics Card Generator

Fecha de lanzamiento: 2026-06-25

La versión 3.3.0 añade el análisis de enlaces de canciones de Spotify. Ahora puedes pegar un enlace de canción de Spotify, completar automáticamente título, artista y portada, y seguir usando la edición de tarjetas de letras, la paleta de portada y el flujo de exportación existentes.

## Análisis de enlaces de Spotify

- Análisis de enlaces de canciones de Spotify.
- Compatibilidad con `open.spotify.com/track/...`, `open.spotify.com/intl-.../track/...`, `open.spotify.com/embed/track/...` y enlaces cortos comunes de Spotify.
- Visualización del logo de Spotify para canciones analizadas.
- La obtención automática de letras sigue usando la búsqueda experimental existente.
- Se corrigió que los pasos posteriores aparecieran con marca de completado justo al iniciar la app; ahora solo los pasos ya recorridos muestran el estado completado.

## Notas

- Esta versión no obtiene letras desde Spotify.
- Esta versión no requiere cuenta de Spotify, OAuth ni clave API.
- Si el análisis automático falla, aún puedes introducir manualmente título, artista, portada y letra.

Validación: `npm run typecheck`, `npm run parse:test`, `npm run core:test`, `npm run build`, además de comprobaciones locales de API para el análisis de Spotify, el schema del endpoint de letras y el asset SVG de Spotify.
