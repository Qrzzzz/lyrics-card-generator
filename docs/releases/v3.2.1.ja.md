# Lyrics Card Generator v3.2.1 リリースノート

リリース日：2026-06-23

> [!NOTE]
> `v3.2.1` は `v3.2.0` のバグ修正と体験向上リリースとして位置付けられています。

## 安定性の修正

- ライトブルーテーマとカスタム背景での文字およびステータス表示のコントラストを修正しました。
- Header のアプリアイコンを拡大し、設定を保持する「すべて消去」を復元しました。
- すべてのモードで背景画像を選択できるようにし、選択後はカバーモードですぐにプレビューします。
- 保存、キャンセル、リセットをトランザクション化し、キャンセル時に以前の背景を削除しないよう修正しました。
- 背景の連続切り替え時のオブジェクト URL を解放し、カスタムテーマの token を補完しました。
- 関連するステータス文言とリリースノートを6言語で追加しました。
- デスクトップ版を再起動するたびに言語選択が表示される問題を修正しました。初回の選択を永続化し、次回以降は空のエディターを直接開きます。
- Spark Cursor スイッチを自動高さと同様に設定カードの横幅いっぱいに表示します。
- 「ビジュアル詳細」に、プレビューと書き出し PNG の両方へ反映される「細かいグリッド背景」スイッチを追加し、既定で有効にしました。

検証：`npm run typecheck`、`npm run core:test`、`npm run build`、`npm run desktop:build`。
