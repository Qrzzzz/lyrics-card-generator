Esta es la primera versión de escritorio oficial de Lyrics Card Generator. En comparación con la versión inicial de escritorio v0.1.0, esta versión se centra en perfeccionar el proceso de distribución para Windows, la verificación de actualizaciones dentro de la aplicación, la estabilidad del diseño de las tarjetas y la experiencia de exportación, lo que la hace adecuada para su uso como versión distribuible formal.

## Principales actualizaciones

### Versión de escritorio para Windows finalizada

* Versión de la aplicación actualizada a `1.0.0`.
* Se agregó un punto de entrada de escritorio con Electron; los usuarios de Windows pueden ejecutar directamente el EXE.
* La versión de escritorio inicia un servidor Next independiente incorporado localmente y carga la aplicación local en una ventana de escritorio.
* No es necesario instalar Node.js ni ejecutar manualmente un servidor de desarrollo.
* Compatible con las ediciones instalable y portátil para Windows x64.
* La ventana se abre maximizada de forma predeterminada.
* Los enlaces externos se abren en el navegador del sistema.
* Al cerrar la aplicación, el proceso del servicio local se limpia automáticamente, reduciendo los residuos en segundo plano.

### Nueva función: Buscar actualizaciones

* Se añadió un botón "Buscar actualizaciones" en la barra de herramientas superior.
* La aplicación solicita la información de la última versión desde GitHub Releases.
* Compatible con la comparación de formatos de número de versión como `v1.0.0` / `1.0.0`.
* Si se encuentra una nueva versión, se proporciona un enlace a la página de descarga.
* Si en la publicación existen instaladores `.exe` o `.msi`, se priorizarán como recursos de descarga.
* Esta función solo busca actualizaciones y abre la página de descarga; no descarga silenciosamente ni reemplaza automáticamente el programa actual.

### Corrección de altura automática

* En dimensiones personalizadas verticales, la altura automática ahora se estima de manera integral según el contenido real de la letra, la traducción, el tamaño de fuente, el interlineado, el área de título, el borde y el contenido del pie de página.
* Al activar el logotipo de la plataforma, el compartidor o la marca de agua de generación, la tarjeta aumentará su altura hacia abajo en lugar de comprimir el área de la letra.
* La altura automática está activada de forma predeterminada.
* El límite máximo de altura personalizada vertical se ha aumentado a `3200px`, adecuado para escenarios con letras largas, traducción y pie de página activados simultáneamente.

### Corrección del diseño con borde horizontal

* Se corrigió la desalineación de la información de la plataforma, el compartidor y la marca de agua de generación al activar "Borde + Sombra" en tarjetas horizontales.
* El diseño horizontal ahora utiliza un sistema de coordenadas unificado sensible al marco (frame-aware).
* Al activar el borde, la portada, la información de la canción, la letra y los elementos del pie de página entran juntos en el área segura interior del borde.
* Se corrigió el problema de desalineación entre el pie de página y el borde en proporciones horizontales como 16:9, 21:9 y 3:2.

### Optimización de la experiencia de exportación

* Se simplificó el flujo de exportación a "Finalizar y exportar", reduciendo los puntos de entrada redundantes para la configuración de exportación.
* La salida PNG de alta resolución 2x se mantiene de forma predeterminada.
* La animación de celebración tras una exportación exitosa se ha reemplazado por un efecto de serpentinas superior más discreto.
* Se corrigió el problema por el cual "Limpiar todo el contenido" podía activar por error la animación de celebración de exportación.

### Mejoras en iconos e ingeniería de publicación

* Se reemplazaron y unificaron los recursos de iconos de la aplicación.
* Se añadieron iconos para el instalador de Windows, la versión portátil, el favicon web y el área de título dentro de la aplicación.
* Se añadieron scripts de compilación y preparación de publicación para la versión de escritorio.
* Se añadieron instrucciones de ejecución para escritorio, lista de verificación de migración, documento de problemas conocidos y registro de publicación.
* Se actualizó `.gitignore` para evitar que se envíen artefactos de compilación, archivos de publicación, cachés y registros al repositorio de código fuente.

## Capacidades conservadas

* Análisis de enlaces de Apple Music, NetEase Cloud Music y QQ Music.
* Edición manual de la información de la canción, letra y traducción.
* Carga de portada local, intermediario de portada remota y extracción de color de portada.
* Generación de tarjetas en orientación vertical / horizontal.
* Configuraciones visuales: fuente, tamaño de fuente, interlineado, color, borde, sombra, marca de agua, compartidor y logotipo de la plataforma.
* Cambio de interfaz entre Chino / English.
* Apertura sin conexión, edición manual, portada local y exportación PNG.

## Funciones que aún requieren conexión a Internet

* Análisis de enlaces de plataformas musicales.
* Carga de portadas remotas.
* Obtención automática de letras mediante LRCLIB.
* Búsqueda de actualizaciones en GitHub.

## Limitaciones conocidas

* La versión actual aún no está firmada con código; Windows puede mostrar una advertencia de SmartScreen.
* La búsqueda de actualizaciones no descarga automáticamente los instaladores; el usuario debe abrir manualmente la página de descarga.
* El objetivo de distribución actual es Windows x64.
* El análisis de plataformas de terceros y la obtención de letras están sujetos a la disponibilidad de los servicios externos.
