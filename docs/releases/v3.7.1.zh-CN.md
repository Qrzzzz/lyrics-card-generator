# Lyrics Card Generator v3.7.1 发布说明

发布日期：2026-06-30

v3.7.1 是一次界面控件标准化版本，不引入 v3.8.0 计划中的动效升级。此次更新聚焦于统一开关、选项卡片、分段控件与设置面板基础控件，同时改善可访问性与键盘/焦点行为，为后续 v3.8.0 的动效升级打基础。

## 改进

- 统一样式面板、歌词输入、歌曲信息和设置中的开关控件，让切换状态、禁用状态和视觉反馈更一致。
- 将语言选择等单选项整理为统一的选项卡片，并将布局模式、网格密度、边框 / 满幅等紧凑选择整理为一致的分段控件。
- 统一设置面板中常用输入框、文本域、下拉选择与操作按钮的外观和交互反馈，使不同分区的控件风格更连贯。

## 可访问性与一致性

- 改善常见控件的键盘可用性、焦点可见性、标签呈现和禁用态反馈，减少不同面板之间的交互差异。
- 收敛部分开关颜色和主题分支样式，改为更多依赖现有主题令牌，以便在深色、浅色、Acrylic 和自定义主题下保持更稳定的表现。
- 本次仅整理控件层与交互基础，不包含新的 v3.8.0 动效系统，也不改变导出结果、设置结构或既有功能流程。

## 验证

- npm run typecheck
- npm run core:test
- npm run build
