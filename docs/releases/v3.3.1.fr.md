# Notes de version de Lyrics Card Generator v3.3.1

Date de publication : 2026-06-27

v3.3.1 est une version bugfix publiée après v3.3.0. Elle corrige principalement l'affichage du réglage « Fond à grille fine » sur les fonds de carte.

## Corrections

- Correction du fond de carte qui affichait deux couches de grille superposées lorsque « Fond à grille fine » était activé.
- Correction de la grille qui restait visible sur le fond de carte après la désactivation de « Fond à grille fine ».
- Le réglage « Fond à grille fine » contrôle désormais correctement la grille interne de la carte ; une fois désactivé, aucune grille fine interne n'apparaît dans l'aperçu ni dans les images exportées.
- La texture de fond de l'interface principale de l'application n'est pas affectée.

## Validation

- Vérification de l'aperçu des cartes portrait avec « Fond à grille fine » activé / désactivé.
- Vérification de l'aperçu des cartes paysage avec « Fond à grille fine » activé / désactivé.
- Vérification de la correspondance entre le PNG exporté et l'aperçu.
- Exécution de `npm run typecheck` et `npm run build`.
