# Lyrics Card Generator v5.12.1

> Estado: publicado públicamente mediante GitHub Releases.

## Conservar solo el texto seleccionado

- El primer elemento de la barra de herramientas del paso 2 es ahora el nuevo comando «Conservar selección», presentado con un color de énfasis ligero. Permanece desactivado hasta que se selecciona texto.
- Al seleccionar texto en la columna original o traducida y ejecutar el comando, se conservan exactamente los caracteres seleccionados y se elimina el resto de la columna activa. La otra columna no cambia.
- El comando utiliza la restauración de selección y el historial de deshacer y rehacer existentes. El texto conservado permanece seleccionado para seguir editándolo o deshacer la operación de inmediato.
