# Lyrics Card Generator v6.5.2 Notas de la versión

Fecha de publicación: 2026-09-18

v6.5.2 corrige las traducciones con IA que se consideraban exitosas después de un error del proveedor, con mensajes coherentes y la restauración de la traducción anterior.

## Correcciones

- Si el servicio de IA informa de un error durante la respuesta o el flujo termina de forma anómala, la traducción falla y se restaura la traducción anterior. Recibir el texto completo ya no convierte una respuesta fallida en un resultado exitoso.
- Se mantiene la compatibilidad con los servicios que indican explícitamente una finalización normal pero omiten el marcador de fin del flujo. Las traducciones normales siguen completándose; después de cancelar, cambiar de documento o iniciar otra traducción, las solicitudes anteriores no pueden sobrescribir el contenido actual.
