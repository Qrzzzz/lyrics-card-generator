# Lyrics Card Generator v3.0.0 發布說明

發布日期：2026-06-20

## 版本定位

v3.0.0 新增 AI 歌詞翻譯工作流，並將語言設定與 AI 設定集中到設定中心。對繁體中文使用者來說，AI 翻譯會生成繁體中文歌詞翻譯，而不是固定生成其他語言。

## 下載與安裝

- 安裝版：`Lyrics Card Generator Setup 3.0.0.exe`
- 便攜版：`Lyrics Card Generator-3.0.0-portable.exe`
- 增量更新校驗文件：`Lyrics Card Generator Setup 3.0.0.exe.blockmap`

## 本次更新

### AI 歌詞翻譯

- 新增 AI 翻譯入口，可在歌詞編輯介面直接使用。
- 使用者選擇翻譯風格後，軟體會生成繁體中文歌詞翻譯。
- 提供推薦、歌唱、忠實、口語、意象、克制六種風格。
- 目標譯文語言會跟隨目前介面語言。
- 支援串流輸出、過程展示、取消請求與錯誤提示。

### 設定中心

- 新增統一設定對話框。
- 支援語言切換即時預覽。
- 支援 AI 翻譯參數設定與連線測試。
- 相關文案已覆蓋六種介面語言。

### 匯出步驟優化

- 最終步驟只保留一個「完成並匯出」主按鈕。
- 完成按鈕動效已遷移到匯出面板。
- 按鈕高度恢復為標準操作尺寸。
- 最後一步導覽區域減少異常空白。

## 驗證結果

發布前已通過：

```bash
npm run typecheck
npm run core:test
npm run build
npm run desktop:build
```

## 注意事項

- Windows 構建未進行程式碼簽章，可能出現 SmartScreen 提示。
- v3.0.0 不內建第三方 AI 服務額度。
- 翻譯品質、速度、費用與限制取決於使用者選擇的服務。
- 從 v2.x 升級後，AI 相關設定需要重新配置。
