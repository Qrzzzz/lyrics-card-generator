# Notes de version de Lyrics Card Generator v0.1.0

Date de publication : 2026-06-16

## Présentation

Cette version est la première version desktop Windows de Lyrics Card Generator. Elle transforme l'application Web Next.js en application Windows prête à lancer, sans installation de Node.js et sans serveur de développement à démarrer manuellement.

L'application utilise Electron avec un service Next local. Au démarrage, elle lance un service intégré local et charge l'interface dans une fenêtre desktop. Les services musicaux, les pochettes distantes et LRCLIB restent uniquement des sources de données.

## Téléchargement et installation

- Installateur : `Lyrics.Card.Generator.Setup.0.1.0.exe`
- Version portable : `Lyrics.Card.Generator-0.1.0-portable.exe`

L'installateur est recommandé pour un usage normal. La version portable convient aux essais temporaires ou aux usages sans installation système.

## Fonctionnalités principales

- Analyse des liens Apple Music, NetEase Cloud Music et QQ Music.
- Modification manuelle du titre, de l'artiste, de l'album et de l'URL de pochette.
- Saisie et édition manuelles des paroles.
- Édition ligne par ligne des traductions, avec affichage ou masquage possible.
- Mode instrumental pour les morceaux sans paroles.
- Pochettes distantes, pochettes locales, intermédiaire de pochette et extraction des couleurs.
- Réglages de mise en page, taille, hauteur automatique, police, couleur, bordure, ombre, logo de plateforme, filigrane et texte de partage.
- Interface chinoise et anglaise avec conservation locale du choix de langue.
- Export PNG haute qualité via le pipeline DOM-to-PNG existant.

## Expérience desktop

- L'application se lance par double-clic.
- La fenêtre s'ouvre maximisée par défaut.
- L'icône de l'application est utilisée dans l'installateur, la version portable, la barre des tâches, le favicon et l'interface.
- La fermeture de la fenêtre arrête aussi le service local intégré.
- Les liens externes s'ouvrent dans le navigateur du système.

## Hors ligne et en ligne

Disponible hors ligne : ouverture de l'application, saisie manuelle des informations, édition des paroles et traductions, pochette locale, réglages visuels et export PNG.

Connexion nécessaire : analyse des liens musicaux, chargement des pochettes distantes et récupération automatique des paroles via LRCLIB.

## Limites initiales

- Pas de mise à jour automatique dans cette version.
- Le build Windows n'est pas signé ; Windows peut afficher un avertissement SmartScreen.
- Les fichiers fournis sont destinés à Windows x64.
- Les fonctions de récupération distante dépendent de services tiers.

## Validation

Avant publication, `npm run typecheck`, `npm run build` et `npm run desktop:build` ont réussi. Les versions installateur et portable ont été générées et les principales fonctions ont été validées avec des exemples.
