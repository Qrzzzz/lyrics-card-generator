# Lyrics Card Generator v3.9.1 Release Notes

Release date: 2026-07-01

v3.9.1 fixes desktop window rounded corners and refreshes the custom title bar layout. Non-Acrylic themes now use native Windows rounded-corner clipping, while the desktop background, title-bar gradient, and noise layer remain drawn inside the app shell. Exported lyric card PNG output is not affected.

## Desktop Window Corners

- Non-Acrylic themes no longer rely on transparent CSS-only shell corners; the native Windows window boundary performs the outer clipping.
- Acrylic themes continue to use the native Windows Acrylic material while keeping the window background transparent.
- The app background layer now uses absolute positioning inside the shell, so image backgrounds, dynamic album backgrounds, and solid backgrounds are clipped by the rounded container.

## Title Bar

- The custom title bar now uses left-side red, yellow, and green window controls for close, minimize, and maximize/restore.
- The app name and version remain next to the controls, and the small right-side app icon has been removed.
- The title bar still supports window dragging, while the control buttons remain non-draggable for stable clicks.

## Export and Web App

- Browser Web runs still hide the desktop title bar and do not reserve desktop-only top spacing.
- The PNG export path remains free of the desktop title bar, window frame, shell background, and Electron desktop API.

## Verification

- npm run typecheck
- npm run core:test
