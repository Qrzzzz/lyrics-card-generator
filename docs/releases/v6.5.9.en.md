# Lyrics Card Generator v6.5.9 Release Notes

Release date: 2026-10-02

v6.5.9 fixes AI input validation and cover request cancellation, improves font cache consistency after updates, and shares the image output workflow.

## Fixes and improvements

- AI requests with invalid field types or excessive lengths return a clear error instead of failing unexpectedly.
- Replacing or cancelling remote covers stops obsolete requests; font updates use content versions.
- Desktop and Web Lite share image output while preserving formats, completion handling after clear, and local cover lifetimes.
- Adds isolated test entry points and distribution size budgets, and corrects historical security exception documentation.
