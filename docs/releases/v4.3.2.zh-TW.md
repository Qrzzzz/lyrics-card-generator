# Lyrics Card Generator v4.3.2 發布說明

發布日期：2026-07-06

本版本聚焦歌曲標題區域的視覺打磨，改善 Explicit 標誌的質感，並讓直式封面與歌曲資訊形成更穩定的視覺中心。

## 主要更新

- 將 Explicit 標誌重寫為單一 SVG 圖形，不再依賴字體字母 `E`。
- Explicit 標誌使用 `currentColor` 與整體透明度，並透過 SVG mask 挖空幾何 E，避免出現黑色實心字母。
- 微調 Explicit 標誌的尺寸、垂直位置與標題間距，使它與歌曲標題中軸線更自然對齊。
- 放大直式專輯封面，並同步調整圓角比例。
- 讓直式歌曲資訊區塊使用與封面一致的最小高度並垂直置中，標題、藝人與專輯三行更貼近封面中心線。
- 保持現有字級、行高與 header 間距不變，降低版面回歸風險。

## 驗證

- npm run typecheck
- npm run core:test
- npm run build
- 瀏覽器載入 `opposite` 範例並匯出 PNG，確認預覽與匯出中的 Explicit 標誌和直式 header 對齊一致。
