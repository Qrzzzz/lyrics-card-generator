# Lyrics Card Generator v5.2.1 發布說明

## 恢復歌曲連結解析

v5.2.1 恢復 Spotify、Apple Music、網易雲音樂與 QQ 音樂的真實歌曲連結解析，並保留 v5.1.0 與 v5.2.0 的網路安全強化。

- QQ 音樂數值 `songDetail` 連結現在依 `songid` 解析，正確填入標題、歌手、專輯與封面。
- 網易雲音樂 JSON API 使用正確的回應協商，重新取得完整歌曲、歌手與專輯中繼資料。
- Apple Music 頁面即使自動重新導向首頁，也會使用原始曲目 ID 查詢歌曲並回傳有效曲目連結。
- Spotify 單曲連結保持相容；四個平台都加入真實連結強斷言回歸測試。

## 安全與相容性

- 保留逐跳 URL/DNS 驗證、重新導向複檢、回應大小與類型限制，以及多位址 IPv6/IPv4 fallback。
- 歌詞卡輸出、專案資料格式與既有視覺方向保持不變。
- Windows x64 Setup 與 portable 已依 v5.2.1 重新建置。
