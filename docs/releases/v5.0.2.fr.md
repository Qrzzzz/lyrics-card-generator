# Notes de version de Lyrics Card Generator v5.0.2

Date de publication : 2026-07-12

La v5.0.2 renforce la publication basée sur la v5.0.0, sans modifier les interactions existantes d’édition, d’aperçu ou d’exportation.

## Principales mises à jour

- Alignement de l’application, du fichier de verrouillage, des six README localisés et des notes de version sur la version 5.0.2.
- Mise à jour de Next.js, Undici et des dépendances associées dans leurs plages compatibles, supprimant les alertes d’exécution de gravité élevée.
- Nouvelle vérification et reconstruction de Web Lite, de l’installateur Windows, de la version portable et du fichier de validation des mises à jour incrémentielles.

## Vérification

- `npm run typecheck`
- `npm run core:test`
- `npm run build`
- `npm run web-lite:build` / `web-lite:check` / `web-lite:smoke`
- `npm run desktop:build` / `desktop:interaction-test`
