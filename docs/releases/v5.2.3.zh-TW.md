# Lyrics Card Generator v5.2.3 發布說明

## 發布驗證修正

v5.2.3 修正 v5.2.2 發布流程最後一道附件重新下載驗證失敗的問題。

- 同一標籤同時存在已發布 Release 與草稿 Release 時，流程不再依標籤下載可能指向錯誤 Release 的附件。
- 工作流程會記錄本次建立的唯一草稿 Release ID，並透過該 ID 下載、驗證與發布同一組附件。
- 正式發布前會嚴格核對安裝版、可攜版、SPDX SBOM、SHA256SUMS、檔案摘要與 GitHub attestation。
- 同標籤已有正式發布時會提前中止；重新執行時只清理同標籤殘留草稿，避免重複或不完整 Release 被誤判為成功。

## 版本範圍

- 應用程式功能、介面行為、歌詞卡輸出與專案資料格式均與 v5.2.2 維持一致。
- 本版本只修正發布與供應鏈驗證流程，並重新產生通過完整驗證的 Windows 成品。
