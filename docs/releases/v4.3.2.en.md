# Lyrics Card Generator v4.3.2 Release Notes

Release date: 2026-07-06

This release polishes the song-title area, improves the Explicit badge, and gives the portrait cover and song info a steadier visual center.

## Main Updates

- Rebuilt the Explicit badge as a single SVG shape instead of relying on a rendered `E` glyph.
- The Explicit badge now uses `currentColor` plus outer opacity, with a geometric E cut out through an SVG mask so no solid black letter appears.
- Fine-tuned the badge size, vertical position, and spacing from the title so it aligns more naturally with the title centerline.
- Enlarged the portrait album cover and adjusted the corner radius proportionally.
- Gave the portrait song-info block the same minimum height as the cover and vertically centered it, keeping title, artist, and album closer to the cover centerline.
- Kept existing font sizes, line heights, and header gap unchanged to reduce layout-regression risk.

## Verification

- npm run typecheck
- npm run core:test
- npm run build
- Loaded the `opposite` example in the browser and exported PNG output to confirm the Explicit badge and portrait header alignment match between preview and export.
