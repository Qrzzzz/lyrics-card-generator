# Lyrics Card Generator v5.8.8 Release Notes

Release date: 2026-07-30

v5.8.8 is an internal cleanup release that freezes the v5.8.7 frontend. It adds or removes no visible feature; it only clarifies implementation boundaries around already-stable behavior.

## Frozen v5.8.7 frontend

- Page structure, element classes, automated `data-testid` contracts, visuals, the fixed 2:1 split, and the narrow-screen drawer are unchanged.
- Shared bilingual scrolling, editor height synchronization, selection and cursor restoration, focus handoff, and inactive-page `inert` isolation are unchanged.
- Escape hierarchy, reduced motion, the AI request start／cancel／back／unmount lifecycle, and translation application logic are unchanged.

## Internal structure cleanup

- Retired style-panel, input, and compatibility paths with no runtime entry point are removed without changing reachable Desktop or Web Lite features.
- `LyricsSidebar` navigation and focus control are separated from Cleanup／Translation presentation. Its three-page track remains specific to the step-two sidebar rather than becoming a generic page system.
- `LyricsWorkspace` document transforms, undo／redo history, and selection control move into a dedicated controller while layout and DOM rendering remain in the workspace component.

## Versioning and verification

- `package.json`, the lockfile, six localized READMEs, six release notes, the release index, and Web Lite are synchronized at 5.8.8.
- Type checking, zero-warning lint, the production build, core regressions, Web Lite checks／smoke tests, and the desktop Electron interaction matrix cover this behavior-preserving cleanup.
