# Lyrics Card Generator v5.6.0 Release Notes

Release date: 2026-07-15

v5.6.0 rebuilds the Lyrics Examples frame, repairs the window-edge gradient, and upgrades Manual Adjust to a bidirectional draft editor with explicit Save and Cancel actions. The example cards themselves and the remaining editing, import, and export capabilities are unchanged.

## Lyrics Examples frame

- Lyrics Examples now reuses the Settings-style top-header structure, with its close button in the upper-right.
- The oversized “Lyrics Card Generator” frame and close entry at the bottom have been removed, while the examples use their own scroll region.
- The content, rendering, selection, and import behavior of the example cards remain unchanged.

## Window-edge gradient

- The duplicate mask on the single titlebar edge gradient has been fixed so the blur and veil no longer fade too early.
- The blur layer and theme veil now share one complete fade envelope across dark, light, and acrylic appearances.
- Lyrics Examples reuses the reversed form of the same effect along its bottom edge, creating a natural transition from scrolling content to the window boundary.

## Manual Adjust

- Opening Manual Adjust slides the existing song summary left while it fades out, as the editor slides and fades in from the right.
- Changes remain isolated in a draft. Save applies that draft, while Cancel discards it without overwriting the current song information during editing.
- After either action, the editor leaves with the reverse transition and the song summary returns from the left.

## Development-cycle note

- GitHub Actions currently warns that some SHA-pinned actions still target Node.js 20 and are being forced by the runner to use Node.js 24.
- This remains a separate evaluation item for the 5.6.0 development cycle. The UI work in this update does not modify workflows or pinned SHAs and does not claim that the warning is resolved.
