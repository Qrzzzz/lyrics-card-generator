# Notes de version de Lyrics Card Generator v3.9.1

Date de publication : 2026-07-01

La v3.9.1 corrige les coins arrondis de la fenêtre de bureau et actualise la barre de titre personnalisée. Les thèmes non Acrylic utilisent maintenant le découpage arrondi natif de Windows, tandis que le fond de bureau, le dégradé de la barre de titre et la couche de bruit restent dessinés dans l’enveloppe de l’application. Les PNG exportés des cartes de paroles ne sont pas affectés.

## Coins de la fenêtre de bureau

- Les thèmes non Acrylic ne dépendent plus de coins transparents uniquement en CSS ; la limite native de la fenêtre Windows effectue le découpage extérieur.
- Les thèmes Acrylic continuent d’utiliser le matériau Acrylic natif de Windows tout en gardant un fond de fenêtre transparent.
- La couche de fond de l’application utilise désormais un positionnement absolu dans l’enveloppe, afin que les images, les fonds dynamiques d’album et les fonds unis soient découpés par le conteneur arrondi.

## Barre de titre

- La barre de titre personnalisée utilise maintenant des contrôles rouge, jaune et vert à gauche pour fermer, réduire et agrandir/restaurer.
- Le nom de l’application et la version restent près des contrôles, et la petite icône de droite a été supprimée.
- La barre de titre permet toujours de déplacer la fenêtre, tandis que les boutons de contrôle restent non déplaçables pour des clics stables.

## Exportation et version Web

- Dans le navigateur, la version Web masque toujours la barre de titre de bureau et ne réserve pas d’espace supérieur propre au bureau.
- Le chemin d’export PNG reste exempt de barre de titre de bureau, de cadre de fenêtre, de fond d’enveloppe et d’API Electron de bureau.

## Vérification

- npm run typecheck
- npm run core:test
- npm run build
