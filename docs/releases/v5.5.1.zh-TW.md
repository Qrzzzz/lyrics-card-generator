# Lyrics Card Generator v5.5.1 發布說明

發布日期：2026-07-14

v5.5.1 將自動寬度設為新建直式自訂歌詞卡的預設行為，並進一步強化內容測量、候選選擇、行高正規化與跨版本回歸測試。

## 主要更新

- 新建直式自訂歌詞卡預設開啟「自動寬度」。啟用時寬度滑桿顯示即時計算結果並暫時停用；關閉後保留最後計算寬度，仍可手動微調。
- 行高統一限制為 1.5–2.1、步長 0.05，新建卡片預設 1.8；舊的越界、非步長與無效值會安全正規化。
- 隱藏的原尺寸排版探針會以最終字型完整測量 720–1440 的 37 個候選寬度，求解結果只由目前內容與排版決定，不受開啟前的手動寬度影響。
- 候選集合必須寬度完整且無重複後才參與計算；評分以全域中位數為中心並使用穩定的同分決勝規則，測量不完整時不會寫入可疑寬度。
- 正文與譯文繼續分別檢查中日韓字素、西文單字與混合文字的嚴重孤行；六個內建範例在 Web Lite 與桌面版從最窄或最寬起點都會收斂到相同寬度。
- 內建範例目標寬度固定為 Opalite 1380、相反的我 840、勇者 1100、光輝歲月 800、蜜蜂 880、謊言 920，並允許不同繪製環境有 ±20 像素差異。

## 版本範圍

- 自動寬度仍僅支援直式、自訂尺寸與歌詞模式；固定比例、橫式與純音樂模式維持原有行為。
- 舊狀態缺少 `autoWidth` 欄位時仍按關閉處理，不會擅自覆寫使用者保存的手動寬度。
- 桌面版與 Web Lite 共用同一套測量、評分、自動高度協調與匯出安全路徑。
