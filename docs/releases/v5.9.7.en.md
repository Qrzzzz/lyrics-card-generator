# Lyrics Card Generator v5.9.7 Release Notes

Candidate date: 2026-08-19

v5.9.7 adds complete support for irregular album artwork. Covers are no longer forced into a square crop: their natural aspect ratio now participates in card layout while existing 1:1 artwork remains pixel-for-pixel unchanged.

## Natural-ratio artwork

- Horizontal artwork keeps the standard square-cover height and expands sideways at its natural ratio.
- Vertical artwork keeps the standard square-cover width and expands vertically at its natural ratio.
- 1:1 artwork retains the same size, corner radius, position, and surrounding layout. Extreme ratios scale down proportionally only when they reach physical canvas safety bounds.
- Every cover displays the complete image without cropping, stretching, or padding it inside a square stage.

## Transparency and end-to-end consistency

- Transparent PNG and WebP artwork no longer receives a square backing plate. Transparent pixels reveal the card background, with shadows that follow alpha edges.
- Natural dimensions, transparency, and palette extraction are resolved during the same image decode so preview and export cannot choose different geometry.
- Editor preview, unscaled export, instrumental cards, Web Lite, song metadata, import summaries, search results, and history thumbnails share the same ratio rules.
- Export snapshots freeze artwork geometry and wait for image decoding before capture, preventing stale ratios or incomplete images during asynchronous cover changes.

## Compatibility and validation

- Lyric-document, import-history, and manual-archive formats are unchanged, so no user-data migration is required.
- Coverage includes 1:1, 1200×802 horizontal, 879×1200 vertical, extreme-ratio, and transparent PNG fixtures. Square cases retain their original dimensions and rectangular cases retain the full image.
- v5.9.6 import, parsing, AI translation, settings, history, and PNG, WebP, and JPG export capabilities remain available.

## Candidate boundary

These notes describe a local v5.9.7 release candidate. It is not yet released and does not imply that push, tag, or GitHub Release operations have occurred. Public availability is determined by the project’s GitHub Releases page.
