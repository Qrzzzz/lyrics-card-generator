# Lyrics Card Generator v4.2.0 发布说明

发布日期：2026-07-03

v4.2.0 升级桌面版示例歌词系统，并修复独立 Web Lite / GitHub Pages 部署准备方式。Web Lite 仍是简化在线演示，不代表桌面版完整体验。

## 主要更新

- 示例歌词配置升级为“原语言歌词 + 五种目标语言翻译样例”的可复用结构。
- 示例弹窗现在展示歌曲标题、歌手和原语言，并可在五种译文之间选择。
- 当当前界面语言存在对应译文时，示例会默认选中该译文；否则使用第一种可用译文。
- 示例配置不再承担卡片高度、尺寸、比例或 AutoHeight 状态职责。
- 加载示例只填入歌曲信息、歌词和译文，仍保留封面与专辑信息的最佳努力补充逻辑。
- Web Lite / GitHub Pages 改用显式相对图标路径，并只打包 `index.html`、`public/app-icon.png` 和 `.nojekyll`。

## 范围说明

- 不把示例文本写入组件，示例数据仍集中在 `lib/examples.ts`。
- 不为示例引入运行时请求，歌词与译文离线可用。
- 不为了 Web Lite 改动桌面版主体逻辑、Electron 构建或桌面版预览 / 导出流程。
- Web Lite 仍是独立、简化、粗略的在线演示，完整体验请使用桌面版。

## 验证

- npm run typecheck
- npm run core:test
- npm run build
