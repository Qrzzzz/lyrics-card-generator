# Lyrics Card Generator v4.1.0 發布說明

發布日期：2026-07-02

v4.1.0 是一次樣式面板視覺層級重構。它不改變歌詞卡渲染、匯出 DOM、左右版面或設定狀態結構，而是重新區分「方案選擇」與「普通參數設定」：字體方案繼續保留卡片質感，字號、行高、對齊、開關、裁切、顏色和細節項改為更連續的設定列。

## 主要更新

- Section 預設改為普通分區，並新增 `plain`、`card`、`subtle` 三種容器等級。
- 新增 SettingRow，用於字號、行高、尺寸、顏色、裁切和其他普通參數設定。
- ToggleRow 去除獨立卡片感，保留整列點擊、switch 語義、鍵盤焦點和無障礙狀態。
- 版面模式等橫向選擇控制保留原有分段呈現，確保可讀性。
- 字體方案和匯出區域不再額外添加最外層卡片邊框。
- 字體預設卡現在整張可點擊，不再要求點中小的套用按鈕。
- 網易雲搜尋提示按介面語言改為不同熱門歌曲示例。
- Stepper 頂部區域改為自動高度，並移除小字提示列。
- 切換語言後的儲存提示會使用新選擇的語言，自訂尺寸的自動高度預設開啟。

## 範圍說明

- 右側 Preview、匯出 DOM、歌詞卡渲染邏輯和狀態結構保持不變。
- 匯出 PNG 的視覺結果不因本次面板重構而改變。
- OptionCard 保留為視覺方案或預設選擇元件，不再用於普通標量設定。

## 驗證

- npm run typecheck
- npm run core:test
- npm run build
