# Lyrics Card Generator v5.8.5 Release Notes

Release date: 2026-07-22

v5.8.5 further streamlines step two of the six-step workspace. Desktop editing gains a more stable lyric canvas, Cleanup and Translation tools are reorganized around actual usage frequency, and the settings and examples surfaces receive a light finishing pass. Existing lyric-processing and export contracts remain unchanged.

## A more stable desktop lyrics workspace

- Desktop uses a fixed roughly 2:1 lyrics-to-tools split, with the tool column taking its allowed maximum width by default and leaving continuous reading and editing space for many short lyric lines.
- Desktop resizing, the collapsed tool rail, and their transitions are removed. Status and quick execution stay in the top command bar, while the sidebar handles scope, parameters, previews, and confirmations.
- Shared scrolling, cursor and selection anchors, undo, the AI panel, the narrow-screen drawer, keyboard access, and the 36-line export boundary are preserved.

## Clearer Cleanup and Translation tools

- The active scope is condensed into a compact context bar that shows the full source or translation column, or the selected line range, alongside Current column and Synchronized choices.
- Blank-line actions and Clean paste are emphasized under Common cleanup. LRC, line merging, and paragraph labels move into an expandable More cleanup area without removing any action.
- Translation opens with Enable translation and AI translation. Alternating split, Chinese formatting, and column swapping are unified under Column tools.
- Previews and confirmations expand inline beneath their operation. High-impact actions such as removing all blank lines, removing labels, and swapping columns still require explicit confirmation.

## Settings and visual finishing

- Each settings tab now opens with a short introduction that clarifies its purpose while leaving `SettingsStepper` behavior untouched.
- The bottom blur is removed from the lyric examples page for a cleaner content edge.
- Operation rows share a consistent visual and information hierarchy, with explanations only where needed and complete keyboard access on desktop and narrow screens.
