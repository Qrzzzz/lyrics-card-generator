# Lyrics Card Generator v0.1.0 发布说明

发布日期：2026-06-16

## 版本定位

这是 Lyrics Card Generator 的第一个 Windows 桌面版发布。它把原有的 Next.js WebUI 歌词卡片生成器封装为可直接运行的 Windows EXE 应用，用户不需要安装 Node.js，也不需要手动启动开发服务器或部署到云端。

桌面版采用 Electron + Next standalone 本地服务方案。应用启动后会自动在本机 `127.0.0.1` 启动内置 Next 服务，并在桌面窗口中加载本地地址。页面和 API routes 均在本地运行；Apple Music、网易云音乐、QQ 音乐、远程封面和 LRCLIB 只是数据来源，不是部署依赖。

## 下载与安装

- 安装版：`Lyrics.Card.Generator.Setup.0.1.0.exe`
- 便携版：`Lyrics.Card.Generator-0.1.0-portable.exe`

普通用户建议使用安装版；如果只是临时试用，或不想写入系统安装目录，可以使用便携版。

## 核心功能

- 支持 Apple Music、网易云音乐、QQ 音乐链接解析。
- 支持手动编辑歌曲名、歌手名、专辑名和封面链接。
- 支持手动输入和编辑歌词。
- 支持逐行编辑翻译，并可显示或隐藏译文。
- 支持无歌词或纯音乐内容展示。
- 支持远程封面、本地封面上传、封面代理和封面取色。
- 支持竖版 / 横版布局、尺寸、自动高度、字体、字号、行距、文字颜色、圆角、边框、阴影、平台 Logo、水印和分享者文字等样式控制。
- 支持中文和 English 界面切换，并保留语言设置。
- 支持通过原有 DOM-to-PNG 流程导出 PNG，默认高清 2x 输出。

## 桌面端体验

- 双击 EXE 即可启动。
- 窗口默认最大化打开。
- 应用图标已覆盖安装包、便携版、任务栏、窗口标题栏、Web favicon 和应用内标题区。
- 关闭窗口时会自动关闭内置本地服务，避免残留后台进程。
- 外部链接会交给系统浏览器打开。

## 离线与联网说明

离线可用：打开应用、手动输入歌曲信息、编辑歌词与翻译、使用本地封面、调整卡片样式、导出 PNG。

需要联网：Apple Music / 网易云音乐 / QQ 音乐链接解析、远程封面加载、LRCLIB 自动歌词获取。

## 初版限制

- 暂不支持自动更新。
- 当前 Windows 构建未进行代码签名，Windows 可能显示 SmartScreen 提示。
- 安装版和便携版均为 Windows x64 构建。
- 远程解析和歌词获取依赖第三方数据源的可用性。
