# Lyrics Card Generator v3.1.0 Release Notes

Release date: 2026-06-21

## Overview

v3.1.0 rebuilds the font scheme panel so CJK and Latin typography can be controlled independently, while continuing to improve Windows system-font reliability in previews and PNG exports.

## Fixes and Improvements

- Added clear Current, Preset, Custom, and Font Preview sections.
- Reduced presets to Source Han Sans and Source Han Serif; each preset uses the same family for CJK and Latin text.
- Custom schemes can select CJK and Latin families independently, with numbers and half-width punctuation preferring the Latin family.
- Replaced the inline system-font list with a dedicated picker containing recommendations, search, a complete scrollable list, and candidate previews.
- Added a lyric-based typography preview whose background uses the real card algorithm with fixed Deep Sea, Cobalt, Indigo, and Nightfall color inputs.
- Moved the full font preview below the real card in the right column and made it narrower, more generously spaced, and only as tall as its lyric content requires.
- Moved Font Schemes out of Layout into a dedicated workflow step and made navigation widths content-aware so short labels no longer force truncation elsewhere.
- Background generation remains preview-only and never changes lyric-card background parameters or exported PNGs.
- Added complete font-scheme copy, actions, the background-algorithm explanation, and the external preview footnote to all six UI languages.
- The current scheme is recognized as Source Han Sans, Source Han Serif, or Custom from its exact family combination.
- The preview DOM and PNG export use the same sanitized CJK / Latin `font-family` stack.
- Windows font enumeration splits combined names, removes duplicates, sorts results, and no longer generates invalid comma-containing family names.
- Localized Chinese display names now map to the real CSS family stored in each font file, including face weight and italic metadata.
- Removed the manual `font-family` field that allowed invalid input.
- Added a non-blocking warning when the browser may not recognize a selected font.
