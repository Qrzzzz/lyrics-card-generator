# Lyrics Card Generator v4.1.5 リリースノート

リリース日：2026-07-02

v4.1.5 は Stepper レイアウトの安定性修正です。メインページ左上のステップインジケーターについて、言語、フォント、ウィンドウ幅によって起きる高さと折り返しの問題を重点的に修正しました。この更新では、右側 Preview、エクスポート DOM、歌詞カードのレンダリングロジック、設定状態の構造は変更していません。

## 主な更新

- Stepper のステップ領域を、実際のコンテナ幅に基づく均衡 Grid レイアウトに変更しました。
- 6 つのステップは `6`、`3 + 3`、`2 + 2 + 2` に限定され、`5 + 1` のような不均衡な折り返しを避けます。
- Stepper 外側のガラスパネルは、タイトル領域とステップグリッドの実測高さから動的な `min-height` を計算します。
- ステップが 1 行に収まる場合はパネルを引き締め、2 行・3 行では安定した視覚下限を維持します。
- 狭いウィンドウや長い翻訳ラベルでは、ステップタイトルを 1 行省略表示にして横方向のはみ出しを防ぎます。
- フォントの読み込み完了、ウィンドウサイズ変更、言語切り替え、ステップタイトルの測定変化後にレイアウトを再測定します。

## 範囲

- 右側 Preview は変更していません。
- エクスポート DOM は変更していません。
- 歌詞カードのレンダリング結果は変更していません。
- 設定状態の構造は変更していません。

- npm run core:test
- npm run desktop:build
