# Lyrics Card Generator v5.5.3 Release Notes

Release date: 2026-07-14

v5.5.3 improves font selection, the desktop titlebar, Step 1 navigation, and Light Acrylic readability while preserving the existing editing and export behaviour.

## Main updates

- The Source Han Sans and Source Han Serif cards in Step 4 render the entire card with their matching bundled OTF font, including the scheme name, font name, description, and selected state.
- The 48px desktop titlebar now uses a lightweight gradual blur across a 144px top-anchored fade region; theme-aware tint gradients remain in dark, light, and both Acrylic modes.
- Manual adjustment moves immediately before Next in Step 1. The song-information panel no longer duplicates the button, and disclosure state, controlled region, and stable ID are fully connected.
- Light Acrylic raises the white masks for panels, inputs, buttons, and elevated surfaces, switches helper copy to opaque slate colours, and fixes segmented-control surfaces in light themes.

## Readability and compatibility

- A contrast matrix covers dark-gray, mid-gray, and light Windows backdrops: small text reaches at least 4.5:1, and important input and button boundaries reach at least 3:1.
- Acrylic transparency, blur, and visible material depth remain intact instead of turning the interface into a solid white theme.
- Dark Acrylic keeps its existing transparent panels, light text, and native window material.

- `npm run typecheck` / `npm run lint` / `npm run core:test` / `npm run build`
- `npm run desktop:pack` / `npm run desktop:interaction-test`
