# Lyrics Card Generator v6.1.4

> Estado: publicación oficial.

## Navegador de fuentes compartido con búsqueda

- La ventana nativa de fuentes de Windows ofrece ahora a los roles CJK y latino un único navegador de fuentes del sistema; basta con cambiar de rol para elegir la familia de cada posición.
- La búsqueda filtra de inmediato las fuentes instaladas. Cada fila muestra el nombre de la familia y una vista previa de glifos, junto con el recuento de resultados y un estado específico cuando no hay coincidencias.
- Se pueden intercambiar ambas fuentes, restaurar la combinación inicial y buscar o seleccionar con el teclado. Solo las selecciones confirmadas se aplican al esquema actual.

## Fiabilidad del puente nativo

- El script auxiliar WinForms completo se envía ahora a PowerShell por la entrada estándar, evitando que las interfaces complejas superen el límite de longitud de la línea de comandos de Windows.
- Se mantienen la propiedad modal de la ventana principal, el análisis acotado del resultado, la validación de entradas y la alternativa ante fallos. No cambian la alternativa de escritorio para otros sistemas, el selector del navegador ni las reglas de renderizado de las tarjetas.
