# Lyrics Card Generator v4.3.6 Release Notes

Release date: 2026-07-07

This release continues polishing the v4.3 example-song surface and its connection with the main editor. The in-app header now belongs to the main editor content instead of floating above it, while the examples surface keeps the reused bottom header as its return anchor. Example import behavior, translation linkage, and export-quality wording have also been tightened.

## Main Updates

- The main editor header now lives in the editor content flow instead of overlaying the stepper and preview areas.
- The examples surface still reuses the same header as the bottom return anchor, and the transition no longer shows a ghost copy while the header slides down.
- The examples surface removes the outer framed-shell feeling, and example cards no longer repeat a translation-language block at the bottom.
- The translation language is now shown once to the right of the Examples title, following the current interface language.
- Added an Import translation toggle, enabled by default. When enabled, loading an example writes the translation and also enables the main editor translation switch; when disabled, only song data and lyrics are imported.
- Simplified Chinese and Traditional Chinese cross-locale examples no longer import a translation by default, avoiding unnecessary automatic translation between the two Chinese UI modes.
- The bottom X return button on the examples surface now has orange-red hover feedback.
- Export quality labels are now Standard / High / Ultra, while the actual export ratios remain 1x / 1.4x / 2x.
