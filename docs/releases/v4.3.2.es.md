# Notas de la versión de Lyrics Card Generator v4.3.2

Fecha de publicación: 2026-07-06

Esta versión pule el área del título de la canción, mejora el distintivo Explicit y da a la portada vertical y a la información de la canción un centro visual más estable.

## Cambios principales

- El distintivo Explicit se reconstruyó como una única forma SVG, sin depender de un glifo `E` renderizado por una fuente.
- El distintivo Explicit ahora usa `currentColor` con opacidad exterior, y recorta una E geométrica mediante una máscara SVG para evitar que aparezca una letra negra sólida.
- Se ajustaron el tamaño, la posición vertical y la separación del distintivo respecto al título para alinearlo de forma más natural con el eje central del título.
- Se aumentó el tamaño de la portada en formato vertical y se ajustó proporcionalmente el radio de las esquinas.
- El bloque de información de la canción en formato vertical usa la misma altura mínima que la portada y se centra verticalmente, para que título, artista y álbum queden más cerca del eje de la portada.
- Se mantienen sin cambios los tamaños de fuente, alturas de línea y separación del header existentes para reducir el riesgo de regresiones de diseño.

## Verificación

- npm run typecheck
- npm run core:test
- npm run build
- Se cargó el ejemplo `opposite` en el navegador y se exportó PNG para confirmar que el distintivo Explicit y la alineación del header vertical coinciden entre la vista previa y la exportación.
