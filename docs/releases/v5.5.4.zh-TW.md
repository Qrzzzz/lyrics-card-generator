# Lyrics Card Generator v5.5.4 發行說明

發行日期：2026-07-15

v5.5.4 加強本機應用程式的變更請求邊界，統一整理六種語言的介面文字，並沿用穩定的共用發行工作流程。既有編輯、匯入、翻譯、匯出與桌面操作維持不變。

## 請求邊界

- 本機應用程式的 POST 路由統一檢查同來源、應用程式請求標記與預期內容格式。
- 不符合邊界條件的 AI 請求會在連線至上游服務前停止；合法的同來源 JSON 請求維持原有行為。
- 自訂 AI Base URL 仍支援 `http://127.0.0.1`、`localhost` 與 IPv6 loopback 服務；模型、API Key、串流回應、取消、Reasoning 與錯誤處理語意皆未變更。

## 六種語言文字

- 簡體中文、繁體中文、English、Français、日本語與 Español 的主畫面、設定、AI、錯誤提示及匯入/匯出文字已統一整理。
- 法文、日文與西班牙文設定項目不再直接沿用英文；繁體中文的重要流程改用台灣常用說法。
- Web Lite 現在支援全部六種語言，並接入語言選擇、瀏覽器偵測與本機偏好儲存。
- 固定浮水印、AI 即時狀態、即時儲存設定的關閉操作、更新提示，以及 API / 桌面錯誤均改用在地化文字或穩定錯誤碼對應。

## 發行與驗證

- CI 與發行繼續使用統一的 `.github/workflows/release.yml`，不再建立版本專用工作流程。
- 驗證涵蓋 Web Lite 建置與漂移檢查、型別與程式碼檢查、穩定性與涵蓋率、核心回歸、桌面建置與互動、最終成品 smoke，以及請求邊界與六語言完整性測試。
