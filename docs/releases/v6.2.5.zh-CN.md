# Lyrics Card Generator v6.2.5

> 状态：已发布。

## 轻量项目署名

- 导出卡片中的 `generated by lyric card generator` 已替换为更短的 `Qrzzzz/lyrics-card-generator`，不再使用描述性前缀。
- 署名取消两侧分隔线，改为 400 字重、26px 竖版基准字号、30px 横版缩放基准和 0.02em 字距的单行标准字宽无衬线文字。
- `Qrzzzz` 与 `/lyrics-card-generator` 保持连续显示，仅通过 72% 与 52% 的克制透明度差异建立识别层级，并避免缩放后变得模糊难读。

## 页脚与设置

- 竖版页脚中署名与平台标识／分享者信息的间距收敛至 14px；横版沿用原有 accessories 渲染链路并采用等比例的 16px 间距，同时移除布局步骤中冗余的自动延长说明。
- 编辑器中的“显示生成水印”改为“显示项目署名”，应用设置中的新卡片默认项也使用相同语义。
- 现有 `showGeneratedWatermark` 等文档和配置字段保持不变，不需要迁移设置或历史文档。

## 下载与升级

- Windows x64 安装版：`Lyrics.Card.Generator.Setup.6.2.5.exe`。
- 本版本继续采用 Setup-only 发布方式；从旧版本升级无需迁移配置。
