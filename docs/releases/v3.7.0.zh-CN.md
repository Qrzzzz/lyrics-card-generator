# Lyrics Card Generator v3.7.0 发布说明

发布日期：2026-06-29

v3.7.0 是一次维护与稳定性版本，不引入新的布局、主题、音乐平台或导出行为。此次更新聚焦于桌面背景图片路径安全、AI 翻译错误兜底、更新入口一致性、旧代码清理与发布校验稳定性。

## 修复

- 强化桌面背景图片 `imageId` 校验，仅接受应用生成的 `png`、`jpg`、`jpeg`、`webp`、`gif` 文件名，并拒绝路径穿越或伪造值。
- 读取背景图片时改用显式 MIME 映射，不再接受 SVG 或未知扩展名。
- 改进 AI 翻译对非标准厂商响应、纯文本错误、损坏 JSON 和空响应的兜底处理，避免异常响应导致应用崩溃。
- “打开发布页面”按钮现在始终打开 GitHub Release 页面，不再跳转到安装包直链。

## 维护

- 移除未使用的旧版 `CustomFontPanel` 代码，同时保留当前 `FontSchemePanel` 行为不变。
- 清理已移除纯音乐输入框的残留 i18n 文案，同时保留 `instrumentalText` 数据兼容与卡片视觉结果。
- 将 `v3.6.1` 专用发布测试拆分为通用发布一致性测试与标题栏回归测试。
- 新增最小 CI 工作流，用于运行安装、类型检查、核心测试与 Web 构建。

## 验证

- npm run core:test
- npm run build
- npm run desktop:dev
- npm run desktop:build
