# Lyrics Card Generator v3.9.1 发布说明

发布日期：2026-07-01

v3.9.1 修复桌面端窗口圆角，并刷新自绘标题栏布局。非 Acrylic 主题改用 Windows 原生圆角裁剪，桌面背景、标题栏渐变和噪声层仍限制在应用外壳内绘制，导出的歌词卡片 PNG 不受影响。

## 桌面窗口圆角

- 非 Acrylic 主题不再依赖透明 CSS 外壳伪装圆角，改由原生 Windows 窗口边界裁剪。
- Acrylic 主题继续使用 Windows 原生 Acrylic 材质，同时保持透明窗口背景。
- 应用背景层从固定定位改为外壳内绝对定位，使图片背景、动态专辑背景和纯色背景都受圆角裁剪。

## 标题栏

- 自绘标题栏改为左侧红、黄、绿窗口控制按钮，分别用于关闭、最小化和最大化/还原。
- 软件名与版本号保留在左侧控制按钮之后，右侧不再显示小应用图标。
- 标题栏仍支持拖动窗口，控制按钮区域保持不可拖动，点击行为更稳定。

## 导出与 Web 版

- Web 浏览器运行时仍不显示桌面标题栏，也不会保留桌面端顶部空白。
- 导出 PNG 路径不包含桌面标题栏、窗口边框、窗口外壳或 Electron 桌面 API。

## 验证

- npm run typecheck
- npm run core:test
