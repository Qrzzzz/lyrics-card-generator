# Notes de version de Lyrics Card Generator v3.4.0

Date de publication : 2026-06-28

v3.4.0 réorganise l'étape Mise en page autour du type de contenu et transforme la grille d'arrière-plan en option configurable dans les détails visuels.

## Changements

- L'étape Mise en page demande maintenant le type de contenu avant d'afficher les options de mise en page, de taille et de typographie disponibles.
- Les cartes instrumentales / sans paroles sont désormais verrouillées en sortie verticale 1:1 afin de stabiliser la pochette et les informations du morceau.
- Suppression du champ de description instrumentale inutilisé dans l'étape Mise en page.
- La grille d'arrière-plan est maintenant désactivée par défaut et disponible dans les détails visuels avec trois densités : Espacée / Moyenne / Dense.

## Corrections

- Correction d'un problème où le mode instrumental / sans paroles pouvait encore sélectionner des cartes horizontales.
- Correction d'un problème où le mode instrumental / sans paroles pouvait utiliser des tailles de canevas non carrées incompatibles.
- Correction de la grille d'arrière-plan trop dense de la version précédente.

## Validation

- Vérification du passage immédiat du mode instrumental / sans paroles en vertical 1:1.
- Vérification du bouton horizontal grisé et désactivé en mode instrumental / sans paroles.
- Vérification de la grille d'arrière-plan désactivée par défaut, puis des trois niveaux de densité après activation.
- Exécution de `npm run typecheck`, `npm run core:test` et `npm run build`.
