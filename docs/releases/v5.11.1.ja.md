# Lyrics Card Generator v5.11.1

> ステータス：GitHub Releases で一般公開済みです。

## 書き出しの正確性を修正

- 縦向きカードの区切りのない共有者テキストが任意の文字で折り返され、コンテンツ、フッター、付属要素全体のはみ出し検査に含まれるようになりました。テキストが気付かないまま切れる状態で書き出しが許可されることはありません。
- PNG、WebP、JPG で、要求したピクセル数と実際のキャンバスのピクセル数を共通して厳密に確認します。高品質の長いカードがブラウザーの一辺 16384 ピクセル制限を超える場合は、画像をひそかに縮小して成功扱いにせず、品質を下げるか内容を短くするよう明示して書き出しを止めます。
- デスクトップ版と Web Lite は同じコンテンツ形状・ピクセル寸法チェックを共有します。通常サイズの縦向き／横向きカードと既存の自動高さ処理は変わりません。
