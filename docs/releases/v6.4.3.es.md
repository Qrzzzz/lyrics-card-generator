# Lyrics Card Generator v6.4.3

Windows x64: `Lyrics.Card.Generator.Setup.6.4.3.exe`.

## Avisos importantes y fiabilidad de los borradores

- Añade notificaciones interactivas en la esquina superior derecha para borradores restaurados, errores de guardado automático o de ajustes y recuperación del historial, con acciones para cerrar, ver el historial y reintentar.
- Muestra la restauración solo cuando al iniciar se recupera realmente un borrador con contenido, distinguiendo las ediciones guardadas de una imagen que aún no se ha exportado.
- Corrige la validación de borradores con Smiley Sans, que podía impedir cerrar la aplicación después de fallar el guardado.
- Unifica títulos, descripciones y alturas de fila de las tarjetas de fuentes, manteniendo la fuente de cada preajuste solo en la muestra de su nombre.
