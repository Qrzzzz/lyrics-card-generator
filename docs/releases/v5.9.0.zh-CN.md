# Lyrics Card Generator v5.9.0 发布说明

发布日期：2026-07-31

v5.9.0 为 Windows 桌面版新增“导入/解析历史”，用于重新导入已经成功解析或保存过的歌曲与封面。它不是歌词自动保存，也不是文档版本历史。

## 桌面端导入/解析历史

- 顶部操作区新增“历史记录”，位于“歌词示例”和“清空内容”之间；全屏历史页支持搜索、来源筛选、分批加载、单条删除和清空全部历史。
- 仅记录真正提交成功的链接解析、歌曲搜索选择、本地 MP3／FLAC 解析，以及上传本地封面后保存的操作。失败、取消、内置示例、普通编辑、清空和导出均不记录。
- 历史卡片显示歌曲、来源、导入时间及文件名或域名。重新导入仍沿用文档替换确认；远程失败或本地文件缺失时，当前文档保持不变。
- 本地文件移动后可“重新定位”；文件大小或修改时间变化时会提示，并按当前文件重新解析。

## 安全存储与保留上限

- 历史由 Electron 主进程以带 schema 版本的 UTF-8 JSON 串行、原子写入。损坏文件会保留带时间戳的备份，再建立空历史。
- 记录只保存重放所需的最小来源和展示文字，不保存图片二进制、Base64、blob URL、导出图片、色板或样式。远程封面仅保存 URL。
- 渲染进程重新导入时只提交记录 ID；本地路径由主进程保存、验证和读取，并通过 Electron 42 的 `webUtils.getPathForFile` 安全登记。
- 相同平台歌曲、规范化链接或本地路径会更新原记录并移到最前。设置 → 通用可选择最多保留 5 条、10 条（默认）或无限；调小上限会先确认再按最近使用顺序裁剪。

## 范围与验证

- 新增界面文案覆盖简体中文、繁體中文、English、Français、日本語和 Español。
- Web Lite 保持原有界面和行为，不提供浏览器端历史替代实现。
- 纯历史存储、安全 IPC、设置迁移、打包清单及真实 Electron 交互回归覆盖持久化、去重、裁剪、重放、文件变化／缺失／重新定位和写入失败语义。
