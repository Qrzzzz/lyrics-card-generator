# Lyrics Card Generator v6.9.0

**2026-10-28**

SaltUI を参考にボタンとスイッチを改善し、入力欄とスライダーは従来のスタイルを維持します。

- カプセル形ボタンで主要、通常、危険、背景なし、アイコンの各操作を区別し、アルバムやカスタムの強調色でも文字の可読性を保ちます。
- スイッチは円環と縦棒で状態を示し、システムとアプリのモーション低減設定に従います。
- 入力欄とスライダーを従来の外観と操作に戻し、設定グループの角丸と間隔を統一します。
- 「このアプリについて」と6言語の README に SaltUI と Moriafly の謝辞を追加し、Apache-2.0 ライセンスと帰属表示をオフラインで参照できるよう同梱します。
