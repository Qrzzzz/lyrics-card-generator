# Lyrics Card Generator v5.9.2 發佈說明

發佈日期：2026-08-06

v5.9.2 修正 Windows 桌面版從歷史記錄載入手動存檔後，已儲存的專輯封面不會恢復的問題。

## 歷史載入與封面恢復

- 載入手動存檔時會恢復存檔中經過安全清理的遠端封面 URL，並交由既有圖片代理與封面取色流程處理。
- 不會重新解析歌曲連結，也不會覆寫存檔中的標題、歌手、專輯、歌詞或翻譯；原有的存檔綁定與後續原位更新語義維持不變。
- 沒有封面 URL 的舊存檔仍以無封面狀態載入；本機封面繼續使用既有檔案歷史與重新定位流程。

## 安全邊界與驗證

- 遠端封面仍只透過應用程式內的圖片代理載入，不直接請求外部封面地址；圖片二進位、Base64、blob URL、本機路徑與敏感查詢參數不會寫入手動存檔。
- 回歸測試確認封面能夠顯示與取色，同時不會觸發歌曲連結、搜尋結果或本機音訊的重複解析。
- Web Lite 的介面與行為維持不變。
