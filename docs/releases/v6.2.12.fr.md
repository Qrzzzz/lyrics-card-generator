# Lyrics Card Generator v6.2.12

## Installation simplifiée

- Une fenêtre minimale avec icône, version et bouton Installer ; langue en haut à droite.
- Un volet dans la même fenêtre regroupe le dossier, la portée et le raccourci de bureau.
- Le thème clair ou sombre suit le système. Cette disposition reste celle des prochaines versions.
- Le mécanisme NSIS reste utilisé pour installer, mettre à niveau et désinstaller, avec six langues.

- Windows x64: `Lyrics.Card.Generator.Setup.6.2.12.exe`.
