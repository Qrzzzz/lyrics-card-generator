# Lyrics Card Generator v4.2.3 發布說明

發布日期：2026-07-03

v4.2.3 重構軟體介面本身的外觀系統，把原本分散在「外觀」「背景」「主題色」「文字顏色」裡的設定收斂為一個清楚的介面外觀模式。此版本不改變歌詞卡匯出樣式，不新增背景圖片玩法，也不擴充使用者手選主題色能力。

## 主要更新

- 設定面板移除獨立「背景」頁，入口收斂為「一般 / 外觀 / 匯出 / AI / 關於」。
- 「外觀」頁只保留「介面外觀」與「介面字型」兩個使用者可見設定。
- 介面外觀固定為五種模式：專輯封面動態取色、深色模式、淺色模式、深色壓克力、淺色壓克力。
- 「專輯封面動態取色」繼續作為預設模式，並繼續使用封面 palette 驅動介面氛圍與強調色。
- 深色模式改為穩定的近黑背景，淺色模式改為穩定的白色背景，不再保留藍白或黑粉預設風格。
- 深色壓克力與淺色壓克力繼續使用 Electron 的 Windows Acrylic 視窗材質鏈路。

## 相容與遷移

- 舊的 `light-blue` 設定會遷移為 `light`。
- 舊的 `dark-pink` 設定會遷移為 `dark`。
- 舊的 `custom` 設定會遷移為 `album-dynamic`。
- 舊背景欄位仍保留在內部設定結構中，但介面背景現在由 `uiTheme` 直接決定。
- 手選介面主色、手選文字顏色與背景圖片模式不再出現在設定 UI 中。

## 範圍說明

- 不改變歌詞卡預覽或匯出 PNG 的視覺樣式。
- 不新增背景圖片功能。
- 不新增自訂主題色功能。
- `BackgroundSettingsSection` 暫時保留為內部相容檔案，但不再掛載到設定面板。

## 驗證

- npm run typecheck
- npm run core:test
- npm run build
