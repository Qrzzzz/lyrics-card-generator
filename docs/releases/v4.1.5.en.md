# Lyrics Card Generator v4.1.5 Release Notes

Release date: 2026-07-02

v4.1.5 is a Stepper layout stability fix. It focuses on the height and wrapping behavior of the top-left step indicator on the main page across languages, fonts, and window widths. This update does not change the right-side Preview, export DOM, lyric-card rendering logic, or settings state shape.

## Main Updates

- The Stepper step area now uses a balanced Grid layout based on the real container width.
- Six steps are constrained to `6`, `3 + 3`, or `2 + 2 + 2`, avoiding uneven `5 + 1` wrapping.
- The outer Stepper glass panel now calculates dynamic `min-height` from the real title and step-grid heights.
- The panel tightens when the steps fit on one row while preserving stable visual limits for two and three rows.
- In narrow windows or with long translated labels, step titles use single-line truncation as a fallback to prevent horizontal overflow.
- Layout is remeasured after fonts load, window size changes, language changes, and step-title measurements change.

## Scope

- The right-side Preview is unchanged.
- The export DOM is unchanged.
- Lyric-card rendering output is unchanged.
- The settings state structure is unchanged.
