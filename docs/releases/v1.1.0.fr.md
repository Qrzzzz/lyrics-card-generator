Il s'agit d'une mise à jour de maintenance axée sur l'allègement et la réorganisation du projet.

Cette version nettoie une grande quantité de code hérité et inutilisé, divise la logique de l'éditeur auparavant trop volumineuse, et réorganise le processus de build et d'empaquetage de la version de bureau Windows. Pour les utilisateurs ordinaires, les fonctionnalités principales restent inchangées ; pour le développement futur, la structure du projet est plus claire et les coûts de maintenance sont réduits.

## Principaux changements

* Nettoyage du code inutilisé et de la logique redondante, réduisant la charge du projet.
* Refonte de la structure de l'éditeur, en divisant certaines parties de l'interface et de la logique en composants indépendants.
* Préservation de l'algorithme de mise en page original des cartes pour éviter que le nettoyage du code n'affecte le rendu des cartes de paroles.
* Correction du panneau d'exportation et des contrôles d'exportation PNG dans la version de bureau.
* Correction du problème d'empaquetage des polices dans la version de bureau, garantissant le chargement correct des polices intégrées.
* Réorganisation du processus de build pour Windows.
* Mise à jour du numéro de version, des noms de fichiers de téléchargement et des informations de version associées vers `1.1.0`.

## Téléchargements

* Installateur : `Lyrics Card Generator Setup 1.1.0.exe`
* Portable : `Lyrics Card Generator-1.1.0-portable.exe`

## Remarque

Cette version n'est toujours pas signée numériquement. Windows peut afficher une alerte SmartScreen, un phénomène courant pour les applications personnelles non signées.
