# Lyrics Card Generator v5.5.2 Release Notes

Release date: 2026-07-14

v5.5.2 clarifies the first two desktop workflow steps by giving each song-import method a clearer place and flattening excessive frames in the long-lyrics workspace.

## Highlights

- Step 1 keeps NetEase search across the top of the left column. Song-link and local-audio import move below it and sit side by side when space allows.
- The right column independently presents album art, title, artist, and album metadata, while retaining the expandable manual editor.
- Step 1 no longer renders an unusable Back button. Back and Next behavior on later steps remains unchanged.
- Step 2 removes the outer lyrics-workspace frame and the individual frames around the summary, document, and editing-tools columns.
- Wide layouts keep only a one-pixel vertical divider between neighbouring columns; stacked narrow layouts switch to one-pixel horizontal dividers.

## Scope

- Search, link parsing, local-audio parsing, manual metadata, lyrics editing, and export behavior remain unchanged.
- Inputs, status messages, lyric statistics, and dynamic tool panels retain the local boundaries needed for clarity.
- The shared desktop and Web Lite step navigation consistently hides the invalid first-step Back action.

## Validation

- `npm run typecheck` / `npm run lint` / `npm run core:test` / `npm run build`
- `npm run web-lite:build` / `npm run web-lite:check` / `npm run web-lite:smoke`
- `npm run desktop:build` / `npm run desktop:interaction-test`
