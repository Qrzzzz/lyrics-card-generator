# Lyrics Card Generator v6.9.1

**2026-10-28**

Fixes button density, settings-row layout and long labels after the SaltUI control update.

- Capsule buttons respect compact sizing and caller-supplied padding, leaving room for adjacent controls.
- The interface font input and reset action share a row when space permits; narrow panels wrap naturally while preserving labels and descriptions.
- Preference actions sit beside their descriptions on wide panels, and long action labels wrap without truncation.
- Named choice controls wrap to the actual panel width to avoid overflow with enlarged text.
- Adds layout regressions across six languages, narrow panels and enlarged text while retaining the 6.9.0 button and switch styling.
- Improves the contrast of descriptions in selected option cards.
