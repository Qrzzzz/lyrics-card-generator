# Lyrics Card Generator v6.8.8

**2026-10-27**

歌詞編集、書き出し、保存済み設定を維持しながら、デスクトップ回帰テストとリリース処理を改善します。

- PR/main で一度だけビルドし、編集、ワークスペース、データ、ネイティブ機能の4グループが独立して検証します。長い設定シナリオを分割し、既存の動作アサーションを維持します。
- ビルド前に固定された Electron ランタイムの脆弱性情報を確認し、最終インストーラーの最新のセキュリティ監査も継続します。
- 最終 main コミットと完全に一致するランタイムを、来歴署名、ツールチェーン、リソースのハッシュを検証したうえで再利用できます。成果物がない場合や期限切れの場合は完全に再ビルドし、識別情報が一致しない場合は停止します。
- リリース候補のアーカイブ、中断からの再開、状態確認の間隔を改善し、重複した待機と再実行を減らします。

5つの必須 CI チェック、最終 Setup のインストールと更新テスト、SBOM、チェックサム、来歴証明、公開添付ファイルの検証を維持します。既存の動きの既定値とウィンドウ対応範囲は変更しません。一定のリリース所要時間を保証するものではありません。
