# Lyrics Card Generator v6.5.2 Release Notes

Release date: 2026-09-18

v6.5.2 fixes AI translations being treated as successful after the provider reports an error, with consistent failure messages and restoration of the previous translation.

## Fixes

- If the AI service reports an error during output or the stream ends abnormally, translation fails and the previous translation is restored. Receiving complete text no longer turns a failed response into a successful result.
- Services that explicitly report normal completion but omit the stream end marker remain supported. Normal translations still complete; after cancellation, switching documents or starting a new translation, older requests cannot overwrite the current content.
