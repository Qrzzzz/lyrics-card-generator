# Lyrics Card Generator v6.2.2

> Statut : publiée.

## Distribution Windows limitée à Setup

- À partir de la v6.2.2, le seul téléchargement Windows est l’installateur x64 `Lyrics.Card.Generator.Setup.6.2.2.exe` ; les paquets autonomes ne sont plus construits ni publiés.
- Les versions v6.2.1 et antérieures ouvrent toujours la dernière GitHub Release depuis la recherche de mise à jour ; les utilisateurs d’un ancien paquet autonome peuvent y télécharger Setup.
- La Release contient exactement trois fichiers : Setup, le SBOM SPDX et `SHA256SUMS`. Le workflow produit une provenance pour chacun.

## Correctifs IA, limites de requête et persistance

- Les URL de services IA hors boucle locale exigent HTTPS, tandis que HTTP en boucle locale reste disponible pour les modèles locaux. Les mutations lient le contrôle d’origine à un hôte externe de confiance. (#143, #145)
- Les corps de requête, réponses amont, flux JSON/SSE IA, métadonnées distantes et annulations disposent de limites explicites de taille, de délai et d’arrêt. (#146)
- Les réglages IA sont enregistrés atomiquement contre les troncatures, et les sauvegardes simultanées de langue et de préférences conservent les derniers réglages. (#147, #148)
- Les images du presse-papiers Electron sont contrôlées selon leur surface décodée et leur budget mémoire avant l’allocation native. (#149)

## Contrôles de publication et de chaîne logicielle

- Une version doit descendre de `main` après revue et son commit exact doit réussir toute la CI requise ; l’autorisation est répétée avant modification et publication. (#144)
- L’ancienne exception Sharp pour Next 15.5.24 est supprimée, et Electron embarqué est couvert par un audit dédié et le SBOM SPDX. (#150, #151)
- La recherche des Releases parcourt toutes les pages et échoue de façon sûre en cas de conflit, y compris au-delà de 100 Releases. (#152)

## Validation

- Les tests Windows installent désormais leurs observateurs avant les mises à jour contrôlées et attendent que la relocalisation d’historique soit réellement prête, sans affaiblir leurs assertions.
- Le typage, lint, les suites de stabilité et principales, Web Lite, les politiques de dépendances et SBOM, les régressions empaquetées et le smoke Setup installation/lancement/fermeture/désinstallation bloquent la publication.
