# Lyrics Card Generator v2.0.0 リリースノート

リリース日：2026-06-18

v2.0.0 は、デスクトップ版とカード生成体験を中心に改善したリリースです。横長レイアウト、カスタムサイズの高さ計算、ローカル音声解析、Windows システムフォント、PNG エクスポート、更新確認、Windows ビルドファイルを扱います。

## 主な更新

- 横長カードを再設計し、カバー、歌詞、楽曲情報、下部情報を安全領域で扱うようにしました。
- 縦長カスタムサイズは実際の DOM 測定に基づいて高さを再計算します。
- 多言語歌詞の分割と中国語翻訳テキストの整理機能を追加しました。
- ローカル MP3 / FLAC 解析に対応し、利用可能な場合はタイトル、アーティスト、アルバム、カバー、埋め込み歌詞を読み取れます。
- デスクトップ版で Windows システムフォント選択と安全な外部リンク起動に対応しました。
- 更新確認はローカル Next API ルート経由で GitHub Releases を取得します。

## リリースファイル

- `Lyrics Card Generator Setup 2.0.0.exe`
- `Lyrics Card Generator-2.0.0-portable.exe`
- `Lyrics Card Generator Setup 2.0.0.exe.blockmap`

## 検証結果

`npm run core:test`、`npm run typecheck`、`npm run build`、`npm run desktop:build` に合格しました。

## 注意事項

現在の Windows ビルドは未署名です。Windows で SmartScreen 警告が表示される場合があります。
