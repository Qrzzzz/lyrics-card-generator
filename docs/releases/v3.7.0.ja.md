# Lyrics Card Generator v3.7.0 リリースノート

リリース日：2026-06-29

v3.7.0 はメンテナンスと安定化のためのリリースです。新しいレイアウト、テーマ、音楽プラットフォーム、エクスポート動作は追加していません。今回の更新は、デスクトップ背景画像のパス安全性、AI 翻訳のエラー処理、更新入口の一貫性、古いコードの整理、リリース確認の安定化に集中しています。

## 修正

- デスクトップ背景画像の `imageId` 検証を強化し、アプリが生成した `png`、`jpg`、`jpeg`、`webp`、`gif` ファイル名のみを受け付け、パストラバーサルや偽装値を拒否します。
- 背景画像の読み込みは明示的な MIME マップを使うようになり、SVG や未知の拡張子を受け付けません。
- 非標準プロバイダー応答、プレーンテキストエラー、不正な JSON、空レスポンスに対する AI 翻訳のフォールバックを改善し、異常応答でアプリが落ちないようにしました。
- 「リリースページを開く」ボタンは、インストーラー直リンクではなく対応する GitHub Release ページを常に開きます。

## メンテナンス

- 未使用の旧 `CustomFontPanel` コードを削除し、現在の `FontSchemePanel` の挙動はそのまま維持しました。
- 削除済みのインストゥルメンタル入力欄に関する古い i18n 文言を整理しつつ、`instrumentalText` の互換性とカード表示は維持しました。
- `v3.6.1` 専用だったリリース確認を、汎用のリリース整合性テストとタイトルバー回帰テストに置き換えました。
- インストール、型チェック、コアテスト、Web ビルドを実行する最小 CI ワークフローを追加しました。

## 検証

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:dev
- npm run desktop:build
