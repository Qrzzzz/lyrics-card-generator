# Lyrics Card Generator v6.10.3

修复浅色封面被压暗的问题，统一原文与译文栏头，并精简仓库根目录。

## 改进

- 浅色封面保留接近原图的明度与颜色占比，小面积淡紫色等点缀不再挤占主体背景；自动文字颜色依据实际渐变选择黑字或白字，保留手动配色。
- 原文与译文采用统一的编辑面板和轻量栏头，当前栏以短线与小标记提示；保留点击题头聚焦和共享滚动吸顶，滚动文字不会透到题头后面。
- 五份翻译 README、四套 Playwright 配置与两份专项 TypeScript 配置集中归档，根目录文件从 26 个减少到 15 个；导航、图片、发布说明和测试入口同步调整，增量缓存移入输出目录。

## 验证范围

- 本地通过取色、色场、正文对比度、布局回归，以及 `npm run typecheck`、`npm run lint`、`npm run build`、`npm run readme:media:check` 和 `npm run web-lite:check`。
- 本机 Chromium 验证浅深色栏头、点击聚焦、共享滚动与选区恢复，以及浅色封面的横竖版 PNG 导出；桌面界面场景使用桌面桥夹具，不代表原生安装包验收。
- 完整回归与最终安装、更新、附件及来源验证由本次 CI 和 Release 工作流执行。应用仍未代码签名；外部收藏的旧翻译 README 文件路径需更新。
