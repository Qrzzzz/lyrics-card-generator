# Lyrics Card Generator v5.11.1

> 状态：已通过 GitHub Releases 公开发布。

## 导出正确性修复

- 竖版中的连续分享者文本现在可以在任意字符处换行，并参与完整内容区、页脚和附件的导出溢出检查，不再出现界面允许导出但成品静默裁切文本的情况。
- PNG、WebP 与 JPG 现在统一核对请求像素和实际画布像素。高质量超长卡片超过浏览器单边 16384 像素限制时会明确阻止导出，提示降低质量或缩短内容，不再暗中缩小图片后报告成功。
- 桌面版与 Web Lite 共用相同的内容几何和像素尺寸门禁；正常尺寸的横版、竖版及现有自动高度算法保持不变。
