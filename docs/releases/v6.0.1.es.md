# Lyrics Card Generator v6.0.1

> Estado: publicación pública mediante GitHub Releases.

## Cuadros de diálogo nativos de Electron

- La aplicación de escritorio para Windows presenta ahora seis avisos como cuadros de diálogo nativos de Electron: reemplazo de canción, sobrescritura de traducción, borrado o reducción del historial, fallo al comprobar el historial y fallo al guardar durante el cierre.
- Las confirmaciones usan el icono de advertencia del sistema y los fallos su icono de error, sin recursos gráficos adicionales.
- Los títulos, detalles y botones son totalmente compatibles con chino simplificado y tradicional, inglés, francés, japonés y español.

## Seguridad y compatibilidad

- Las acciones destructivas seleccionan Cancelar de forma predeterminada; cerrar el cuadro o pulsar Escape también cancela la operación.
- Las entradas se validan en el renderizador, preload y proceso principal, y solo campos primitivos acotados atraviesan contextBridge.
- Web Lite y los navegadores normales conservan una alternativa compatible sin cambios funcionales.
