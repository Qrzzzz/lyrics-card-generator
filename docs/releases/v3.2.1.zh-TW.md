# Lyrics Card Generator v3.2.1 發布說明

發布日期：2026-06-23

v3.2.1 繼續作為 v3.2.0 的錯誤修復版本，不另行升級版本號。

## 穩定性修復

- 修復藍白淺色主題及自訂背景下的文字與狀態提示可讀性。
- 放大 Header 應用程式圖示，並恢復「一鍵清空」入口；清空歌曲內容時保留軟體設定。
- 背景圖片選擇入口現在會一直顯示，選擇後自動切換至圖片填滿模式並立即預覽。
- 修復背景設定儲存、取消與重設的交易邏輯，避免取消操作誤刪原背景。
- 修復反覆切換背景時的物件 URL 洩漏，並補齊自訂主題 token。
- 補齊六種語言的相關狀態文字與發布說明。
- 修復桌面版重新啟動後反覆要求選擇語言的問題；首次選擇會持久儲存，之後直接進入空白編輯器。
- Spark Cursor 開關改為橫向填滿設定卡片，與自動高度開關保持一致。
- 在「視覺細節」中新增預設開啟的細網格背景開關，並同步控制預覽與實際匯出的 PNG。

驗證：`npm run typecheck`、`npm run core:test`、`npm run build`、`npm run desktop:build`。
