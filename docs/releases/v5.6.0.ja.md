# Lyrics Card Generator v5.6.0 リリースノート

リリース日：2026 年 7 月 15 日

v5.6.0 では「歌詞サンプル」の外枠を作り直し、ウィンドウ端のグラデーションを修正し、「手動調整」を保存とキャンセルを明示した双方向スライドの下書き編集へ更新しました。サンプルカード自体と、その他の編集、取り込み、書き出し機能は変更していません。

## 歌詞サンプルの外枠

- 「歌詞サンプル」は設定画面と同じ形式の上部ヘッダーを使用し、閉じるボタンを右上に配置しました。
- 下部にあった大きな「Lyrics Card Generator」タイトル枠と閉じる入口を削除し、サンプル部分は専用のスクロール領域になりました。
- サンプルカードの内容、表示、選択、取り込み動作は変更していません。

## ウィンドウ端のグラデーション

- タイトルバー端の単一グラデーションに重複して適用されていたマスクを修正し、ぼかしとベールが早く消えすぎないようにしました。
- ぼかしレイヤーとテーマのベールは、ダーク、ライト、アクリルの各外観で 1 つの完全なフェード範囲を共有します。
- 「歌詞サンプル」の下端には同じ効果を反転して再利用し、スクロール内容からウィンドウ境界まで自然につなげます。

## 手動調整

- 「手動調整」を開くと、既存の曲情報概要が左へスライドしながらフェードアウトし、編集画面が右からスライドしながら表示されます。
- 変更内容は独立した下書きとして保持されます。「保存」は下書きを反映し、「キャンセル」は編集中の曲情報を直接上書きせずに破棄します。
- どちらの操作でも編集画面は逆向きのアニメーションで退出し、曲情報概要が左から戻ります。

## 開発サイクルの注記

- GitHub Actions では現在、SHA を固定した一部の action が Node.js 20 を対象としており、runner によって Node.js 24 で強制実行されるという警告が表示されます。
- この項目は 5.6.0 開発サイクル内で別途評価します。今回の UI 更新では workflow や固定 SHA を変更しておらず、警告が解決済みであるとはしていません。
