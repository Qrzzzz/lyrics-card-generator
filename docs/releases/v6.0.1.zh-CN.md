# Lyrics Card Generator v6.0.1

> 状态：已通过 GitHub Releases 公开发布。

## Electron 原生系统弹窗

- Windows 桌面版将替换歌曲、覆盖译文、清空历史、裁剪历史、历史核对失败和关闭时保存失败这 6 处提示统一为 Electron 原生系统弹窗。
- 确认操作使用系统警告图标，失败提示使用系统错误图标，无需额外打包图标资源。
- 弹窗标题、正文和按钮完整支持简体中文、繁體中文、English、Français、日本語与 Español。

## 安全与兼容性

- 替换、覆盖和删除等危险操作默认聚焦“取消”；关闭弹窗或按 Esc 同样不会继续执行。
- 渲染层、preload 与主进程都会校验弹窗参数，跨 contextBridge 只传递受限的基础字段。
- Web Lite 和普通浏览器环境继续使用兼容回退，不改变现有网页端功能。
