# Lyrics Card Generator v4.3.4 發布說明

發布日期：2026-07-06

本版本將「歌詞範例」從彈窗改為主介面上方的空間層。開啟範例時，編輯器整體退到下方，應用程式內標題列滑到底部作為返回錨點，範例卡片改為依主視窗寬度自動排列的響應式網格。

## 主要更新

- 將原本的 ExamplesDialog 彈窗改為 ExamplesFloor 上方空間層，不再使用遮罩、Modal 或 Portal。
- 點擊標題列的「範例」後，範例層從上方進入，主編輯介面向下退場，標題列滑到底部。
- 底部標題列復用正常標題列結構，並在原「範例」按鈕位置替換為精簡的 X 返回按鈕。
- 範例卡片依主視窗寬度自動切換為一欄、兩欄或三欄，小視窗下避免橫向捲動。
- 範例層底部保留標題列高度，捲動到底部時不會遮住最後一行卡片。
- 支援按 Escape 返回主介面，載入任一範例後會自動回到編輯器。
- 動畫改為更克制的 spring 曲線，並在 reduced motion 設定下關閉大幅滑動。

## 驗證

- npm run typecheck
- npm run core:test
- npm run build
- 瀏覽器檢查 1280px、900px、520px 三個寬度下的範例層版面、X 返回、Escape 返回、載入範例後返回和底部留白。
