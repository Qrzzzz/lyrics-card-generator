# Lyrics Card Generator v5.6.1 リリースノート

リリース日：2026年7月15日

v5.6.1 では、v5.5.4 で追加したリクエスト境界の回帰を修正し、NetEase Cloud Music の検索、検索結果の読み込み、複数サービスの曲リンク解析を復旧しました。

## 検索とリンク解析の復旧

- NetEase Cloud Music の検索結果が再び表示され、選択した曲の情報と歌詞を取り込めるようになりました。
- Spotify、Apple Music、NetEase、QQ Music のリンクから、曲情報を再び自動入力できます。
- NetEase の検索、曲情報、歌詞 API の仕様は変わっていません。既存の解析処理と出力形式はそのまま維持しています。

## リクエスト境界の修正

- v5.5.4 はブラウザーの `Origin` と Next 内部の `request.url` を直接比較していました。デスクトップ画面は `127.0.0.1` から開かれる一方、Next はルート URL を `localhost` に正規化するため、同じループバックサービスが別オリジンと誤判定され、すべて 403 で拒否されていました。
- 現在は `Host`、`X-Forwarded-Host`、転送プロトコルからブラウザーが実際にアクセスした外部オリジンを復元します。`Origin` の欠落、明示的なクロスサイトリクエスト、実際の不一致は引き続き拒否し、アプリ識別ヘッダーとコンテンツ形式の検証も維持しています。
- AI 翻訳、ローカル音声解析、歌詞取得で共有する保護も維持しています。

## 検証

- Next 内部の `localhost` URL と外部の `127.0.0.1` オリジンの組み合わせ、`Origin` の欠落、アプリ識別ヘッダーの欠落、明示的なクロスサイト情報を回帰テストに追加しました。
- production 環境の Chromium で NetEase 検索、結果の取り込み、曲リンク解析を確認しました。
- 編集、取り込み、翻訳、書き出し、および v5.6.0 の見た目と操作は変更していません。
