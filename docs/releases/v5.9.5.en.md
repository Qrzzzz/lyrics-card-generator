# Lyrics Card Generator v5.9.5 Release Notes

Release date: 2026-08-08

v5.9.5 is a stability rollback. It withdraws the v5.9.4 performance implementation, returns the affected desktop startup, resource-loading, editor-rendering, export-measurement, and system-font paths to the accepted v5.9.3 architecture, and makes action feedback clearer and more concise.

## Stability rollback

- Desktop local-service startup, renderer-origin validation, and static-resource loading return to the verified v5.9.3 path while retaining the existing security checks.
- Examples, History, Settings, AI translation, and Export return to the established loading and error-handling paths instead of relying on the deferred-surface layer added in v5.9.4.
- ClickSpark, auto width, editor render boundaries, and export-readiness measurement return to their accepted implementations.
- System fonts again use the established query path instead of the v5.9.4 in-process cache, directory service, and registry-refresh logic.

## Result feedback

- App-wide feedback distinguishes green success, yellow warning, and red error states. Desktop History, manual saves, Settings, AI translation, clearing, and export share the same state semantics.
- Six-language Desktop and Web Lite messages are shorter, omit terminal punctuation, and no longer expose internal error details, paths, or backup filenames on the general interface.
- Standard motion uses clearer scale and vertical movement; reduced-motion mode remains opacity-only.

## Compatibility

- This release does not change lyric-document, import-history, or manual-save formats, and no user-data migration is required.
- The v5.9.3 request boundaries, single-instance protection, local-audio parsing, multi-platform song imports, AI translation, and PNG, WebP, and JPG export remain available.
- The public v5.9.4 release record and files remain in the release history; v5.9.5 is the new recommended stable version.

## Release status

v5.9.5 is publicly available through GitHub Releases. The tagged source, installer, portable build, SPDX SBOM, and SHA256SUMS are available from that release page.
