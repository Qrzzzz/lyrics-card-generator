# Lyrics Card Generator v5.11.1

> Status: publicly released through GitHub Releases.

## Export correctness fixes

- Unbroken “Shared by” text on portrait cards can now wrap at any character and participates in complete content, footer, and accessory overflow checks. The app no longer enables an export that silently clips this text.
- PNG, WebP, and JPG now share an exact requested-versus-rendered pixel check. When a high-quality long card exceeds the browser’s 16384-pixel per-side limit, export is explicitly blocked with guidance to lower quality or shorten the content instead of silently scaling the image and reporting success.
- Desktop and Web Lite share the same content-geometry and pixel-size gates. Existing auto-height behavior and normal-sized portrait and landscape cards are unchanged.
