# Lyrics Card Generator v2.0.0 发布说明

发布日期：2026-06-18

v2.0.0 集中增强卡片编辑、预览、导出和桌面端能力。主要内容包括横版布局重构、自定义尺寸高度计算、本地音频解析、Windows 系统字体、PNG 导出、更新检查和 Windows 构建说明。

## 主要更新

- 横版卡片改用安全区域约束封面、歌词、歌曲信息和底部信息，减少挤压、越界和遮挡。
- 竖版自定义尺寸改为基于真实 DOM 测量重新计算高度。
- 新增多语言歌词拆分与中文翻译整理能力。
- 新增本地 MP3 / FLAC 解析，可尝试读取标题、歌手、专辑、封面和内嵌歌词。
- 桌面版新增 Windows 系统字体选择和外部链接打开能力。
- 更新检查改为通过本地 Next API 路由请求 GitHub Releases。

## 发布产物

- `Lyrics Card Generator Setup 2.0.0.exe`
- `Lyrics Card Generator-2.0.0-portable.exe`
- `Lyrics Card Generator Setup 2.0.0.exe.blockmap`

## 验证结果

已通过 `npm run core:test`、`npm run typecheck`、`npm run build` 和 `npm run desktop:build`。

## 注意事项

当前 Windows 构建未进行代码签名，Windows 可能显示 SmartScreen 提示。
