# Lyrics Card Generator v4.6.2 Release Notes

Release date: 2026-07-11

This release fixes the serious editing issue in v4.6.0 and completes reset support for the Prompt Library and Live Preview layout.

## Main Updates

- Fixed replacement typing in desktop text fields, including AI presets and unlocked Strict Format Rules.
- Added a Reset button inside every prompt preset so its initial title and prompt can be restored.
- Added Reset all to the Prompt Library home page to restore defaults, strict format rules, removed presets, and custom presets together.
- Custom presets now record their initial content when first saved; existing presets safely use their current content as the reset baseline after migration.
- Simplified the Prompt Library description and changed the maximized green-button tooltip to “Windowed.”
- Made the Live Preview border follow the card content height instead of leaving a large blank area below it.
