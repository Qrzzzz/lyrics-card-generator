# Lyrics Card Generator v6.6.0 發布說明

發布日期：2026-10-04

v6.6.0 支援在桌面版中選擇紅綠燈或 Windows 風格頂欄，預設繼續使用紅綠燈。視窗按鈕的配置可以依個人習慣調整。

## 頂欄樣式

- 在「設定 → 外觀 → 頂欄樣式」中選擇「紅綠燈（預設）」或「Windows 風格」。新安裝和未設定過此選項的使用者繼續使用紅綠燈。
- Windows 風格將最小化、最大化和關閉按鈕放在頂欄右側；最大化後，按鈕圖示和提示會切換為「窗口化」。
- 切換立即生效並自動儲存，重新啟動後保留選擇。還原應用程式預設設定時，頂欄會回到紅綠燈樣式。
