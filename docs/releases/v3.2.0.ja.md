# Lyrics Card Generator v3.2.0 リリースノート

> [!WARNING]
> このバージョン `v3.2.0` には未修正のバグが含まれています。このバージョンへのアップデートは推奨されません。

リリース日：2026年6月23日

## 設定センターとパーソナライズ

- 一般、外観、背景、書き出し、AI、このアプリについての6タブに設定を再構成しました。
- Spark Cursor、3つのUIテーマ、UIフォント／アクセント／文字色、可読性保護を追加しました。
- 単色、引き伸ばし、全体表示、カバー、ぼかし、画像パレットの背景を永続化します。既定は引き続きアルバム動的配色です。
- PNGの既定品質に低、標準、高、超高の4段階を追加しました。
- 初回起動時に6言語から選択し、空のエディターから開始します。
- `opposite` はサンプルから読み込み、更新確認とGitHubリンクは「このアプリについて」に移動しました。
