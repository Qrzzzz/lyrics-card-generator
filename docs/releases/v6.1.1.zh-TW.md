# Lyrics Card Generator v6.1.1

> 狀態：已透過 GitHub Releases 正式發布。

## Windows 系統原生字型對話方塊

- Windows 桌面版現在直接呼叫系統內建的 `FontDialog`，不再為字型選擇建立 Electron 或 HTML 自繪視窗。
- 系統對話方塊以 Electron 主視窗控制代碼作為 owner，維持真正的 Windows 模態關係；同一時間只允許一個對話方塊，選取或取消後都會恢復主視窗焦點。
- 選取的字型家族仍先更新自訂方案草稿與右側真實歌詞卡預覽，只有「儲存為目前方案」才會提交變更。

## 可靠性與相容性

- 原生橋接明確使用 STA，並對視窗控制代碼、字型名稱、輔助程序輸出與回傳值進行邊界驗證；啟動失敗時會安全回到未選取狀態。
- 桌面回歸可綁定精確的隔離候選 EXE，避免誤測舊的 `release` 建置；原生橋接、IPC 安全與封裝清單均有獨立契約測試。
- 非 Windows 桌面環境與一般瀏覽器繼續使用既有的應用程式內回退，Web Lite 的字型選擇行為不變。
