# 初回 Windows デスクトップ版リリース / Windows デスクトップ版初版公開

## 更新履歴

### リリース概要

本リリースは、Lyrics Card Generator 初の Windows デスクトップ版です。従来の Next.js WebUI 歌詞カードジェネレーターを、そのまま単体で動作する Windows EXE アプリケーションとしてパッケージ化しました。Node.js のインストールは不要で、開発サーバーを手動起動する必要も、Vercel・Netlify・その他のクラウドサービスへのデプロイも不要です。

デスクトップ版は Electron + Next standalone ローカルサーバー構成を採用しており、アプリ起動時に自動でローカルホスト（`127.0.0.1`）上に Next サーバーを起動し、デスクトップウィンドウ内でローカルアドレスを読み込みます。すべてのページおよび API routes はローカルで実行され、Apple Music・NetEase Cloud Music・QQ Music・リモートカバー・LRCLIB はあくまでデータ取得元であり、アプリの動作環境として依存するものではありません。

### ダウンロード選択肢

- インストーラー版：`Lyrics.Card.Generator.Setup.0.1.0.exe`
- ポータブル版：`Lyrics.Card.Generator-0.1.0-portable.exe`

通常のご利用にはインストーラー版を推奨します。一時的な試用や、インストール先へ書き込みを行いたくない場合はポータブル版をご利用ください。

### 主要機能

- 楽曲リンク解析：Apple Music、NetEase Cloud Music、QQ Music のリンクに対応。
- 手動入力：曲名・アーティスト名・アルバム名・カバーURL を手動編集可能。
- 歌詞編集：歌詞の手動入力および編集に対応。
- 翻訳編集：行単位での翻訳テキスト入力、翻訳の表示/非表示切り替え。
- インストゥルメンタルモード：歌詞なし・インストゥルメンタル楽曲の表示に対応。
- カバー画像機能：リモートカバー、ローカルカバーアップロード、カバープロキシ、カバー色抽出に対応。
- ビジュアルスタイル：縦向き/横向き、サイズ設定、高さ自動調整、フォント・文字サイズ・行間・文字色・角丸・枠線・影・プラットフォームロゴ・ウォーターマーク・共有者テキストなど、多彩なスタイル制御が可能。
- 言語切り替え：中国語 / English UI に対応し、言語設定は保持されます。
- PNG 書き出し：従来の DOM-to-PNG 方式を維持し、デフォルトで高精細 2x 出力（Electron のスクリーンショット機能は不使用）。

### デスクトップ版の使用感

- EXE ファイルをダブルクリックするだけで起動。
- 既定で最大化ウィンドウで開きます。
- アプリアイコンを、透過丸角の新アイコンに統一（インストーラー、ポータブル版、タスクバー、ウィンドウタイトルバー、Web favicon、アプリ内タイトル部分に適用）。
- ウィンドウを閉じると内蔵ローカルサーバーも自動終了し、バックグラウンドプロセスが残りません。
- 外部リンクはシステム既定のブラウザで開き、アプリ内での不意な画面遷移を防止します。

### オフライン／オンラインに関する注意

オフラインで利用可能：

- アプリの起動
- 楽曲情報の手動入力
- 歌詞・翻訳の手動編集
- ローカルカバー画像の使用
- カードスタイルの調整
- PNG 書き出し

オンライン接続が必要：

- Apple Music / NetEase Cloud Music / QQ Music のリンク解析
- リモートカバー画像の読み込み
- LRCLIB 経由の歌詞自動取得

### 初版の制限事項

- 本バージョンには自動更新機能はありません。
- コード署名は行われていないため、Windows 上で SmartScreen 警告が表示される場合があります。
- インストーラー版・ポータブル版とも Windows x64 向けビルドです。
- リモート解析および歌詞自動取得は、サードパーティーデータソースの可用性に依存します。

### 検証結果

- `npm run typecheck` 合格。
- `npm run build` 合格。
- `npm run desktop:build` 合格。
- インストーラー版・ポータブル版の生成を確認。
- ポータブル版および unpacked EXE が内蔵 Next サーバーを起動できることを確認。
- EXE 起動時に既定で最大化表示されることを確認。
- アプリ終了後に残留プロセスがないことを確認。
- Apple Music、NetEase Cloud Music、QQ Music の解析をサンプル検証で確認。
- ローカルカバープロキシ API の動作を確認。
- LRCLIB 経由の歌詞自動取得をサンプル検証で確認。
- PNG 書き出しを確認。デフォルトの `1040x1080` カードが `2080x2160` で出力されることを確認。
- 新アイコンが `build/icon.ico`、`app/icon.png`、`public/app-icon.png`、パッケージ後の `resources/icon.ico` に反映されていることを確認。
