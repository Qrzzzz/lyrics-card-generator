# Lyrics Card Generator v0.1.0 リリースノート

公開日：2026-06-16

## リリース概要

これは Lyrics Card Generator 初の Windows デスクトップ版です。既存の Web 版を、Windows で利用しやすいデスクトップアプリとして配布しました。

## ダウンロードとインストール

- インストーラー版：`Lyrics.Card.Generator.Setup.0.1.0.exe`
- ポータブル版：`Lyrics.Card.Generator-0.1.0-portable.exe`

通常利用にはインストーラー版を推奨します。ポータブル版は一時的な試用に適しています。

## 主な機能

- Apple Music、NetEase Cloud Music、QQ Music のリンク解析。
- 曲名、アーティスト、アルバム、カバー URL の手動編集。
- 歌詞と訳文の入力、編集、表示切替。
- リモートカバー、ローカルカバー、カバー色抽出。
- 縦長 / 横長レイアウト、サイズ、フォント、行間、色、枠線、影、ロゴ、透かしなどのスタイル調整。
- 中国語と English の UI 切り替え。
- PNG 書き出し。

## 初版の制限

- このバージョンでは自動更新に対応していません。
- Windows ビルドは未署名のため、SmartScreen の警告が表示される場合があります。
- インストーラー版とポータブル版はいずれも Windows x64 向けです。
- リモート解析と歌詞取得は外部データソースの可用性に依存します。

## 検証結果

公開前に主要な型チェック、ビルド、デスクトップビルドを実行し、代表的なリンク解析、歌詞取得、PNG 書き出しをサンプルで確認しました。
