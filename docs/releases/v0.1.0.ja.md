# Lyrics Card Generator v0.1.0 リリースノート

公開日：2026-06-16

## リリース概要

これは Lyrics Card Generator 初の Windows デスクトップ版です。既存の Next.js WebUI ベースの歌詞カード生成ツールを、すぐに起動できる Windows EXE アプリとしてパッケージ化しました。Node.js のインストール、開発サーバーの手動起動、クラウドへのデプロイは不要です。

デスクトップ版は Electron と Next standalone のローカルサービス構成を採用しています。起動時に `127.0.0.1` 上で内蔵 Next サービスを開始し、そのローカルアドレスをデスクトップウィンドウ内で読み込みます。Apple Music、NetEase Cloud Music、QQ Music、リモートカバー、LRCLIB はデータ取得元であり、デプロイ依存ではありません。

## ダウンロードとインストール

- インストーラー版：`Lyrics.Card.Generator.Setup.0.1.0.exe`
- ポータブル版：`Lyrics.Card.Generator-0.1.0-portable.exe`

通常利用にはインストーラー版を推奨します。一時的に試したい場合や、システムのアプリケーションディレクトリに書き込みたくない場合はポータブル版を利用できます。

## 主な機能

- Apple Music、NetEase Cloud Music、QQ Music のリンク解析。
- 曲名、アーティスト、アルバム、カバー URL の手動編集。
- 歌詞の手動入力と編集。
- 行ごとの訳文編集、および訳文の表示 / 非表示。
- 歌詞なし、またはインストゥルメンタル曲の表示。
- リモートカバー、ローカルカバーアップロード、カバープロキシ、カバー色抽出。
- 縦長 / 横長レイアウト、サイズ、自動高さ、フォント、文字サイズ、行間、文字色、角丸、枠線、影、プラットフォームロゴ、透かし、共有者テキストなどのスタイル調整。
- 中国語と English の UI 切り替え、および言語設定の保存。
- 既存の DOM-to-PNG 処理による PNG 書き出し。標準で高品質 2x 出力に対応。

## デスクトップ体験

- EXE をダブルクリックして起動できます。
- ウィンドウは標準で最大化表示されます。
- アプリアイコンはインストーラー、ポータブル版、タスクバー、タイトルバー、Web favicon、アプリ内ヘッダーに反映されています。
- ウィンドウを閉じると内蔵ローカルサービスも終了し、バックグラウンドプロセスが残りにくくなっています。
- 外部リンクはシステムブラウザで開きます。

## オフライン / オンライン動作

オフラインで利用可能：アプリ起動、曲情報の手動入力、歌詞と訳文の編集、ローカルカバーの使用、カードスタイル調整、PNG 書き出し。

インターネット接続が必要：Apple Music / NetEase Cloud Music / QQ Music のリンク解析、リモートカバー読み込み、LRCLIB による自動歌詞取得。

## 初版の制限

- このバージョンでは自動更新に対応していません。
- Windows ビルドはコード署名されていないため、SmartScreen の警告が表示される場合があります。
- インストーラー版とポータブル版はいずれも Windows x64 向けです。
- リモート解析と歌詞取得は外部データソースの可用性に依存します。

## 検証結果

公開前に `npm run typecheck`、`npm run build`、`npm run desktop:build` が成功しています。インストーラー版とポータブル版が生成され、内蔵 Next サービスの起動、主要なリンク解析、ローカルカバープロキシ、LRCLIB 歌詞取得、PNG 書き出しがサンプルで検証されています。
