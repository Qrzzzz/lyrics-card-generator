# Lyrics Card Generator v4.2.0 發佈說明

發佈日期：2026-07-03

v4.2.0 升級桌面版範例歌詞系統，並修復獨立 Web Lite / GitHub Pages 部署準備方式。Web Lite 仍是簡化線上演示，不代表桌面版完整體驗。

## 主要更新

- 範例歌詞設定升級為「原語言歌詞 + 五種目標語言翻譯樣例」的可重用結構。
- 範例彈窗現在展示歌曲標題、歌手和原語言，並可在五種譯文之間選擇。
- 當目前介面語言存在對應譯文時，範例會預設選中該譯文；否則使用第一種可用譯文。
- 範例設定不再承擔卡片高度、尺寸、比例或 AutoHeight 狀態職責。
- 載入範例只填入歌曲資訊、歌詞和譯文，仍保留封面與專輯資訊的最佳努力補充邏輯。
- Web Lite / GitHub Pages 改用明確的相對圖示路徑，並只打包 `index.html`、`public/app-icon.png` 和 `.nojekyll`。

## 範圍說明

- 不把範例文字寫入元件，範例資料仍集中在 `lib/examples.ts`。
- 不為範例引入執行階段請求，歌詞與譯文可離線使用。
- 不為了 Web Lite 改動桌面版主體邏輯、Electron 建置或桌面版預覽 / 匯出流程。
- Web Lite 仍是獨立、簡化、粗略的線上演示，完整體驗請使用桌面版。

## 驗證

- npm run typecheck
- npm run core:test
- npm run build
