# Lyrics Card Generator v2.1.0 Release Notes

Languages: [简体中文](./v2.1.0.zh-CN.md) · [繁體中文](./v2.1.0.zh-TW.md) · English · [Français](./v2.1.0.fr.md) · [日本語](./v2.1.0.ja.md) · [Español](./v2.1.0.es.md)

## Download and Installation

Download the matching assets from GitHub Releases:

- Installer: `Lyrics Card Generator Setup 2.1.0.exe`
- Portable build: `Lyrics Card Generator-2.1.0-portable.exe`

The installer is recommended for regular use. Choose the portable build for temporary use, testing, or running the app from a removable drive.

> This build is not code-signed. Windows may show a SmartScreen warning, which is common for unsigned personal applications.

## What's New

v2.1.0 focuses on the desktop experience, landscape layout, custom canvas sizing, multilingual UI, and local media handling.

### Added

- Added the Windows desktop packaging flow.
- Added installer and portable distribution formats.
- Added local MP3 / FLAC parsing for title, artist, album, cover art, and embedded lyrics.
- Added Windows system font detection and custom font selection.
- Added interface switching for Simplified Chinese, Traditional Chinese, English, French, Japanese, and Spanish.
- Added an entry point for checking updates through GitHub Releases.

### Improved

- Rebuilt the landscape layout around safe areas, cover column, content column, and footer regions.
- Added measured auto-height support for portrait custom canvases.
- Improved original lyric and translation layout, including splitting original / translated lines based on the current interface language.
- Switched remote cover export to the image proxy to reduce cross-origin PNG export failures.
- Moved platform logos to local SVG assets so PNG export does not depend on remote icons.

### Fixed

- Fixed content overflow or unexpected blank space in some custom canvas sizes.
- Fixed cover, lyric, and footer regions crowding each other in landscape cards.
- Fixed cases where remote covers could not be written correctly into exported PNG files.

## Upgrade Notes

- Upgrading from an older version usually does not require uninstalling first.
- If the installer cannot overwrite the old build, exit the old version and run the installer again.
- If the portable build does not start, check whether an old process is still running in the background.

## Known Limitations

- Music platform link parsing, remote cover loading, automatic lyric fetching, and update checking require an internet connection.
- Automatic lyric fetching is still experimental. Results may be incomplete or inaccurate. Make sure you have the right to use the lyrics.
- The current build is not code-signed. A Windows SmartScreen warning does not necessarily mean the program is unsafe.
