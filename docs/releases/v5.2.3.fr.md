# Notes de version de Lyrics Card Generator v5.2.3

## Correction de la vérification de publication

La v5.2.3 corrige l’échec de la vérification finale qui retélécharge les fichiers de la publication v5.2.2.

- Lorsqu’une Release publiée et un brouillon partagent le même tag, le workflow ne télécharge plus les fichiers via un tag susceptible de désigner la mauvaise Release.
- Le workflow enregistre l’identifiant unique du brouillon qu’il crée et l’utilise pour télécharger, vérifier et publier le même jeu de fichiers.
- Avant publication, il contrôle strictement l’installateur, la version portable, le SPDX SBOM, SHA256SUMS, les empreintes et les attestations GitHub.
- Une Release déjà publiée pour le tag bloque le workflow ; une relance ne supprime que les brouillons résiduels portant ce même tag afin qu’aucune Release incomplète ou dupliquée ne paraisse réussie.

## Périmètre de la version

- Les fonctionnalités, le comportement de l’interface, le rendu des cartes et les formats de données restent identiques à la v5.2.2.
- Cette version corrige uniquement la publication et la vérification de la chaîne d’approvisionnement, puis régénère des fichiers Windows entièrement vérifiés.
