# Lyrics Card Generator v6.1.5

> 狀態：已正式發佈。

## 應用程式內雙字體工作台

- 自訂字體選擇不再開啟獨立的 WinForms 視窗，而是在現有「字體方案」區域內展開，與軟體的主題、控制項和版面風格保持一致。
- 中日韓與西文字體各有一張精簡角色卡，並共用搜尋、推薦字體及完整系統字體清單；每個項目都會顯示字體名稱與字形預覽。
- 懸停或使用鍵盤瀏覽字體時會即時更新右側真實歌詞卡。交換、還原和取消只操作草稿，只有「一次套用」才會同時寫入兩種字體。

## 範例預覽還原與桌面鏈路精簡

- 舊版專用範例歌詞卡已還原至真實預覽下方，以固定背景協助比較字形；它只會在自訂字體編輯期間顯示，不會進入匯出內容。
- 移除已不再需要的原生子視窗、WinForms 輔助指令碼及相關 IPC／打包入口，同時保留受保護的系統字體目錄服務。
- 補齊明暗主題、自訂強調色、焦點返回及無結果／載入失敗狀態；桌面版與 Web Lite 繼續共用同一套字體方案和預覽規則。
