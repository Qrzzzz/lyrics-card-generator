# Lyrics Card Generator v6.1.4

> Status: officially released.

## Searchable shared font browser

- The native Windows font-scheme window now gives CJK and Latin roles one shared system-font browser; switch roles to choose the family for each position.
- Search filters installed fonts immediately. Every row shows the family name and a glyph preview, with result counts and a dedicated empty state.
- You can swap both fonts, restore the opening scheme, and search or select by keyboard. Only confirmed selections are applied to the current scheme.

## Native bridge reliability

- The complete WinForms helper script is now passed to PowerShell through standard input, preventing complex UI scripts from exceeding the Windows command-line length limit.
- Main-window modal ownership, bounded result parsing, input validation, and failure fallback remain intact. The non-Windows desktop fallback, browser picker, and lyric-card rendering rules are unchanged.
