# Lyrics Card Generator v5.2.2 リリースノート

## リリースとワークフローの修正

v5.2.2 は v5.2.1 リリースのタグ不一致を修正し、Stepper の状態、設定ナビゲーション、サンプル読み込み後のライブプレビューを改善します。

- v5.2.1 ワークフローは v5.2.0 のタグパターンを使用しなくなりました。各リリースワークフローが自身のバージョンと対応する RC タグのみを受け付ける回帰チェックを追加しました。
- v5.2.2 の公開フローでは、アプリのバージョン、6 言語のノート、Windows 成果物名、SBOM、公開ファイル検証を同期します。

## インターフェースとプレビュー

- Stepper のチェックは現在の手順より前に完了した項目だけに表示し、現在と以降の手順は正しい番号を維持します。
- 設定の戻る/進むボタン群から外枠を除き、間隔を少し広げて右側のパンくずバーをコンパクトにしました。
- 手順 3 からサンプルを開き、別の曲への置換を確認してエディターへ戻ると、画面遷移の完了後にライブプレビューを再計測し、異常に小さい状態が残りません。
- 歌詞カード出力、プロジェクトデータ形式、既存のビジュアル方針は変更しません。
