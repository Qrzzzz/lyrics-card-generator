# Lyrics Card Generator v3.9.0 發布說明

發布日期：2026-07-01

v3.9.0 聚焦設定儲存流程、編輯步驟簡化、卡片資訊顯示和發布準備。本次更新保留原有六語言範圍，不新增或移除語言，並把設定儲存流程改為即時生效，減少使用者在背景、外觀與 AI 設定之間反覆確認的操作。

## 設定儲存流程

- 設定中心改為即時儲存，背景圖片、AI 設定、外觀和一般設定調整後會直接寫入本機偏好。
- 舊的底部「儲存 / 取消」確認列已移除，設定變更會透過輕量提示回饋儲存狀態。
- 背景圖片替換後會清理舊資源，桌面版偏好仍會同步寫入 Electron 偏好儲存。

## 多語言範圍

- 介面語言範圍保持原有六語言：簡體中文、繁體中文、English、Français、日本語、Español。
- 本版本不新增語言，也不刪除既有語言入口。
- 多語言 README 與發布說明繼續保持 6 個語言版本一致更新。

## 編輯流程與卡片資訊

- 手動歌曲資訊從獨立步驟合併到歌曲連結步驟，可透過「手動調整」展開填寫標題、歌手、專輯和封面。
- 歌詞卡片新增「顯示專輯名」開關，直式、橫式和純音樂卡片都會依照開關顯示或隱藏專輯名。
- 自動高度和橫式版面會為專輯名預留空間，減少歌曲資訊與歌詞內容互相擠壓的情況。

## 發布準備

- 版本元資料、`package.json`、`package-lock.json` 和 README 下載檔名已同步到 `3.9.0`。
- 多語言發布說明已補齊 6 個語言檔案，並更新 `docs/releases/README.md` 索引。
- Windows 安裝版、可攜版和 `latest.yml` 已隨本版本重新建置，用於 GitHub Release 上傳。

## 驗證

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:build
