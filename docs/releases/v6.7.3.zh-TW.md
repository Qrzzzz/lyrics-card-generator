# Lyrics Card Generator v6.7.3 發布說明

發布日期：2026-10-14。

v6.7.3 區分同一句的自動折行與手動換行，改善長句與雙語歌詞的排版層次，並保留現有可變行高。

- 同一句因寬度不足而折行時，使用更緊湊的間距；使用者輸入的換行維持所選行高，讓相鄰歌詞更容易辨認。
- 行高繼續支援 1.5–2.1、步長 0.05、預設 1.8；原文與譯文的折行間距隨滑桿同步調整，無須新增設定。
- 統一橫式、直式、預覽、匯出與自動尺寸測量；合併單元中的多行歌詞也保留手動換行層次，空行、分隔線與雙語對應關係繼續保留。
