# Lyrics Card Generator v3.9.0 发布说明

发布日期：2026-07-01

v3.9.0 聚焦设置保存流程、编辑步骤简化、卡片信息显示和发布准备。本次更新保留原有六语言范围，不新增或移除语言，并把设置保存流程改为即时生效，减少用户在背景、外观和 AI 设置之间来回确认的操作。

## 设置保存流程

- 设置中心改为即时保存，背景图片、AI 设置、外观和通用设置调整后会直接写入本地偏好。
- 旧的底部“保存 / 取消”确认栏已移除，设置变更会通过轻量提示反馈保存状态。
- 背景图片替换后会清理旧资源，桌面版偏好仍会同步写入 Electron 偏好存储。

## 多语言范围

- 界面语言范围保持原有六语言：简体中文、繁體中文、English、Français、日本語、Español。
- 本版本不新增语言，也不删除既有语言入口。
- 多语言 README 与发布说明继续保持 6 个语言版本一致更新。

## 编辑流程与卡片信息

- 手动歌曲信息从独立步骤合并到歌曲链接步骤，可通过“手动调整”展开填写标题、歌手、专辑和封面。
- 歌词卡片新增“显示专辑名”开关，竖版、横版和纯音乐卡片都会按开关显示或隐藏专辑名。
- 自动高度和横版布局会为专辑名预留空间，减少歌曲信息与歌词内容互相挤压的情况。

## 发布准备

- 版本元数据、`package.json`、`package-lock.json` 和 README 下载文件名已同步到 `3.9.0`。
- 多语言发布说明已补齐 6 个语言文件，并更新 `docs/releases/README.md` 索引。
- Windows 安装版、便携版和 `latest.yml` 已随本版本重新构建，用于 GitHub Release 上传。
