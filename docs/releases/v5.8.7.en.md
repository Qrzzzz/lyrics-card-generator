# Lyrics Card Generator v5.8.7 Release Notes

Release date: 2026-07-25

v5.8.7 unifies horizontal page navigation in the right-hand tools of step two. Cleanup and Translation now slide according to direction. Once AI translation starts, connection status, reasoning, and translation streams move to an independent run/results page instead of expanding below the setup controls. Lyric editing, AI requests, prompts, and translation application are unchanged.

## Horizontal Cleanup／Translation navigation

- Cleanup and Translation share one state-preserving page track: moving forward sends the old page left, while returning reverses the direction.
- The top tabs, operation feedback, sidebar frame, lyric editor, command bar, and fixed 2:1 split remain stationary.
- The top AI translation shortcut moves directly from the current page to AI setup without flashing the intermediate Translation home page.

## Independent AI run/results page

- Starting translation slides AI setup left while connection status, reasoning, translation output, errors, and Stop enter on a dedicated page from the right.
- Returning to setup first cancels an active request and then reverses the transition. Completed or failed output remains available on the run page.
- Translation home, AI setup, and AI run maintain independent scrolling and local state, avoiding extra space or horizontal overflow from a taller sibling page.

## Keyboard and motion behavior

- After each transition, focus moves to the new page’s primary Back or action control. The exiting page is immediately isolated from pointer, keyboard, and assistive-technology navigation.
- Escape in the narrow-screen drawer follows the full hierarchy: run page → setup → Translation home → close drawer.
- Reduced motion removes horizontal travel while preserving page hierarchy, cancellation, focus, and interaction isolation.
