# Notas de la versión Lyrics Card Generator v4.2.0

Fecha de lanzamiento: 2026-07-03

La versión 4.2.0 actualiza el sistema de ejemplos de letras del escritorio y corrige la preparación del despliegue para la demo separada Web Lite / GitHub Pages. Web Lite sigue siendo una demo en línea simplificada, no la experiencia completa de escritorio.

## Actualizaciones principales

- Los ejemplos de letras usan ahora una estructura reutilizable: letra en idioma original + cinco muestras de traducción.
- El diálogo de ejemplos muestra título, artista e idioma original, y permite elegir entre cinco traducciones.
- Si el idioma actual de la interfaz tiene una muestra correspondiente, esa traducción se selecciona por defecto; si no, se usa la primera disponible.
- La configuración de ejemplos ya no incluye altura, tamaño, proporción ni estado AutoHeight de la tarjeta.
- Cargar un ejemplo solo rellena canción, letra y traducción, manteniendo el enriquecimiento opcional de portada y álbum.
- Web Lite / GitHub Pages usa rutas relativas explícitas para el icono y empaqueta solo `index.html`, `public/app-icon.png` y `.nojekyll`.

## Alcance

- El texto de los ejemplos no se incrusta en componentes; sigue centralizado en `lib/examples.ts`.
- Los ejemplos no añaden solicitudes en tiempo de ejecución, por lo que las letras y traducciones siguen disponibles sin conexión.
- La corrección de Web Lite no cambia la lógica de escritorio, el flujo de build de Electron ni el comportamiento de vista previa / exportación del escritorio.
- Web Lite sigue siendo una demo en línea independiente, simplificada y aproximada; usa la app de escritorio para la experiencia completa.
