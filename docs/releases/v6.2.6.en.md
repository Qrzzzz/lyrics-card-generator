# Lyrics Card Generator v6.2.6

> Status: not yet released.

## Lighter content depth

- Broad local-readability masks behind song metadata, lyrics, and footer content are removed, so the background no longer contains large tone-shifted patches.
- Light text keeps only a low-opacity 2px offset and 8px blur; dark text uses an even quieter 1px offset and 4px light edge so glyphs appear to float gently above the background.
- Transparent artwork edges and ordinary rectangular covers now share smaller, lower-opacity shadows while transparent PNG contours remain natural.

## Font schemes and layout

- The custom scheme drops its nested backing panel and adopts the same single-layer card, border, and selected-state language as the Source Han Sans and Source Han Serif presets.
- The Edit Scheme action, current-state indication, custom font summary, and keyboard focus behavior remain unchanged.
- The redundant “If the content needs more space...” layout hint remains removed. Automatic height and anti-cropping behavior are unchanged.

## Download and upgrade

- Windows x64 installer: `Lyrics.Card.Generator.Setup.6.2.6.exe`.
- This release remains Setup-only; upgrades from earlier versions require no settings migration.
