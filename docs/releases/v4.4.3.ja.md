# Lyrics Card Generator v4.4.3 リリースノート

リリース日：2026-07-10

このリリースでは、設定ウィングとアプリ全体のボタン操作を統一しました。エディター、歌詞サンプル、設定の既存三サーフェス構成を維持したまま、小画面ナビゲーション、AI 設定の保存表示、空間遷移、複数の視覚的な細部を修正しています。

## 主な更新

- 既存のモーションシステムを通じて、多くのボタンに上方向 1px の控えめなホバー効果を追加しました。共通コントロールは spring、ネイティブボタンは同じ時間と easing を使い、動きを減らす設定にも全面的に従います。
- 720px 未満の設定カテゴリーは、不完全な `menu` モデルではなく通常の disclosure/list として扱います。設定を閉じると必ずリストが閉じ、再度開いたときに展開状態が残りません。
- カテゴリーリストが開いている場合、最初の Escape はリストだけを閉じ、設定の終了処理を止めてトリガーボタンへフォーカスを戻します。二回目の Escape で設定ウィングを閉じます。
- AI 設定の保存状態を `saved`、`pending`、`saving`、`error` の四つに分けました。変更直後は保存待ちを表示し、失敗後に緑色の「保存済み」へ戻ることもありません。
- 既存の 700ms 遅延保存と終了時保存を維持しつつ、連続した保存を順番に処理して古い要求が新しい画面状態を上書きしないようにしました。
- サンプル画面の後に設定を開く際のガードを削除し、歌詞サンプルを閉じた後も設定ウィングの横方向遷移が確実に始まるようにしました。
- 設定ウィング外層を透明化し、アプリ背景へ直接配置しました。既定の書き出し品質は既存の三段階セグメントを使用し、ウィンドウのクリップ角丸を 8px に統一し、サンプルの閉じるボタンを中立的なアクセント表現へ変更しました。
- 設定、モーション、タイトルバー、リリース整合性の回帰テストを拡充し、保存待ちと保存失敗の表示を六つの言語すべてに追加しました。

## 検証

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:build
- git diff --check
- 680px での Escape、フォーカス復元、再表示状態の確認
- サンプル終了後の設定遷移とデスクトップ表示の確認
