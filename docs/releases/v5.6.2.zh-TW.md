# Lyrics Card Generator v5.6.2 發布說明

發布日期：2026 年 7 月 16 日

v5.6.2 改善後半段編輯流程的空間連續性與預覽手感，並為桌面版和 Web Lite 加入真正的 WebP、JPG 匯出。

## 更有層次的即時預覽

- 第 3 至第 6 步的歌詞卡片會隨指標位置輕微傾斜，在懸停時抬升，按下時提供克制的回彈回饋。
- 指標在卡片外放開、取消操作或離開預覽後，卡片會可靠復位，不會停留在傾斜或抬升狀態。
- 觸控裝置不啟用指標傾斜；系統或應用程式選擇「減少動態效果」時，預覽會使用穩定的靜態呈現。
- 這些效果只存在於可見預覽層，獨立的匯出宿主不會包含 3D 變形、高光或陰影回饋。

## 第 5 步到第 6 步的連續工作台

- 從「視覺」進入「匯出」時，舊設定、預覽與新匯出設定位於同一條三面板軌道，並作為整體向左平移。
- 預覽會由右側連續移到左側，舊設定離開左側，匯出設定由右側進入；返回第 5 步時會沿同一路徑反向復原。
- 離屏設定會標記為不可互動並對輔助技術隱藏，避免鍵盤焦點進入不可見區域。
- 窄視窗改用預覽在前、目前設定在後的縱向版面，保留捲動、sticky 預覽與無水平溢出的行為。

## PNG、WebP 與 JPG 匯出

- 第 6 步現在可選擇 PNG、WebP 或 JPG，並產生相符的真實編碼、副檔名與 MIME 類型。
- PNG 保留無損輸出；WebP 與 JPG 使用高品質有損編碼。原有品質等級仍控制匯出像素比例。
- 「設定 → 匯出」可儲存預設圖片格式；儲存後，第 6 步與下次啟動會同步使用該選項。Web Lite 也會保存自己的格式與品質偏好。
- 每次匯出都會凍結格式、檔名、畫布尺寸、像素比例與卡片內容；並行點擊、逾時或取消不會提交過期下載。
- SVG 不在 v5.6.2 的範圍內，本版本沒有新增 SVG 匯出。

## 跨端與發布驗證

- Desktop 與 Web Lite 共用格式選擇、快照匯出與響應式工作台行為；產生的 `index.html` 與原始碼保持一致。
- 回歸涵蓋六種介面語言、鍵盤與輔助技術語意、觸控/減少動態效果降級、正反向切換、小視窗版面，以及 PNG、WebP、JPG 檔案簽章。
- Windows 安裝版與可攜版持續通過封裝互動測試和最終製品 smoke；正式 Release 會驗證精確的版本化資產名稱、SHA256SUMS、SPDX SBOM 與 GitHub attestation。
