# Lyrics Card Generator v5.9.5 发布说明

发布日期：2026-08-08

v5.9.5 是稳定性回退版本。它撤回 v5.9.4 的性能优化实现，将受影响的桌面启动、资源加载、编辑器渲染、导出测量与系统字体路径恢复到经过验收的 v5.9.3 架构，并让操作结果提示更清楚、更精简。

## 稳定性回退

- 桌面本地服务、renderer 来源确认与静态资源加载恢复为 v5.9.3 已验证的启动路径，同时保留原有安全检查。
- 示例、历史、设置、AI 翻译与导出界面恢复为稳定的既有加载和错误处理方式，不再依赖 v5.9.4 新增的延迟界面层。
- ClickSpark、自适应宽度、编辑器渲染边界与导出就绪测量恢复为验收过的实现。
- 系统字体重新使用原有查询路径，不再依赖 v5.9.4 的进程内缓存、目录服务与注册表刷新逻辑。

## 结果反馈

- 全局结果提示按绿色成功、黄色警告、红色错误区分，桌面版的历史、手动存档、设置、AI 翻译、清理与导出操作使用同一套状态语义。
- 六语言 Desktop 与 Web Lite 结果文案同步精简，省去句末标点以及不适合在通用界面直接显示的内部错误细节、路径和备份文件名。
- 正常动画使用更明确的缩放与位移反馈；减少动态设置下仍只进行透明度切换。

## 兼容性

- 本版本不改变歌词文档、导入历史或手动存档的数据格式，也不需要迁移用户数据。
- v5.9.3 的请求边界、单实例保护、本地音频解析、多平台歌曲导入、AI 翻译以及 PNG、WebP、JPG 导出继续保留。
- v5.9.4 的公开发布记录与文件仍保留在历史页面；v5.9.5 是新的推荐稳定版本。

## 发布状态

v5.9.5 已通过 GitHub Releases 公开发布。标签源码、安装版、便携版、SPDX SBOM 与 SHA256SUMS 均可从该发布页面获取。
