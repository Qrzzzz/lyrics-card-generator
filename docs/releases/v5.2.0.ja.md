# Lyrics Card Generator v5.2.0 リリースノート

公開日：2026-07-13

v5.2.0 は安定性、アクセシビリティ、デスクトップセキュリティ、リリース工程の更新です。カード出力、データ形式、既存のビジュアルは維持されます。

## 主な更新

- Safe Fetch は解決された全アドレスを検証し、IPv6/IPv4 を交互に試して接続失敗時に切り替えます。要求全体で共通のタイムアウトとリダイレクト上限を使います。
- 文書の意味に関わる変更は実行中の AI generation を原子的に取り消し、通常の視覚調整では不要な取消を行いません。Electron の取消はウィンドウ単位で分離され、provider の最初の待機前にも有効です。
- デスクトップ設定は単調 revision で JSON と renderer cache を調整し、5.1.0 データを移行、連続保存を直列化し、全終了経路で pending settings を flush します。
- 共通 accessible dialog は初期フォーカス、Tab ループ、背景 inert、Escape、アニメーション軽減、フォーカス復帰に対応します。検索、リンク解析、ローカル音声はキーボードと live region で操作できます。
- 6 言語のエラーは安定したコードから表示され、文書言語は locale に同期します。カスタム accent と Forced Colors でもフォーカスが明確です。
- 外部ナビゲーション、特権 IPC sender、権限、production CSP に明示的なポリシーを適用しました。

## リリース保証

- CI に lint、重要モジュール coverage、axe、言語カタログ、Electron セキュリティ、ライフサイクル、最終成果物のゲートを追加しました。
- Setup と portable は最終バイトをテストし、同じファイルに SHA-256、SPDX SBOM、GitHub attestation を付けて公開します。
