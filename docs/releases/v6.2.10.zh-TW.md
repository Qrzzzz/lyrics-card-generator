# Lyrics Card Generator v6.2.10

## 修復與改進

- [#165](https://github.com/Qrzzzz/lyrics-card-generator/issues/165) 修復匯入等待取代確認或自動草稿補存時，舊操作可能覆蓋新連結、歌詞或文件的問題。
- [#166](https://github.com/Qrzzzz/lyrics-card-generator/issues/166) AI 翻譯與連線測試統一拒絕 HTTP 重新導向，避免將請求本文轉送至未授權的下一站。
- [#167](https://github.com/Qrzzzz/lyrics-card-generator/issues/167) 為已驗證的備用網路位址保留首個回應的等待時間，避免無回應的首個位址耗盡整次請求的逾時預算。
- Explicit 標識改為白色、50% 不透明度的圓角 SVG，以透明鏤空 E 統一卡片預覽與匯出。

自訂 AI 提供者須使用可直接回應的 HTTPS 位址，或合法的本機 loopback HTTP 位址；需要重新導向的位址請改為最終介面位址。

- Windows x64: `Lyrics.Card.Generator.Setup.6.2.10.exe`.
