# Lyrics Card Generator v6.5.5 リリースノート

公開日：2026-09-22

v6.5.5 では、デスクトップ版の設定内にある「このアプリについて」から開く作者支援ページを整理し、ネットワークの選択、QR コード、受取情報を見やすくまとめました。

## 作者支援ページ

- TRON と X Layer の選択肢をコンパクトにし、選択中のネットワークを分かりやすく表示します。
- QR コードを小さくし、通貨、ネットワーク、アドレス、コピーボタンを再配置しました。重複するラベルとアドレス専用の枠を減らしました。
- 見出しのアイコン、説明文、余白を調整し、ダーク・ライトテーマと幅の狭いウィンドウに対応しました。
