# Lyrics Card Generator v6.6.0 Notes de version

Date de publication : 2026-10-04

v6.6.0 permet de choisir, dans la version de bureau, entre les feux tricolores et une barre de titre de style Windows. Les feux tricolores restent le choix par défaut ; la disposition des boutons peut être adaptée à vos habitudes.

## Styles de barre de titre

- Choisissez « Feux tricolores (par défaut) » ou « Style Windows » dans Paramètres → Apparence → Style de la barre de titre. Les nouvelles installations et les utilisateurs qui n’ont pas choisi de style conservent les feux tricolores.
- Le style Windows place les boutons de réduction, d’agrandissement et de fermeture à droite. Quand la fenêtre est agrandie, l’icône et l’infobulle du bouton d’agrandissement passent à « Mode fenêtré ».
- Les changements prennent effet immédiatement, sont enregistrés automatiquement et sont conservés après le redémarrage. La restauration des paramètres par défaut rétablit les feux tricolores.
