# Lyrics Card Generator v6.2.3

> 状态：已发布。

## 局部可读性阴影修复

- 歌曲信息、歌词和页脚附件区域现在使用相同的局部可读性阴影深度。
- 三个区域的渐变会先合并成单一透明度遮罩，再统一应用明暗调整；交叠区域不会重复加深，也不会形成突兀的页头或页脚深色带。
- 移除平台 Logo、分享人和生成水印自身的额外投影，让这些元素只受同一可读性层保护，并保持实时预览与最终导出一致。

## 验证范围

- 背景组合回归覆盖 120 组确定性组合，并新增“重叠区域不得超过单层透明度上限”和“三个区域深度一致”断言。
- 已通过类型检查、lint、生产构建、Web Lite 构建与一致性检查，并完成 Chromium 真实 2× PNG 导出以及 Firefox、WebKit 渲染检查。

## 下载与升级

- Windows x64 安装版：`Lyrics.Card.Generator.Setup.6.2.3.exe`。
- 本版本继续采用 Setup-only 发布方式；从旧版本升级无需迁移配置。
