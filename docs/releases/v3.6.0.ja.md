# Lyrics Card Generator v3.6.0 リリースノート

リリース日：2026-06-29

v3.6.0 は Windows デスクトップ版の Acrylic 表現を中心にした更新です。ダーク Acrylic とライト Acrylic のアプリテーマを追加し、本物の Windows Acrylic 半透明ウィンドウ素材を利用できるようにし、デスクトップウィンドウをカスタムタイトルバーへ移行しました。

## 追加

- ダーク Acrylic とライト Acrylic の UI テーマを追加しました。
- 対応する Windows 環境ではネイティブ Acrylic ウィンドウ素材を使用し、ウィンドウ背後の内容がシステムのぼかしを通して見えるようになりました。
- アプリアイコン、アプリ名、バージョン番号、最小化、最大化/復元、閉じるボタンを備えたカスタムデスクトップタイトルバーを追加しました。
- カスタムタイトルバーから最小化、最大化/復元、閉じる操作を呼び出すためのデスクトップウィンドウ制御 IPC を追加しました。

## 改善

- タイトルバーとウィンドウ本体が同じ透明 Acrylic 背景を共有するようになり、上部バーとメイン画面の境界が目立ちにくくなりました。
- デスクトップ版の内容スクロールをアプリウィンドウ内部に移し、右側のスクロールバーがウィンドウ外側に貼り付かないようにしました。
- アプリ内スクロール領域に控えめな細いスクロールバーのスタイルを追加し、Chromium overlay scrollbar の挙動を有効化しました。
- Acrylic テーマでのテキスト、ボタン、入力欄、設定ダイアログ、ステータスメッセージ、toast の読みやすさを改善しました。
- Acrylic テーマはアプリのインターフェイスだけに影響し、歌詞カード本体や PNG 書き出しには影響しません。

## 修正

- デスクトップ版が起動時にデフォルトで最大化される問題を修正し、通常のウィンドウサイズで開くようにしました。
- カスタムタイトルバーの閉じるボタンでウィンドウを正しく閉じられない問題を修正しました。
- 最大化後に同じボタンでウィンドウ表示へ戻せない問題を修正しました。通常時のウィンドウサイズを記録し、再クリック時に確実に復元します。
- Windows 以外、または Acrylic 非対応の Windows では、クラッシュせず読みやすい透明インターフェイスにフォールバックします。

## 検証

- 2 つの Acrylic テーマが「設定 → 外観 → UI テーマ」に表示されることを確認しました。
- 通常テーマに戻すと Acrylic ウィンドウ素材が無効になることを確認しました。
- デスクトップ開発版が正常に起動し、ページを返すことを確認しました。
- `npm run typecheck`、`npm run core:test`、`npm run build`、`npm run desktop:build` を実行しました。
