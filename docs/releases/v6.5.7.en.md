# Lyrics Card Generator v6.5.7 Release notes

Release date：2026-09-26

v6.5.7 refines credits on instrumental and no-lyrics cards, bringing the sharer and project signature into a clear hierarchy beneath the song information.

## Instrumental sharing layout

- Lock no-lyrics sharing to portrait mode, with every cover above the song information and both credit rows centered below it.
- Reduce the project signature size, remove italics from instrumental credits, and refine the spacing between credit rows and song information.
- Size artwork using the actual height of metadata and credits. Reduce unusually long multiline titles within a bounded size range to retain space for the cover, and collapse unused spacing when credits are disabled or the sharer is blank.
