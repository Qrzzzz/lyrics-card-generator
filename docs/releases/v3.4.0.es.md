# Notas de la versión Lyrics Card Generator v3.4.0

Fecha de lanzamiento: 2026-06-28

v3.4.0 reorganiza el paso Diseño alrededor del tipo de contenido y convierte la cuadrícula de fondo en una opción configurable dentro de Detalles visuales.

## Cambios

- El paso Diseño ahora pide primero el tipo de contenido y después muestra las opciones disponibles de diseño, tamaño y tipografía.
- Las tarjetas instrumentales / sin letra ahora quedan bloqueadas en salida vertical 1:1 para mantener estables la portada y la información de la canción.
- Se eliminó del paso Diseño el campo de descripción instrumental que no tenía efecto útil.
- La cuadrícula de fondo ahora está desactivada por defecto y está disponible en Detalles visuales con densidades Espaciada / Media / Densa.

## Correcciones

- Se corrigió un problema por el que el modo instrumental / sin letra aún permitía seleccionar tarjetas horizontales.
- Se corrigió un problema por el que el modo instrumental / sin letra aún permitía usar tamaños de lienzo no cuadrados incompatibles.
- Se corrigió la cuadrícula de fondo excesivamente densa de la versión anterior.

## Validación

- Se verificó que el modo instrumental / sin letra cambia inmediatamente a vertical 1:1.
- Se verificó que el botón horizontal queda atenuado y desactivado en modo instrumental / sin letra.
- Se verificó que la cuadrícula de fondo está desactivada por defecto y permite cambiar entre los tres niveles de densidad al activarla.
- Se ejecutaron `npm run typecheck`, `npm run core:test` y `npm run build`.
