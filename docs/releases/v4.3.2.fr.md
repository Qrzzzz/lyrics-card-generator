# Notes de version de Lyrics Card Generator v4.3.2

Date de publication : 2026-07-06

Cette version affine la zone du titre, améliore le badge Explicit et donne à la pochette verticale et aux informations du morceau un centre visuel plus stable.

## Principales nouveautés

- Le badge Explicit est reconstruit comme une forme SVG unique, sans dépendre d'un glyphe `E` rendu par une police.
- Le badge Explicit utilise désormais `currentColor` avec une opacité extérieure, et un E géométrique est découpé par un masque SVG pour éviter toute lettre noire pleine.
- La taille, la position verticale et l'espacement du badge par rapport au titre ont été ajustés pour mieux suivre l'axe central du titre.
- La pochette d'album en mode vertical est agrandie et son rayon d'angle est ajusté proportionnellement.
- Le bloc d'informations du morceau en mode vertical utilise la même hauteur minimale que la pochette et se centre verticalement, afin que le titre, l'artiste et l'album se rapprochent de l'axe de la pochette.
- Les tailles de police, hauteurs de ligne et espacements du header existants restent inchangés afin de limiter les risques de régression de mise en page.

## Vérification

- npm run typecheck
- npm run core:test
- npm run build
- Chargement de l'exemple `opposite` dans le navigateur et export PNG pour confirmer que le badge Explicit et l'alignement du header vertical sont identiques entre aperçu et export.
