# Lyrics Card Generator v5.6.0 發行說明

發行日期：2026-07-15

v5.6.0 重製「歌詞範例」的外層框架，修正視窗邊緣漸層，並將第一步「手動調整」升級為可儲存或取消草稿的雙向滑動編輯流程。範例卡片本身以及其他編輯、匯入與匯出功能皆維持不變。

## 歌詞範例框架

- 「歌詞範例」現在沿用「設定」畫面的頂部標題列結構，並將關閉按鈕移至右上角。
- 頁面底部原有的「歌詞卡片生成器」大型標題框架與關閉入口已移除，範例內容改用獨立捲動區域。
- 內部範例卡片的內容、呈現與選取匯入行為維持不變。

## 視窗邊緣漸層

- 修正標題列單層視窗邊緣漸層的重複遮罩，避免模糊與遮罩在邊緣過早衰減。
- 模糊層與主題遮罩現在共用一層完整的漸隱範圍，並繼續支援深色、淺色與壓克力介面。
- 「歌詞範例」底部沿用同一效果的反向版本，讓捲動內容與視窗邊緣自然銜接。

## 手動調整

- 開啟「手動調整」時，既有歌曲資訊預覽向左滑動並淡出，編輯頁面由右側滑入並淡入。
- 編輯內容會先保存在獨立草稿中；「儲存」會套用草稿，「取消」會捨棄草稿，編輯期間不會直接覆寫目前的歌曲資訊。
- 儲存或取消後，編輯頁面會以相反動畫退出，歌曲資訊預覽則由左側恢復。

## 開發週期備註

- GitHub Actions 目前提示部分固定 SHA 的 action 仍以 Node.js 20 為目標，並由 runner 強制使用 Node.js 24。
- 此提示留待 5.6.0 開發週期內獨立評估；本次介面更新未修改 workflow 或固定 SHA，也不表示該提示已解決。
