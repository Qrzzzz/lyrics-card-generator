# Lyrics Card Generator v5.12.0

> 状态：已通过 GitHub Releases 公开发布。

## 本地 M4A 解析

- 本地音频上传现已在 MP3、FLAC 之外支持 M4A，可从文件中读取标题、歌手、专辑、封面和内嵌歌词；没有内嵌歌词时仍会保留已读取的歌曲信息供手动编辑。
- 支持浏览器和 Windows 常见的 `audio/mp4`、`audio/m4a` 与 `audio/x-m4a` 类型，并沿用现有的 100 MB 文件限制、受限 multipart 读取与解析失败保护。
- Windows 桌面版的导入历史可记录成功提交的 M4A 文件，并支持重新导入和文件重新定位；历史仍只保存必要的路径与元数据，不保存音频内容。
