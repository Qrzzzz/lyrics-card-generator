# Lyrics Card Generator v5.5.4 发布说明

发布日期：2026-07-15

v5.5.4 加固本地应用的变更请求边界，统一整理六种语言的产品文案，并沿用稳定的共享发布工作流。现有编辑、导入、翻译、导出与桌面交互保持不变。

## 请求边界

- 本地应用的 POST 路由统一检查同源、应用请求标记和预期内容格式。
- 不符合边界要求的 AI 请求会在访问上游服务前停止；合法的同源 JSON 请求保持原有行为。
- 自定义 AI Base URL 继续支持 `http://127.0.0.1`、`localhost` 和 IPv6 loopback 服务；模型、API Key、流式响应、取消、Reasoning 与错误处理语义不变。

## 六语言文案

- 简体中文、繁體中文、English、Français、日本語和 Español 的主界面、设置、AI、错误提示及导入/导出文案经过统一整理。
- 法语、日语和西班牙语设置项不再直接沿用英文；繁体中文关键流程改用台湾常用表达。
- Web Lite 现已支持全部六种语言，并接入语言选择、浏览器检测和本地偏好保存。
- 固定水印、AI 实时状态、即时保存设置的关闭操作、更新提示以及 API / 桌面错误均使用本地化文案或稳定错误码映射。

## 发布与验证

- CI 与发布继续使用统一的 `.github/workflows/release.yml`，避免复制版本专属工作流。
- 已覆盖 Web Lite 构建与漂移检查、类型与代码检查、稳定性与覆盖率、核心回归、桌面构建与交互、最终制品 smoke 以及请求边界和六语言完整性测试。
