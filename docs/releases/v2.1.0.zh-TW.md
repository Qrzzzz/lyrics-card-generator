# Lyrics Card Generator v2.1.0 發布說明

語言：[简体中文](./v2.1.0.zh-CN.md) · 繁體中文 · [English](./v2.1.0.en.md) · [Français](./v2.1.0.fr.md) · [日本語](./v2.1.0.ja.md) · [Español](./v2.1.0.es.md)

## 下載與安裝

請在 GitHub Releases 下載對應資產：

- 安裝版：`Lyrics Card Generator Setup 2.1.0.exe`
- 免安裝便攜版：`Lyrics Card Generator-2.1.0-portable.exe`

一般使用者建議使用安裝版；如果只是臨時試用、測試，或想放在隨身碟中使用，可以選擇便攜版。

> 目前版本尚未進行程式碼簽章。Windows 可能顯示 SmartScreen 提示，這是未簽章個人應用程式常見現象。

## 本次更新

v2.1.0 重點強化桌面端體驗、橫版排版、自訂尺寸、多語言介面和本機素材處理能力。

### 新增

- 新增 Windows 桌面應用程式打包流程。
- 新增安裝版和便攜版兩種分發形式。
- 新增本機 MP3 / FLAC 解析，嘗試讀取標題、藝人、專輯、封面和內嵌歌詞。
- 新增 Windows 系統字型讀取和自訂字型選擇。
- 新增簡體中文、繁體中文、英文、法語、日語、西班牙語介面切換。
- 新增從 GitHub Releases 檢查更新的入口。

### 改進

- 重構橫版佈局，基於安全區域、封面欄、內容欄和底部資訊區進行排版。
- 直版自訂尺寸支援基於真實 DOM 測量的自動高度。
- 歌詞原文與譯文排版更穩定，支援按目前介面語言拆分原文 / 譯文。
- 遠端封面匯出改用圖片代理，降低 PNG 匯出時的跨域失敗機率。
- 平台 Logo 改為本機 SVG 資源，匯出時不依賴遠端圖示。

### 修復

- 修復部分自訂尺寸下內容溢出或留白異常的問題。
- 修復橫版卡片中封面、歌詞和底部資訊互相擠壓的問題。
- 修復部分遠端封面在匯出時無法被正確寫入 PNG 的問題。

## 升級注意事項

- 從舊版本升級通常不需要解除安裝。
- 如果安裝版無法覆蓋安裝，可以先退出舊版本，再重新執行安裝程式。
- 如果便攜版無法啟動，建議確認舊行程是否仍在背景執行。

## 已知限制

- 音樂平台連結解析、遠端封面載入、自動歌詞取得、檢查更新需要網路連線。
- 自動歌詞取得仍為實驗性功能，結果可能不完整或不準確，請自行確認使用權限。
- 目前版本未程式碼簽章，Windows SmartScreen 提示不代表程式一定有風險。
