# Notas de la versión 5.5.3 de Lyrics Card Generator

Fecha de lanzamiento: 2026-07-14

La versión 5.5.3 mejora la selección de fuentes, la barra de título de escritorio, la navegación del paso 1 y la legibilidad de Acrílico claro, sin cambiar el comportamiento existente de edición y exportación.

## Principales novedades

- En el paso 4, las tarjetas Source Han Sans y Source Han Serif usan su fuente OTF local correspondiente en toda la tarjeta, incluidos el nombre del esquema, la fuente, la descripción y el estado seleccionado.
- La barra de título de 48 px usa ahora un desenfoque gradual ligero en una región superior con desvanecimiento de 144 px; los degradados de color siguen adaptándose a los modos oscuro, claro y a ambos modos Acrílico.
- Ajuste manual se sitúa justo antes de Siguiente en el paso 1. El panel de información ya no duplica el botón y el estado de expansión, la región controlada y el ID estable quedan completamente relacionados.
- Acrílico claro refuerza las máscaras blancas de paneles, campos, botones y superficies elevadas, usa texto auxiliar pizarra opaco y corrige los controles segmentados de los temas claros.

## Legibilidad y compatibilidad

- Una matriz de contraste cubre fondos de Windows gris oscuro, gris medio y claros: el texto pequeño alcanza al menos 4,5:1 y los límites importantes de campos y botones al menos 3:1.
- Se conservan la transparencia, el desenfoque y la profundidad visible del material en lugar de convertir la interfaz en un tema blanco sólido.
- Acrílico oscuro mantiene sus paneles transparentes, texto claro y material nativo de ventana.

## Verificación

- `npm run typecheck` / `npm run lint` / `npm run core:test` / `npm run build`
- `npm run desktop:pack` / `npm run desktop:interaction-test`
- Inspección visual de capturas reales de escritorio Windows en Acrílico claro y oscuro
