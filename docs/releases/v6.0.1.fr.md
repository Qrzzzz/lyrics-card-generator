# Lyrics Card Generator v6.0.1

> Statut : publication publique via GitHub Releases.

## Boîtes de dialogue système Electron natives

- L’application Windows affiche désormais six messages dans des boîtes de dialogue système Electron natives : remplacement du morceau, écrasement de la traduction, effacement ou réduction de l’historique, échec de vérification de l’historique et échec d’enregistrement à la fermeture.
- Les confirmations utilisent l’icône d’avertissement du système et les échecs son icône d’erreur, sans ressource graphique supplémentaire.
- Les titres, détails et boutons prennent entièrement en charge le chinois simplifié et traditionnel, l’anglais, le français, le japonais et l’espagnol.

## Sécurité et compatibilité

- Les actions destructives sélectionnent Annuler par défaut ; fermer la boîte ou appuyer sur Échap annule également l’opération.
- Les paramètres sont validés dans le rendu, le preload et le processus principal ; seuls des champs primitifs bornés traversent contextBridge.
- Web Lite et les navigateurs ordinaires conservent un repli compatible sans changement fonctionnel.
