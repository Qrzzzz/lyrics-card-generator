# Lyrics Card Generator v6.4.0

Windows x64: `Lyrics.Card.Generator.Setup.6.4.0.exe`.

## New Smiley Sans font preset

- Select Smiley Sans in the desktop app and Web Lite for lyric-card previews and exports.
- Uses the font bundled in the previous release, with no extra installation; the desktop selection is saved and restored with card settings.
