# Lyrics Card Generator v6.7.2 リリースノート

公開日：2026-10-12。

v6.7.2 は通常の選択項目を左側の名称と右側の折りたたみ式選択欄に整理し、同じ位置での開閉アニメーションを調整します。

## 選択と操作

- 文字色、サイズ、配置、書き出しの項目は現在の値だけを表示します。クリックすると選択欄の位置に縦型リストが開き、選択後に閉じます。コンテンツ種類、レイアウト、背景モードは横並びを維持します。
- リスト表示中は元の選択欄を隠し、現在の値が重複しないようにします。角丸、背景、アクセントカラーを画面に合わせ、ウィンドウ端では開く方向を調整します。
- 開閉には控えめな動きを使い、閉じ始めたリストはすぐ入力を受け付けなくなります。動きを減らす設定では状態を直接切り替えます。
- 矢印キー、Home、End、Enter、Esc に対応します。選択後はフォーカスを戻し、外側のクリックや Tab で閉じます。無効な項目はキーボード操作で飛ばします。
- 横並び選択の強調表示のずれを修正し、文字色の見出しの重複を解消します。
