# Lyrics Card Generator v5.5.2 发布说明

发布日期：2026-07-14

v5.5.2 调整前两步的桌面工作流，让歌曲导入层级更清楚，并减少长歌词编辑工作台中过多的嵌套边框。

## 主要更新

- 第一步将网易云音乐搜索保留在左侧上方；歌曲链接解析与本地音频解析移动到搜索下方，并在空间足够时横向并排。
- 右侧独立展示专辑封面、歌曲名、歌手名和专辑名，仍可展开手动编辑歌曲信息。
- 第一步不再渲染不可用的“上一步”按钮；后续步骤的“上一步”和“下一步”行为保持不变。
- 第二步移除整个歌词工作台的外框，以及摘要、歌词文档、编辑工具三栏各自的外框。
- 宽屏下仅在相邻栏位之间保留 1 像素竖向分隔线；窄屏堆叠时自动改为 1 像素横向分隔线。

## 版本范围

- 搜索、链接解析、本地音频解析、手动歌曲信息、歌词编辑和导出逻辑均保持原有行为。
- 输入框、状态提示、歌词统计和动态工具面板仍保留必要的局部边界，不受外层扁平化影响。
- 桌面版与 Web Lite 共用的步骤导航会一致隐藏第一步的无效返回按钮。

- `npm run web-lite:build` / `npm run web-lite:check` / `npm run web-lite:smoke`
