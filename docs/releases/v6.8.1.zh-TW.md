# Lyrics Card Generator v6.8.1

**2026-10-22**

v6.8.1 聚焦內容保護、輸出失敗復原、視窗與緊湊版面，以及清楚的編輯狀態。核心範圍為 #229、#230、#231、#232、#233、#235、#237、#238，另包含 #240 六語言設定文案整理。

- 切換純音樂模式時隱藏譯文而不刪除；清除歌曲、封面、原文與譯文前要求確認，取消保留內容，儲存失敗仍會阻止清除。
- 匯出或複製失敗後保留錯誤與重試入口，重試沿用輸出交易保護，不改變內容。
- 視窗依顯示器邏輯工作區設定初始、最小及還原邊界，顯示器或顯示參數變更後重新約束。強制色彩下紅綠燈按鈕具有可辨識圖形與邊界。
- 緊湊視窗先顯示設定及任務操作，再顯示預覽；步驟導航區分目前與已造訪狀態，不再以位置表示檢查完成。原文與譯文有持續可見的欄頭及活動欄提示。
- 設定文案改用字型名稱與推理過程等使用者術語，金鑰儲存說明依桌面或瀏覽器顯示，保留安全、隱私與計費告知。

已通過 Windows 實際深淺高對比、1366×768／125%、1920×1080／150%、原生分割畫面及執行中 DPI 切換檢查。#232 的跨螢幕移動仍待雙螢幕實機驗收，維持未完成；瀏覽器模擬與幾何單元測試不可替代。詳見[本機候選驗收記錄](../acceptance/v6.8.1.md)。#239 精確數值輸入留待後續。
