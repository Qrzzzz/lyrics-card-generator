# Lyrics Card Generator v6.1.0

> Status: publicly released through GitHub Releases.

## Native Electron font picker window

- The Windows desktop app moves custom font selection out of the in-app overlay and into a native Electron child window with an operating-system title bar.
- Search, recommendations, the complete system-font list, and per-font samples remain available, with a larger preview that follows hover and keyboard focus.
- A selection still updates only the custom-scheme draft and the real lyric-card preview; Save as Current Scheme remains the commit point.

## Security and compatibility

- The font window has a separate minimal IPC identity and cannot use the main window's file, history, or AI privileges.
- Web Lite and regular browsers retain a compatible in-app fallback.
