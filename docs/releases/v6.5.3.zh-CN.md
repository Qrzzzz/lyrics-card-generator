# Lyrics Card Generator v6.5.3 发布说明

发布日期：2026-09-18

v6.5.3 修复浅色背景下 Explicit 标记不可见的问题，让标记跟随卡片文字颜色，横版、竖版及导出保持一致。

## 修复

- 选择白色纯色背景并使用自动文字颜色时，Explicit 标记现在随标题显示为黑色；深色背景下仍显示为白色。
- 单行、多行标题与横竖版共用一致的标记颜色。关闭 Explicit 后不显示标记，原有形状、尺寸和无障碍标签保持不变。
