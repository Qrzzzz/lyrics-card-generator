# Lyrics Card Generator v5.12.1

> Status: publicly released through GitHub Releases.

## Keep only selected text

- A new lightly accented “Keep selection” command now appears first in the Step 2 toolbar. It remains disabled until text is selected.
- Selecting text in either the original or translation column and running the command keeps the exact selected characters while removing everything else from the active column. The other column is left unchanged.
- The command uses the existing selection restoration and undo/redo history. The retained text remains selected afterward, ready for further editing or an immediate undo.
