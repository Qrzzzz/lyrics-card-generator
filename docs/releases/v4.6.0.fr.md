# Notes de version de Lyrics Card Generator v4.6.0

> [!WARNING]
> La version `v4.6.0` contient un bug grave non corrigé. La mise à jour vers cette version est déconseillée.

Date de publication : 2026-07-11

Cette version reconstruit le système de prompts de traduction afin de gérer séparément les règles de sortie strictes, les styles par défaut et les styles personnalisés, tout en exigeant que l’IA ne renvoie que les paroles traduites.

## Principales nouveautés

- Les réglages IA proposent désormais deux pages : Configuration API et Bibliothèque de prompts, avec navigation Retour, Suivant et chemin cliquable inspirée d’un explorateur de fichiers.
- Recommandée est l’unique préréglage protégé et reste toujours disponible. Les cinq autres peuvent être renommés, modifiés, supprimés, réinitialisés ou restaurés.
- Deux préréglages personnalisés au maximum peuvent être créés, chacun avec un titre et un prompt de style, soit huit préréglages au total.
- Sur le panneau principal, les préréglages personnalisés restent repliés par défaut et deux éléments au maximum sont affichés après ouverture.
- Les règles de format strictes restent communes à tous les préréglages. Deux confirmations sont requises avant modification et une réinitialisation vers les valeurs de la v4.6.0 reste disponible.
- Les anciens réglages IA sont migrés automatiquement. Un style personnalisé remplace uniquement le module de style, sans supprimer les règles communes de sortie.

## Vérification

- npm run typecheck
- npm run core:test
- npm run build
- Vérification de cohérence des versions, noms de fichiers, liens de langue et entrées de notes dans les six langues
