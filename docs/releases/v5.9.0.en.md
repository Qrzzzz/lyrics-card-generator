# Lyrics Card Generator v5.9.0 Release Notes

Release date: 2026-07-31

v5.9.0 adds import and parsing history to the Windows desktop app so successfully parsed songs and saved covers can be imported again. This is not lyric autosave or document version history.

## Desktop import and parsing history

- A History action now sits between Lyric Examples and Clear Content. The full-screen history view supports search, source filters, paged loading, individual deletion, and clearing all history.
- History is written only after a link parse, selected song-search result, local MP3／FLAC parse, or uploaded local cover is successfully committed. Failures, cancellations, built-in examples, ordinary edits, clearing, and exports are not recorded.
- Cards show the song, source, import time, and file name or domain. Reimporting uses the existing document-replacement confirmation; remote failures and missing local files leave the current document unchanged.
- A moved local file can be relocated. If its size or modification time changed, the app gives a light notice and parses the current file.

## Secure storage and retention

- The Electron main process serializes atomic writes to schema-versioned UTF-8 JSON. A damaged file is kept as a timestamped backup before a fresh history is created.
- Records contain only the minimum replay source and display text. Image binaries, Base64, blob URLs, exported images, palettes, and styles are never stored; a remote cover is stored only as a URL.
- The renderer submits only a history record ID for replay. The main process retains, validates, and reads local paths, which are registered safely through Electron 42 `webUtils.getPathForFile`.
- The same platform song, normalized link, or local path updates the existing card and moves it to the front. Settings → General offers limits of 5, 10 (default), or Unlimited; lowering the limit requires confirmation before least-recently-used items are trimmed.

## Scope and verification

- New interface copy is complete in Simplified Chinese, Traditional Chinese, English, French, Japanese, and Spanish.
- Web Lite keeps its existing interface and behavior and has no browser-side history substitute.
- Pure store, secure IPC, settings migration, packaging, and real Electron interaction regressions cover persistence, deduplication, limits, replay, changed／missing／relocated files, and write-failure semantics.
