# Lyrics Card Generator v3.9.1 發布說明

發布日期：2026-07-01

v3.9.1 修復桌面端視窗圓角，並更新自繪標題列版面。非 Acrylic 主題改用 Windows 原生圓角裁切，桌面背景、標題列漸層與噪聲層仍限制在應用外殼內繪製，匯出的歌詞卡片 PNG 不受影響。

## 桌面視窗圓角

- 非 Acrylic 主題不再依賴透明 CSS 外殼偽裝圓角，改由原生 Windows 視窗邊界裁切。
- Acrylic 主題繼續使用 Windows 原生 Acrylic 材質，同時保持透明視窗背景。
- 應用背景層從固定定位改為外殼內絕對定位，使圖片背景、動態專輯背景與純色背景都受圓角裁切。

## 標題列

- 自繪標題列改為左側紅、黃、綠視窗控制按鈕，分別用於關閉、最小化與最大化/還原。
- 軟體名稱與版本號保留在左側控制按鈕之後，右側不再顯示小應用圖示。
- 標題列仍支援拖動視窗，控制按鈕區域保持不可拖動，點擊行為更穩定。

## 匯出與 Web 版

- Web 瀏覽器執行時仍不顯示桌面標題列，也不會保留桌面端頂部空白。
- 匯出 PNG 路徑不包含桌面標題列、視窗邊框、視窗外殼或 Electron 桌面 API。

## 驗證

- npm run typecheck
- npm run core:test
- npm run build
