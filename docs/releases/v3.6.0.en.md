# Lyrics Card Generator v3.6.0 Release Notes

Release date: 2026-06-29

v3.6.0 focuses on the Windows desktop Acrylic experience: it adds Dark Acrylic and Light Acrylic app themes, connects the desktop window to the real Windows Acrylic translucent material, and upgrades the desktop window to a custom title bar.

## Added

- Added Dark Acrylic and Light Acrylic UI themes.
- The Windows desktop app uses the native Acrylic window material on supported systems, so content behind the window appears through the system blur.
- Added a custom desktop title bar with the app icon, app name, version number, and the minimize, maximize/restore, and close buttons.
- Added desktop window-control IPC so the custom title bar can minimize, maximize/restore, and close the window.

## Improved

- The title bar and window body now share the same transparent Acrylic background, reducing the visible boundary between the top bar and the main interface.
- Desktop content now scrolls inside the app window, so the right scrollbar no longer sits outside the window surface.
- Added a cleaner thin scrollbar style for in-app scroll areas and enabled Chromium overlay scrollbar behavior.
- Improved readability for text, buttons, inputs, settings dialogs, status messages, and toast messages under Acrylic themes.
- Acrylic themes affect only the app interface, not the lyric card itself or PNG exports.

## Fixed

- Fixed the desktop app opening maximized by default; it now opens at the normal window size.
- Fixed the custom title bar close button not closing the window correctly.
- Fixed the maximize button being unable to restore the window after maximizing; the app now records the normal window bounds and restores them reliably.
- Non-Windows systems and unsupported Windows versions fall back to a readable transparent interface without crashing.

## Validation

- Verified that both Acrylic themes appear under Settings → Appearance → UI theme.
- Verified that switching back to a regular theme disables the Acrylic window material.
- Verified that the desktop development app starts normally and returns the page.
- Ran `npm run typecheck`, `npm run core:test`, `npm run build`, and `npm run desktop:build`.
