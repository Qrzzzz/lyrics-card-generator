# Lyrics Card Generator v3.0.0 Release Notes

Release date: 2026-06-20

## Overview

v3.0.0 adds AI lyric translation and a unified settings center. For English users, the translation output is English; it is not hard-coded to Chinese.

## Downloads

- Installer: `Lyrics Card Generator Setup 3.0.0.exe`
- Portable: `Lyrics Card Generator-3.0.0-portable.exe`
- Blockmap: `Lyrics Card Generator Setup 3.0.0.exe.blockmap`

## What's New

### AI Lyric Translation

- Added an AI translation entry point in the lyric editor.
- After choosing a style, the app can generate English lyric translations.
- Six styles are available: Recommended, Singable, Faithful, Spoken, Imagistic, and Restrained.
- The target language follows the current interface language.
- Streaming output, process display, cancellation, and error feedback are supported.

### Settings Center

- Added a unified settings dialog.
- Language switching now previews immediately.
- AI translation parameters and connection testing are available in settings.
- Related UI text is available in all six interface languages.

### Export Flow

- The final step now keeps only one primary Finish and Export button.
- The completion animation has been moved to the export panel.
- The button height now matches standard action controls.
- The final navigation area now avoids excessive blank space.

## Validation

```bash
npm run typecheck
npm run core:test
npm run build
npm run desktop:build
```

## Notes

- The Windows build is unsigned, so Windows may show a SmartScreen warning.
- v3.0.0 does not include bundled AI service access.
- Translation quality and speed depend on the service selected by the user.
- When upgrading from v2.x, AI-related settings need to be configured again.
