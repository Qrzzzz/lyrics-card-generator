# Lyrics Card Generator v6.5.10 Release Notes

Release date: 2026-10-02

v6.5.10 improves saving with many drafts, unifies draft style and AI settings validation, and protects data when history exceeds its storage limit.

## Fixes and improvements

- Skip repeated copies for identical drafts and preview-only changes; detect deleted history records with a linear scan.
- Stop loading or saving history JSON files above 64 MiB, preserve existing files and backups, and show recovery guidance. If a save exceeds the limit, delete unneeded drafts in History and retry.
- Use shared validation for draft styles and AI settings. Older drafts retain existing defaults for missing fields; AI requests with incorrect field types are rejected before provider calls.

## Upgrade notes

Drafts are not automatically evicted by record-count limits. If an existing history file exceeds 64 MiB and History cannot open, back up app-data/import-history.json and its .bak copy in the user data directory, then contact the maintainer for recovery.
