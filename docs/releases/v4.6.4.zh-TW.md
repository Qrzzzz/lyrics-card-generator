# Lyrics Card Generator v4.6.4 發布說明

發布日期：2026-07-11

此版本繼續完善 v4.6.2 的設定重設、提示詞資源庫與編輯器預覽體驗，並修正影響全域互動的嚴重問題。

## 主要更新

- 修正提示詞預設重設後所有頁面與文字欄位失去互動的問題；重設不再呼叫會阻塞桌面殼層的原生確認框。
- 嚴格格式規則固定為不可修改的內建安全模組；移除所有解鎖編輯入口，歷史覆寫內容不再參與生成。
- 設定頁新增適用於全部分類與子頁的全域上一頁、下一頁與路徑列，並統一放入左上角頁首。
- 右側真實卡片預覽在編輯頁捲動時固定於頂部；文字設計頁移除獨立字型預覽卡片，字型變更直接顯示在真實卡片上。
- 四張範例歌曲卡片略為縮短，並移除卡片頂部的「專輯」標籤。
- 每個提示詞預設保留「重設」按鈕，可還原各自的初始標題與提示詞。
- 提示詞資源庫首頁保留「全部重設」，同時還原預設、已刪除與自訂預設。
- 自訂預設首次儲存時記錄初始內容；舊資料移轉後安全地以目前內容作為重設基準。
- 精簡提示詞資源庫說明，並將最大化狀態的綠燈提示改為「窗口化」。
- 即時預覽邊框會隨卡片內容自動調整高度，不再於下方保留大片空白。

## 驗證

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:build
