# Lyrics Card Generator v3.7.0 Release Notes

Release date: 2026-06-29

v3.7.0 is a maintenance and stabilization release. It does not add a new layout, theme, music platform, or export behavior. The release focuses on desktop path safety, AI translation error fallback, update-link consistency, stale-code cleanup, and release-check stability.

## Fixes

- Hardened desktop background image ID validation so only app-generated png, jpg, jpeg, webp, and gif filenames are accepted, with traversal and forged values rejected.
- Uses an explicit MIME map when reading background images and does not accept SVG or unknown extensions.
- Improved AI translation fallback for non-standard provider responses, plain-text errors, malformed JSON, and empty bodies so bad responses do not crash the app.
- The ?Open release page? button now consistently opens the GitHub Release page instead of a direct installer asset link.

## Maintenance

- Removed unused legacy CustomFontPanel code while keeping the current FontSchemePanel behavior unchanged.
- Removed stale i18n copy for the old instrumental input while keeping instrumentalText data compatibility and card visuals unchanged.
- Split the v3.6.1-specific release test into a generic release consistency test and a titlebar regression test.
- Added a minimal CI workflow for install, typecheck, core tests, and Web build.

## Verification

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:dev
- npm run desktop:build
