# Lyrics Card Generator v3.7.0 Release Notes

Release date: 2026-06-29

v3.7.0 is a maintenance and stabilization release. It does not add a new layout, theme, music platform, or export behavior. This update focuses on desktop background image path safety, AI translation error fallback, update-entry consistency, stale-code cleanup, and stable release verification.

## Fixes

- Hardened desktop background image `imageId` validation so only app-generated `png`, `jpg`, `jpeg`, `webp`, and `gif` filenames are accepted, with traversal and forged values rejected.
- Background image reads now use an explicit MIME map and do not accept SVG or unknown extensions.
- Improved AI translation fallback for non-standard provider responses, plain-text errors, malformed JSON, and empty bodies so bad responses do not crash the app.
- The “Open release page” button now always opens the matching GitHub Release page instead of a direct installer asset link.

## Maintenance

- Removed unused legacy `CustomFontPanel` code while keeping the current `FontSchemePanel` behavior unchanged.
- Removed stale i18n copy for the old instrumental input while keeping `instrumentalText` compatibility and card visuals unchanged.
- Replaced the `v3.6.1`-specific release test with a generic release consistency test and a titlebar regression test.
- Added a minimal CI workflow for install, typecheck, core tests, and Web build.

## Verification

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:dev
- npm run desktop:build
