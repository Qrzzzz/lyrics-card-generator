# Lyrics Card Generator v5.5.1 リリースノート

リリース日：2026-07-14

v5.5.1 では、新しい縦向きカスタム歌詞カードで自動幅を初期状態から有効にし、内容測定、候補選択、行間の正規化、両エディションの回帰テストを強化しました。

## 主な更新

- 新しい縦向きカスタム歌詞カードは「自動幅」がオンの状態で始まります。オンの間は幅スライダーに結果を表示して操作を無効化し、オフにすると最後の計算幅を保ったまま手動調整できます。
- 行間を 1.5〜2.1、刻み 0.05 に統一し、新しいカードの初期値を 1.8 にしました。従来の範囲外、刻み外、無効な値は安全に正規化されます。
- 非表示の等倍プローブが最終フォントで 720〜1440 の全 37 候補幅を測定します。結果は現在の内容と組版だけで決まり、有効化前の手動幅には左右されません。
- 候補集合が完全で重複のない場合だけ計算します。全体中央値を中心に評価し、同点時も決定的な規則を使うため、不完全な測定で疑わしい幅を書き込みません。
- 原文と翻訳は CJK の書記素、西洋言語の単語、混在テキストの深刻な孤立行を別々に検査します。6 つの内蔵例は Web Lite とデスクトップ版の両方で、最小幅と最大幅のどちらから始めても同じ幅に収束します。
- 内蔵目標幅は Opalite 1380、相反する私 840、勇者 1100、光輝歳月 800、蜜蜂 880、嘘 920 で、描画環境差として ±20 ピクセルを許容します。

## 対象範囲

- 自動幅は引き続き縦向き・カスタムサイズ・歌詞モードだけで利用できます。固定比率、横向き、インストゥルメンタルは従来の動作を維持します。
- `autoWidth` 項目がない旧状態は手動のままとし、保存済みの幅を勝手に置き換えません。
- デスクトップ版と Web Lite は測定、評価、自動高さ連携、書き出し安全機構を共有します。
