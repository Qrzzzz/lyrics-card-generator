# Lyrics Card Generator v6.1.3

> Estado: versión publicada oficialmente.

## Selección de dos fuentes en una sola ventana

- La ventana WinForms nativa de Windows contiene ahora directamente las listas de fuentes CJK y latina, en lugar de abrir un `FontDialog` del sistema distinto para cada rol.
- Ambas listas enumeran las familias del sistema instaladas sin deducir la cobertura lingüística a partir del nombre de la fuente, y se excluyen los alias verticales.
- Las dos selecciones actuales y sus vistas previas permanecen visibles. Cancelar descarta todo el borrador, mientras que «Aplicar combinación» sigue confirmando ambas fuentes de forma atómica con una sola acción.

## Nitidez con DPI alto y compatibilidad

- El auxiliar nativo activa la compatibilidad DPI Per-Monitor V2 antes de crear la interfaz WinForms, lo que impide que Windows estire como mapa de bits una ventana renderizada a 96 DPI.
- El diseño base de 96 DPI se escala de forma nativa según el DPI real de la pantalla de la ventana principal, mejorando la nitidez de controles y texto a escalas como 125 %, 150 % y 175 %.
- El puente nativo conserva la validación acotada de campos, la propiedad mediante el identificador de la ventana principal y el análisis restringido del resultado. La alternativa de escritorio no Windows, el selector del navegador y las reglas de renderizado de tarjetas no cambian.
