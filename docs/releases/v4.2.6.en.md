# Lyrics Card Generator v4.2.6 Release Notes

Release date: 2026-07-03

This version rebuilds the app accent system so interface accent colors now come from one unified global Accent mechanism instead of scattered palette lookups.

## Main Updates

- Added unified accent color settings with album-cover dynamic color, preset colors, and custom hex colors.
- Preset accent colors now include red, orange, yellow, green, blue, and purple.
- Unified the accent source for AI translation buttons, the final export button, Spark Cursor, Stepper, selected controls, and focus states.
- Reworked Appearance settings so interface mode and Acrylic effect are separate settings.
- Album dynamic mode does not support Acrylic yet.
- Added image export quality selection to the final export step.
- Export quality is now Low, Standard, and High.
- Removed Ultra export quality and automatically downgrades old Ultra settings to High.
- Added a multilingual Taylor Swift “Opalite” example song.
- Cleaned up legacy settings fields and background-related copy for future interface theme expansion.

## Compatibility and Migration

- Legacy `uiAccentColor` migrates into the new accent settings and is no longer the primary field.
- Legacy `dark-acrylic` / `light-acrylic` settings migrate into interface mode plus the Acrylic toggle.
- Legacy `ultra` export quality migrates to `high`.
