# Initial Windows desktop release

## Changelog

### Release Overview

This is the first Windows desktop release of Lyrics Card Generator. This release packages the existing Next.js WebUI lyrics card generator into a fully self-contained Windows EXE application. Users do not need to install Node.js, manually start a development server, or deploy the project to Vercel, Netlify, or any cloud services.

The desktop version uses an Electron + Next standalone local server solution: after launch, the application automatically starts a built-in Next server on `127.0.0.1` and loads the local address in the desktop window. All pages and API routes run locally; Apple Music, NetEase Cloud Music, QQ Music, remote covers, and LRCLIB are only data sources and not deployment dependencies.

### Download Options

- Installer: `Lyrics.Card.Generator.Setup.0.1.0.exe`
- Portable: `Lyrics.Card.Generator-0.1.0-portable.exe`

Regular users are advised to use the installer. If you only want to try it temporarily or prefer not to write to an installation directory, you can use the portable version.

### Core Features

- Song link parsing: supports Apple Music, NetEase Cloud Music, and QQ Music links.
- Manual song information input: song title, artist, album, and cover link can be edited manually.
- Lyrics editing: supports manual entry and editing of lyrics.
- Translation editing: supports line-by-line translation text, with the option to show or hide translations.
- Instrumental mode: supports display of lyrics-free or purely instrumental content.
- Cover capabilities: supports remote covers, local cover upload, cover proxy, and cover color extraction.
- Visual styles: supports vertical/horizontal layout, dimensions, auto height, font, font size, line spacing, text color, rounded corners, border, shadow, platform logo, watermark, and contributor text.
- Language switching: supports Chinese and English UI, with language setting persistence.
- PNG export: retains the original DOM-to-PNG export method, default high-definition 2x output, without using Electron screenshots.

### Desktop Experience

- Double-click the EXE to start.
- Opens maximized by default.
- App icon has been uniformly replaced with a new transparent rounded icon, covering installer, portable version, taskbar, window title bar, web favicon, and in-app title area.
- Closing the window automatically shuts down the built-in local service, avoiding leftover background processes.
- External links are opened in the system browser instead of navigating inside the application.

### Offline and Online Notes

Available offline:

- Open the application.
- Manually enter song information.
- Manually edit lyrics and translations.
- Use local covers.
- Adjust card styles.
- Export PNG.

Requires internet:

- Apple Music / NetEase Cloud Music / QQ Music link parsing.
- Loading remote covers.
- Automatic lyrics retrieval via LRCLIB.

### Initial Release Limitations

- This release does not have an auto-update feature.
- This release is not code-signed; Windows may show a SmartScreen warning.
- Both installer and portable versions are built for Windows x64.
- Remote parsing and lyrics retrieval depend on the availability of third-party data sources.
