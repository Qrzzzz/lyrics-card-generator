# Lyrics Card Generator v0.1.0 Release Notes

Release date: 2026-06-16

## Release Positioning

This is the first Windows desktop release of Lyrics Card Generator. It packages the existing Next.js WebUI lyric card generator as a ready-to-run Windows EXE app. Users do not need to install Node.js, manually start a development server, or deploy the project to any cloud platform.

The desktop app uses Electron with a local Next standalone server. When the app starts, it launches a bundled Next service on `127.0.0.1` and loads that local address inside the desktop window. All pages and API routes run locally. Apple Music, NetEase Cloud Music, QQ Music, remote covers, and LRCLIB are data sources only; they are not deployment dependencies.

## Downloads and Installation

- Installer: `Lyrics.Card.Generator.Setup.0.1.0.exe`
- Portable: `Lyrics.Card.Generator-0.1.0-portable.exe`

Most users should choose the installer. Use the portable build if you only want to try the app temporarily or avoid writing to the system application directory.

## Core Features

- Parse links from Apple Music, NetEase Cloud Music, and QQ Music.
- Manually edit song title, artist, album, and cover URL.
- Manually enter and edit lyrics.
- Edit line-by-line translations, with show / hide support.
- Display instrumental or lyric-free tracks.
- Use remote covers, local cover uploads, cover proxying, and cover color extraction.
- Customize portrait / landscape layout, canvas size, auto height, font, font size, line height, text color, radius, frame, shadow, platform logo, watermark, and shared-by text.
- Switch between Chinese and English UI, with local language persistence.
- Export PNG through the existing DOM-to-PNG pipeline, keeping high-quality 2x output.

## Desktop Experience

- Start the app by double-clicking the EXE.
- The window opens maximized by default.
- The app icon is applied to the installer, portable build, taskbar, title bar, Web favicon, and in-app header.
- Closing the window also stops the bundled local service, preventing leftover background processes.
- External links open in the system browser.

## Offline and Online Behavior

Available offline: opening the app, manually entering song metadata, editing lyrics and translations, using a local cover, adjusting card styles, and exporting PNG images.

Requires internet access: Apple Music / NetEase Cloud Music / QQ Music link parsing, remote cover loading, and LRCLIB automatic lyric fetching.

## Initial Limitations

- Auto-update is not supported in this version.
- The Windows build is unsigned, so Windows may show a SmartScreen warning.
- Installer and portable builds are Windows x64.
- Remote parsing and lyric fetching depend on the availability of third-party data sources.
