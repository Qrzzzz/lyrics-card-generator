# Lyrics Card Generator v5.9.7 發布說明

發布日期：2026-08-19

v5.9.7 完整支援不規則專輯封面。封面不再被強制裁成正方形，而會依圖片原始長寬比參與卡片版面，同時讓既有 1:1 封面維持像素級不變。

## 原始比例封面

- 橫式封面保留原正方形封面的標準高度，並依原始比例向左右延伸。
- 直式封面保留原正方形封面的標準寬度，並依原始比例向上下延伸。
- 1:1 封面的尺寸、圓角、位置與周邊排版完全不變；極端長寬比只有碰到畫布安全邊界時才整體等比縮小。
- 所有封面都顯示完整圖片，不裁切、不拉伸，也不以方形舞台補邊。

## 透明封面與全流程一致性

- 透明 PNG／WebP 不再鋪設方形底板，透明區域直接顯示卡片背景，並使用適合透明輪廓的陰影。
- 封面的天然寬高、透明度與取色在同一次圖片解碼中完成，避免預覽與匯出採用不同尺寸。
- 編輯預覽、未縮放匯出、純音樂卡、Web Lite、歌曲資訊、匯入摘要、搜尋結果與歷史縮圖共用同一套比例規則。
- 匯出快照會凍結封面尺寸資訊，並在圖片解碼完成前保持等待，避免切換封面時擷取舊比例或未完成影像。

## 相容性與驗證

- 不變更歌詞文件、匯入歷史或手動存檔格式，不需要遷移使用者資料。
- 已涵蓋 1:1、1200×802 橫式、879×1200 直式、極端比例與透明 PNG；1:1 案例保留原尺寸，長方形案例保留完整原圖。
- v5.9.6 的匯入、解析、AI 翻譯、設定、歷史記錄以及 PNG、WebP、JPG 匯出能力皆繼續保留。

## 發布狀態

v5.9.7 已透過 GitHub Releases 公開發布。標籤原始碼、安裝版、可攜版、SPDX SBOM 與 SHA256SUMS 均可從該發布頁面取得。
