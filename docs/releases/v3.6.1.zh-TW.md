# Lyrics Card Generator v3.6.1 發布說明

發布日期：2026-06-29

v3.6.1 是 v3.6.0 Acrylic 桌面更新後的修復版本，重點修繕自繪標題列的視窗狀態同步、視覺融合、hover 狀態、層級和多語言文案，同時修正目前下載入口。

## 改進

- 標題列加入向下自然消失的漸層玻璃模糊層，讓頂部區域與 Acrylic 視窗材質融合得更自然。
- 標題列層級調整到設定、範例、首次語言選擇和 toast 下方，避免壓住彈窗內容。
- 標題列視窗控制按鈕補齊多語言 `aria-label` 和 `title` 文案，並隨最大化/還原狀態切換。
- 最大化按鈕現在會在視窗最大化後切換為還原圖示。

## 修復

- 修復點擊最大化/還原後前端圖示狀態沒有立即更新的問題。
- 修復系統 Snap、雙擊標題列或原生視窗事件觸發最大化後，標題列按鈕狀態不同步的問題。
- 修復淺色亞克力主題下關閉按鈕 hover 可能不穩定變紅的問題。
- 修復 README 目前版本下載檔名和發布說明入口仍可能指向舊版的問題。
- 歌詞卡片 PNG 匯出邏輯未改動，Acrylic 和標題列不會進入匯出圖片。

## 驗證

- 驗證自繪標題列在桌面環境外不會渲染。
- 驗證標題列按鈕文案可隨目前界面語言變化。
- 驗證 `data-export-card="true"` 的卡片區域不包含桌面標題列。
- 執行 `npm run typecheck`、`npm run core:test`、`npm run build` 和 `npm run desktop:build`。
