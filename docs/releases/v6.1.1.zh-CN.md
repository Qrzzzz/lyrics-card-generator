# Lyrics Card Generator v6.1.1

> 状态：已通过 GitHub Releases 正式发布。

## Windows 系统原生字体对话框

- Windows 桌面版现在直接调用系统自带的 `FontDialog`，不再为字体选择创建 Electron 或 HTML 自绘窗口。
- 系统对话框以 Electron 主窗口句柄作为 owner，保持真正的 Windows 模态关系；同一时间只允许一个对话框，选择或取消后都会恢复主窗口焦点。
- 选中的字体家族仍先更新自定义方案草稿与右侧真实歌词卡预览，只有“保存为当前方案”才会提交更改。

## 可靠性与兼容性

- 原生桥接显式使用 STA，并对窗口句柄、字体名、辅助进程输出与返回值进行边界校验；启动失败会安全回到未选择状态。
- 桌面回归可绑定精确的隔离候选 EXE，避免误测旧的 `release` 构建；原生桥接、IPC 安全与打包清单均有独立契约测试。
- 非 Windows 桌面环境和普通浏览器继续使用现有的应用内回退，Web Lite 的字体选择行为不变。
