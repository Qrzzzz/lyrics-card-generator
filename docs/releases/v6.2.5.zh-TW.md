# Lyrics Card Generator v6.2.5

> 狀態：已發布。

## 輕量專案署名

- 匯出卡片中的 `generated by lyric card generator` 已改為更短的 `Qrzzzz/lyrics-card-generator`，不再使用描述性前綴。
- 署名移除兩側分隔線，改為 400 字重、26px 直式基準字級、30px 橫式縮放基準與 0.02em 字距的單行標準字寬無襯線文字。
- `Qrzzzz` 與 `/lyrics-card-generator` 保持連續顯示，只以 72% 和 52% 的克制透明度差異建立辨識層級，並避免縮放後模糊難讀。

## 頁尾與設定

- 直式頁尾中署名與平台標誌／分享者資訊的間距收斂至 14px；橫式沿用原有 accessories 渲染鏈路並採用等比例的 16px 間距，同時移除版面步驟中冗餘的自動延長說明。
- 編輯器中的「顯示生成水印」改為「顯示專案署名」，應用程式設定中的新卡片預設項目也使用相同語意。
- 現有 `showGeneratedWatermark` 等文件與設定欄位維持不變，不需要移轉設定或歷史文件。

## 下載與升級

- Windows x64 安裝版：`Lyrics.Card.Generator.Setup.6.2.5.exe`。
- 本版本繼續採用僅 Setup 的發佈方式；從舊版本升級不需要移轉設定。
