# Lyrics Card Generator v5.2.1 リリースノート

## 曲リンク解析の復旧

v5.2.1 は Spotify、Apple Music、NetEase Cloud Music、QQ Music の実際の曲リンク解析を復旧し、v5.1.0 と v5.2.0 のネットワーク保護を維持します。

- 数値形式の QQ Music `songDetail` リンクは `songid` を使用し、タイトル、アーティスト、アルバム、カバーを正しく取得します。
- NetEase JSON リクエストの応答形式ネゴシエーションを修正し、曲・アーティスト・アルバムの完全なメタデータを復元しました。
- Apple Music ページがホームへ転送されても元のトラック ID を使用し、有効な曲リンクを返します。
- Spotify の曲リンクは引き続き利用でき、4 プラットフォームすべてを実リンク回帰テストで確認します。

## セキュリティと互換性

- ホップ単位の URL/DNS 検証、リダイレクト再検証、応答サイズ・形式制限、複数アドレス IPv6/IPv4 fallback を維持します。
- 歌詞カード出力、プロジェクトデータ形式、既存のビジュアル方向は変更していません。
- Windows x64 Setup と portable を v5.2.1 として再ビルドしました。
