# Lyrics Card Generator v6.2.4

> 状态：已发布。

## 设置可靠性与信息架构

- 应用偏好和 AI 设置保存失败后会在设置页之外持续显示本地化提示，并提供明确的重试状态；关闭设置时也不会静默丢失失败信息。
- “卡片与导出”分别管理新建卡片的页脚默认值和文件导出默认值。软件水印、分享者及其文本只在真正新建卡片时应用，不会覆盖当前文档；清空内容仍保留当前视觉设置。
- AI 工作区将连接配置、翻译默认值和提示词库分层展示，并在首次进入 AI 分类时才加载数据，同时保留已打开页面的本地状态。

## 安全、历史与存储

- 新增安全的 AI 连接测试：不发送歌词或用户内容，执行严格超时与资源上限，支持取消，并会在触达服务商前拒绝不安全或恶意 Base URL。
- 自动导入历史新增“不保留”，不影响用户显式保存的手动归档。应用偏好重置仅恢复界面、外观与导出默认值，不会清除当前文档、历史、手动归档或 AI API Key。
- 清理了不可达的旧独立背景设置与桌面桥接；当前有效的专辑动态应用背景、旧设置迁移兼容性及 Web Lite 行为保持不变。

## 可访问性、字体与许可

- 修正设置标题层级、分组名称、输入标签与错误关联，并改善移动端导航 landmark、历史导航和最小窗口布局。
- 原始 CSS 字体设置新增系统默认恢复、输入净化、校验及可访问错误提示；提示词库统计现在会区分受保护、可编辑和自定义预设。
- 关于页新增离线可用的软件 Source Available License 与随包思源字体等第三方许可入口，桌面版和 Web Lite 均可访问。

## 下载与升级

- Windows x64 安装版：`Lyrics.Card.Generator.Setup.6.2.4.exe`。
- 本版本继续采用 Setup-only 发布方式；从旧版本升级无需迁移配置。
