# Lyrics Card Generator v5.2.3 リリースノート

## リリース検証の修正

v5.2.3 は、v5.2.2 の公開処理で最後のアセット再ダウンロード検証が失敗する問題を修正します。

- 同じタグに公開済み Release と下書き Release が共存しても、誤った Release を指す可能性があるタグ経由ではアセットを取得しません。
- ワークフローは作成した下書きの一意な Release ID を記録し、その ID で同じアセット一式をダウンロード、検証、公開します。
- 公開前に Setup、ポータブル版、SPDX SBOM、SHA256SUMS、ファイルダイジェスト、GitHub attestation を厳密に確認します。
- 同じタグの公開済み Release がある場合は早期に停止し、再実行時は同じタグの残存下書きだけを削除して、不完全または重複した Release が成功扱いになることを防ぎます。

## リリース範囲

- アプリの機能、インターフェース動作、歌詞カード出力、プロジェクトデータ形式は v5.2.2 から変更していません。
- 本リリースは公開処理とサプライチェーン検証のみを修正し、完全に検証した Windows 成果物を再生成します。
