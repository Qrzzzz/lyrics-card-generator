# Lyrics Card Generator v5.7.0 Release Notes

Release date: 2026-07-16

v5.7.0 rebuilds the desktop editor's six-step flow. Steps 3–5 now let you resize settings and live preview for the task at hand, while settings groups compact themselves from their actual container width. PNG, WebP, and JPG export remain available across Desktop and Web Lite.

## Adjustable settings and preview workbench

- A vertical divider on steps 3–5 continuously expands settings from one half to at most two thirds of the workbench.
- On smaller desktop windows, the upper bound tightens automatically to preserve at least 360 px for preview. Layouts below 1024 px keep the existing vertical stack.
- The divider supports pointer drag, arrow-key adjustment, Home/End, and double-click reset to 1:1, with percentage semantics for assistive technology.
- The step 5→6 pan keeps one preview instance mounted and translates by the measured settings width instead of assuming equal columns.

## Container-driven compact layout

- Layout, typography, and visual-detail groups derive their columns from the real settings-pane width instead of only viewport breakpoints.
- Ordinary layout rows can move from one to two columns. The visual toggle group can compact from two columns and four rows to three columns and three rows.
- Conditional panels and dependent text fields continue to span the full row, while DOM and keyboard order stay unchanged.
- Toggle controls use minimum rather than fixed height so longer localized labels can wrap without clipping.

## Main editor, preview, and export

- All six desktop editing steps share the compact Stepper and top action area, keeping song import, lyrics, settings, preview, and export at one hierarchy.
- Live preview remeasures after pane resizing, window resizing, and example imports, with lightweight pressure feedback on supported pointer devices.
- Desktop and Web Lite can export PNG, WebP, or JPG per transaction. The default format is saved in settings, and the filename extension matches the encoded image.
