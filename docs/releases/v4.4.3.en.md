# Lyrics Card Generator v4.4.3 Release Notes

Release date: 2026-07-10

This release focuses on interaction consistency across the Settings Wing and app buttons. The existing editor, lyric examples, and settings surface architecture remains intact while small-screen navigation, AI save feedback, spatial transitions, and several visual details are corrected.

## Main Updates

- Added a shared 1px hover lift to most buttons through the existing motion system. Shared controls retain spring motion, native buttons use the same duration and easing, and reduced-motion preferences are respected throughout.
- Below 720px, settings categories now use ordinary disclosure/list semantics instead of an incomplete `menu` model. Closing Settings always collapses the list, so reopening never restores a stale expanded state.
- While the category list is open, the first Escape closes only the list, stops the Settings close handler, and returns focus to the trigger. A second Escape then closes the Settings Wing.
- AI settings now expose four explicit save states: `saved`, `pending`, `saving`, and `error`. Changes immediately report pending status, and failures remain visible instead of reverting to a green “Settings saved” message.
- The existing 700ms deferred AI save and close-time flush are preserved, with sequential save queuing to prevent older requests from overwriting newer interface state.
- Removed the post-Examples guard on opening Settings so closing the lyric examples surface reliably leads into the Settings Wing’s horizontal transition.
- The Settings Wing outer layer is now transparent and sits directly on the app background. Default export quality uses the existing three-way segmented slider, window clipping uses one 8px corner radius, and the Examples close button has a neutral accent treatment.
- Expanded regression coverage for Settings, motion, the title bar, and release consistency. Pending and failed save labels are localized across all six interface languages.
