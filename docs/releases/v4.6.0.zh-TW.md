# Lyrics Card Generator v4.6.0 發布說明

> [!WARNING]
> 此版本 `v4.6.0` 存在尚未修復的嚴重 Bug，不建議更新至此版本。

發布日期：2026-07-11

此版本重構 AI 歌詞翻譯的提示詞系統，讓固定格式要求、預設風格與使用者自訂風格可分開管理，同時維持 AI 只輸出譯文原文的嚴格限制。

## 主要更新

- AI 設定拆分為「API 設定」與「提示詞資源庫」兩個子頁面，並加入類似檔案總管的上一頁、下一頁及可點擊路徑導覽。
- 推薦版是唯一固定且永遠保留的預設；其餘 5 個預設可編輯標題與風格提示詞，也可刪除、重設或還原。
- 最多可新增 2 個自訂預設，每個包含標題與風格提示詞；資源庫最多可同時提供 8 個預設。
- 主頁面的自訂預設入口預設收合，展開後最多顯示 2 個使用者預設，不干擾原有翻譯流程。
- 嚴格格式規則仍是所有預設共用的獨立模組。編輯前需兩次確認，並可隨時重設為 v4.6.0 預設內容。
- 舊版 AI 設定會自動遷移至新結構；自訂風格只取代風格模組，不會覆蓋共用的輸出格式要求。

## 驗證

- npm run typecheck
- npm run core:test
- npm run build
- 六種語言的版本號、下載檔名、頂端語言連結與發布說明入口一致性檢查
