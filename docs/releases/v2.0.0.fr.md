# Notes de version de Lyrics Card Generator v2.0.0

Date de publication : 2026-06-18

v2.0.0 améliore surtout l’expérience de bureau et la génération de cartes. Cette version couvre la mise en page horizontale, le calcul de hauteur pour les tailles personnalisées, l’analyse audio locale, les polices système Windows, l’export PNG, la vérification des mises à jour et les fichiers Windows.

## Points clés

- Refonte de la carte horizontale avec une zone sûre pour la pochette, les paroles, les informations du morceau et le pied de carte.
- Les tailles verticales personnalisées recalculent la hauteur à partir d’une mesure DOM réelle.
- Ajout de la séparation multilingue des paroles et d’outils de nettoyage pour les traductions chinoises.
- Ajout de l’analyse MP3 / FLAC locale pour lire titre, artiste, album, pochette et paroles intégrées lorsque disponibles.
- Ajout de la sélection des polices système Windows et d’une ouverture plus sûre des liens externes dans l’application de bureau.
- La vérification des mises à jour passe par une route locale Next API vers GitHub Releases.

## Fichiers publiés

- `Lyrics Card Generator Setup 2.0.0.exe`
- `Lyrics Card Generator-2.0.0-portable.exe`
- `Lyrics Card Generator Setup 2.0.0.exe.blockmap`

## Validation

Commandes validées : `npm run core:test`, `npm run typecheck`, `npm run build` et `npm run desktop:build`.

## Remarques

La version Windows actuelle n’est pas signée. Windows peut afficher une alerte SmartScreen.
