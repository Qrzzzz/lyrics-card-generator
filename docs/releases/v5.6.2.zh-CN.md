# Lyrics Card Generator v5.6.2 发布说明

发布日期：2026 年 7 月 16 日

v5.6.2 改进了后半段编辑流程的空间连续性和预览手感，并为桌面版与 Web Lite 增加真实的 WebP、JPG 导出。

## 更有层次的实时预览

- 第 3 至第 6 步的歌词卡片会随指针位置轻微倾斜，在悬停时抬升，并在按下时提供克制的回弹反馈。
- 指针在卡片外松开、取消操作或离开预览后，卡片会可靠复位，不会停留在倾斜或抬升状态。
- 触控设备不启用指针倾斜；系统或应用选择“减弱动效”时，预览使用稳定的静态呈现。
- 这些效果只存在于可见预览层，独立的导出宿主不会包含 3D 变换、高光或阴影反馈。

## 第 5 步到第 6 步的连续工作台

- 从“视觉”进入“导出”时，旧设置、预览和新导出设置位于同一条三面板轨道上，并作为整体向左平移。
- 预览会从右侧连续移动到左侧，旧设置离开左侧，导出设置从右侧进入；返回第 5 步时沿同一路径反向恢复。
- 离屏设置会被标记为不可交互并从辅助技术中隐藏，避免键盘焦点落入不可见区域。
- 窄窗口改用预览在前、当前设置在后的纵向布局，保留滚动、sticky 预览和无横向溢出的行为。

## PNG、WebP 与 JPG 导出

- 第 6 步现在可选择 PNG、WebP 或 JPG，并生成匹配的真实编码、文件扩展名与 MIME 类型。
- PNG 保留无损输出；WebP 与 JPG 使用高质量有损编码。原有质量档继续控制导出像素比例。
- “设置 → 导出”可保存默认图片格式；保存后，第 6 步与下次启动会同步使用该选择。Web Lite 也会保存自己的格式与质量偏好。
- 每次导出都会冻结格式、文件名、画布尺寸、像素比例和卡片内容；并发点击、超时或取消不会提交过期下载。
- SVG 不属于 v5.6.2 的范围，本版本没有新增 SVG 导出。

## 跨端与发布验证

- Desktop 与 Web Lite 共用格式选择、快照导出和响应式工作台行为；生成的 `index.html` 与源代码保持一致。
- 回归覆盖六种界面语言、键盘与辅助技术语义、触控/减弱动效降级、正反向切换、小窗口布局，以及 PNG、WebP、JPG 文件签名。
- Windows 安装版与便携版继续通过打包交互测试和最终制品 smoke；正式 Release 校验精确的版本化资产名、SHA256SUMS、SPDX SBOM 与 GitHub attestation。
