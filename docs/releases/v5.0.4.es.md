# Notas de la versión 5.0.4 de Lyrics Card Generator

Fecha de lanzamiento: 12 de julio de 2026

La versión 5.0.4 simplifica la edición de letras y unifica la jerarquía visual de Ajustes.

## Principales novedades

- Conserva de la v5.0.2 el área fija de resultados, el contador, la etiqueta de origen de NetEase y la lista de canciones rediseñada.
- El segundo paso usa siempre la altura máxima disponible y elimina los controles Estándar, Ampliada e Inmersiva y el tirador inferior.
- Se reorganizan la cabecera de Ajustes y las migas de pan para ganar espacio y mostrar mejor la ruta actual.
- El espacio de trabajo de IA pasa a ser una lista compacta coherente con las demás páginas de Ajustes.
- Se añaden los ejemplos «honeybee» de Olivia Rodrigo y «Lies» de BIGBANG, con una galería desplazable de dos filas.

## Verificación

- `npm run typecheck`
- `npm run core:test`
- `npm run build`
