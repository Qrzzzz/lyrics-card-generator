# Notas de la versión Lyrics Card Generator v4.2.3

Fecha de lanzamiento: 2026-07-03

v4.2.3 reconstruye el sistema de apariencia de la interfaz de la aplicación. Los ajustes que antes estaban repartidos entre Apariencia, Fondo, color de acento y color de texto se consolidan en un único modelo de modo de apariencia. Esta versión no cambia el estilo de las tarjetas exportadas, no añade flujos de imagen de fondo y no amplía los colores de tema elegidos por el usuario.

## Cambios principales

- Se elimina la página independiente Fondo del diálogo de ajustes; las pestañas ahora son General / Apariencia / Exportar / AI / Acerca de.
- La página Apariencia solo muestra el modo de apariencia y la familia de fuente de la interfaz.
- El modo de apariencia se limita a cinco opciones: Dinámico del álbum, Modo oscuro, Modo claro, Acrílico oscuro y Acrílico claro.
- Dinámico del álbum sigue siendo el modo predeterminado y continúa usando la paleta de la portada para la atmósfera y el color de acento.
- El modo oscuro usa ahora un fondo estable casi negro, y el modo claro usa un fondo blanco estable, sin los antiguos preajustes azul-blanco o negro-rosa.
- Acrílico oscuro y Acrílico claro siguen usando la ruta de material de ventana Windows Acrylic de Electron.

## Compatibilidad y migración

- Los ajustes existentes `light-blue` migran a `light`.
- Los ajustes existentes `dark-pink` migran a `dark`.
- Los ajustes existentes `custom` migran a `album-dynamic`.
- Los campos de fondo heredados siguen en la estructura interna de ajustes, pero el fondo de la aplicación ahora lo decide directamente `uiTheme`.
- El color de acento manual, el color de texto manual y los modos de imagen de fondo ya no aparecen en la interfaz de ajustes.

## Alcance

- La vista previa de la tarjeta y el estilo del PNG exportado no cambian.
- No se añaden funciones de imagen de fondo.
- No se añaden funciones de color de tema personalizado.
- `BackgroundSettingsSection` permanece temporalmente como archivo interno de compatibilidad, pero ya no se monta en el diálogo de ajustes.

## Verificación

- npm run typecheck
- npm run core:test
- npm run build
