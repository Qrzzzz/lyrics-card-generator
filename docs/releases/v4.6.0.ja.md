# Lyrics Card Generator v4.6.0 リリースノート

> [!WARNING]
> バージョン `v4.6.0` には未修正の重大な不具合があります。このバージョンへの更新は推奨しません。

リリース日：2026-07-11

このリリースでは AI 歌詞翻訳のプロンプトシステムを再構築し、厳格な出力ルール、既定スタイル、ユーザー定義スタイルを個別に管理できるようにしました。AI は引き続き翻訳本文だけを返します。

## 主な更新

- AI 設定を「API 設定」と「プロンプトライブラリ」の二つに分け、ファイル管理画面のような戻る、進む、クリック可能なパスを追加しました。
- おすすめ版は唯一の固定プリセットとして常に残ります。他の 5 件はタイトルとスタイルプロンプトの編集、削除、リセット、復元が可能です。
- タイトルとスタイルプロンプトを持つカスタムプリセットを最大 2 件追加でき、ライブラリ全体では最大 8 件になります。
- メイン翻訳パネルのカスタム項目は初期状態で折りたたまれ、展開時もユーザープリセットを最大 2 件だけ表示します。
- 厳格な形式ルールは全プリセット共通の独立モジュールです。編集には二重確認が必要で、v4.6.0 の既定内容へいつでも戻せます。
- 旧 AI 設定は自動移行されます。カスタムスタイルが置き換えるのはスタイル部分だけで、共通の出力形式ルールは維持されます。

## 検証

- npm run typecheck
- npm run core:test
- npm run build
- 6 言語のバージョン、配布ファイル名、言語リンク、リリースノート入口の整合性確認
