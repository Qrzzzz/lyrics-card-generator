# Lyrics Card Generator v6.5.4 版本說明

發布日期：2026-09-19

v6.5.4 整理設定頁的內容分組，並在桌面版「關於」中新增作者贊助入口。

## 設定頁分組

- 通用頁將還原應用程式偏好放入獨立的「重設」區域，歷史保留數量仍位於「歷史與儲存」。
- 外觀頁按主題與材質、強調色、介面字型及互動效果分組，原有設定行為保持一致。

## 支持作者

- 桌面版設定 → 關於 → 支持作者新增 USDT 贊助，提供 TRON（TRC20）及 X Layer（USDT0）兩個網路選項。
- 切換網路時同步顯示對應的完整收款地址與 QR Code；支援複製地址，並分別提示成功或失敗。QR Code 和網路圖示隨應用程式提供，可離線查看。
- 贊助詳情支援麵包屑與上一頁、下一頁導覽。QR Code 僅包含地址，轉帳時需在錢包核對幣種與網路。
- 收款地址首尾使用不同顏色標記，適配深淺主題，並保留完整地址與原始複製內容。
