# Lyrics Card Generator v5.10.2

> 狀態：已透過 GitHub Releases 公開發布。

這是一次輕量的提示配色更新。成功、警告與錯誤輕提示現在統一使用對應語意色的深色底，並搭配更鮮亮的同色邊框與文字，減少亮色提示的視覺突兀，同時保持狀態清楚易辨。

## 更新重點

- 成功提示改為深綠色底，搭配鮮綠色邊框與文字。
- 警告提示改為深黃色底，搭配鮮黃色邊框與文字，不再使用亮黃色背景。
- 錯誤提示改為深紅色底，搭配鮮紅色邊框與文字。
- 提示版面、動效、觸發方式及產品行為保持不變。

## 驗證

三種提示均完成實際介面檢查，並通過樣式契約、型別檢查、程式碼檢查、正式建置和 Web Lite 回歸門禁。文字與背景對比度約為：成功 5.23:1、警告 9.52:1、錯誤 5.84:1。
