# Lyrics Card Generator v6.4.3

Windows x64: `Lyrics.Card.Generator.Setup.6.4.3.exe`.

## Important notices and draft reliability

- Add interactive notifications in the upper-right corner for restored drafts, auto-save failures, settings-save failures, and history recovery, with dismiss, history, and retry actions.
- Show “Your last draft has been restored” only when startup actually restores a non-empty draft, clearly distinguishing saved edits from an image that has not been exported.
- Fix Smiley Sans drafts failing validation during shutdown, which could prevent the app from closing after it could not save the draft.
- Align font-scheme card headings, descriptions, and row heights while keeping each preset font limited to its font-name sample.
