# Lyrics Card Generator v4.2.0 Release Notes

Release date: 2026-07-03

v4.2.0 upgrades the desktop example-lyrics system and fixes the deployment preparation for the separate Web Lite / GitHub Pages demo. Web Lite remains a simplified online demo, not the full desktop experience.

## Main Updates

- Example lyrics now use a reusable “original-language lyrics + five target-language translation samples” structure.
- The examples dialog now shows the song title, artist, and original language, with five selectable translations.
- When the current UI language has a matching sample, that translation is selected by default; otherwise the first available translation is used.
- Example configuration no longer carries card height, size, ratio, or AutoHeight state.
- Loading an example only fills song info, lyrics, and translation text while keeping best-effort cover and album enrichment.
- Web Lite / GitHub Pages now uses explicit relative icon paths and packages only `index.html`, `public/app-icon.png`, and `.nojekyll`.

## Scope

- Example text is not embedded in components; it remains centralized in `lib/examples.ts`.
- Examples do not introduce runtime requests, so lyrics and translations remain available offline.
- The Web Lite fix does not change desktop app logic, Electron build flow, or desktop preview / export behavior.
- Web Lite remains a separate, simplified, rough online demo; use the desktop app for the complete experience.
