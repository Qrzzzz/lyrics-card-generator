# Notes de version de Lyrics Card Generator v4.2.6

Date de sortie : 2026-07-03

Cette version reconstruit le système de couleur d’accent de l’application afin que l’interface utilise un mécanisme global unifié au lieu de sources dispersées.

## Principales nouveautés

- Ajout de réglages de couleur d’accent unifiés : dynamique depuis la pochette, couleurs prédéfinies et couleur hex personnalisée.
- Les couleurs prédéfinies incluent rouge, orange, jaune, vert, bleu et violet.
- Source d’accent unifiée pour les boutons de traduction IA, le bouton final d’export, Spark Cursor, Stepper, les contrôles sélectionnés et les états de focus.
- Réorganisation d’Apparence avec un mode d’interface séparé de l’effet Acrylic.
- Le mode dynamique de l’album ne prend pas encore en charge Acrylic.
- Ajout du choix de qualité d’image à l’étape finale d’exportation.
- Les qualités d’exportation sont désormais Faible, Standard et Haute.
- Suppression de la qualité Ultra et migration automatique des anciens réglages Ultra vers Haute.
- Ajout d’un exemple multilingue Taylor Swift « Opalite ».
- Nettoyage de champs de réglages hérités et de textes liés aux arrière-plans pour préparer les futures extensions de thème.

## Compatibilité et migration

- L’ancien `uiAccentColor` migre vers les nouveaux réglages d’accent et n’est plus le champ principal.
- Les anciens `dark-acrylic` / `light-acrylic` migrent vers mode d’interface plus interrupteur Acrylic.
- L’ancienne qualité `ultra` migre vers `high`.

## Vérification

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:build
