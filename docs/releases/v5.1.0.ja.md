# Lyrics Card Generator v5.1.0 リリースノート

リリース日：2026年7月13日

v5.1.0 は安定性とセキュリティのリリースです。v5 の最初の 2 ステップの視覚方針を保ちながら、ネットワーク要求、読み込み競合、書き出しの一貫性を強化しました。

## 主な更新

- 統一 Safe Fetch を導入し、各リダイレクト先を要求前に解決・検証します。プライベート／予約済みアドレス、タイムアウト、遷移回数、コンテンツ種別、応答サイズを制限します。
- 曲、歌詞、サンプルの読み込みに document revision と last-intent-wins を導入し、クリア、曲変更、より新しい操作で古い処理を中止・無効化します。
- 曲変更を部分マージではなく完全置換にし、前の曲のカバー、explicit、最終 URL、解析方法、翻訳が残らないようにしました。
- デスクトップ書き出しは不変スナップショットと同期 mutex を使い、歌詞、スタイル、寸法、ファイル名、PNG を同じ revision に固定します。
- Web Lite は独立したオフスクリーン書き出し host を使い、36 行、フォント読み込み、測定、寸法安定性、overflow の判定をデスクトップ版と共有します。
- 書き出し中、ブロック、失敗の各状態で、ローカライズされた復旧可能なメッセージを表示します。

## 検証

- SSRF 対象へのアクセス 0、読み込み競合、曲間フィールド初期化、書き出しスナップショットと同時実行の決定的テストを追加しました。
- Web Lite の 36/37 行、固定 1:1 overflow、プレビュー折りたたみ時の書き出しテストを追加しました。
- コア、Web Lite、デスクトップビルド、デスクトップ操作の回帰確認を完了しました。
