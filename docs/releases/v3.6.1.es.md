# Notas de la versión Lyrics Card Generator v3.6.1

Fecha de publicación: 2026-06-29

v3.6.1 es una versión correctiva posterior a la actualización Acrylic de escritorio de v3.6.0. Se centra en la sincronización de estado de la barra de título personalizada, su integración visual, hover, capas, localización y entradas actuales de descarga.

## Mejoras

- Se añadió una capa de desenfoque de cristal con degradado hacia abajo para que la barra de título se integre mejor con el material Acrylic.
- La barra de título queda por debajo de ajustes, ejemplos, selección inicial de idioma y toast para no cubrir diálogos.
- Se añadieron textos `aria-label` y `title` localizados para los controles de ventana, con etiquetas de maximizar/restaurar según el estado.
- El botón maximizar cambia ahora a un icono de restaurar cuando la ventana está maximizada.

## Correcciones

- Se corrigió que el estado del icono no se actualizara inmediatamente tras maximizar o restaurar.
- Se corrigió la desincronización tras Snap del sistema, doble clic en la barra de título o eventos nativos de ventana.
- Se corrigió que el hover del botón cerrar no siempre se volviera rojo con el tema Acrylic claro.
- Se corrigieron nombres de descarga y enlaces de notas de versión del README que podían seguir apuntando a una versión anterior.
- La lógica de exportación PNG de las tarjetas de letras no cambia; Acrylic y la barra de título no entran en las imágenes exportadas.

## Validación

- Se verificó que la barra de título personalizada no se renderiza fuera del entorno de escritorio.
- Se verificó que los textos de los botones siguen el idioma actual de la interfaz.
- Se verificó que el área `data-export-card="true"` no contiene la barra de título de escritorio.
- Se ejecutó `npm run typecheck`, `npm run core:test`, `npm run build` y `npm run desktop:build`.
