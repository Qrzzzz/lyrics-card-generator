# Lyrics Card Generator v5.2.1 发布说明

## 歌曲链接解析恢复

v5.2.1 恢复 Spotify、Apple Music、网易云音乐和 QQ 音乐的真实歌曲链接解析，并保留 v5.1.0 与 v5.2.0 已加入的网络安全加固。

- QQ 音乐数值 `songDetail` 链接现在会按 `songid` 解析，正确填入标题、歌手、专辑和封面。
- 网易云音乐 JSON API 使用正确的响应协商，重新获得完整的歌曲、歌手与专辑元数据。
- Apple Music 页面即使自动跳转首页，也会使用原始曲目 ID 查询歌曲，并返回有效曲目链接。
- Spotify 单曲链接保持兼容；四个平台均加入真实链接强断言回归测试。

## 安全与兼容性

- 保留逐跳 URL/DNS 校验、重定向复检、响应大小和类型限制，以及多地址 IPv6/IPv4 fallback。
- 歌词卡输出、项目数据格式和现有视觉方向保持不变。
- Windows x64 Setup 与 portable 已按 v5.2.1 重新构建。
