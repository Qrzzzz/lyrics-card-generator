# Lyrics Card Generator v3.8.0 发布说明

发布日期：2026-06-30

v3.8.0 聚焦于界面动效与交互打磨，在 v3.7.1 统一控件层的基础上引入集中化动效系统。动效应用于编辑器外壳、设置对话框、预览外壳、共享控件、AI 翻译面板和应用背景；导出的歌词卡片 PNG 输出没有刻意变化，本版本也不引入动画化卡片导出。

## 动效系统与编辑体验

- 新增轻量动效令牌与可复用动效组件，统一面板、对话框、步骤切换和控件反馈的持续时间、缓动与弹性参数。
- 步骤设置器改用方向感知切换：前进时内容从右侧进入、向左退出；后退时方向相反。
- 设置对话框、设置分类标签和预览外壳采用统一进入 / 退出动效，移动端预览展开收起更平滑。

## 控件、AI 面板与背景

- 共享按钮、开关、选项卡片和分段控件加入克制的按压、选中和指示器动效，并保留键盘操作、焦点样式、ARIA 与测试钩子。
- AI 翻译面板改用共享选项卡片、开关和按钮，并为状态、思考流和译文流加入统一过渡；请求、流式输出和取消逻辑保持不变。
- 应用外壳背景在主题、图片和调色板模式切换时更顺滑，但不改动导出卡片内部的 `PaletteBackground`。

## 可访问性与导出安全

- 尊重 `prefers-reduced-motion`：横向移动、悬浮位移、装饰 keyframe、点击火花和导出庆祝等动效会降级为透明度变化或直接禁用。
- `LyricCard.tsx`、`LandscapeLyricCard.tsx` 和 `PaletteBackground.tsx` 未引入 Framer Motion。
- `data-export-card="true"` 的静态导出路径保持稳定，导出的 PNG 外观没有刻意改动。
