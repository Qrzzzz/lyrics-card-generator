# Lyrics Card Generator v4.3.2 发布说明

发布日期：2026-07-06

本版本聚焦歌曲标题区域的视觉打磨，改进 Explicit 标识的质感，并让竖版封面与歌曲信息形成更稳定的视觉中心。

## 主要更新

- 将 Explicit 标识重写为单一 SVG 图形，不再依赖字体字母 `E`。
- Explicit 标识使用 `currentColor` 与整体透明度，并通过 SVG mask 挖空几何 E，避免出现黑色实心字母。
- 微调 Explicit 标识的尺寸、垂直位置和标题间距，使它与歌曲标题中轴线更自然对齐。
- 放大竖版专辑封面，并同步调整圆角比例。
- 让竖版歌曲信息块使用与封面一致的最小高度并垂直居中，标题、艺人和专辑三行更贴近封面中心线。
- 保持现有字号、行高和 header 间距不变，降低布局回归风险。

## 验证

- npm run typecheck
- npm run core:test
- npm run build
- 浏览器加载 `opposite` 示例并导出 PNG，确认预览与导出中的 Explicit 标识和竖版 header 对齐一致。
