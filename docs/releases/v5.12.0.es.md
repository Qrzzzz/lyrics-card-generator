# Lyrics Card Generator v5.12.0

> Estado: publicado públicamente mediante GitHub Releases.

## Análisis local de M4A

- La carga de audio local ahora admite M4A además de MP3 y FLAC, y puede leer el título, el artista, el álbum, la portada y las letras incrustadas cuando estén disponibles. Si no hay letras incrustadas, la información detectada se conserva para editarla manualmente.
- Se admiten los tipos habituales de navegadores y Windows —`audio/mp4`, `audio/m4a` y `audio/x-m4a`—, manteniendo el límite existente de 100 MB, la lectura multipart acotada y las protecciones ante errores de análisis.
- El historial de importación de la versión de escritorio para Windows puede registrar archivos M4A confirmados correctamente, volver a importarlos y reubicar archivos ausentes. El historial sigue guardando únicamente la ruta y los metadatos necesarios, nunca el contenido del audio.
