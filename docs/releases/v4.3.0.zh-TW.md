# Lyrics Card Generator v4.3.0 發布說明

發布日期：2026-07-05

本版本更新了範例歌曲流程、佈局控制項、顯式標誌渲染以及最終匯出步驟。

## 主要更新

- 重建範例歌曲對話框為響應式網格，根據視窗寬度自動選擇兩欄或三欄佈局。
- 移除逐首歌曲的翻譯語言按鈕；範例現在載入與目前介面語言相符的翻譯。
- 英文介面下選擇英文原詞時，翻譯欄位留空。
- 新增可選歌曲欄位 `explicit: boolean`；視覺細節開關直接控制標誌顯示。
- 在預覽和匯出 PNG 中，標題旁渲染內聯 E 標誌。
- 初始尺寸模式保持在自訂並啟用自動高度。
- 將內容類型和文字顏色改為分段滑桿控制項。
- 僅在選取對應模式時才顯示預設或自訂文字顏色選項。
- 將視覺細節開關重排為兩欄佈局。
- 將完成並匯出移至最終步驟導航的右側，與返回按鈕高度對齊。
- 移除框架與陰影渲染路徑及其視覺控制項。
