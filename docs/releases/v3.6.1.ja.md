# Lyrics Card Generator v3.6.1 リリースノート

リリース日：2026-06-29

v3.6.1 は v3.6.0 の Acrylic デスクトップ更新に対する修正版です。カスタムタイトルバーのウィンドウ状態同期、視覚的ななじみ、hover、重なり順、ローカライズ、現在のダウンロード入口を整えます。

## 改善

- 下方向に自然に消えるガラスぼかしレイヤーを追加し、タイトルバーが Acrylic ウィンドウ素材になじむようにしました。
- タイトルバーを設定、サンプル、初回言語選択、toast より下のレイヤーにして、ダイアログを覆わないようにしました。
- タイトルバーのウィンドウ操作ボタンにローカライズされた `aria-label` と `title` を追加し、最大化/復元ラベルを状態に合わせました。
- ウィンドウ最大化後、最大化ボタンは復元アイコンに切り替わります。

## 修正

- 最大化または復元をクリックした直後に、レンダラー側のアイコン状態が更新されない問題を修正しました。
- システム Snap、タイトルバーのダブルクリック、ネイティブウィンドウイベント後にボタン状態が同期しない問題を修正しました。
- Light Acrylic テーマで閉じるボタンの hover が安定して赤にならない問題を修正しました。
- README のダウンロードファイル名とリリースノートリンクが古いバージョンを指す可能性を修正しました。
- 歌詞カード PNG 出力ロジックは変更していません。Acrylic とタイトルバーは書き出し画像に入りません。

## 検証

- デスクトップ環境外ではカスタムタイトルバーが描画されないことを確認しました。
- タイトルバーボタンの文言が現在の UI 言語に追従することを確認しました。
- `data-export-card="true"` のカード領域にデスクトップタイトルバーが含まれないことを確認しました。
- `npm run typecheck`、`npm run core:test`、`npm run build`、`npm run desktop:build` を実行しました。
