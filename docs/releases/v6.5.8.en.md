# Lyrics Card Generator v6.5.8 Release notes

Release date：2026-09-30

v6.5.8 fixes desktop draft recovery and tightens cover loading boundaries.

## Fixes

- Recover complete drafts, the active record and covers from a valid backup when the main history file is missing. Create a recovery copy on the first draft save and keep deleted records out of recovery.
- Route remote covers through the restricted proxy and match same-origin resources precisely. Preserve local uploads and reject local-file protocols and disguised hosts. Limit cover uploads and inline images to 20 MB.
- Fix the brace-expansion and fast-uri security advisories in build and test dependencies.
