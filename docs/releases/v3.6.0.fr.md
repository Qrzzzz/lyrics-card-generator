# Notes de version de Lyrics Card Generator v3.6.0

Date de publication : 2026-06-29

v3.6.0 se concentre sur l'expérience Acrylic du bureau Windows : cette version ajoute les thèmes Acrylique sombre et Acrylique clair, connecte la fenêtre de bureau au véritable matériau translucide Windows Acrylic, et remplace la barre de titre native par une barre personnalisée.

## Ajouts

- Ajout des thèmes d'interface Acrylique sombre et Acrylique clair.
- L'application de bureau Windows utilise le matériau de fenêtre Acrylic natif sur les systèmes compatibles, afin que le contenu derrière la fenêtre apparaisse avec le flou système.
- Ajout d'une barre de titre personnalisée avec l'icône de l'application, le nom du logiciel, le numéro de version et les boutons réduire, agrandir/restaurer et fermer.
- Ajout d'IPC de contrôle de fenêtre pour permettre à la barre de titre personnalisée de réduire, agrandir/restaurer et fermer la fenêtre.

## Améliorations

- La barre de titre et le corps de la fenêtre partagent désormais le même arrière-plan Acrylic transparent, ce qui réduit la séparation visible entre la barre supérieure et l'interface principale.
- Le contenu du bureau défile désormais à l'intérieur de la fenêtre de l'application, afin que la barre de défilement droite ne soit plus placée à l'extérieur de la surface de la fenêtre.
- Ajout d'un style de barre de défilement fine plus discret pour les zones de défilement internes, avec activation du comportement Chromium overlay scrollbar.
- Amélioration de la lisibilité des textes, boutons, champs, fenêtres de paramètres, messages d'état et toast dans les thèmes Acrylic.
- Les thèmes Acrylic affectent uniquement l'interface de l'application, pas la carte de paroles ni les exports PNG.

## Corrections

- Correction de l'ouverture du bureau en plein écran par défaut ; l'application s'ouvre maintenant avec une taille de fenêtre normale.
- Correction du bouton de fermeture de la barre de titre personnalisée.
- Correction du bouton d'agrandissement qui ne permettait pas de restaurer la fenêtre ; l'application enregistre maintenant les dimensions de fenêtre normales et les restaure de manière fiable.
- Les systèmes non Windows et les versions Windows non compatibles utilisent une interface transparente lisible sans provoquer de plantage.

## Validation

- Vérification de l'apparition des deux thèmes Acrylic dans Paramètres → Apparence → Thème d'interface.
- Vérification de la désactivation du matériau Acrylic lors du retour à un thème classique.
- Vérification du démarrage normal de l'application de bureau en mode développement.
- Exécution de `npm run typecheck`, `npm run core:test`, `npm run build` et `npm run desktop:build`.
