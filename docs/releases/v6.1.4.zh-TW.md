# Lyrics Card Generator v6.1.4

> 狀態：已正式發佈。

## 可搜尋的共享字體瀏覽器

- Windows 原生字體方案視窗現在讓中日韓與西文字體共用一個系統字體瀏覽器，切換角色即可為對應位置選擇字體。
- 搜尋框會即時篩選已安裝字體，每個項目直接顯示字體名稱與字形預覽，並提供結果數量與空結果狀態。
- 支援交換兩種字體、還原開啟視窗時的方案，以及鍵盤搜尋與選擇；只有確認提交後的選擇才會套用到目前方案。

## 原生橋接可靠性

- 完整 WinForms 輔助指令碼改由標準輸入傳給 PowerShell，避免複雜介面指令碼超過 Windows 命令列長度限制。
- 保留主視窗模態歸屬、受限輸出解析、輸入欄位驗證與異常回退，不改變非 Windows 桌面版、瀏覽器選擇器或歌詞卡渲染規則。
