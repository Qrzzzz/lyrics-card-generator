# Lyrics Card Generator v5.0.2 发布说明

发布日期：2026-07-12

v5.0.2 是基于 v5.0.0 的发布加固版本，不改变现有编辑、预览与导出交互。

## 主要更新

- 统一应用、锁文件、六语 README 与发布说明中的 5.0.2 版本信息。
- 在兼容范围内更新 Next.js、Undici 等依赖，清除运行时高危依赖告警。
- 重新验证并构建 Web Lite、Windows 安装版、便携版和增量更新校验文件。

## 验证

- `npm run typecheck`
- `npm run core:test`
- `npm run build`
- `npm run web-lite:build` / `web-lite:check` / `web-lite:smoke`
- `npm run desktop:build` / `desktop:interaction-test`
