# Lyrics Card Generator v6.1.1

> Status: publicly released through GitHub Releases.

## Native Windows system font dialog

- The Windows desktop app now calls the operating system's `FontDialog` directly instead of creating an Electron or HTML-rendered font window.
- The system dialog uses the Electron main-window handle as its owner, preserving true Windows modality; only one dialog can open at a time, and focus returns after selection or cancellation.
- The selected font family still updates the custom-scheme draft and real lyric-card preview first; Save as Current Scheme remains the commit point.

## Reliability and compatibility

- The native bridge explicitly uses STA and bounds the window handle, font name, helper output, and returned value; launch failures safely resolve as no selection.
- Desktop regression can target an exact isolated candidate EXE instead of accidentally exercising an older `release` build, with separate contracts for the bridge, IPC security, and packaged manifest.
- Non-Windows desktop environments and regular browsers retain the existing in-app fallback, while Web Lite font selection is unchanged.
