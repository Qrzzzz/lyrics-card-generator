# Notas de la versión Lyrics Card Generator v2.1.0

Idiomas: [简体中文](./v2.1.0.zh-CN.md) · [繁體中文](./v2.1.0.zh-TW.md) · [English](./v2.1.0.en.md) · [Français](./v2.1.0.fr.md) · [日本語](./v2.1.0.ja.md) · Español

## Descarga e instalación

Descarga los archivos correspondientes desde GitHub Releases:

- Instalador: `Lyrics Card Generator Setup 2.1.0.exe`
- Versión portable: `Lyrics Card Generator-2.1.0-portable.exe`

Se recomienda el instalador para uso habitual. Elige la versión portable para pruebas temporales, evaluación o ejecución desde una unidad extraíble.

> Esta compilación no está firmada con código. Windows puede mostrar una advertencia de SmartScreen, algo común en aplicaciones personales sin firma.

## Novedades

v2.1.0 se centra en la experiencia de escritorio, el diseño horizontal, los tamaños de lienzo personalizados, la interfaz multilingüe y el manejo de archivos locales.

### Añadido

- Se añadió el flujo de empaquetado para la aplicación de escritorio de Windows.
- Se añadieron dos formatos de distribución: instalador y versión portable.
- Se añadió el análisis local de MP3 / FLAC para intentar leer título, artista, álbum, portada y letras incrustadas.
- Se añadió detección de fuentes del sistema Windows y selección de fuente personalizada.
- Se añadió cambio de interfaz en chino simplificado, chino tradicional, inglés, francés, japonés y español.
- Se añadió una entrada para comprobar actualizaciones mediante GitHub Releases.

### Mejorado

- Se reconstruyó el diseño horizontal con áreas seguras, columna de portada, columna de contenido y zona inferior de información.
- Se añadió altura automática medida para lienzos verticales personalizados.
- Se mejoró la estabilidad del diseño de letras originales y traducción, con separación de líneas según el idioma actual de la interfaz.
- La exportación de portadas remotas ahora usa el proxy de imagen para reducir errores de PNG por restricciones cross-origin.
- Los logos de plataforma se movieron a recursos SVG locales para que la exportación PNG no dependa de iconos remotos.

### Corregido

- Se corrigieron desbordamientos de contenido o espacios en blanco inesperados en algunos tamaños personalizados.
- Se corrigieron casos en los que portada, letras e información inferior se comprimían entre sí en tarjetas horizontales.
- Se corrigieron casos en los que algunas portadas remotas no se escribían correctamente en el PNG exportado.

## Notas de actualización

- Actualizar desde una versión anterior normalmente no requiere desinstalar primero.
- Si el instalador no puede sobrescribir la versión anterior, cierra la aplicación antigua y ejecuta el instalador de nuevo.
- Si la versión portable no inicia, comprueba si hay un proceso antiguo ejecutándose en segundo plano.

## Limitaciones conocidas

- El análisis de enlaces de plataformas musicales, la carga de portadas remotas, la obtención automática de letras y la comprobación de actualizaciones requieren conexión a internet.
- La obtención automática de letras sigue siendo experimental. Los resultados pueden estar incompletos o ser inexactos. Asegúrate de tener derecho a usarlos.
- La compilación actual no está firmada. Una advertencia de Windows SmartScreen no significa necesariamente que el programa sea peligroso.
