# Notas de la versión v2.0.0 de Lyrics Card Generator

Fecha de publicación: 2026-06-18

v2.0.0 mejora principalmente la experiencia de escritorio y la generación de tarjetas. Incluye diseño horizontal, cálculo de altura para tamaños personalizados, análisis de audio local, fuentes del sistema Windows, exportación PNG, comprobación de actualizaciones y archivos de compilación para Windows.

## Cambios principales

- Se rediseñó la tarjeta horizontal con un área segura para portada, letras, información de la canción y pie de tarjeta.
- Los tamaños verticales personalizados recalculan la altura mediante medición real del DOM.
- Se añadieron separación multilingüe de letras y herramientas de limpieza para traducciones al chino.
- Se añadió análisis local de MP3 / FLAC para leer título, artista, álbum, portada y letras incrustadas cuando estén disponibles.
- La aplicación de escritorio añade selección de fuentes del sistema Windows y apertura segura de enlaces externos.
- La comprobación de actualizaciones obtiene GitHub Releases mediante una ruta local de Next API.

## Archivos publicados

- `Lyrics Card Generator Setup 2.0.0.exe`
- `Lyrics Card Generator-2.0.0-portable.exe`
- `Lyrics Card Generator Setup 2.0.0.exe.blockmap`

## Validación

Se validaron `npm run core:test`, `npm run typecheck`, `npm run build` y `npm run desktop:build`.
