# Lyrics Card Generator v6.2.3

> 狀態：已發布。

## 局部可讀性陰影修復

- 歌曲資訊、歌詞與頁尾附件區域現在使用相同的局部可讀性陰影深度。
- 三個區域的漸層會先合併為單一透明度遮罩，再統一套用明暗調整；交疊區域不會重複加深，也不會形成突兀的頁首或頁尾深色帶。
- 移除平台 Logo、分享人與生成浮水印自身的額外投影，讓這些元素只受同一可讀性層保護，並維持即時預覽與最終匯出一致。

## 驗證範圍

- 背景組合回歸涵蓋 120 組確定性組合，並新增「重疊區域不得超過單層透明度上限」與「三個區域深度一致」斷言。
- 已通過型別檢查、lint、正式建置、Web Lite 建置與一致性檢查，並完成 Chromium 真實 2× PNG 匯出以及 Firefox、WebKit 轉譯檢查。

## 下載與升級

- Windows x64 安裝版：`Lyrics.Card.Generator.Setup.6.2.3.exe`。
- 本版本繼續採用 Setup-only 發布方式；從舊版本升級不需要遷移設定。
