# Notas de la versión Lyrics Card Generator v3.6.0

Fecha de publicación: 2026-06-29

v3.6.0 se centra en la experiencia Acrylic del escritorio de Windows: añade los temas Acrílico oscuro y Acrílico claro, conecta la ventana de escritorio con el material translúcido Windows Acrylic real y actualiza la ventana de escritorio con una barra de título personalizada.

## Añadido

- Se añadieron los temas de interfaz Acrílico oscuro y Acrílico claro.
- La app de escritorio de Windows usa el material de ventana Acrylic nativo en sistemas compatibles, de modo que el contenido detrás de la ventana aparece con el desenfoque del sistema.
- Se añadió una barra de título personalizada con el icono de la app, el nombre del software, el número de versión y los botones minimizar, maximizar/restaurar y cerrar.
- Se añadió IPC de control de ventana para que la barra de título personalizada pueda minimizar, maximizar/restaurar y cerrar la ventana.

## Mejorado

- La barra de título y el cuerpo de la ventana comparten ahora el mismo fondo Acrylic transparente, reduciendo la separación visible entre la barra superior y la interfaz principal.
- El contenido de escritorio ahora se desplaza dentro de la ventana de la app, por lo que la barra de desplazamiento derecha ya no queda fuera de la superficie de la ventana.
- Se añadió un estilo de barra de desplazamiento fina y más limpio para las áreas internas, y se activó el comportamiento Chromium overlay scrollbar.
- Mejorada la legibilidad de texto, botones, campos, diálogos de ajustes, mensajes de estado y toast en los temas Acrylic.
- Los temas Acrylic afectan solo a la interfaz de la app, no a la tarjeta de letras ni a las exportaciones PNG.

## Corregido

- Corregido que la app de escritorio se abriera maximizada por defecto; ahora se abre con el tamaño normal de ventana.
- Corregido el botón de cierre de la barra de título personalizada.
- Corregido que el botón de maximizar no pudiera restaurar la ventana; la app ahora registra los límites normales de la ventana y los restaura de forma fiable.
- Los sistemas que no sean Windows y las versiones de Windows no compatibles usan una interfaz transparente legible sin bloquear la app.

## Validación

- Verificado que ambos temas Acrylic aparecen en Ajustes → Apariencia → Tema de interfaz.
- Verificado que al volver a un tema normal se desactiva el material de ventana Acrylic.
- Verificado que la app de escritorio en modo desarrollo arranca correctamente y devuelve la página.
- Ejecutados `npm run typecheck`, `npm run core:test`, `npm run build` y `npm run desktop:build`.
