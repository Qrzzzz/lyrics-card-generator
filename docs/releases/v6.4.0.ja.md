# Lyrics Card Generator v6.4.0

Windows x64: `Lyrics.Card.Generator.Setup.6.4.0.exe`.

## 得意黑（Smiley Sans）のプリセットを追加

- デスクトップ版と Web Lite で、歌詞カードのプレビューと書き出しに Smiley Sans を選択できます。
- 前バージョンに同梱されたフォントを使用するため、追加インストールは不要です。デスクトップ版の選択はカード設定とともに保存・復元されます。
