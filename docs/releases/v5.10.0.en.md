# Lyrics Card Generator v5.10.0

> Status: publicly released through GitHub Releases.

This release rebuilds cover-derived card backgrounds. Instead of fixed curves or simple corner swatches, it creates a stable, continuous soft color field from the cover's spatial color relationships and recomposes it for each card ratio.

## Highlights

- The perceptual palette retains color position, area, luminance, and salience, with a stable cover-derived seed.
- Spatial anchors rearrange for portrait, landscape, and extra-long canvases before blending into a continuous field.
- New constraints suppress parallel bands, closed contours, repeated S curves, muddy mixtures, and abrupt highlights.
- Lyric safe zones use local luminance and contrast control instead of a uniform dark veil.
- Editor preview, export, and Web Lite share one deterministic rendering path for reproducible results.

## Validation

Coverage includes palette extraction, spatial fields, composition matrices, text contrast, Web Lite visual regression, and desktop artifact checks.
