# Lyrics Card Generator v6.4.3

Windows x64：`Lyrics.Card.Generator.Setup.6.4.3.exe`。

## 重要提示與草稿可靠性

- 新增右上角可互動通知，用於草稿恢復、自動儲存失敗、設定儲存失敗和歷史恢復等需要使用者處理的情況；支援關閉、查看歷史和重試儲存。
- 啟動時僅在實際恢復了有內容的草稿後顯示「已恢復上次的草稿」，並明確區分自動儲存的編輯內容和尚未匯出的圖片。
- 修復得意黑字型方案無法通過草稿驗證、導致關閉前儲存失敗並阻止應用程式結束的問題。
- 統一字型方案卡片的標題、說明和同列高度，只在字型名稱樣本中使用對應的預覽字型。
