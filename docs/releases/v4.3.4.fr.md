# Notes de version de Lyrics Card Generator v4.3.4

Date de publication : 2026-07-06

Cette version transforme les exemples de paroles : ils ne s'ouvrent plus dans une fenêtre modale, mais dans une couche située au-dessus de l'éditeur. Quand elle s'ouvre, l'éditeur descend, l'en-tête interne vient se placer en bas comme point de retour, et les cartes d'exemple s'adaptent à la largeur de la fenêtre principale.

## Principales nouveautés

- Remplacement de la modale ExamplesDialog par une couche supérieure ExamplesFloor, sans masque, fenêtre modale ni Portal.
- Le bouton Exemples de l'en-tête fait entrer la couche depuis le haut, pousse l'éditeur vers le bas et place l'en-tête en bas.
- L'en-tête du bas réutilise la structure normale et remplace l'emplacement du bouton Exemples par un bouton X compact.
- Les cartes d'exemple passent automatiquement d'une à deux puis trois colonnes selon la largeur de la fenêtre principale, sans débordement horizontal sur les petites fenêtres.
- La couche d'exemples réserve l'espace de l'en-tête en bas, afin que la dernière rangée de cartes reste visible au défilement.
- Escape revient à l'éditeur, et le chargement d'un exemple ramène automatiquement à l'éditeur.
- Le mouvement utilise désormais une courbe spring plus douce, avec désactivation des grands déplacements lorsque reduced motion est activé.

## Vérification

- npm run typecheck
- npm run core:test
- npm run build
- Vérifications navigateur en 1280px, 900px et 520px pour les colonnes, le retour par X, le retour par Escape, le retour après chargement d'un exemple et l'espace en bas.
