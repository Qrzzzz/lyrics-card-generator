# Lyrics Card Generator v5.10.1

> Status: publicly released through GitHub Releases.

This release fixes a v5.10.0 spatial-field failure that could amplify a small high-chroma accent until it displaced the cover's dominant color family. Backgrounds now allocate source-family budgets from visible cover area before optimizing spatial composition and separation.

## Highlights

- Anchor count and total energy follow each source color family's visible area, preserving the dominant family across preset ratios.
- Small highlight families have an explicit expansion cap and can no longer consume the background.
- All four edge anchors receive source-family preferences; color separation is optimized only inside the allocated family.
- Equal aspect ratios share one semantic seed, so resolution changes do not reshuffle color roles.
- Editor preview, export, and Web Lite share the corrected deterministic rendering path.

## Validation

A checked-in regression fixture with 88% cool blue and a 12% warm accent covers all five preset ratios; sampled warm area remains between 5.0% and 8.2%. The full core suite, 120-case composition matrix, production build, Web Lite browser suite, and Windows installer/portable smoke tests also pass.
