# Lyrics Card Generator v5.9.1 發布說明

候選說明日期：2026-08-04

v5.9.1 為 Windows 桌面版新增明確觸發的手動存檔。本文描述本機候選實作，不代表此版本已經發布。它不是自動儲存，也不是完整的文件版本歷史。

## 手動存檔與載入

- 桌面版頂端操作區在「歷史記錄」與「清除內容」之間新增圖示式「手動存檔」按鈕。第一次儲存會建立記錄；繼續編輯後再次儲存會更新同一 ID，並保留原始建立時間。
- 同一份文件沒有變更時不會寫入磁碟；快速連按只會產生一次寫入。空白文件、AI 操作或文件取代交易進行時不能儲存，寫入失敗也不會把目前修訂誤標為已儲存。
- 歷史頁可單獨篩選手動存檔，並以「載入存檔」在本機還原內容，不發出網路請求，也不提供檔案重新定位。刪除目前綁定記錄或清除歷史會解除綁定。
- 載入手動存檔後繼續儲存會更新原記錄；一般匯入、其他歷史重播、內建範例、清除編輯器和上傳本機封面會開始新的存檔工作階段。記錄已在磁碟外部刪除時，本次儲存只解除舊綁定，不會悄悄新增。

## 安全儲存與遷移

- 歷史 schema 升級至 v2；舊 v1 記錄依原順序無損遷移，重複載入不會繼續改變資料。
- 手動存檔只保留歌曲來源、標題、歌手、專輯、歌詞、翻譯、翻譯開關及安全的遠端 URL 等語義內容。樣式、設定、匯出圖片、本機路徑、API 金鑰、圖片二進位、Base64、blob URL 與 data URL 均不保存。
- ID 與時間戳記由 Electron 主程序建立；新增和更新使用獨立的安全 IPC，並經過欄位限制、單筆 512 KiB 上限、串行原子寫入及結束前排空保護。

## 範圍與驗證

- 新增介面文字涵蓋简体中文、繁體中文、English、Français、日本語與 Español。
- Web Lite 的介面與行為維持不變，不提供瀏覽器版手動存檔，也不新增 `Ctrl+S` 快捷鍵。
- 儲存、遷移、安全 IPC、介面契約、封裝及真實 Electron 互動回歸涵蓋建立、原位更新、無變更略過、綁定生命週期、失敗重試與結束排空語意。
