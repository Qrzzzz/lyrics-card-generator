# Lyrics Card Generator v5.5.0 发布说明

发布日期：2026-07-14

v5.5.0 为竖版自定义歌词卡新增可选的自动宽度，让相近长度的歌词在不过度拉宽画布的前提下获得更舒适的换行。

## 主要更新

- 在“竖版 → 自定义 → 歌词”中新增默认关闭的“自动宽度”。开启后宽度滑块显示实时像素值并暂时禁用；关闭后会保留最后计算宽度，方便继续手动微调。
- 使用隐藏的原尺寸排版探针和最终字体测量浏览器真实视觉行，不根据字符数估算，也不使用缩放后的可见预览。
- 正文和翻译分别检测中日韩字素、西文单词与混合文本，强力规避下一视觉行只留下 1–2 个字或短词的情况。
- 通过全局候选宽度评分、主体行抽样与离群降权，避免极短副歌或单条超长正文/翻译把卡片拉到最大宽度；翻译参与孤行约束，但不会反客为主。
- 内容、字体、字号与翻译变化会在 300ms 防抖后重新求解，并使用稳定阈值避免输入过程中反复跳动。
- 自动宽度先稳定，自动高度再根据新宽度测量；中间态禁止导出，固定高度不足时仍由真实溢出检查阻止导出。

## 版本范围

- 自动宽度仅支持竖版、自定义尺寸和歌词模式；固定比例、横版与纯音乐模式保持原有行为。
- 旧状态缺少自动宽度字段时默认关闭；竖版、横版、固定比例、自定义尺寸和纯音乐之间往返时会保存并恢复相应尺寸历史。
- 桌面版与 Web Lite 使用同一套测量、评分、自动高度协调与导出安全路径。
