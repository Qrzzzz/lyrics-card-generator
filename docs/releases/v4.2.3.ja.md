# Lyrics Card Generator v4.2.3 リリースノート

リリース日：2026-07-03

v4.2.3 では、アプリ本体の外観システムを再構成しました。これまで外観、背景、アクセントカラー、文字色に分かれていた設定を、ひとつの明確な外観モードに統合しています。この更新では、歌詞カードの書き出しスタイル、背景画像ワークフロー、ユーザーが選ぶテーマ色の機能は拡張していません。

## 主な更新

- 設定画面から独立した「背景」ページを外し、タブを「一般 / 外観 / 書き出し / AI / このアプリについて」に整理しました。
- 「外観」ページに表示される設定は、外観モードと UI フォントだけになりました。
- 外観モードは、アルバム動的カラー、ダークモード、ライトモード、ダークアクリル、ライトアクリルの 5 種類に限定されます。
- アルバム動的カラーは引き続き既定モードで、カバー画像の palette を使ってアプリの雰囲気とアクセント色を決めます。
- ダークモードは安定した黒に近い背景、ライトモードは安定した白背景になり、従来の青白系や黒ピンク系プリセットは使いません。
- ダークアクリルとライトアクリルは、引き続き Electron の Windows Acrylic ウィンドウ素材を使用します。

## 互換性と移行

- 既存の `light-blue` 設定は `light` に移行されます。
- 既存の `dark-pink` 設定は `dark` に移行されます。
- 既存の `custom` 設定は `album-dynamic` に移行されます。
- 従来の背景フィールドは内部設定構造に残りますが、アプリ背景は `uiTheme` から直接決まります。
- 手動アクセントカラー、手動文字色、背景画像モードは設定 UI に表示されなくなりました。

## 範囲

- 歌詞カードのプレビューと PNG 書き出しの見た目は変更していません。
- 背景画像機能は追加していません。
- カスタムテーマカラー機能は追加していません。
- `BackgroundSettingsSection` は内部互換用ファイルとして一時的に残りますが、設定画面にはマウントされません。

## 検証

- npm run typecheck
- npm run core:test
- npm run build
