# Lyrics Card Generator v5.4.0 發佈說明

發佈日期：2026-07-13

v5.4.0 完成六步編輯器頂部結構的統一，並將第一步重構為與後續步驟一致的緊湊工作區。

## 主要更新

- 第一步現在使用與第 2 至第 6 步相同的緊湊 Stepper，目前步驟、完整六步導覽及「範例」「一鍵清空」「設定」集中在同一個流程面板。
- 移除第一步重複的大型軟體標題列，Windows 自繪標題列繼續保留應用程式名稱、圖示與版本資訊。
- 第一頁改為共用雙欄工作區，頂部流程面板橫跨網易雲搜尋主區與歌曲匯入側欄。
- 歌曲資訊、歌曲連結、本機音訊與手動調整整合到同一個側欄面板，原有匯入路徑與輔助功能語意保持可用。
- 1000px 桌面最小寬度繼續使用 320px 側欄，並在更寬視窗逐級擴展至 360px 與 400px。

## 版本範圍

- 網易雲搜尋、連結解析、本機音訊解析、手動歌曲資訊、歌詞文件與 AI 翻譯行為均未改變。
- 第 2 至第 6 步、即時預覽、PNG 匯出、設定資料、專案格式與 Web Lite 共用元件行為均未改變。

## 驗證

- `npm run lint` / `npm run typecheck` / `npm run core:test` / `npm run build`
- `npm run web-lite:build` / `npm run web-lite:check` / `npm run web-lite:smoke`
- `npm run desktop:build` / `npm run desktop:interaction-test` / `npm run desktop:final-artifact-smoke`
- 1000×700、1023×700、1024×700、1280×900、1440×900 與 1920×1080 桌面視窗回歸
