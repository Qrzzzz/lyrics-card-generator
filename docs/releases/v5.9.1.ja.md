# Lyrics Card Generator v5.9.1 リリースノート

リリース候補ノート作成日：2026-08-04

v5.9.1 では Windows デスクトップ版に明示的な手動保存を追加しました。この文書はローカルのリリース候補について説明するもので、公開済みであることを示すものではありません。自動保存や完全な文書バージョン履歴ではありません。

## 手動保存と読み込み

- デスクトップのヘッダーで「履歴」と「内容を消去」の間に、アイコンのみの手動保存を追加しました。最初の保存で項目を作成し、編集後の保存では作成日時を保ったまま同じ ID を更新します。
- 文書に変更がなければディスクへ書き込まず、すばやいダブルクリックでも書き込みは 1 回だけです。空の文書、AI 処理中、文書置換処理中は保存できません。書き込みに失敗しても現在のリビジョンを保存済みにはしません。
- 履歴では手動保存だけを絞り込み、「保存を読み込む」でネットワーク通信やファイル再指定を行わずローカルに復元できます。結び付いた項目の削除または履歴の全消去で、その結び付きを解除します。
- 手動保存を読み込んだ後は元の項目を更新します。通常の読み込み、別の履歴項目の再読み込み、内蔵例、エディターの消去、ローカルカバーのアップロードでは新しい保存セッションになります。項目が外部で削除済みの場合、その操作では古い結び付きだけを解除し、暗黙に新規作成しません。

## 安全な保存と移行

- 履歴 schema v2 は従来の v1 項目を元の順序のまま欠損なく移行し、再読み込みしてもデータはそれ以上変化しません。
- 手動保存に含めるのは取得元、タイトル、アーティスト、アルバム、歌詞、翻訳、翻訳の有効状態、安全なリモート URL などの意味内容だけです。スタイル、設定、書き出し画像、ローカルパス、API キー、画像バイナリ、Base64、blob URL、data URL は保存しません。
- ID とタイムスタンプは Electron のメインプロセスが作成します。作成・更新を分けた安全な IPC で、フィールド制限、1 項目 512 KiB の上限、直列化した原子的書き込み、終了前の書き込み完了待機を行います。

## 対象範囲と検証

- 新しい画面テキストは簡体字中国語、繁体字中国語、英語、フランス語、日本語、スペイン語に対応しています。
- Web Lite の画面と動作は変更せず、ブラウザー側の手動保存代替機能や新しい `Ctrl+S` ショートカットも追加しません。
- store、移行、安全な IPC、画面契約、パッケージ、実 Electron 操作の回帰テストで、作成、同一項目の更新、未変更時の省略、結び付きのライフサイクル、失敗後の再試行、終了時の書き込み完了を確認します。
