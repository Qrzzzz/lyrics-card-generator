This is a maintenance update focused on slimming down and organizing the project.

This release cleans up a large amount of legacy and unused code, splits the previously bloated editor logic, and reorganizes the Windows desktop build and packaging workflow. For regular users, the core functionality remains largely unchanged; for ongoing development, the project structure is clearer and maintenance costs are lower.

## Major Changes

* Cleaned up unused code and redundant logic, reducing project overhead.
* Refactored the editor structure, splitting portions of the UI and logic into independent components.
* Preserved the original card layout algorithm to ensure code cleanup does not affect lyric card rendering.
* Fixed the desktop export panel and PNG export controls.
* Fixed the desktop font bundling issue to ensure built-in fonts load correctly.
* Reorganized the Windows desktop build workflow.
* Updated version number, download filenames, and related version info to `1.1.0`.

## Downloads

* Installer: `Lyrics Card Generator Setup 1.1.0.exe`
* Portable: `Lyrics Card Generator-1.1.0-portable.exe`

## Note

This version is still not code-signed. Windows may display a SmartScreen prompt, which is common for unsigned personal applications.
