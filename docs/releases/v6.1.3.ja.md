# Lyrics Card Generator v6.1.3

> 状態：正式リリース済みです。

## 1 つのウィンドウでの 2 フォント選択

- Windows のネイティブ WinForms 構成ウィンドウに CJK 用と欧文用のフォント一覧を直接組み込み、ロールごとに別のシステム `FontDialog` を開かなくなりました。
- 両方の一覧はインストール済みシステムフォントを列挙し、名称から言語カバレッジを推測せず、縦書き用エイリアスは除外します。
- 現在の両方の選択とライブプレビューを常に表示します。キャンセルは下書き全体を破棄し、「フォント構成を適用」は従来どおり 1 回の確定で両方を原子的に反映します。

## 高 DPI での鮮明さと互換性

- ネイティブヘルパーは WinForms UI を作成する前に Per-Monitor V2 DPI 感知を有効にし、Windows が 96 DPI のウィンドウをビットマップ拡大することを防ぎます。
- 96 DPI 基準のレイアウトをメインウィンドウがあるディスプレイの実 DPI に合わせてネイティブ拡大縮小し、125%、150%、175% などでのコントロールと文字の鮮明さを改善します。
- ネイティブ橋渡しの値検証、メインウィンドウハンドルによる所有、制限付き結果解析は維持します。非 Windows デスクトップ版、ブラウザ選択画面、歌詞カードの描画規則は変更しません。
