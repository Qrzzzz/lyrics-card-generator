# Lyrics Card Generator v6.1.2

> Status: publicly released through GitHub Releases.

## Native two-font scheme

- The separate CJK and Latin custom-font entries are replaced by one “Edit Scheme” entry.
- On Windows, it opens a native WinForms scheme window owned by the main window. Its two Choose buttons each invoke the system `FontDialog`; no Electron or HTML-drawn font picker is created.
- The scheme window shows both current families and previews. Cancel discards the whole draft; “Apply Font Scheme” commits both families once and restores focus to the main entry.

## Font completeness and compatibility

- Windows `FontDialog` presents system fonts directly, without application-side name classification. In the non-Windows desktop and browser fallbacks, categories affect recommendations and preview text only, and every enumerated font remains available for both roles.
- The native bridge retains bounded field validation, main-window handle ownership, and restricted result parsing. The non-Windows desktop fallback keeps isolated minimal IPC.
- Custom schemes keep the existing preview, export, and persistence data model, without changing lyric-card rendering rules.
