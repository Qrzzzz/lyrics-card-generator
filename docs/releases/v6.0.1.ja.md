# Lyrics Card Generator v6.0.1

> 状態：GitHub Releases で公開済みです。

## Electron ネイティブのシステムダイアログ

- Windows デスクトップ版では、曲の置き換え、訳詞の上書き、履歴の消去・縮小、履歴確認の失敗、終了時の保存失敗という 6 つの通知を Electron ネイティブのシステムダイアログに統一しました。
- 確認には OS の警告アイコン、失敗にはエラーアイコンを使用し、追加のアイコン素材は必要ありません。
- タイトル、詳細、ボタンは簡体字中国語、繁体字中国語、英語、フランス語、日本語、スペイン語に完全対応しています。

## 安全性と互換性

- 置き換え、上書き、削除などの操作は「キャンセル」を既定で選択し、ダイアログを閉じるか Esc を押した場合も実行されません。
- renderer、preload、main process の各層で入力を検証し、contextBridge には制限された基本フィールドだけを渡します。
- Web Lite と通常のブラウザーでは、既存機能を変えずに互換フォールバックを維持します。
