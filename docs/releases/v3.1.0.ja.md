# Lyrics Card Generator v3.1.0 リリースノート

リリース日：2026年6月21日

## 概要

v3.1.0 ではフォント構成パネルを再構築し、CJK フォントと欧文フォントを個別に制御できるようにしました。同時に、プレビューと PNG 書き出しにおける Windows システムフォントの信頼性も改善しています。

## 修正と改善

- 「現在の構成」「プリセット構成」「カスタム構成」「フォントプレビューカード」の4つの明確な領域を追加しました。
- プリセットを源ノ角ゴシックと源ノ明朝の2つに整理し、各構成で CJK と欧文に同じファミリーを使用します。
- カスタム構成では CJK と欧文のファミリーを個別に選択でき、数字と半角記号は欧文フォントを優先します。
- インラインの一覧を、おすすめ、検索、完全なスクロールリスト、候補プレビューを備えた専用選択画面に置き換えました。
- 実際の歌詞によるプレビューを追加し、背景は実際のカードと同じアルゴリズムへ深海ブルー、コバルトブルー、インディゴブルー、ナイトブルーの4色を固定入力して生成します。
- 完全なフォントプレビューを右列の実際のカード下へ移し、幅と行間を調整して、歌詞がちょうど収まる高さの縦長レイアウトに変更しました。
- フォント構成をレイアウトから独立した手順へ分離し、短いラベルの幅を抑えて他の手順名が省略されないナビゲーションにしました。
- 背景生成はプレビュー専用で、カードの背景設定や書き出す PNG には影響しません。
- 6つの UI 言語すべてに、フォント構成の文言、操作、背景アルゴリズムの説明、カード外の注記を追加しました。
- 現在の構成をファミリーの完全一致から源ノ角ゴシック、源ノ明朝、カスタムとして識別します。
- プレビュー DOM と PNG 書き出しで、同じ正規化済み CJK / 欧文 `font-family` スタックを使用します。
- Windows フォント列挙で複合名を分割し、重複を除去して並べ替え、カンマを含む無効なファミリー名を生成しないようにしました。
- 中国語の表示名をフォントファイル内の実際の CSS ファミリーへ対応付け、ウェイトと斜体情報も保持します。
- 無効な入力の原因となる手動 `font-family` 入力欄を削除しました。
- 選択したフォントをブラウザが認識できない可能性がある場合、処理を妨げない警告を表示します。
