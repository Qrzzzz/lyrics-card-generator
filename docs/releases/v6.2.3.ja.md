# Lyrics Card Generator v6.2.3

> 状態：公開済み。

## ローカル可読性シャドウの修正

- 曲情報、歌詞、フッター付属要素のローカル可読性シャドウを同じ深さに統一しました。
- 3 領域のグラデーションを単一のアルファマスクへ統合してから明暗調整を適用します。重なりによる二重の暗化や上下の濃い帯は発生しません。
- プラットフォームロゴ、共有者名、生成ウォーターマーク固有の追加シャドウを削除し、同じ可読性レイヤーだけを使用してプレビューと書き出し結果を揃えました。

## 検証

- 背景合成回帰は 120 通りの決定的な組み合わせを網羅し、重なりに対する単一の不透明度上限と 3 領域の同一深度を検証します。
- 型チェック、lint、本番ビルド、Web Lite のビルドと整合性チェックに合格し、Chromium での実際の 2× PNG 書き出しおよび Firefox/WebKit の描画確認も完了しました。

## ダウンロードと更新

- Windows x64 インストーラー：`Lyrics.Card.Generator.Setup.6.2.3.exe`。
- 本版も Setup のみを提供します。旧版からの更新時に設定の移行は不要です。
