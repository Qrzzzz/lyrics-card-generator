# Lyrics Card Generator v4.2.3 发布说明

发布日期：2026-07-03

v4.2.3 重构软件界面本身的外观系统，把原来分散在“外观”“背景”“主题色”“文字颜色”里的设置收敛为一个清晰的界面外观模式。此次更新不改变歌词卡导出样式，不新增背景图片玩法，也不扩展用户手选主题色能力。

## 主要更新

- 设置面板移除独立“背景”页，入口收敛为“通用 / 外观 / 导出 / AI / 关于”。
- “外观”页只保留“界面外观”和“界面字体”两个用户可见设置。
- 界面外观固定为五种模式：专辑封面动态取色、深色模式、浅色模式、深色亚克力、浅色亚克力。
- “专辑封面动态取色”继续作为默认模式，并继续使用封面 palette 驱动界面氛围与强调色。
- 深色模式改为稳定的近黑背景，浅色模式改为稳定的白色背景，不再保留蓝白或黑粉预设风格。
- 深色亚克力和浅色亚克力继续走 Electron 的 Windows Acrylic 窗口材质链路。

## 兼容与迁移

- 旧的 `light-blue` 设置会迁移为 `light`。
- 旧的 `dark-pink` 设置会迁移为 `dark`。
- 旧的 `custom` 设置会迁移为 `album-dynamic`。
- 旧背景字段仍保留在内部设置结构中，但界面背景现在由 `uiTheme` 直接决定。
- 手选界面主色、手选文字颜色和背景图片模式不再出现在设置 UI 中。

## 范围说明

- 不改变歌词卡预览或导出 PNG 的视觉样式。
- 不新增背景图片功能。
- 不新增自定义主题色功能。
- `BackgroundSettingsSection` 暂时保留为内部兼容文件，但不再挂载到设置面板。
