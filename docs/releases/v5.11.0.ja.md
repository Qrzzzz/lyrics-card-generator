# Lyrics Card Generator v5.11.0

> ステータス：GitHub Releases で一般公開済みです。

## 横向きカードの全面再設計

- 横向きは自由比率の 2 カラム構成になり、歌詞領域の自動幅と自動高さが既定で有効です。16:9、21:9、3:2 のプリセットは廃止しました。
- 自動幅は DOM の折り返しと自然な高さをすべて計測し、はみ出し、孤立行、過剰な複数行化を強く避け、近い評価ではコンパクトな幅を選びます。
- 左カラムは実際の比率のカバー、曲情報、プラットフォーム、共有者、生成透かしを一体のデザイン単位として等倍に拡大縮小します。
- 指定する高さは最小値です。歌詞を切り取ったり縮小したりせず、必要に応じてキャンバスを延長します。

## 編集と互換性

- 曲情報は常に表示されます。横向きではカバーも必須で、縦向きでは引き続き非表示にできます。
- 横向きは原文と有効な翻訳を合わせて空でない論理行を 12 行まで扱います。13 行目は保持したまま案内付きで歌詞編集へ戻します。
- 旧横向き比率、サイズのスナップショット、非表示の曲情報／カバー状態は安全に移行します。
- デスクトップと Web Lite のプレビュー、画面外書き出し、不変スナップショットは同じ計測プランを共有します。
