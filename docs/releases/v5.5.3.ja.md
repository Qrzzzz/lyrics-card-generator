# Lyrics Card Generator v5.5.3 リリースノート

リリース日：2026-07-14

v5.5.3 は、既存の編集・書き出し動作を維持しながら、フォント選択、デスクトップのタイトルバー、ステップ 1 のナビゲーション、ライトアクリルの可読性を改善します。

## 主な更新

- ステップ 4 の Source Han Sans／Source Han Serif カード全体に、対応する内蔵 OTF フォントを適用しました。スキーム名、フォント名、説明、選択状態も同じ書体で表示されます。
- 48 px のデスクトップタイトルバーを、上端に固定した 144 px のフェード領域に 4 層の軽量ぼかしを重ねる構成へ変更しました。濃色、淡色、両アクリルテーマの色付きグラデーションは維持されます。
- ステップ 1 の「手動調整」を「次へ」の直前へ移しました。楽曲情報パネル内の重複ボタンをなくし、開閉状態、対象領域、安定した ID を完全に関連付けています。
- ライトアクリルのパネル、入力欄、ボタン、前面サーフェスの白いマスクを強め、補助テキストを不透明なスレート色に変更し、淡色テーマの分割コントロールも修正しました。

## 可読性と互換性

- 暗い灰色、中間の灰色、明るい Windows 背景を対象にしたコントラスト行列を追加し、小さい文字は 4.5:1 以上、重要な入力欄とボタンの境界は 3:1 以上を確保します。
- 透明感、ぼかし、素材の奥行きを残し、単なる不透明な白テーマには変更していません。
- ダークアクリルの透明パネル、明るい文字、ネイティブウィンドウ素材は従来どおりです。

## 検証

- `npm run typecheck` / `npm run lint` / `npm run core:test` / `npm run build`
- `npm run desktop:pack` / `npm run desktop:interaction-test`
- Windows デスクトップ上のライト／ダークアクリル実画面キャプチャを目視確認
