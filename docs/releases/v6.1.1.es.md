# Lyrics Card Generator v6.1.1

> Estado: publicado oficialmente mediante GitHub Releases.

## Diálogo nativo de fuentes de Windows

- La aplicación de Windows ahora llama directamente al `FontDialog` del sistema en lugar de crear una ventana de fuentes renderizada con Electron o HTML.
- El diálogo usa el identificador de la ventana principal de Electron como propietario y mantiene una modalidad real de Windows; solo puede abrirse uno a la vez y el foco vuelve tras aceptar o cancelar.
- La familia elegida sigue actualizando primero el borrador y la vista previa real de la tarjeta; Guardar como combinación actual continúa siendo el punto de confirmación.

## Fiabilidad y compatibilidad

- El puente nativo usa STA de forma explícita y limita el identificador de ventana, el nombre de fuente, la salida del proceso auxiliar y el valor devuelto; los fallos de inicio terminan de forma segura sin selección.
- La regresión de escritorio puede dirigirse a un EXE candidato aislado exacto en vez de probar por error una compilación antigua de `release`, con contratos separados para el puente, la seguridad IPC y el manifiesto empaquetado.
- Los entornos de escritorio que no son Windows y los navegadores normales conservan la alternativa integrada existente; la selección de fuentes de Web Lite no cambia.
