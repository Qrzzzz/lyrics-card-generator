# Lyrics Card Generator v4.4.6 發布說明

發布日期：2026-07-11

本版本集中修正六步編輯流程、設定側翼與匯出階段的版面及動效問題。既有卡片元素、匯出品質滑桿以及完成與匯出按鈕的行為維持不變，同時讓各步驟的空間節奏、設定視覺語言與 PNG 產生回饋更加一致。

## 主要更新

- Stepper 在不同步驟下使用一致的內容高度與底部留白，不再因特定步驟產生過高行高；左側底部的「上一步／下一步」導覽同步移除外圍大邊框，改為與第六步一致的無外框版面。
- 修正點擊「設定」時側翼向右切換動畫偶爾消失的問題，確保從主介面或歌詞範例返回後都能可靠播放橫向過渡。
- 設定介面改用與主介面一致的大標題及表面語言，移除最外層大邊框、直角分隔和分頁說明小字；關閉按鈕沿用歌詞範例的 X 號回饋，並取消右上角常駐「設定已儲存」，只保留原有輕提示。
- 左上角紅黃綠視窗控制按鈕略微放大並加入更靈動的懸浮回饋；同時移除標題列左側應用程式圖示周圍的細邊框。
- 第四步「字型方案」更名為「文字設計」，並接收原第五步的「文字顏色」；文字顏色不再提供預設集合，「自動」改為唯一的「白色」選項，同時保留自訂顏色，右側預覽同步反映新設定。
- 移除「封面裁切」控制項並將裁切值固定為 1；重新整理「純音樂／無歌詞」的選擇版面，使內容類型更易讀、更易操作。
- 直向卡片尺寸預設只保留 1:1 與自訂，預設選擇自訂並開啟自動高度；第三步底部的對齊控制改為橫向滑桿，維持版面控制項語言一致。
- 第六步在保留原有元素的前提下重新組織匯出資訊層級與間距，並為「正在產生 PNG」加入更清楚、美觀且遵守 reduced motion 的動畫；既有清晰度滑桿和「完成並匯出」按鈕的互動不變。

## 驗證

- npm run core:test
- npm run build
- npm run desktop:build
- git diff --check
- 六步 Stepper、底部導覽與第三至第六步控制項的桌面視覺檢查
- 設定橫向過渡、關閉按鈕、儲存提示、標題列控制與 PNG 產生動畫檢查
