# Notas de la versión de Lyrics Card Generator v5.0.2

Fecha de lanzamiento: 2026-07-12

La versión 5.0.2 refuerza la publicación basada en v5.0.0 sin cambiar las interacciones existentes de edición, vista previa ni exportación.

## Actualizaciones principales

- Se alinearon la aplicación, el archivo de bloqueo, los seis README localizados y las notas de la versión con la versión 5.0.2.
- Se actualizaron Next.js, Undici y otras dependencias dentro de rangos compatibles, eliminando las alertas de ejecución de gravedad alta.
- Se volvieron a verificar y compilar Web Lite, el instalador de Windows, la versión portable y el archivo de validación de actualizaciones incrementales.

## Verificación

- `npm run typecheck`
- `npm run core:test`
- `npm run build`
- `npm run web-lite:build` / `web-lite:check` / `web-lite:smoke`
- `npm run desktop:build` / `desktop:interaction-test`
