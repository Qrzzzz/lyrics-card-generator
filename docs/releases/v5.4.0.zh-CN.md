# Lyrics Card Generator v5.4.0 发布说明

发布日期：2026-07-13

v5.4.0 完成六步编辑器顶部结构的统一，并将第一步重构为与后续步骤一致的紧凑工作台。

## 主要更新

- 第一步现在使用与第 2 至第 6 步相同的紧凑 Stepper，当前步骤、完整六步导航及“示例”“一键清空”“设置”集中在同一块流程面板中。
- 移除第一步重复的大型软件标题栏，Windows 自绘标题栏继续保留应用名称、图标和版本信息。
- 第一页改为共享双栏工作台，顶部流程面板横跨网易云搜索主区与歌曲导入侧栏。
- 歌曲信息、歌曲链接、本地音频和手动调整收敛到同一个侧栏面板，所有原有导入路径和辅助功能语义保持可用。
- 1000px 桌面最小宽度继续使用 320px 侧栏，并在更宽窗口逐级扩展到 360px 和 400px。

## 版本范围

- 网易云搜索、链接解析、本地音频解析、手动歌曲信息、歌词文档和 AI 翻译行为均未改变。
- 第 2 至第 6 步、实时预览、导出 PNG、设置数据、项目格式和 Web Lite 共享组件行为均未改变。

## 验证

- `npm run lint` / `npm run typecheck` / `npm run core:test` / `npm run build`
- `npm run web-lite:build` / `npm run web-lite:check` / `npm run web-lite:smoke`
- `npm run desktop:build` / `npm run desktop:interaction-test` / `npm run desktop:final-artifact-smoke`
- 1000×700、1023×700、1024×700、1280×900、1440×900 与 1920×1080 桌面窗口回归
