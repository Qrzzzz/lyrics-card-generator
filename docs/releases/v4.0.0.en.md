# Lyrics Card Generator v4.0.0 Release Notes

Release date: 2026-07-01

v4.0.0 upgrades the first song-picking step to NetEase Cloud Music song-name search. Users can type a title, artist, or album keyword, choose from live candidates, and automatically import metadata, cover art, and available lyrics. Existing link parsing, local audio parsing, manual editing, AI translation, themes, and PNG export remain available.

## Main Updates

- Added NetEase Cloud Music song search as the first “Choose a song” entry.
- Shows live candidate songs with title, artist, album, and duration while typing.
- Supports arrow-key selection, Enter import, and mouse-click import.
- Imports title, artist, album, cover art, and NetEase lyrics when available.
- Lyric fetch failures do not block metadata import; users can still use the existing lyric fetch button or edit manually.

## Compatibility

- Spotify, Apple Music, NetEase Cloud Music, and QQ Music link parsing entries remain available.
- Local MP3 / FLAC metadata and embedded lyric parsing remain available.
- Manual song edits, lyric editing, AI translation, cover color extraction, style controls, and PNG export are unchanged.

## Usage Notes

- If search results are imprecise, search with both title and artist.
- NetEase search and lyric fetching require internet access.
- Automatically fetched lyrics may be incomplete, so review them before export.
