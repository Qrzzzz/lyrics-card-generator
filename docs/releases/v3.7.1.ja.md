# Lyrics Card Generator v3.7.1 リリースノート

リリース日：2026-06-30

v3.7.1 は UI コントロールの標準化リリースです。v3.8.0 で予定しているアニメーション刷新はまだ実装していません。今回の更新では、トグル、オプションカード、セグメントコントロール、設定パネルの入力系コンポーネントを統一しつつ、アクセシビリティとキーボード / フォーカス挙動を改善し、後続の v3.8.0 アニメーション更新に向けた土台を整えています。

## 改善

- スタイルパネル、歌詞入力、曲情報、設定内のトグルを標準化し、オン / オフ状態、無効状態、視覚フィードバックの挙動をそろえました。
- 言語選択のような単一選択を共通のオプションカードへ整理し、レイアウトモード、グリッド密度、フレーム / フルブリードのようなコンパクトな選択肢を一貫したセグメントコントロールへ統一しました。
- 設定パネルで使う入力欄、テキストエリア、セレクト、アクションボタンの見た目と操作時のフィードバックを統一し、各セクションのコントロールをより一貫させました。

## アクセシビリティと一貫性

- 共通コントロールのキーボード操作性、フォーカスの見え方、ラベル表示、無効状態のフィードバックを改善し、パネルごとの操作差を減らしました。
- 一部のスイッチ色やテーマ別の個別スタイルを整理し、既存のテーマトークンにより多く寄せることで、ダーク、ライト、Acrylic、カスタム各テーマでの見た目を安定させました。
- このリリースは v3.8.0 のアニメーション更新に向けてコントロール層を整えるものであり、新しいアニメーションシステム自体は追加していません。また、書き出し結果、設定スキーマ、既存の操作フローも変更していません。

## 検証

- npm run typecheck
- npm run core:test
- npm run build
