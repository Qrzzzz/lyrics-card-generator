# Lyrics Card Generator v6.2.0

> 状态：已发布。

## 复制成品图片

- “完成并导出”旁新增“复制图片”，无需先保存文件即可把当前成品写入系统剪贴板。
- 剪贴板统一使用兼容性更稳妥的 PNG，并继承当前导出清晰度；复制不会改变 PNG、WebP 或 JPG 的下载格式选择。
- 操作期间会显示专用进度与完成提示；失败时会给出剪贴板权限检查指引。

## 与导出共用安全边界

- 复制与下载共用不可变文档快照、字体与图片就绪检查、内容溢出防线、像素尺寸上限和互斥事务。
- Windows 桌面版通过受信任的 Electron IPC 将已解码图片写入原生剪贴板，并在预加载层与主进程重复限制 PNG 数据和尺寸。
- Web Lite 在浏览器支持图片剪贴板 API 时提供同一入口；不支持或权限被拒绝时保持编辑内容不变并显示错误提示。

## 验证范围

- 类型检查、导出事务、六语种完整性、Electron 预加载与安全契约、步骤布局、Web Lite 真实 PNG 复制及桌面原生剪贴板交互均纳入回归。
