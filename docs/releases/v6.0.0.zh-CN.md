# Lyrics Card Generator v6.0.0

> 状态：已通过 GitHub Releases 公开发布。

## 结构化歌词文档内核

- 歌词数据真源升级为 `LyricDocumentV2`。自然段对应 Block，原文与译文组对应带稳定 ID 的 Unit，每次有效操作递增 document revision。
- 纯文本粘贴和编辑方式保持不变；确定性解析器负责分段、对齐和 ID 协调，并保留顺序、空行及译文。旧存档会在加载时迁移。
- 导入、编辑、撤销／重做、手动存档、预览、自动布局与导出现在消费同一份文档。旧 `lyrics` 和 `translationText` 仅作为派生兼容投影。

## AI 翻译与导出一致性

- AI 翻译按 Unit ID 请求和提交结构化 JSON，只接受完整、顺序一致且 revision 仍匹配的结果。
- 迟到响应、错误 ID、缺失 Unit 和额外字段不会覆盖当前文档；流式响应只在形成合法完整 JSON 后更新译文。
- 导出快照冻结歌词文档、document revision、样式与已求解布局，避免编辑期间的预览／导出差异。

## 兼容性

- 桌面端与 Web Lite 保留现有歌词编辑体验和卡片视觉语言。
- v1 手动存档仍可读取；新 v2 存档持久化稳定 Block／Unit ID，并通过严格边界校验。
