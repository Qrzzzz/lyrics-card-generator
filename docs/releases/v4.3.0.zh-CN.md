# Lyrics Card Generator v4.3.0 发布说明

发布日期：2026-07-05

本版本更新了示例歌曲流程、布局控件、显式标志渲染以及最终导出步骤。

## 主要更新

- 重建示例歌曲对话框为响应式网格，根据窗口宽度自动选择两列或三列布局。
- 移除逐首歌曲的翻译语言按钮；示例现在加载与当前界面语言匹配的翻译。
- 英文界面下选择英文原词时，翻译字段留空。
- 新增可选歌曲字段 `explicit: boolean`；视觉细节开关直接控制标志显示。
- 在预览和导出 PNG 中，标题旁渲染内联 E 标志。
- 初始尺寸模式保持在自定义并启用自动高度。
- 将内容类型和文字颜色改为分段滑块控件。
- 仅在选中对应模式时才显示预设或自定义文字颜色选项。
- 将视觉细节开关重排为两列布局。
- 将完成并导出移至最终步骤导航的右侧，与返回按钮高度对齐。
- 移除框架与阴影渲染路径及其视觉控件。

## 验证

- npm run core:test
