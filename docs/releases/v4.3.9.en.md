# Lyrics Card Generator v4.3.9 Release Notes

Release date: 2026-07-10

This release refines the example-song experience around continuous album-palette cards with real track metadata. Each card is now the single import control, while example maintenance stores palette metadata extracted from temporary album covers instead of generating or distributing local preview images.

## Main Updates

- Example cards use a continuous album-palette background across the full card, without explicit swatches, simulated covers, placeholder content, or split sections.
- Cards display the real album, song, artist, and source language. Clicking anywhere on a card, or pressing Enter / Space while focused, imports the example.
- The bottom “Load example” row is now an integrated visual cue instead of a separate button; hover, press, and keyboard focus feedback belong to the whole card.
- The existing contrast resolver automatically switches to dark text on light palettes, and the import-translation toggle has a simpler borderless treatment.
- Example maintenance now extracts 2–6 palette colors directly from temporary album covers. Real covers and generation files are neither committed nor bundled.
- Updated `docs/examples.md` and the example regression suite to enforce real album metadata, whole-card interaction, and offline availability.
