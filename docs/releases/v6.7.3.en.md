# Lyrics Card Generator v6.7.3 Release Notes

Release date: 2026-10-14.

v6.7.3 distinguishes automatic wrapping from entered line breaks, improving long and bilingual lyrics while retaining adjustable line height.

- Wrapped parts of the same entered line use closer spacing. Entered line breaks retain the selected line height so adjacent lyrics remain distinct.
- Line Height retains its 1.5–2.1 range, 0.05 step and 1.8 default. Wrapping in both lyrics and translations follows the slider without adding a setting.
- Portrait, landscape, preview, export and automatic size measurement share the same spacing. Multi-line merged units, blank lines, separators and bilingual alignment are preserved.
