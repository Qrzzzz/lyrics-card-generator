# Lyrics Card Generator v6.2.11

## 修復與改進

- 移除首次啟動時的語言選擇視窗，開啟軟體即可進入編輯器。
- 沒有已儲存的語言時，依系統語言偏好順序比對現有六種語言；皆不支援或讀取失敗時使用英語。
- 正確辨識簡繁中文與地區變體；既有語言選擇繼續生效，也可隨時在設定中更改。
- Web Lite 同樣依瀏覽器語言偏好順序比對；啟動時會等待語言偏好讀取完成再顯示桌面編輯器。

- Windows x64: `Lyrics.Card.Generator.Setup.6.2.11.exe`.
