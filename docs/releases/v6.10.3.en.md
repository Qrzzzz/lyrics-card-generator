# Lyrics Card Generator v6.10.3

Preserves pale cover colors, unifies the original and translation editor headings, and simplifies the repository root.

## Improvements

- Pale covers retain their source brightness and color coverage, without small accents displacing the dominant background. Automatic text color evaluates the composed gradient and selects black or white; manual colors remain supported.
- Original and translation columns share a consistent editor surface and lightweight headings. A short underline and marker identify the active column; heading clicks focus the editor, and sticky headings cover text during shared scrolling.
- Translated READMEs, Playwright configurations, and dedicated TypeScript configurations move into focused directories. Root files decrease from 26 to 15, with navigation, media, release links, test commands, and incremental-cache paths updated.

## Validation scope

Relevant behavior regressions, type checking, lint, production build, generated Web Lite, and documentation links passed locally. Local Chromium covered light/dark editor headings, focus, shared scroll and selection restoration, and portrait/landscape PNG exports for pale covers. Desktop rendering uses a bridge fixture; CI and Release own full regression and native installation, update, asset, and provenance verification. The application remains unsigned; external links to the former translated README paths need updating.
