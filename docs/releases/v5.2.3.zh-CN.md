# Lyrics Card Generator v5.2.3 发布说明

## 发布验证修复

v5.2.3 修复 v5.2.2 发布流程最后一道附件回下载校验失败的问题。

- 当同一标签下同时存在已发布 Release 与草稿 Release 时，流程不再通过标签下载可能指向错误 Release 的附件。
- 工作流会记录本次创建的唯一草稿 Release ID，并通过该 ID 下载、校验和发布同一组附件。
- 正式发布前会严格核对 Setup、便携版、SPDX SBOM、SHA256SUMS、文件摘要与 GitHub attestation。
- 同标签已存在正式发布时会提前中止；重新执行时只清理同标签残留草稿，避免重复或不完整 Release 被误认为成功。

## 版本范围

- 应用功能、界面行为、歌词卡输出和项目数据格式与 v5.2.2 保持一致。
- 本版本仅修复发布与供应链验证流程，并重新生成经过完整验证的 Windows 制品。
