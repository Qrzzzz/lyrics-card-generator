# Lyrics Card Generator v6.1.3

> 状态：已正式发布。

## 单窗口双字体选择

- Windows 原生 WinForms 方案窗口现在直接内置中日韩与西文字体下拉列表，不再为两个角色分别弹出系统 `FontDialog`。
- 两个列表都直接枚举系统已安装字体，不使用字体名称猜测语言覆盖范围，并排除竖排别名。
- 当前选择和两组实时预览始终可见；“取消”整体放弃草稿，“应用字体方案”仍以一次确认原子提交两种字体。

## 高 DPI 清晰度与兼容性

- 原生辅助进程在创建 WinForms 界面前启用 Per-Monitor V2 DPI 感知，避免 Windows 以 96 DPI 位图整体拉伸窗口。
- 窗口布局以 96 DPI 为基准，按主窗口所在显示器的实际 DPI 原生缩放，提升 125%、150%、175% 等缩放比下的文字与控件清晰度。
- 原生桥接仍保留严格字段校验、主窗口句柄模态归属和受限结果解析；非 Windows 桌面回退、浏览器选择器与歌词卡渲染规则保持不变。
