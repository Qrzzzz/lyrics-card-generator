# Notas de la versión 5.2.1 de Lyrics Card Generator

## Restauración del análisis de enlaces musicales

La versión 5.2.1 restaura el análisis de enlaces reales de Spotify, Apple Music, NetEase Cloud Music y QQ Music sin eliminar las protecciones de red incorporadas en las versiones 5.1.0 y 5.2.0.

- Los enlaces QQ Music `songDetail` numéricos ahora usan `songid` y completan correctamente el título, artista, álbum y portada.
- Las solicitudes JSON de NetEase negocian el tipo de respuesta correcto y vuelven a obtener todos los metadatos de canción, artista y álbum.
- Apple Music utiliza el ID original aunque la página redirija al inicio y devuelve un enlace de canción válido.
- Los enlaces de Spotify siguen siendo compatibles y las cuatro plataformas cuentan con pruebas de regresión mediante enlaces reales.

## Seguridad y compatibilidad

- Se mantienen la validación URL/DNS por salto, la revisión de redirecciones, los límites de tamaño y tipo de respuesta, y el fallback IPv6/IPv4 multidirección.
- La salida de las tarjetas, los formatos de datos y la dirección visual existente no cambian.
- Los artefactos Setup y portable para Windows x64 se han reconstruido para la versión 5.2.1.
