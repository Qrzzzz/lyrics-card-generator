# Lyrics Card Generator v3.3.1 Release Notes

Release date: 2026-06-27

v3.3.1 is a bugfix release after v3.3.0. It mainly fixes how the "Fine grid background" toggle is displayed on card backgrounds.

## Fixes

- Fixed two grid layers overlapping on the card background when "Fine grid background" is enabled.
- Fixed one grid layer remaining on the card background after "Fine grid background" is disabled.
- The "Fine grid background" toggle now accurately controls the internal card grid; after it is disabled, no internal fine grid appears in preview or exported images.
- The main application background texture is unaffected.

## Validation

- Verified preview behavior for portrait cards with "Fine grid background" enabled / disabled.
- Verified preview behavior for landscape cards with "Fine grid background" enabled / disabled.
- Verified exported PNG output matches the preview.
- Ran `npm run typecheck` and `npm run build`.
