# Lyrics Card Generator v6.5.3 發布說明

發布日期：2026-09-18

v6.5.3 修正淺色背景下 Explicit 標記不可見的問題，讓標記跟隨卡片文字顏色，橫版、直版及匯出保持一致。

## 修正

- 選擇白色純色背景並使用自動文字顏色時，Explicit 標記現在隨標題顯示為黑色；深色背景下仍顯示為白色。
- 單行、多行標題與橫直版共用一致的標記顏色。關閉 Explicit 後不顯示標記，原有形狀、尺寸與無障礙標籤保持不變。
