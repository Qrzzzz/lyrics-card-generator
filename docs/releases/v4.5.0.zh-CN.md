# Lyrics Card Generator v4.5.0 发布说明

发布日期：2026-07-11

本版本优化纯音乐卡片的信息排版与桌面窗口控制样式，并让设置中的标签页切换、动效偏好和导出默认值更加完整。新增设置均直接服务于当前编辑流程，不改变既有窗口按钮动效。

## 主要更新

- 纯音乐 / 无歌词卡片重新调整歌曲标题、歌手和专辑信息之间的间距，整体排版更加舒展；有专辑名时会像有歌词模式一样显示专辑信息，没有专辑名时则不额外占位。
- 左上角红黄绿窗口控制按钮取消上一版本的 3D 风格，恢复平面样式并缩小三个按钮之间的间距，同时保留现有动效。
- 设置的不同标签页新增内容切换动效，使分类之间的切换更连贯。
- 通用页新增默认关闭的“减弱动效”开关。启用后会减少界面位移、切换与庆祝动效；无论软件开关状态如何，系统的减弱动态效果偏好仍会自动生效。
- 导出页在“导出质量”前新增生成水印与分享人默认值。分享人默认关闭；启用后可填写默认分享人文本，开关和文本变化会即时联动当前卡片。

- “一键清空”现在会让旧预览卡片向左滑出并隐去，同时让新的空白卡片从右侧滑入并渐显；卡片已经为空时只显示轻提示，不会重复执行清空。
- 轻提示重新设计了图标、层次、阴影、底部计时线与进出场动效，连续触发相同消息时也能重新展示。
- 导出步骤移除了冗余的外围大边框与“只导出歌词卡片，不包含编辑器界面。”说明标签，同时保留导出质量选择、导出按钮和进度反馈。
