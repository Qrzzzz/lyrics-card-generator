# Lyrics Card Generator v5.10.3

> Statut : publié publiquement via GitHub Releases.

Cette version de maintenance renforce l’accessibilité, la chaîne d’approvisionnement et les contrôles qualité multiplateformes. L’interface et le rendu des exports restent inchangés, tandis que des limites auparavant vérifiées manuellement deviennent reproductibles.

## Points forts

- Corrige les repères `main` dupliqués ou imbriqués dans Web Lite et fait appliquer les règles d’accessibilité concernées par le contrôle axe.
- Met à jour les dépendances de production et de construction, avec des exceptions motivées et limitées dans le temps, un SBOM de publication et une politique CI/Release bloquante.
- Inclut le texte OFL complet de Source Han Sans et Serif dans le dépôt, Web Lite, GitHub Pages, le serveur desktop, l’installateur et la version portable.
- Ajoute les régressions de rendu continues, un benchmark planifié des longues cartes, l’analyse statique et la couverture des limites à risque d’Electron, ainsi que des tests Firefox et WebKit.

## Validation

Cette version a réussi les contrôles de types, lint, dépendances et licences de polices, l’accessibilité Chromium, les tests Firefox/WebKit, les limites de rendu en production, la régression Web Lite complète, la couverture Electron, les interactions desktop, le smoke test des artefacts Windows finaux, le SBOM, les sommes de contrôle et les attestations.
