# Lyrics Card Generator v3.8.0 リリースノート

リリース日：2026-06-30

v3.8.0 は UI モーションとインタラクションの磨き込みに集中したリリースです。v3.7.1 の共有コントロール標準化を土台に、集中管理されたモーションシステムを追加しました。モーションはエディター外枠、設定ダイアログ、プレビュー外枠、共有コントロール、AI パネル、アプリ背景に適用されています。エクスポートされる歌詞カード PNG の出力は意図的に変更しておらず、このリリースでアニメーション付きカード書き出しは追加していません。

## モーションシステムと編集体験

- 軽量なモーショントークンと再利用可能なコンポーネントを追加し、時間、イージング、スプリング、パネル遷移、ダイアログ遷移、ステップ遷移、モーション削減時の挙動を統一しました。
- 設定ステッパーは方向を持つ遷移に変更しました。前進時は右から入り左へ抜け、後退時は逆方向に動きます。
- 設定ダイアログ、設定タブ、プレビュー外枠の出入りを統一し、モバイルでのプレビュー展開 / 折りたたみをより滑らかにしました。

## コントロール、AI パネル、背景

- 共有ボタン、トグル、オプションカード、セグメントコントロールに控えめな押下、選択、インジケーターのマイクロインタラクションを追加しつつ、キーボード操作、フォーカス表示、ARIA、テストフックを維持しました。
- AI 翻訳パネルは共有オプションカード、トグル、アクションボタンを使う形へ整理し、ステータス、推論、翻訳出力セクションに統一した遷移を追加しました。リクエスト、ストリーミング、キャンセルの動作は変えていません。
- テーマ、画像、パレットモードの切り替え時にアプリ背景がより滑らかに変化しますが、エクスポートカード内の `PaletteBackground` は変更していません。

## アクセシビリティとエクスポート安全性

- `prefers-reduced-motion` を尊重します。横移動、ホバー移動、装飾 keyframe、クリック火花、エクスポート祝い演出は、透明度のみの挙動へ縮小するか無効化されます。
- `LyricCard.tsx`、`LandscapeLyricCard.tsx`、`PaletteBackground.tsx` は Framer Motion をインポートしていません。
- 静的な `data-export-card="true"` のエクスポート経路は維持され、PNG の見た目は意図的に変更していません。

## 検証

- npm run typecheck
- npm run core:test
- npm run build
