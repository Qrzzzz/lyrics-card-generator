# Lyrics Card Generator v5.11.2

> 状態：GitHub Releases で一般公開済みです。

## 複数行タイトルの修正

- 旧「タイトルを2行まで許可」は6言語すべてで「タイトルの複数行表示を許可」に改名され、動作も2行に制限されなくなりました。有効にすると縦向きの歌詞カードとインストゥルメンタルカードで3行以上のタイトルを表示でき、無効時は従来どおり1行で省略します。
- 縦向き歌詞カードの自動高さがタイトルの行数を考慮するようになり、長いタイトルが歌詞領域を圧迫したり、書き出し時に切れたりすることを防ぎます。
- 固定1:1のインストゥルメンタルカードは複数行の曲情報に必要な高さを動的に確保し、空間が足りない場合はアートワークを縮小してタイトル、アーティスト、アルバム情報のはみ出しを防ぎます。既存の横向き実測複数行レイアウトは監査の結果、変更不要でした。デスクトップ版と Web Lite は同じ動作を共有します。
