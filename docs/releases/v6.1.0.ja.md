# Lyrics Card Generator v6.1.0

> 状態：GitHub Releases で正式公開済みです。

## Electron ネイティブのフォント選択ウィンドウ

- Windows デスクトップ版では、カスタムフォント選択をアプリ内オーバーレイから、OS のタイトルバーを持つ Electron 子ウィンドウへ移しました。
- 検索、おすすめ、システムフォント一覧、各フォントのサンプルを維持し、ホバーやキーボードフォーカスに追従する拡大プレビューも追加しました。
- 選択後もまずカスタム構成の下書きと実際の歌詞カードプレビューだけを更新し、「現在の構成として保存」で確定します。

## セキュリティと互換性

- フォントウィンドウは独立した最小権限の IPC ID を使用し、メインウィンドウのファイル、履歴、AI 権限にはアクセスできません。
- Web Lite と通常のブラウザーでは、互換性のあるアプリ内フォールバックを維持します。
