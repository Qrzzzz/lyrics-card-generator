# Notes de publication de Lyrics Card Generator v5.5.2

Date de publication : 2026-07-14

La v5.5.2 clarifie les deux premières étapes du flux de bureau en donnant une place nette à chaque méthode d’import et en allégeant les cadres imbriqués de l’espace des longues paroles.

## Points clés

- À l’étape 1, la recherche NetEase occupe le haut de la colonne gauche. L’import par lien et par fichier audio passe dessous et s’affiche côte à côte lorsque l’espace le permet.
- La colonne droite présente séparément la pochette, le titre, l’artiste et l’album, tout en conservant l’éditeur manuel dépliable.
- L’étape 1 n’affiche plus de bouton Retour inutilisable ; la navigation des étapes suivantes reste inchangée.
- L’étape 2 retire le cadre général ainsi que les cadres des colonnes de résumé, de document et d’outils.
- Les mises en page larges ne gardent qu’un séparateur vertical d’un pixel ; les colonnes empilées utilisent un séparateur horizontal d’un pixel.

## Portée

- La recherche, l’analyse des liens et fichiers audio, l’édition des métadonnées, des paroles et l’export conservent leur comportement.
- Les champs, états, statistiques et panneaux dynamiques gardent leurs bordures locales utiles.
- La navigation partagée par le bureau et Web Lite masque partout le retour invalide de la première étape.

## Validation

- `npm run typecheck` / `npm run lint` / `npm run core:test` / `npm run build`
- `npm run web-lite:build` / `npm run web-lite:check` / `npm run web-lite:smoke`
- `npm run desktop:build` / `npm run desktop:interaction-test`
