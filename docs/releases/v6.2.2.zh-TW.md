# Lyrics Card Generator v6.2.2

> 狀態：已發布。

## Windows 發行改為僅提供 Setup

- 從 v6.2.2 起僅發布 Windows x64 安裝程式 `Lyrics.Card.Generator.Setup.6.2.2.exe`，不再建置或提供免安裝版本。
- v6.2.1 與更早版本仍可透過應用程式內更新入口開啟最新 GitHub Release；舊免安裝版使用者可從該頁下載 Setup。
- 發布附件固定為 Setup、SPDX SBOM 與 `SHA256SUMS`，三項都由發布流程產生來源證明。

## AI、請求邊界與持久化修正

- 非回環 AI 服務位址現在必須使用 HTTPS；回環 HTTP 仍保留給本機模型。應用程式寫入請求的來源檢查會綁定受信任的外部主機。（#143、#145）
- 請求內容、上游回應、AI JSON/SSE 串流、遠端中繼資料與取消傳遞採用明確的容量、時限與中止預算。（#146）
- AI 設定改為原子寫入，避免當機或斷電留下截斷檔案；並行語言與偏好儲存會保留最新使用者設定。（#147、#148）
- Electron 剪貼簿圖片會在配置原生影像前檢查解碼後的像素面積與位元組預算。（#149）

## 發布與供應鏈閘門

- 發布來源必須是已審查的 `main` 祖先，而且精確發布提交必須通過全部必要 CI；發布前與公開前都會重新授權。（#144）
- 移除 Next 15.5.24 下已過期的 Sharp 稽核例外；封裝進應用程式的 Electron 執行階段納入獨立相依性稽核與 SPDX SBOM。（#150、#151）
- Release 查詢會走訪所有分頁並在衝突狀態下安全失敗，避免倉庫超過 100 個 Release 後錯誤重用或覆寫。（#152）

## 驗證範圍

- 修正 Windows 封裝互動測試的觀察時序競態：觀察器會在觸發受控輸入更新前安裝，歷史重新定位會等待動作真正就緒，同時保留原有嚴格斷言。
- 型別檢查、lint、穩定性、核心測試、Web Lite、相依性與 SBOM policy、封裝回歸，以及 Setup 安裝／啟動／關閉／解除安裝 smoke 都屬於發布閘門。
