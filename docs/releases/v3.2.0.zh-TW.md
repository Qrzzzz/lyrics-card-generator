# Lyrics Card Generator v3.2.0 發布說明

發布日期：2026-06-23

## 設定中心與個人化更新

- 設定升級為一般、外觀、背景、匯出、AI、關於六個分類。
- 新增 Spark Cursor 開關、三套介面主題、介面字型／主色／文字顏色與可讀性保護。
- 新增可持久化的純色、拉伸、適應、填滿、模糊與圖片取色背景；預設仍為專輯封面動態取色。
- 新增低、標準、高清、超清四檔 PNG 匯出品質。
- 首次啟動可選擇六種語言，預設進入空白編輯器。
- `opposite` 改由「範例」入口載入；更新檢查與 GitHub 連結移至「關於」。
- Header 新增統一應用程式圖示；AI 金鑰繼續使用安全儲存。
