# Lyrics Card Generator v5.9.4 發佈說明

發佈日期：2026-08-08

v5.9.4 是不變更既有功能的效能最佳化版本，重點減少桌面啟動與編輯操作中的重複工作、無效重新渲染及高成本掃描，並補齊效能改造後的失敗復原邊界。

## 啟動與資源載入

- 最佳化打包版的本機服務啟動編排、renderer 來源確認與靜態資源快取，減少重複探測和不必要的啟動工作，同時維持原有安全檢查。
- 為非同步資料與非作用中介面設定更清楚的工作邊界，避免尚未使用的內容參與目前互動。
- 範例、歷史、設定、AI 翻譯與匯出介面仍採按需載入，不增加首屏負擔。

## 編輯與匯出效能

- ClickSpark 在閒置時不再持續執行動畫影格迴圈；觸發效果與可見行為維持不變。
- 自動寬度量測會重用同一個宿主，並縮小歌詞輸入時的視窗計算與元件提交範圍。
- 匯出就緒量測會合併重複請求，避免同一狀態變更觸發多輪幾何讀取。
- 重新渲染邊界會隔離已關閉或非作用中的介面，長歌詞輸入與 AI 串流更新不再帶動無關區域重複渲染。

## 延遲介面與系統字型

- 每個延遲介面都有獨立錯誤邊界；分塊首次載入失敗時，編輯器主體仍可使用，並可關閉、返回或重試。
- 重試會建立新的 `React.lazy` generation 並再次呼叫 loader，不會重用 React 已快取的失敗 promise。
- 系統字型清單使用程序內快取與並行去重；熱請求不會重複啟動 PowerShell 掃描，四個並行冷請求只共用一個掃描程序。
- 字型目錄變更仍會立即失效；僅發生在 Windows 登錄檔中的字型註冊、移除或顯示名稱變更，最長會在 5 分鐘內使快取失效。

## 發佈狀態

v5.9.4 已透過 GitHub Releases 公開發佈。標籤原始碼、安裝版、可攜版、SPDX SBOM 與 SHA256SUMS 均可從該發佈頁取得。
