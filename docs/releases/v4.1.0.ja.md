# Lyrics Card Generator v4.1.0 リリースノート

リリース日：2026-07-02

v4.1.0 はスタイルパネルの視覚的な階層を整理するリファクタリングです。歌詞カードの描画、エクスポート DOM、左右レイアウト、設定状態の構造は変更しません。代わりに、視覚方案の選択と通常のパラメータ調整を分け、フォント方案はカード感を維持し、フォントサイズ、行間、配置、スイッチ、クロップ、色、細部項目は連続した設定行として表示します。

## 主な更新

- Section の既定表示を通常セクションに変更し、`plain`、`card`、`subtle` の 3 段階を追加しました。
- フォントサイズ、行間、サイズ、色、クロップなどの通常設定向けに SettingRow を追加しました。
- ToggleRow は独立したカードのような見た目をやめ、行全体のクリック、switch セマンティクス、キーボードフォーカス、アクセシビリティ状態を維持します。
- レイアウトモードなどの横方向セレクターは、読みやすさを保つため従来のセグメント表示を維持します。
- フォント方案とエクスポート領域では、外側の余分なカード枠を追加しないようにしました。
- フォントプリセットカード全体をクリックできるようにし、小さな適用ボタンを狙う必要をなくしました。
- NetEase 検索のプレースホルダーを、表示言語ごとの人気曲例に変更しました。
- Stepper のヘッダーは自動高さになり、小さな補助説明行を表示しなくなりました。
- 言語変更後の保存通知は新しく選択した言語で表示され、カスタムサイズの自動高さは既定で有効になります。

## 範囲

- 右側 Preview、エクスポート DOM、歌詞カード描画ロジック、設定状態構造は変更していません。
- エクスポートされる PNG の見た目は、このパネル整理によって意図的には変更されません。
- OptionCard は視覚方案またはプリセット選択用に残し、通常の数値設定には使用しません。
