# Lyrics Card Generator v3.3.1 リリースノート

リリース日：2026-06-27

v3.3.1 は v3.3.0 後の bugfix リリースです。主に、カード背景の「細かいグリッド背景」スイッチの表示問題を修正します。

## 修正内容

- 「細かいグリッド背景」を有効にしたとき、カード背景に 2 層のグリッドが重なって表示される問題を修正しました。
- 「細かいグリッド背景」を無効にしたあとも、カード背景に 1 層のグリッドが残る問題を修正しました。
- 「細かいグリッド背景」スイッチがカード内部のグリッド表示を正確に制御するようになりました。無効にしたあとは、プレビューにも書き出し画像にもカード内部の細かいグリッドは表示されません。
- アプリ本体の背景テクスチャには影響ありません。

## 検証

- 縦向きカードで「細かいグリッド背景」のオン / オフ時のプレビュー表示を確認しました。
- 横向きカードで「細かいグリッド背景」のオン / オフ時のプレビュー表示を確認しました。
- 書き出した PNG がプレビューと一致することを確認しました。
- `npm run typecheck` と `npm run build` を実行しました。
