# Lyrics Card Generator v4.6.2 リリースノート

リリース日：2026-07-11

このバージョンでは v4.6.0 の重大な編集不具合を修正し、プロンプトライブラリの復元機能とライブプレビューのレイアウトを完成させました。

## 主な更新

- プロンプトプリセットのリセット後に全ページとテキスト欄が操作不能になる問題を修正し、ブロックするネイティブ確認ダイアログを廃止しました。
- 厳格な形式ルールを変更不可の内蔵安全モジュールに固定し、編集ロック解除の入口をすべて削除しました。過去の上書き内容も生成には使われません。
- 設定の全カテゴリと子ページで使える「戻る」「進む」とパス表示を左上ヘッダーに統合しました。
- 編集画面の実カードプレビューをスクロール中も上部に固定し、文字デザインの独立フォントプレビューカードを削除しました。
- 4 枚のサンプル曲カードを少し低くし、「アルバム」ラベルを削除しました。
- 各プロンプトプリセットにリセットボタンを追加し、初期タイトルとプロンプトへ戻せるようにしました。
- ライブラリのメイン画面では「すべてリセット」で既定値、削除済み項目、カスタム項目をまとめて復元できます。
- カスタムプリセットは初回保存時の内容を記録し、既存データは移行時の現在内容を安全な復元基準として使用します。
- ライブラリの説明を簡潔にし、最大化時の緑ボタン表示を「ウィンドウ表示」に変更しました。
- ライブプレビューの枠をカード内容の高さに合わせ、下部の大きな空白を解消しました。

## 検証

- npm run typecheck
- npm run core:test
- npm run build
- npm run desktop:build
