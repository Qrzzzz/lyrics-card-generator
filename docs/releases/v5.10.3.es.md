# Lyrics Card Generator v5.10.3

> Estado: publicado mediante GitHub Releases.

Esta versión de mantenimiento refuerza la accesibilidad, la cadena de suministro y las puertas de calidad multiplataforma. La interfaz y el diseño de exportación se mantienen, mientras que los límites críticos que antes dependían de revisión manual pasan a verificarse de forma reproducible.

## Novedades

- Corrige los puntos de referencia `main` duplicados o anidados en Web Lite y hace que la automatización de axe aplique las reglas de accesibilidad pertinentes.
- Actualiza las dependencias de producción y compilación, con excepciones justificadas y con fecha de vencimiento, un SBOM de la versión y una política bloqueante de CI/Release.
- Incluye el texto OFL completo de Source Han Sans y Serif en el repositorio, Web Lite, GitHub Pages, el servidor de escritorio, el instalador y la versión portable.
- Añade regresiones continuas de renderizado, un benchmark programado de composición de tarjetas largas, análisis estático y cobertura de límites de riesgo de Electron, y pruebas de humo en Firefox y WebKit.

## Validación

La versión superó las puertas de comprobación de tipos, lint, políticas de dependencias y licencias tipográficas, accesibilidad en Chromium, pruebas de humo en Firefox/WebKit, límites de renderizado de producción, regresión completa de Web Lite, cobertura de Electron, interacción de escritorio, artefactos Windows finales, SBOM, sumas de comprobación y attestations.
