# Lyrics Card Generator v4.5.0 發布說明

發布日期：2026-07-11

本版本改善純音樂卡片的資訊排版與桌面視窗控制樣式，並讓設定中的分頁切換、動效偏好和匯出預設值更加完整。新增設定都直接服務於目前的編輯流程，不會改變既有視窗按鈕動效。

## 主要更新

- 純音樂／無歌詞卡片重新調整歌曲標題、歌手和專輯資訊之間的間距，整體版面更加舒展；有專輯名稱時會比照有歌詞模式顯示專輯資訊，沒有專輯名稱時則不會額外佔位。
- 左上角紅黃綠視窗控制按鈕取消上一版本的 3D 風格，恢復平面樣式並縮小三個按鈕之間的間距，同時保留現有動效。
- 設定的不同分頁新增內容切換動效，讓分類之間的切換更連貫。
- 一般頁新增預設關閉的「減弱動效」開關。啟用後會減少介面位移、切換與慶祝動效；無論軟體開關狀態如何，系統的減少動態效果偏好仍會自動生效。
- 匯出頁在「匯出品質」前新增產生浮水印與分享者預設值。分享者預設關閉；啟用後可填寫預設分享者文字，開關與文字變更會即時連動目前卡片。

- 「一鍵清空」現在會讓舊預覽卡片向左滑出並淡出，同時讓新的空白卡片從右側滑入並漸顯；卡片已經空白時只顯示輕提示，不會重複執行清空。
- 輕提示重新設計了圖示、層次、陰影、底部計時線與進出場動效，連續觸發相同訊息時也能重新顯示。
- 匯出步驟移除了多餘的外圍大邊框與「只匯出歌詞卡片，不包含編輯器介面。」說明標籤，同時保留匯出品質選擇、匯出按鈕與進度回饋。
