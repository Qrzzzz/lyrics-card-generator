# Lyrics Card Generator v4.1.5 發佈說明

發佈日期：2026-07-02

v4.1.5 是一次 Stepper 版面穩定性修復，重點解決主頁左側頂部步驟指示器在不同語言、字體和視窗寬度下的高度與換行問題。本次更新不改變右側 Preview、匯出 DOM、歌詞卡渲染邏輯或設定狀態結構。

## 主要更新

- Stepper 步驟區改為基於真實容器寬度的均衡 Grid 版面。
- 6 個步驟只會在 `6`、`3 + 3`、`2 + 2 + 2` 三種結構中切換，避免出現 `5 + 1` 的不均衡排版。
- Stepper 外層玻璃面板改為根據標題區和步驟區真實高度計算動態 `min-height`。
- 一行步驟時面板會自動收緊高度，兩行和三行時仍保留穩定的視覺下限。
- 極窄視窗或長翻譯文字下，步驟標題使用單行截斷兜底，避免橫向溢出。
- 字體載入完成、視窗尺寸變化、語言切換和步驟標題變化後會重新測量版面。

## 範圍說明

- 不改變右側 Preview。
- 不改變匯出 DOM。
- 不改變歌詞卡渲染結果。
- 不改變設定狀態結構。

## 驗證

- npm run typecheck
- npm run core:test
- npm run desktop:build
