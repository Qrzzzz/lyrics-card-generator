# Notas de la versión de Lyrics Card Generator v4.3.4

Fecha de publicación: 2026-07-06

Esta versión convierte los ejemplos de letras: dejan de abrirse como un modal y pasan a ser una capa superior sobre el editor principal. Al abrirlos, el editor baja, la cabecera interna se acopla abajo como punto de regreso y las tarjetas de ejemplo se adaptan al ancho de la ventana principal.

## Cambios principales

- Se reemplazó el modal ExamplesDialog por una capa superior ExamplesFloor, sin máscara, modal ni Portal.
- Al pulsar el botón Ejemplo de la cabecera, la capa entra desde arriba, el editor se desplaza hacia abajo y la cabecera queda acoplada abajo.
- La cabecera inferior reutiliza la estructura normal y sustituye la posición original del botón Ejemplo por un botón X compacto para volver.
- Las tarjetas de ejemplo cambian automáticamente entre una, dos y tres columnas según el ancho de la ventana principal, evitando desplazamiento horizontal en ventanas pequeñas.
- La capa de ejemplos reserva espacio inferior para la cabecera acoplada, de modo que la última fila de tarjetas no queda tapada al desplazarse.
- Escape vuelve al editor, y cargar cualquier ejemplo también regresa automáticamente al editor.
- El movimiento usa ahora una curva spring más suave, y los desplazamientos grandes se desactivan cuando reduced motion está habilitado.

## Verificación

- npm run typecheck
- npm run core:test
- npm run build
- Comprobaciones en navegador a 1280px, 900px y 520px para columnas, regreso con X, regreso con Escape, regreso tras cargar un ejemplo y espacio inferior.
