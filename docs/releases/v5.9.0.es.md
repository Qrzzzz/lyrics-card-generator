# Notas de la versión 5.9.0 de Lyrics Card Generator

Fecha de publicación: 2026-07-31

La versión 5.9.0 añade un historial de importación y análisis a la aplicación de escritorio para Windows. Sirve para volver a importar canciones analizadas y portadas guardadas correctamente; no es un guardado automático de letras ni un historial de versiones del documento.

## Historial de importación y análisis en escritorio

- La acción Historial aparece ahora entre Ejemplos de letras y Borrar contenido. La vista de pantalla completa permite buscar, filtrar por origen, cargar por páginas, eliminar una entrada y borrar todo el historial.
- Solo se registra una entrada cuando se confirma correctamente el análisis de un enlace, un resultado de búsqueda seleccionado, un MP3／FLAC local o una portada local subida y guardada. No se registran errores, cancelaciones, ejemplos integrados, ediciones normales, borrados ni exportaciones.
- Las tarjetas muestran la canción, el origen, la fecha de importación y el nombre del archivo o dominio. La reimportación usa la confirmación de sustitución del documento existente; un error remoto o un archivo local ausente no modifica el documento actual.
- Los archivos locales movidos se pueden reubicar. Si cambió el tamaño o la fecha de modificación, la aplicación lo indica brevemente y analiza el archivo actual.

## Almacenamiento seguro y retención

- El proceso principal de Electron serializa escrituras atómicas en un JSON UTF-8 con versión de schema. Un archivo dañado se conserva como copia con marca de tiempo antes de crear un historial nuevo.
- Cada entrada guarda únicamente el origen mínimo necesario para repetir la operación y el texto de presentación. Nunca almacena binarios de imagen, Base64, URL blob, imágenes exportadas, paletas ni estilos; una portada remota se conserva solo como URL.
- Para repetir una entrada, el renderer envía únicamente su identificador. El proceso principal conserva, valida y lee las rutas locales, registradas de forma segura mediante `webUtils.getPathForFile` de Electron 42.
- La misma canción de una plataforma, enlace normalizado o ruta local actualiza la tarjeta existente y la mueve al principio. Ajustes → General permite conservar 5, 10 (valor predeterminado) o Sin límite; reducir el máximo exige confirmación antes de recortar los elementos menos recientes.

## Alcance y verificación

- Los nuevos textos de interfaz están disponibles en chino simplificado, chino tradicional, inglés, francés, japonés y español.
- Web Lite conserva su interfaz y comportamiento actuales, sin una alternativa de historial en el navegador.
- Las regresiones del store puro, IPC seguro, migración de ajustes, empaquetado e interacción real con Electron cubren persistencia, deduplicación, límites, repetición, archivos modificados／ausentes／reubicados y fallos de escritura.
