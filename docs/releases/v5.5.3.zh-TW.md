# Lyrics Card Generator v5.5.3 發佈說明

發佈日期：2026-07-14

v5.5.3 改進字型選擇、桌面標題列、第一步導覽與淺色壓克力可讀性，並在維持既有編輯與匯出行為的前提下補齊視覺與無障礙細節。

## 主要更新

- 第四步的思源黑體與思源宋體方案卡會以對應的本機 OTF 字型呈現整張卡片，方案名稱、字型名稱、說明和選取狀態都繼承實際字型。
- 48 像素桌面標題列改用 144 像素高、四層、向下漸隱的輕量模糊；著色漸層繼續適配深色、淺色與兩種壓克力主題。
- 第一步「手動調整」移至「下一步」左側，右側歌曲資訊欄不再重複顯示按鈕；展開狀態、受控區域與穩定 ID 已完整關聯。
- 淺色壓克力提高面板、輸入框、按鈕與浮層的白色遮罩，輔助文字改為不透明深灰，並修正淺色主題下的分段控制項表面。

## 可讀性與相容性

- 淺色壓克力針對暗灰、中灰與淺色 Windows 底層建立對比矩陣：小字至少 4.5:1，重要輸入框與按鈕邊界至少 3:1。
- 保留可辨識的透明、模糊與材質層次，沒有將淺色壓克力改成一般實色白主題。
- 深色壓克力的透明面板、亮色文字與視窗材質維持原有行為。

## 驗證

- `npm run typecheck` / `npm run lint` / `npm run core:test` / `npm run build`
- `npm run desktop:pack` / `npm run desktop:interaction-test`
- Windows 桌面淺色與深色壓克力真實視窗截圖檢查
