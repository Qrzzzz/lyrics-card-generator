# Lyrics Card Generator v3.6.1 Release Notes

Release date: 2026-06-29

v3.6.1 is a follow-up fix release for the v3.6.0 Acrylic desktop update. It focuses on custom titlebar window-state sync, visual blending, hover behavior, stacking, localization, and the current download entry points.

## Improved

- Added a soft downward fading glass blur layer so the titlebar blends more naturally with the Acrylic window material.
- Lowered the titlebar below settings, examples, first-launch language selection, and toast layers so it does not cover dialogs.
- Added localized `aria-label` and `title` text for titlebar window controls, including stateful maximize/restore labels.
- The maximize button now switches to a restore icon after the window is maximized.

## Fixed

- Fixed the renderer icon state not updating immediately after clicking maximize or restore.
- Fixed titlebar button state desynchronization after system Snap, titlebar double-clicks, or native window events.
- Fixed close-button hover not reliably turning red under the Light Acrylic theme.
- Fixed README download filenames and release-note links that could still point to an older version.
- Lyric card PNG export logic is unchanged; Acrylic and the titlebar do not enter exported images.

## Validation

- Verified that the custom titlebar does not render outside the desktop environment.
- Verified that titlebar button copy follows the current interface language.
- Verified that the `data-export-card="true"` card area does not contain the desktop titlebar.
- Ran `npm run typecheck`, `npm run core:test`, `npm run build`, and `npm run desktop:build`.
