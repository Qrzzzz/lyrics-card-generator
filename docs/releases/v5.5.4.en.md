# Lyrics Card Generator v5.5.4 Release Notes

Release date: 2026-07-15

v5.5.4 strengthens the local app’s mutation-request boundary, revises product copy in all six supported languages, and continues to use the shared release workflow. Existing editing, import, translation, export, and desktop interactions are unchanged.

## Request boundary

- Local app POST routes now share checks for same-origin requests, the app request marker, and the expected content type.
- AI requests that do not meet the boundary stop before a provider is contacted; valid same-origin JSON requests keep their existing behavior.
- Custom AI Base URLs still support `http://127.0.0.1`, `localhost`, and IPv6 loopback services. Model, API Key, streaming, cancellation, Reasoning, and error semantics are unchanged.

## Six-language copy

- Main UI, settings, AI, errors, import, and export copy was revised in Simplified Chinese, Traditional Chinese, English, French, Japanese, and Spanish.
- French, Japanese, and Spanish settings no longer inherit English text; high-value Traditional Chinese flows now use common Taiwan wording.
- Web Lite now supports all six languages through its existing selector, browser detection, and local preference path.
- Fixed watermarks, live AI status, the close action for instant-save settings, update messages, and API / desktop errors now use localized copy or stable error-code mappings.

## Release and verification

- CI and release automation continue to use the shared `.github/workflows/release.yml` instead of a version-specific copy.
- Verification covers Web Lite generation and drift checks, type and lint checks, stability and coverage, core regression, desktop build and interaction, final-artifact smoke, request-boundary tests, and six-language completeness tests.
