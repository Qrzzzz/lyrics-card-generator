# Lyrics Card Generator v4.6.2 发布说明

发布日期：2026-07-11

本版本修复 v4.6.0 的严重编辑问题，并补齐提示词资源库的可恢复机制与实时预览布局。

## 主要更新

- 修复桌面端主页面及 AI 设置中预设、严格格式规则文本框无法正常替换输入的问题。
- 每个提示词预设页新增“重置”按钮，可恢复到该预设最初的标题与提示词。
- 提示词资源库主界面新增“重置全部”，可同时恢复默认预设、严格格式规则、已删除预设和自定义预设的初始内容。
- 自定义预设首次保存时会记录初始内容；升级后的旧预设会以当前内容建立安全的重置基线。
- 提示词资源库说明改为“查看、编辑和整理翻译预设。”；窗口最大化时绿灯提示改为“窗口化”。
- 右侧实时预览边框改为随卡片内容自适应高度，不再在下方留下大块空白。

## 验证

- npm run typecheck
- npm run core:test
- npm run build
