# Lyrics Card Generator v6.1.3

> 狀態：已正式發布。

## 單視窗雙字體選擇

- Windows 原生 WinForms 方案視窗現在直接內建中日韓與西文字體下拉清單，不再為兩個角色分別彈出系統 `FontDialog`。
- 兩個清單都直接列舉系統已安裝字體，不使用字體名稱猜測語言覆蓋範圍，並排除直排別名。
- 目前選擇與兩組即時預覽始終可見；「取消」整體放棄草稿，「套用字體方案」仍以一次確認原子提交兩種字體。

## 高 DPI 清晰度與相容性

- 原生輔助處理程式在建立 WinForms 介面前啟用 Per-Monitor V2 DPI 感知，避免 Windows 以 96 DPI 位圖整體拉伸視窗。
- 視窗佈局以 96 DPI 為基準，依主視窗所在顯示器的實際 DPI 原生縮放，提升 125%、150%、175% 等縮放比下的文字與控制項清晰度。
- 原生橋接仍保留嚴格欄位驗證、主視窗控制代碼模態歸屬與受限結果剖析；非 Windows 桌面回退、瀏覽器選擇器與歌詞卡渲染規則保持不變。
