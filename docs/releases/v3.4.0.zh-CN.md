# Lyrics Card Generator v3.4.0 发布说明

发布日期：2026-06-28

v3.4.0 重构了“布局”步骤的内容类型逻辑，并把背景网格升级为可配置的视觉细节选项。

## 变更

- “布局”步骤现在先选择内容类型，再显示可用的布局、尺寸和文字排版选项。
- “纯音乐 / 无歌词”卡片现在锁定为竖向 1:1 输出，保证封面和歌曲信息稳定显示。
- 移除了“布局”步骤中无效的“纯音乐说明”输入框。
- 背景网格现在默认关闭，并在“视觉细节”中提供“稀疏 / 中等 / 密”三档密度。

## 修复

- 修复“纯音乐 / 无歌词”模式仍可选择横向卡片的问题。
- 修复“纯音乐 / 无歌词”模式仍可使用不兼容的非方形尺寸问题。
- 修复上一版本背景网格视觉过密的问题。

## 验证

- 验证“纯音乐 / 无歌词”会立即切换为竖向 1:1。
- 验证横向按钮在“纯音乐 / 无歌词”模式下置灰且不可点击。
- 验证背景网格默认关闭，开启后可切换三档密度。
- 执行 `npm run typecheck`、`npm run core:test`、`npm run build`。
