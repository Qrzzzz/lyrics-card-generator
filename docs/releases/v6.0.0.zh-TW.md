# Lyrics Card Generator v6.0.0

> 狀態：已透過 GitHub Releases 公開發布。

## 結構化歌詞文件核心

- 歌詞資料真源升級為 `LyricDocumentV2`。自然段對應 Block，原文與譯文組對應具穩定 ID 的 Unit，每次有效操作都會增加 document revision。
- 純文字貼上與編輯方式不變；確定性解析器負責分段、對齊與 ID 協調，並保留順序、空行及譯文。舊存檔會在載入時遷移。
- 匯入、編輯、復原／重做、手動存檔、預覽、自動版面與匯出使用同一份文件。舊 `lyrics` 與 `translationText` 僅為衍生相容投影。

## AI 翻譯與匯出一致性

- AI 翻譯依 Unit ID 請求及提交結構化 JSON，只接受完整、順序一致且 revision 仍相符的結果。
- 延遲回應、錯誤 ID、缺少 Unit 或額外欄位不會覆蓋目前文件；串流內容只在形成合法完整 JSON 後更新譯文。
- 匯出快照凍結歌詞文件、document revision、樣式與已求解版面，避免編輯期間的預覽／匯出差異。

## 相容性

- 桌面版與 Web Lite 保留現有歌詞編輯體驗及卡片視覺語言。
- v1 手動存檔仍可讀取；新的 v2 存檔會保存穩定 Block／Unit ID，並通過嚴格邊界驗證。
