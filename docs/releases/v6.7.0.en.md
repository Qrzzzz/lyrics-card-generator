# Lyrics Card Generator v6.7.0 Release Notes

Release date: 2026-10-07.

v6.7.0 adds layout seeds for flowing gradients so you can try, save and reproduce different arrangements with the same cover palette. It also improves solid color recommendations and transparent cover analysis.

## Flowing gradient layouts

- Enter a Layout seed in background settings or select Try another layout to move color fields and change their flow direction. Reset layout returns to seed 0.
- Layout changes preserve the cover palette and per-color energy weights. The same cover, seed and aspect ratio reproduce the composition; increasing export resolution at the same ratio does not rearrange it.
- The seed is saved and restored with desktop drafts and retained when switching between solid and gradient backgrounds.

## Cover palette improvements

- Fix solid recommendations favoring a large individual cluster over a larger combined group of similar colors. Rank colors by their merged effective coverage.
- Merge related colors before filtering small regions to retain representative cover candidates.
- Suppress almost invisible color residue. Hidden RGB in fully transparent pixels and original image resolution no longer change the default composition seed.
- Reuse recent analysis of the same cover and stop color clustering once it converges.

## Usage notes

- Moving fields changes overlap and local color mixtures. Variations may be subtle on single-color covers. Old drafts without a seed use the default layout.
- After the palette stability changes, default gradients in older drafts may be recomposed. Manually selected solid colors retain their saved values.
