# Notas de la versión 5.1.0 de Lyrics Card Generator

Fecha de lanzamiento: 13 de julio de 2026

La versión 5.1.0 se centra en estabilidad y seguridad. Conserva la dirección visual de los dos primeros pasos de v5 y refuerza las solicitudes de red, las carreras de importación y la coherencia de exportación.

## Principales novedades

- Incorpora una capa Safe Fetch unificada que resuelve y valida cada redirección antes de solicitarla, con límites para direcciones privadas o reservadas, tiempo, saltos, tipo de contenido y tamaño de respuesta.
- Las importaciones de canciones, letras y ejemplos usan revisiones de documento y last-intent-wins; borrar, cambiar de canción o iniciar una acción más reciente cancela e invalida resultados anteriores.
- El cambio de canción sustituye el documento completo en lugar de mezclar campos, evitando conservar portada, explicit, URL final, método de análisis o traducción de la canción anterior.
- La exportación de escritorio usa una instantánea inmutable y un mutex síncrono para que letras, estilo, dimensiones, nombre de archivo y PNG pertenezcan a la misma revisión.
- Web Lite usa un host de exportación independiente fuera de pantalla y comparte con escritorio las comprobaciones de 36 líneas, fuentes, medición, dimensiones estables y overflow.
- Las exportaciones ocupadas, bloqueadas o fallidas muestran mensajes localizados y recuperables.

## Verificación

- Se añadieron pruebas deterministas de acceso cero al objetivo SSRF, carreras de importación, reinicio entre canciones, instantáneas y concurrencia de exportación.
- Se añadieron pruebas Web Lite de 36/37 líneas, overflow fijo 1:1 y exportación con la vista previa plegada.
- Se completaron las regresiones del núcleo, Web Lite, compilación de escritorio e interacción de escritorio.
