# Lyrics Card Generator v5.0.2 發布說明

發布日期：2026-07-12

v5.0.2 是以 v5.0.0 為基礎的發布強化版本，不改變既有的編輯、預覽與匯出互動。

## 主要更新

- 統一應用程式、鎖定檔、六語 README 與發布說明中的 5.0.2 版本資訊。
- 在相容範圍內更新 Next.js、Undici 等相依套件，清除執行階段高風險相依套件警告。
- 重新驗證並建置 Web Lite、Windows 安裝版、可攜版與增量更新驗證檔。

## 驗證

- `npm run typecheck`
- `npm run core:test`
- `npm run build`
- `npm run web-lite:build` / `web-lite:check` / `web-lite:smoke`
- `npm run desktop:build` / `desktop:interaction-test`
