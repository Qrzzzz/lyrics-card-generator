# Lyrics Card Generator v4.3.2 リリースノート

リリース日：2026-07-06

このバージョンでは曲タイトル周辺の見た目を磨き込み、Explicit バッジの質感を改善し、縦向きカードのカバーと曲情報の視覚的な中心をより安定させました。

## 主な更新

- Explicit バッジを、フォントで描画した `E` に依存しない単一の SVG 図形として作り直しました。
- Explicit バッジは `currentColor` と外側の opacity を使い、SVG mask で幾何学的な E をくり抜くため、黒い実字の E が表示されません。
- バッジのサイズ、垂直位置、タイトルとの間隔を微調整し、タイトルの中心線とより自然に揃えました。
- 縦向きカードのアルバムカバーを大きくし、角丸も比率に合わせて調整しました。
- 縦向きカードの曲情報ブロックにカバーと同じ最小高さを持たせて中央揃えにし、タイトル、アーティスト、アルバムの 3 行がカバーの中心線に近づくようにしました。
- 既存のフォントサイズ、行高、header の間隔は維持し、レイアウトの回帰リスクを抑えています。

## 検証

- npm run typecheck
- npm run core:test
- npm run build
- ブラウザで `opposite` サンプルを読み込み PNG を書き出し、プレビューと書き出し結果で Explicit バッジと縦向き header の揃いが一致することを確認しました。
