# Lyrics Card Generator v3.3.0 リリースノート

リリース日：2026-06-25

v3.3.0 では Spotify の楽曲リンク解析を追加しました。Spotify の楽曲リンクを貼り付けると、曲名、アーティスト、カバー画像を自動入力し、既存の歌詞カード編集、カバーパレット、書き出しフローをそのまま利用できます。

## Spotify リンク解析

- Spotify の楽曲リンク解析。
- `open.spotify.com/track/...`、`open.spotify.com/intl-.../track/...`、`open.spotify.com/embed/track/...`、一般的な Spotify 短縮リンクに対応。
- 解析した Spotify 楽曲のプラットフォームロゴ表示。
- 自動歌詞取得は引き続き既存の実験的な歌詞検索を使用します。
- 起動直後に後続ステップが完了済みのチェック表示になる問題を修正しました。現在は通過済みのステップだけが完了状態として表示されます。

## 補足

- このバージョンは Spotify から歌詞を取得しません。
- Spotify アカウント、OAuth、API キーは不要です。
- 自動解析に失敗した場合でも、曲名、アーティスト、カバー、歌詞を手動入力できます。

検証：`npm run typecheck`、`npm run parse:test`、`npm run core:test`、`npm run build`、および Spotify 解析、歌詞エンドポイント schema、Spotify SVG アイコンアセットのローカル API 確認。
