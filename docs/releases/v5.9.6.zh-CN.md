# Lyrics Card Generator v5.9.6 发布说明

发布日期：2026-08-09

v5.9.6 是性能实现恢复版本。它在 v5.9.5 基线上重新引入 v5.9.4 最终版经过验收的性能架构，同时完整保留 v5.9.5 的三级轻提示、精简文案与桌面关闭生命周期修复。

## 性能实现恢复

- 恢复打包版本地服务启动编排、renderer 来源确认与静态资源缓存，减少重复探测和不必要的启动工作。
- 恢复空闲 ClickSpark、单宿主自动宽度测量、歌词输入与渲染边界优化，减少无效动画帧、布局读取和无关区域提交。
- 恢复导出就绪测量合并、按需加载的示例／历史／设置／AI／导出界面，以及分块失败隔离和真正可重试的加载路径。
- 恢复系统字体扫描的进程内缓存与并发去重；目录变化即时失效，仅注册表变化的最长陈旧时间仍限制为 5 分钟。

## 保留 v5.9.5 反馈体验

- 全局轻提示继续使用绿、黄、红三种固定语义底色，不恢复左侧圆形标识或倒计时进度条。
- 进入与退出继续采用互为反向的位移、缩放和透明度动画；减少动态效果模式仍只切换透明度。
- 六种语言的提示文案继续保持精简、无句末标点，并避免在通用界面暴露内部路径、备份文件名或异常详情。

## 兼容性

- 本版本不改变歌词文档、导入历史或手动存档的数据格式，不需要迁移用户数据。
- v5.9.5 的导入、解析、AI 翻译、设置、历史记录以及 PNG、WebP、JPG 导出行为继续保留。

## 发布状态

v5.9.6 已通过 GitHub Releases 公开发布。标签源码、安装版、便携版、SPDX SBOM 与 SHA256SUMS 均可从该发布页面获取。
