# Lyrics Card Generator v5.11.0

> 状态：已通过 GitHub Releases 公开发布。

## 横版卡片全面重写

- 横版改为自由比例双列布局，默认同时启用自动歌词区域宽度和自动高度，不再提供 16:9、21:9、3:2 预设。
- 自动宽度会完整测量真实 DOM 换行与自然高度，并强烈规避溢出、孤行和不合理的多重折行；得分接近时优先更紧凑的宽度。
- 左列统一承载完整比例封面、歌曲信息、平台标识、分享者和生成水印，并作为一个设计单元等比例缩放。
- 请求高度只作为最小值；内容需要更多空间时画布会继续延长，不会裁切或自动缩小歌词字号。

## 编辑与兼容

- 歌曲信息始终显示；横版封面始终显示，竖版仍可关闭封面。
- 横版最多支持 12 个非空逻辑行（原文加已启用译文）；第 13 行会保留内容并返回歌词编辑给出操作提示。
- 旧横版比例、尺寸快照以及隐藏歌曲信息／封面的状态会安全迁移到新模型。
- 桌面版与 Web Lite 的预览、离屏导出和不可变导出快照共用同一份测量计划。
