# Lyrics Card Generator v6.7.3 发布说明

发布日期：2026-10-14。

v6.7.3 区分同一句的自动折行与手动换行，改善长句和双语歌词的排版层次，并保留现有可变行高。

- 同一句因宽度不足而折行时，使用更紧凑的间距；用户输入的换行保持所选行高，使相邻歌词更容易辨认。
- 行高继续支持 1.5–2.1、步长 0.05、默认 1.8；原文和译文的折行间距随滑块同步调整，无需新增设置。
- 统一横版、竖版、预览、导出和自动尺寸测量；合并单元中的多行歌词也保留手动换行层次，空行、分隔线和双语对应关系继续保留。
