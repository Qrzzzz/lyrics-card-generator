這是一次以「瘦身」和「整理」為主的維護更新。

本版本清理了大量歷史遺留和未使用程式碼，拆分了原本過於臃腫的編輯器邏輯，並整理了 Windows 桌面版的建構與打包流程。對一般使用者來說，核心功能基本保持不變；對後續開發來說，專案結構更清楚，維護成本更低。

## 主要變化

* 清理未使用程式碼和冗餘邏輯，減少專案負擔。
* 重構編輯器結構，將部分介面和邏輯拆分為獨立元件。
* 保留原有卡片佈局演算法，避免清理程式碼影響歌詞卡片渲染效果。
* 修復桌面版匯出面板和 PNG 匯出控制項。
* 修復桌面版字型打包問題，確保內建字型能夠正常載入。
* 整理 Windows 桌面版建構流程。
* 更新版本號、下載檔案名稱和相關版本資訊至 `1.1.0`。

## 下載

* 安裝版：`Lyrics Card Generator Setup 1.1.0.exe`
* 可攜版：`Lyrics Card Generator-1.1.0-portable.exe`

## 注意

本版本仍未進行程式碼簽章。Windows 可能會顯示 SmartScreen 提示，這是個人未簽章應用程式的常見現象。
