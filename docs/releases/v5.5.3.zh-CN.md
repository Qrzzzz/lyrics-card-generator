# Lyrics Card Generator v5.5.3 发布说明

发布日期：2026-07-14

v5.5.3 改进字体选择、桌面标题栏、第一步导航和浅色亚克力可读性，在保持现有编辑与导出行为的同时补齐视觉和无障碍细节。

## 主要更新

- 第四步的思源黑体与思源宋体方案卡会用对应的本地 OTF 字体渲染整张卡片，方案名、字体名、说明和选中状态都继承实际字体。
- 48 像素桌面标题栏改用 144 像素高、四层、向下渐隐的轻量模糊；着色渐变继续适配深色、浅色和两种亚克力主题。
- 第一步“手动调整”移动到“下一步”左侧，右侧歌曲信息栏不再重复显示按钮；展开状态、受控区域与稳定 ID 已完整关联。
- 浅色亚克力提高面板、输入框、按钮和浮层的白色遮罩，辅助文字改为不透明深灰，并修正浅色主题下的分段控件表面。

## 可读性与兼容性

- 浅色亚克力针对暗灰、中灰和浅色 Windows 底层建立对比度矩阵：小字号文字至少 4.5:1，重要输入框和按钮边界至少 3:1。
- 保留可辨识的透明、模糊与材质层次，没有把浅色亚克力改成普通实色白主题。
- 深色亚克力的透明面板、亮色文字和窗口材质保持原有行为。

## 验证

- `npm run typecheck` / `npm run lint` / `npm run core:test` / `npm run build`
- `npm run desktop:pack` / `npm run desktop:interaction-test`
- Windows 桌面浅色与深色亚克力真实窗口截图检查
