# Lyrics Card Generator v5.12.0

> 状態：GitHub Releases で一般公開済みです。

## ローカル M4A 解析

- ローカル音声のアップロードで、MP3 と FLAC に加えて M4A に対応しました。利用可能な場合はタイトル、アーティスト、アルバム、アートワーク、埋め込み歌詞を読み取ります。埋め込み歌詞がない場合も、取得した曲情報は手動編集に利用できます。
- ブラウザーや Windows で一般的な `audio/mp4`、`audio/m4a`、`audio/x-m4a` を受け付け、既存の 100 MB 上限、制限付き multipart 読み取り、解析失敗時の保護を維持します。
- Windows デスクトップ版の読み込み履歴は、正常に確定した M4A ファイルを記録し、再読み込みや見つからないファイルの再指定に対応します。履歴に保存するのは必要なパスとメタデータだけで、音声データは保存しません。
