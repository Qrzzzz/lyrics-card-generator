# Lyrics Card Generator v3.2.1 发布说明

发布日期：2026-06-23

v3.2.1 继续作为 v3.2.0 的错误修复版本，不引入新的版本号升级。

## 稳定性修复

- 修复蓝白浅色主题及自定义背景下的文字和状态提示可读性。
- 放大 Header 应用图标，并恢复“一键清空”入口；清空歌曲内容时保留软件设置。
- 背景图片选择入口现在始终可见，选择后会自动切换到图片填充模式并立即预览。
- 修复背景设置保存、取消和重置的事务逻辑，避免取消操作误删原背景。
- 修复反复切换背景时的对象 URL 泄漏，并补齐自定义主题 token。
- 补齐六种语言的相关状态文案和发布说明。
- 修复桌面版重启后反复要求选择语言的问题；首次选择会持久保存，后续直接进入空白编辑器。
- Spark Cursor 开关改为横向填满设置卡片，与自动高度开关保持一致。
- 在“视觉细节”中新增默认开启的细网格背景开关，并同步控制预览和实际导出的 PNG。

验证：`npm run typecheck`、`npm run core:test`、`npm run build`、`npm run desktop:build`。
