# Lyrics Card Generator v6.1.0

> 狀態：已透過 GitHub Releases 正式發布。

## Electron 原生字體選擇視窗

- Windows 桌面版將自訂字體選擇器從應用程式內疊加層移至帶系統標題列的 Electron 原生子視窗。
- 字體搜尋、推薦字體、完整系統字體清單與逐項字樣預覽全部保留，並新增隨懸停或鍵盤焦點變化的放大預覽。
- 選擇字體後仍先更新自訂方案草稿與右側真實歌詞卡預覽，只有「儲存為目前方案」才會提交變更。

## 安全與相容性

- 字體視窗使用獨立且最小化的 IPC 身分，無法呼叫主視窗的檔案、歷史記錄或 AI 權限。
- Web Lite 與一般瀏覽器繼續使用相容的應用程式內回退介面。
