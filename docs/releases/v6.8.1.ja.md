# Lyrics Card Generator v6.8.1

**2026-10-22**

v6.8.1 は内容の保護、画像出力失敗からの再試行、ウィンドウとコンパクト表示、編集状態の明確化に重点を置きます。対象は #229、#230、#231、#232、#233、#235、#237、#238 と、6言語の設定文言整理 #240 です。

- インストゥルメンタル表示でも訳文を削除せず保持します。曲情報、ジャケット、原文と訳文の消去は確認が必要で、キャンセルでは内容を保持し、保存失敗時は消去を中止します。
- 書き出しとコピーの失敗を再試行ボタンとともに表示し続けます。再試行でもトランザクション保護を使い、文書を変更しません。
- ウィンドウの初期・最小・復元サイズをディスプレイの論理作業領域に合わせ、表示の変更にも追従します。強制カラーではウィンドウボタンに識別可能な図形と枠線を表示します。
- コンパクト表示では設定と操作をプレビューより先に配置します。ステップは現在位置と訪問済みを示し、未確認の完了を示しません。共有スクロール中も原文・訳文の見出しと操作対象を表示します。
- 設定文言を分かりやすくし、キーの保存説明を実行環境に合わせます。プライバシー、安全性と課金に関する説明は保持します。

Windows 実機の明暗ハイコントラスト、1366×768／125%、1920×1080／150%、分割表示、実行中の DPI 変更はローカルで検証済みです。#232 の画面間移動は実際の2画面環境での検証待ちであり、模擬や単体テストでは代替できません。[候補版の検証記録](../acceptance/v6.8.1.md)をご覧ください。#239 は次回以降に延期します。
