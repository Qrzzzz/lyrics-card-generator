# Lyrics Card Generator v5.7.3 發行說明

發行日期：2026-07-17

v5.7.3 重構第二步歌詞工作區，讓連續閱讀與編輯成為視覺主體，同時把歌詞工具集中到可調整、可收合的右側工具區。頂部 Stepper、後續設定步驟與既有匯出邊界維持不變。

## 以編輯為主的雙欄工作區

- 第二步內部改為左側編輯區與右側工具區；編輯區預設占可用寬度的 3/4，工具區可擴展到 1/3，編輯區始終不少於 2/3。
- 分隔線沿用第 3–5 步的 20 px 命中區、整高 1 px 直線、主題色狀態回饋，以及滑鼠、方向鍵、Shift 加速、Home/End 與雙擊還原操作。
- 工具區可收合為約 64 px，切換步驟後仍會保留收合狀態與上次展開寬度。

## 更連續的歌詞編輯

- 單語編輯使用完整左側區域，並把稿紙維持在舒適的置中寬度；雙語編輯平均使用全部編輯空間，兩欄等高且共用唯一主捲動。
- 原有的文件標題、共用捲動提示、語言標題與行數合併為一條緊湊的黏性狀態列，減少重複層級並釋放垂直空間。
- 視窗縮放、翻譯開關與分欄變化仍會保留游標、選取範圍、邏輯行錨點與捲動位置；長行會在編輯區內換行，不產生水平溢位。

## 集中的工具與安全邊界

- 收合狀態保留展開入口、AI 翻譯、翻譯開關、拆分雙語歌詞與目前行數/36 狀態。
- 展開狀態依序提供快速工具、翻譯控制，以及歌詞取得或 AI 面板；沒有動態面板時會顯示歌曲摘要、原文/譯文統計與段落數。
- 36 個非空行的匯出限制、第二步不顯示預覽、離屏匯出宿主、第 3–5 步既有比例，以及 Web Lite 功能邊界均維持不變。
