# Notes de version de Lyrics Card Generator v3.6.1

Date de publication : 2026-06-29

v3.6.1 est une version corrective après la mise à jour Acrylic de v3.6.0. Elle cible la synchronisation d'état de la barre de titre personnalisée, son intégration visuelle, le hover, les couches, la localisation et les entrées de téléchargement actuelles.

## Améliorations

- Ajout d'un flou de verre dégradé vers le bas pour mieux fusionner la barre de titre avec le matériau Acrylic.
- La barre de titre passe sous les réglages, exemples, choix initial de langue et toast afin de ne pas couvrir les fenêtres modales.
- Ajout de textes `aria-label` et `title` localisés pour les contrôles de fenêtre, avec libellés maximiser/restaurer selon l'état.
- Le bouton maximiser affiche désormais une icône de restauration lorsque la fenêtre est maximisée.

## Corrections

- Correction de l'état d'icône qui ne se mettait pas à jour immédiatement après maximiser ou restaurer.
- Correction de la désynchronisation après Snap système, double-clic sur la barre de titre ou événements natifs de fenêtre.
- Correction du hover du bouton fermer qui ne devenait pas toujours rouge avec le thème Acrylic clair.
- Correction des noms de fichiers de téléchargement et liens de notes de version du README qui pouvaient encore pointer vers une ancienne version.
- La logique d'export PNG des cartes de paroles ne change pas ; Acrylic et la barre de titre n'entrent pas dans les images exportées.

## Validation

- Vérifié que la barre de titre personnalisée ne s'affiche pas hors de l'environnement bureau.
- Vérifié que les libellés des boutons suivent la langue actuelle de l'interface.
- Vérifié que la zone `data-export-card="true"` ne contient pas la barre de titre de bureau.
- Exécuté `npm run typecheck`, `npm run core:test`, `npm run build` et `npm run desktop:build`.
