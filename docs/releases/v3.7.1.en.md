# Lyrics Card Generator v3.7.1 Release Notes

Release date: 2026-06-30

v3.7.1 is a UI control standardization release. It does not ship the planned v3.8.0 animation upgrade. This update focuses on unifying toggles, option cards, segmented controls, and settings-panel input primitives while improving accessibility and keyboard/focus behavior so the UI control layer is ready for the later v3.8.0 animation work.

## Improvements

- Standardized toggle controls across the style panel, lyric input, song info, and settings so on/off states, disabled states, and visual feedback behave more consistently.
- Consolidated single-choice patterns such as language selection into shared option cards, and aligned compact choices such as layout mode, grid density, and frame/full-bleed into a consistent segmented-control pattern.
- Standardized the look and interaction feedback of common settings-panel inputs, textareas, selects, and action buttons so related controls feel more coherent across sections.

## Accessibility and Consistency

- Improved keyboard usability, focus visibility, label presentation, and disabled-state feedback for common controls to reduce interaction differences between panels.
- Reduced special-case switch colors and theme-specific control styling in favor of the existing theme tokens so dark, light, acrylic, and custom themes stay more consistent.
- This release prepares the UI control layer for the upcoming v3.8.0 animation upgrade without adding that animation system, and without changing export output, settings schema, or existing user flows.
